# AI Engineering from Scratch — Türkçe

Bu depo, [AI Engineering from Scratch](https://github.com/rohitg00/ai-engineering-from-scratch)
eğitim programının Türkçe topluluk çevirisini içerir. İngilizce kaynak metinler,
çalıştırılabilir örnekler ve testler korunmuş; Türkçe ders anlatımları kaynak metinlerin
yanına eklenmiştir.

> Bu çalışma özgün projenin resmî Türkçe sürümü değildir. Türkçe yerelleştirme
> `ademiru` tarafından hazırlanmış ve yayımlanmıştır.

[English README](README.md) · [Türkçe çeviri rehberi](docs/translation-guide-tr.md) ·
[Lisans](LICENSE)

## Okumaya başla

Her aşamanın Türkçe içindekiler sayfası `README.tr.md`, her çevrilmiş dersin anlatımı
ise ders dizinindeki `docs/tr.md` dosyasıdır.

- [Aşama 00 — Kurulum ve Araçlar](phases/00-setup-and-tooling/README.tr.md)
- [Aşama 05 — NLP Temellerinden İleri Düzeye](phases/05-nlp-foundations-to-advanced/README.tr.md)
- [Aşama 09 — Pekiştirmeli Öğrenme](phases/09-reinforcement-learning/README.tr.md)
- [Tüm aşamalar](README.md#contents)

Depoyu yerel olarak kullanmak için:

```bash
git clone https://github.com/ademiru/ai-engineering-from-scratch.git
cd ai-engineering-from-scratch
```

Kod örnekleri dil bağımsızdır; derslerin kendi `code/` dizinlerinde bulunan komutlarla
çalıştırılabilir.

## Çeviri yaklaşımı

Türkçe metinler kelime kelime aktarım yerine teknik doğruluk, doğal anlatım ve tutarlı
terim kullanımı hedeflenerek hazırlanmıştır. Kod, komutlar, dosya yolları, API adları,
matematiksel gösterimler ve diğer teknik sabitler çevrilmeden korunur.

Bir çeviri hatası bulursanız
[ademiru deposunda issue açabilir](https://github.com/ademiru/ai-engineering-from-scratch/issues)
veya düzeltme içeren bir pull request gönderebilirsiniz.
