kagent is a CLI for kagent

Usage:
  kagent [flags]
  kagent [command]

Available Commands:
  agent       Discover agents and work with their conversations
  apply       Create or update an Agent or AgentTemplate
  bug-report  Generate a bug report
  completion  Generate the autocompletion script for the specified shell
  config      Inspect and validate configuration
  dashboard   Open the kagent dashboard
  db          Database operations (migrations, inspection)
  help        Help about any command
  install     Install kagent
  sandbox     Run commands and transfer files in standalone sandboxes
  uninstall   Uninstall kagent
  version     Print the kagent version

Flags:
      --api-url string         KAgent control-plane API URL (default "http://localhost:8083")
      --ca-file string         CA certificate file for KAgent endpoints
      --config string          Configuration file (default: user config directory/kagent/config.yaml)
      --gateway-url string     KAgent A2A and MCP gateway URL (default "http://localhost:8083")
  -h, --help                   help for kagent
      --log-level string       Log level: debug, info, warn, error (default "info")
  -n, --namespace string       Namespace (default "kagent")
  -o, --output-format string   Output format (default "table")
      --server-name string     TLS server name for KAgent endpoints
      --timeout duration       Timeout (default 5m0s)
      --user-id string         Caller identity used to select the server-side data partition (default "admin@kagent.dev")
  -v, --verbose                Verbose output

Use "kagent [command] --help" for more information about a command.

Run commands and transfer files in standalone sandboxes

Usage:
  kagent sandbox [command]

Available Commands:
  create      Create a sandbox from a prepared template
  delete      delete a sandbox
  download    Download a file, replacing the local destination only after success
  exec        Start a command once and wait for its result
  get         get a sandbox
  kill        Terminate a process and its children
  list        List your sandboxes
  process     Inspect process status without waiting
  resume      resume a sandbox
  suspend     suspend a sandbox
  templates   List SandboxTemplates in the selected namespace
  upload      Stream a local file into a sandbox (replaces the remote file)
  wait        Collect output and wait for an existing process without restarting it

Flags:
  -h, --help   help for sandbox
