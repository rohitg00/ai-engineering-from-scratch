# 不平衡数据策略

处理不平衡分类的决策清单。按此顺序为你的问题选择正确的方法。

## 第一步：衡量不平衡程度

- 统计每个类别的样本数
- 计算不平衡比率（多数类 / 少数类）
- 轻度：比率 < 3:1（例如70/30）
- 中度：比率3:1到20:1（例如95/5）
- 严重：比率 > 20:1（例如99/1）

## 第二步：选择正确的指标

对不平衡数据集，优先使用精确率/召回率/F1而非准确率。根据你的问题选择：

| 情况 | 主要指标 | 次要指标 |
|-----------|---------------|-----------------|
| 漏检阳性代价极高（欺诈、疾病） | 召回率 | F2分数 |
| 误报代价高（垃圾邮件过滤、推荐） | 精确率 | F0.5分数 |
| 两者大致同等重要 | F1分数 | MCC |
| 需要单个排序指标 | AUPRC | AUC-ROC |
| 需要跨数据集比较 | MCC | AUPRC |

## 第三步：选择重平衡策略

### 按不平衡严重程度

| 不平衡程度 | 首选 | 次选 | 避免 |
|-----------|-----------|------------|-------|
| 轻度（< 3:1） | 类别权重 | 阈值调优 | 过采样（不必要） |
| 中度（3:1到20:1） | SMOTE + 类别权重 | 在此基础上进行阈值调优 | 欠采样（数据损失太大） |
| 严重（> 20:1） | SMOTE + 类别权重 + 阈值 | 带平衡装袋的集成 | 仅欠采样 |

### 按数据集大小

| 数据集大小 | 首选策略 | 原因 |
|-------------|-------------------|--------|
| < 1,000个样本 | 过采样或SMOTE | 无法承受丢失多数类数据 |
| 1,000 - 10,000 | SMOTE + 阈值调优 | 少数类有足够样本用于k-NN |
| > 10,000 | 类别权重或欠采样 | 快速，有足够的少数类数据 |

## 第四步：应用技术

### 类别权重（总是先尝试）
- 在sklearn中：`class_weight='balanced'`
- 无需修改数据
- 适用于任何基于损失的模型
- 期望上等价于过采样

### SMOTE
- 仅应用于训练数据（从不用于测试/验证）
- 使用k=5个邻居（默认）
- 与类别权重结合使用以获得最佳效果
- 注意边界附近的噪声合成点

### 阈值调优
- 训练模型，在验证集上获取预测概率
- 从0.05到0.95扫描阈值
- 选择最大化所选指标的阈值
- 始终在验证数据上调优，从不使用测试数据

## 第五步：正确验证

- 使用分层交叉验证（每折保留类别比例）
- 在原始（未重采样）测试集上报告指标
- 绝不在划分前应用SMOTE——仅在训练折上使用
- 与"总是预测多数类"的基线比较

## 第六步：避免的常见错误

- 在训练/测试划分前对整个数据集应用SMOTE（数据泄漏）
- 使用准确率作为评估指标
- 没有先尝试类别权重（最简单的方法，通常就足够了）
- 过采样后进行交叉验证（合成点跨折泄漏）
- 忽略阈值调优（免费的性能提升，无需重新训练）
- 在小数据集上使用随机欠采样（丢弃了太多数据）

## 快速决策树

1. 不平衡比率 < 3:1？-> 仅尝试类别权重
2. 数据集 > 10,000个样本？-> 类别权重 + 阈值调优
3. 数据集 < 1,000个样本？-> SMOTE + 类别权重
4. 否则 -> SMOTE + 类别权重 + 阈值调优
5. 仍然不够好？-> 平衡装袋集成
