# 模型评估策略

正确评估任何ML模型的清单。按此顺序操作以避免最常见的评估错误。

## 第一步：正确划分数据

- 在任何预处理（缩放、插补、编码）之前进行划分
- 对分类任务使用分层划分
- 保留一个测试集，仅在最后使用一次
- 对于小数据集，使用5折或10折交叉验证代替单次划分
- 对于时间序列，使用基于时间的划分（绝不打乱）

## 第二步：选择正确的指标

### 分类

| 情况 | 使用此指标 | 原因 |
|-----------|----------------|-----|
| 类别平衡，简单比较 | 准确率 | 易于解释，当类别均衡时有意义 |
| 假阳性代价高（垃圾邮件过滤、欺诈警报） | 精确率 | 衡量被标记项中实际为正的比例 |
| 假阴性代价高（癌症筛查、安全） | 召回率 | 衡量实际阳性中你捕捉到的比例 |
| 需要平衡精确率和召回率 | F1分数 | 调和平均数，惩罚极端不平衡 |
| 跨阈值比较模型 | AUC-ROC | 与阈值无关的排序质量 |
| 不平衡数据 | F1、AUC-ROC或PR-AUC | 准确率在不平衡类别下具有误导性 |

### 回归

| 情况 | 使用此指标 | 原因 |
|-----------|----------------|-----|
| 标准回归，异常值可接受 | RMSE | 与目标相同单位，惩罚大误差 |
| 对异常值鲁棒的评估 | MAE | 平等对待所有误差，不被异常值主导 |
| 在不同尺度上比较模型 | R-squared | 归一化的0-1尺度（解释的方差比例） |
| 业务需要金额度量 | MAE或RMSE | 可直接解释为误差大小 |

## 第三步：建立基线

在评估模型之前，计算基线性能：
- 分类：多数类预测器（始终预测最常见的类别）
- 回归：始终预测训练目标的均值
- 任何无法击败这些基线的模型都没有在学习

## 第四步：交叉验证

- 使用K折（K=5或K=10）以获得稳定估计
- 对分类使用分层K折
- 报告各折的均值和标准差
- 均值为0.85且标准差为0.02的模型比均值为0.87且标准差为0.10的模型更可信

## 第五步：统计比较模型

- 不要仅凭最高平均分数就选择模型而不检查显著性
- 使用跨交叉验证折的配对t检验
- 如果|t| < 2.78（对于K=5，df=4，p<0.05），差异可能来自随机性
- 当性能差异不显著时，考虑更简单的模型

## 第六步：检查常见错误

- 数据泄漏：是否有任何测试数据信息流入训练？（划分前缩放、基于目标的特征）
- 类别不平衡：准确率是否掩盖了较差的少数类性能？
- 过拟合：训练和验证性能之间的差距大吗？
- 评估过多：你是否不止一次查看了测试集？

## 第七步：报告最终性能

- 在训练集+验证集合并后的数据上训练
- 在保留的测试集上仅评估一次
- 报告所选指标，如有可能附带置信区间
- 说明基线比较（比随机/均值好多少）
