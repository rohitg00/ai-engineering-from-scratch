# 分类基线指南

在尝试复杂模型之前，先用逻辑回归建立基线。它只需几秒即可训练，能输出概率，且完全可解释。令人惊讶的是，许多现实世界的问题根本不需要更复杂的模型。

## 决策清单

1. 决策边界可能是线性的吗？
   - 是：逻辑回归可能就足够了
   - 否：你仍然需要它作为基线来衡量改进程度

2. 你有多少特征？
   - 少于50个：标准逻辑回归就很好
   - 50到10,000个：添加L2正则化（岭回归）
   - 超过10,000个（例如TF-IDF文本特征）：使用L1正则化（Lasso）或LinearSVC

3. 数据集不平衡吗？
   - 比例低于5:1：不调整可能也没问题
   - 5:1到50:1：在sklearn中使用`class_weight="balanced"`
   - 超过50:1：将类别权重与适当的指标（精确率、召回率或F1）结合使用

4. 特征处于不同量级吗？
   - 在逻辑回归之前始终进行标准化。它使用基于梯度的优化，未缩放的特征会减慢收敛速度或扭曲决策边界。

5. 有缺失值吗？
   - 在拟合之前进行插补。逻辑回归无法处理NaN。
   - 数值列使用中位数插补，类别列使用众数。

## 何时逻辑回归已足够

- 主要具有线性特征关系的二分类
- 你需要概率输出（不仅仅是类别标签）
- 需要可解释性（标准化后的系数指示特征重要性的方向和相对大小）
- 训练数据小（几百到几千个样本）
- 你需要一个快速的实时服务模型（推理时只需一次点积）
- 监管或合规要求需要可解释性

## 何时需要升级

- 准确率远低于目标且已尝试过特征工程
- 特征与目标之间的关系明显是非线性的（检查残差图）
- 你有大型表格数据（10k+行）：尝试梯度提升（XGBoost或LightGBM）
- 特征有复杂交互，多项式特征无法捕捉
- 你有图像、文本或序列数据：对原始输入使用逻辑回归行不通

## 分类基线的预处理步骤

1. **先进行训练/测试集划分**，在任何预处理之前。这防止数据泄露。
2. **处理缺失值**：数值列用中位数插补，类别列用众数。
3. **编码类别特征**：低基数（少于10个值）用独热编码，更高的用目标编码。仅在训练折上拟合目标编码（使用折外编码防止数据泄露）。
4. **缩放数值特征**：StandardScaler（零均值，单位方差）。在训练集上拟合，转换两者。
5. **拟合逻辑回归**，使用`C=1.0`（默认正则化）。
6. **评估**：混淆矩阵、精确率、召回率、F1。不仅仅是准确率。
7. **调优阈值**：默认0.5很少是最优的。在0.1到0.9之间扫描，选择匹配你精确率/召回率优先级的阈值。

## 常见错误

- 仅在不平衡数据上评估准确率（预测多数类的模型得分高但无用）
- 忘记缩放特征（未缩放的逻辑回归训练缓慢，收敛到更差的解）
- 使用测试集来调优决策阈值（应使用验证集或交叉验证）
- 跳过基线直接跳到XGBoost（你失去了可解释性且没有参考点）
- 不检查多重共线性（高度相关特征会膨胀系数方差）

## 快速参考

| 场景 | 模型 | 正则化 | 关键设置 |
|----------|-------|---------------|-------------|
| 特征少，需可解释 | LogisticRegression | L2（默认） | C=1.0 |
| 特征多，部分无关 | LogisticRegression | L1 | penalty="l1", solver="saga" |
| 高维稀疏（文本） | SGDClassifier | L1或弹性网络 | loss="log_loss" |
| 不平衡类别 | LogisticRegression | L2 | class_weight="balanced" |
| 需要概率 | LogisticRegression | L2 | predict_proba() |
| 只需要类别标签 | LinearSVC | L2 | 对大数据比LR更快 |
