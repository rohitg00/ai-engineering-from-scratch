# 集成方法选择指南

集成方法将多个模型组合，以产生比任何单个模型更好的预测。问题总是：哪种集成，以及何时使用？

## 决策清单

1. 你当前模型的主要问题是什么？
   - 高方差（过拟合）：使用装袋（随机森林）
   - 高偏差（欠拟合）：使用提升（梯度提升、XGBoost）
   - 两者都有，或想要最大准确率：使用堆叠

2. 你有多少数据？
   - 少于1,000行：随机森林（鲁棒，难以配置错误）
   - 1,000到100,000：XGBoost或LightGBM（表格数据整体最佳）
   - 超过100,000：LightGBM（最快的梯度提升，良好处理大数据）

3. 你能投入多少调优时间？
   - 最少：使用默认参数的随机森林（几乎总是有效）
   - 中等：使用learning_rate=0.1的XGBoost，用早停调优n_estimators
   - 最多：使用贝叶斯超参数搜索的LightGBM或XGBoost

4. 你需要可解释性吗？
   - 是：单棵决策树或带特征重要性的小型随机森林
   - 部分：带SHAP值的梯度提升
   - 否：堆叠或深度集成

5. 数据有噪声且含很多异常值吗？
   - 是：随机森林（装袋对噪声具有鲁棒性）
   - 否：梯度提升（可在干净数据上进一步推进准确率）

## 何时使用每种方法

**随机森林（装袋）**：你安全的首选。在自助采样上训练多棵树并取平均。减少方差而不增加偏差。在中等数据上几乎不可能过拟合。最少的调优：设置n_estimators=100-500，保留其他默认值。

**AdaBoost**：带样本重加权的顺序提升。与简单的基学习器（决策树桩）配合良好。对异常值和噪声标签敏感，因为它会提高误分类点的权重。实践中已被梯度提升大幅取代。

**梯度提升**：每棵新树拟合到当前集成整体的残差上。减少偏差。表格数据最强大的方法。需要调优：learning_rate、n_estimators、max_depth、min_child_weight、subsample。

**XGBoost**：带正则化、二阶优化和系统级加速的梯度提升。原生处理缺失值。Kaggle竞赛和生产级表格数据ML的默认选择。

**LightGBM**：按叶生长（而非按层生长）的梯度提升。在大数据集上比XGBoost更快。使用基于直方图的分裂。最适合超过5万行的数据集。

**CatBoost**：原生处理类别特征的梯度提升。无需独热编码。当你有很多类别特征时效果很好。

**堆叠**：在多个不同基模型的预测上训练元学习器。当你需要绝对的最佳准确率且有计算资源时使用。始终通过交叉验证生成基模型预测以避免泄漏。

**投票**：最简单的集成。硬投票（多数类）或软投票（平均概率）。无需元学习器即可快速组合2-3个不同模型。

## 常见错误

- 使用没有早停的梯度提升（如果运行太多轮次会过拟合）
- 将learning_rate设置得太高（超过0.3通常会导致不稳定）
- 不为梯度提升调优max_depth（无限或非常深的树默认会过拟合）
- 堆叠中所有模型都是同一类型（多样性是堆叠的核心）
- 在噪声数据上使用AdaBoost（异常值每轮获得越来越高的权重）
- 期望随机森林修复欠拟合（它减少方差，而非偏差）

## 按方法划分的调优优先级

**随机森林：**
1. n_estimators: 100-500（更多几乎总是更好，只是更慢）
2. max_depth: None（让树完全生长）或为了速度限制在10-20
3. max_features: 分类用"sqrt"，回归用"log2"或n/3

**XGBoost / LightGBM：**
1. learning_rate: 0.01-0.3（如果你有计算资源做更多树，则越低越好）
2. n_estimators: 使用验证集上的早停代替猜测
3. max_depth: 3-8（从6开始）
4. min_child_weight / min_data_in_leaf: 1-20（越高越防止过拟合）
5. subsample: 0.7-1.0
6. colsample_bytree: 0.7-1.0
7. reg_alpha（L1）和reg_lambda（L2）: 0-10

## 快速参考

| 方法 | 减少 | 速度 | 调优工作量 | 最适合 |
|--------|---------|-------|--------------|----------|
| 随机森林 | 方差 | 快 | 低 | 噪声数据，快速基线 |
| AdaBoost | 偏差 | 快 | 低 | 简单基学习器，干净数据 |
| 梯度提升 | 偏差 | 中 | 高 | 表格数据，竞赛 |
| XGBoost | 两者 | 快 | 高 | 生产级表格ML |
| LightGBM | 两者 | 最快 | 高 | 大数据集（5万+行） |
| CatBoost | 两者 | 中 | 中 | 许多类别特征 |
| 堆叠 | 两者 | 慢 | 高 | 最大准确率，多样模型 |
| 投票 | 方差 | 快 | 无 | 快速组合2-3个模型 |
