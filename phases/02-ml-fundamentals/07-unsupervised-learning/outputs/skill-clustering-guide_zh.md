# 聚类算法选择指南

聚类没有单一的最佳算法。正确的选择取决于簇的形状、你是否知道簇的数量、数据中的噪声量以及数据集的大小。

## 决策清单

1. 你知道簇的数量吗？
   - 是：K-Means或GMM
   - 否：DBSCAN（自动发现簇）或层次聚类（在不同级别切割树状图）

2. 簇是什么形状？
   - 大致球形（类似团块）：K-Means
   - 不同大小的椭圆形：GMM
   - 任意形状（月牙形、环形、链形）：DBSCAN
   - 嵌套或层次结构：层次聚类

3. 数据包含噪声或异常值吗？
   - 是：DBSCAN（明确标注噪声点）或GMM（低概率点视为异常值）
   - 否：K-Means就可以

4. 你需要软分配（概率）吗？
   - 是：GMM给出每个簇的P(簇 | 数据点)
   - 否：K-Means或DBSCAN给出硬分配

5. 数据集有多大？
   - 少于10,000：任何算法都可以
   - 10,000到1,000,000：K-Means（快），Mini-Batch K-Means（更快）
   - 超过1,000,000：Mini-Batch K-Means或BIRCH。层次聚类太慢。

## 何时使用每种方法

**K-Means**：默认的起点。快速（O(n * k * 迭代)），简单，对许多问题来说已足够。使用肘部法或轮廓分数选择K。局限性：假设簇为球形，对初始化敏感（使用K-Means++或多次运行），不能很好地处理不同大小的簇。

**DBSCAN**：最适合发现任意形状的簇并自动检测异常值。两个参数：eps（邻域半径）和min_samples（最小密度）。不需要指定K。局限性：当簇的密度差异很大时效果不佳，调优eps可能很棘手。使用k-距离图估算eps：计算每个点到其第k个最近邻的距离，排序，寻找肘部。

**层次聚类（凝聚式）**：构建一个合并树。当你想要在多个粒度上探索簇结构时很有用（在不同高度切割树状图）。Ward连接对紧凑簇效果最好。单连接能发现细长簇但对噪声敏感。局限性：O(n^2)内存和O(n^3)时间，因此对大数据集不实用。

**GMM（高斯混合模型）**：使用概率分配进行软聚类。将每个簇建模为具有自身均值和协方差的高斯分布。当簇为椭圆形或重叠时优于K-Means。使用BIC（贝叶斯信息准则）选择组件数量。局限性：假设高斯分布，在非凸形状上可能失败，对初始化敏感。

## 评估聚类质量（无标签）

| 指标 | 衡量内容 | 范围 | 使用场景 |
|--------|-----------------|-------|----------|
| 轮廓分数 | 内聚性与分离性 | -1到1（越高越好） | 比较K值或算法 |
| 惯量（簇内平方和） | 簇的紧密程度 | 0到无穷（越低越好） | K-Means的肘部法 |
| BIC / AIC | 带复杂度惩罚的模型拟合 | 越低越好 | 选择GMM组件数量 |
| Calinski-Harabasz指数 | 组间方差与组内方差之比 | 越高越好 | 快速比较 |
| Davies-Bouldin指数 | 簇之间的平均相似度 | 越低越好 | 惩罚重叠的簇 |

## 常见错误

- 不缩放特征就运行K-Means（尺度较大的特征主导距离计算）
- 当实际数据为高维时，通过2D图形目测选择K（应使用轮廓分数）
- 在非球形簇上使用K-Means（月牙形或环形数据需要DBSCAN）
- 将DBSCAN eps设置得太大（所有点在一个簇中）或太小（所有点都是噪声）
- 将聚类标签视为真实标注（聚类是探索性的；用领域知识验证）
- 在超过20,000个点的数据集上运行层次聚类（内存和时间爆炸）
