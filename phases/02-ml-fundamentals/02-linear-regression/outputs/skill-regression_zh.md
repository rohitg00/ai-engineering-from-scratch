# 回归策略指南

回归预测连续值。正确的方法取决于特征与目标之间的关系、特征数量以及过拟合风险。

## 决策清单

1. 特征与目标之间的关系近似线性吗？
   - 是：从普通线性回归开始
   - 否：尝试多项式特征或非线性模型

2. 相对于样本量，你有多少特征？
   - 特征少，样本多：普通线性回归就够了
   - 特征多，样本少：使用正则化（岭回归或Lasso）
   - 特征比样本还多：Lasso（L1）用于特征选择，或岭回归（L2）用于收缩所有权重

3. 你需要可解释性吗？
   - 是：使用少量特征的线性回归，或使用Lasso进行自动特征选择
   - 否：使用多项式特征，或转向基于树的模型或神经网络

4. 数据集小（少于10,000行）吗？
   - 使用正规方程（闭式解）以获得速度
   - 交叉验证对于可靠评估至关重要

5. 数据集大（数百万行）吗？
   - 使用随机梯度下降（SGD）或小批量梯度下降
   - 正规方程因O(n^3)矩阵求逆而太慢

## 何时使用每种方法

**普通线性回归**：任何回归任务的基线。从这里开始。如果R-squared可接受且模型简单，就此打住。

**多项式回归**：散点图显示曲线而非直线。从2次开始。只有在验证性能证明合理时才增加次数。次数>5几乎总是过拟合。

**岭回归（L2）**：许多相关特征。所有权重向零收缩但没有一个精确归零。当你相信所有特征都有贡献时适用。

**Lasso回归（L1）**：特征很多且你怀疑只有少数重要。Lasso将不相关特征的权重精确归零，执行自动特征选择。

**弹性网络**：结合L1和L2惩罚。当你有许多相关特征且希望进行一些特征选择时使用。

## 常见错误

- 在梯度下降前跳过特征缩放（收敛变得极其缓慢）
- 使用测试集性能来调优超参数（应使用验证集或交叉验证）
- 拟合高次多项式而不检查验证误差（训练R^2总是随次数增加）
- 忽略残差图（如果残差显示模式，R^2可能具有误导性）
- 将R^2视为唯一指标（检查残差分布、MAE和领域特定阈值）

## 快速参考

| 方法 | 何时使用 | 正则化 | 特征选择 |
|--------|------------|---------------|-------------------|
| OLS | 基线，特征少 | 无 | 手动 |
| 岭回归 | 特征多，全部相关 | L2（收缩） | 否 |
| Lasso | 特征多，少数相关 | L1（归零） | 自动 |
| 弹性网络 | 许多相关特征 | L1 + L2 | 部分 |
| 多项式 | 非线性关系 | 在上面添加岭回归/Lasso | 手动选择次数 |
