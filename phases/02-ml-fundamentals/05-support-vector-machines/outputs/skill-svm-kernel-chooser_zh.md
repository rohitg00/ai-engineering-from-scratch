# SVM核函数选择指南

SVM由两个选择决定：核函数（决定决策边界的形状）和正则化参数（控制间隔宽度和分类错误之间的权衡）。正确设置这些参数是区分无用模型和强大模型的关键。

## 决策清单

1. 数据是否线性可分（或接近线性可分）？
   - 是：使用线性核。更快且更可解释。
   - 否：进入第2步。

2. 特征数 vs 样本数？
   - 特征 >> 样本（例如TF-IDF文本）：使用线性核。高维数据通常是线性可分的。RBF增加了复杂性却没有收益。
   - 样本 >> 特征（例如10-50个特征的表格数据）：RBF核是默认选择。

3. 决策边界预期是平滑的吗？
   - 平滑、连续的边界：RBF核
   - 多项式形状的边界：多项式核（从2次或3次开始）
   - 领域知识表明有特定的交互项：使用匹配次数的多项式核

4. 数据集有多大？
   - 少于10,000个样本：任何核都可以，RBF是安全默认值
   - 10,000到100,000：线性核或LinearSVC（原始形式，每轮O(n)）
   - 超过100,000：不要使用核SVM。切换到线性SVM、梯度提升或神经网络。

5. 你缩放特征了吗？
   - SVM需要特征缩放。在拟合前始终进行标准化（零均值，单位方差）。未缩放的特征会扭曲间隔几何。

## 核函数选择流程图

```
开始
  |
  v
特征 > 1000 或 特征 >> 样本？
  是 --> 线性核（用LinearSVC提高速度）
  否  --> 数据集 < 10k 样本？
            是 --> 先尝试RBF（最好的通用核函数）
            否  --> 线性核（核SVM是O(n^2)到O(n^3)）
```

如果RBF效果不好，尝试2-3次多项式。如果仍不行，问题可能不适合SVM。

## 调优C（正则化）

C控制误分类的惩罚。它与正则化强度成反比。

| C值 | 效果 | 何时使用 |
|---------|--------|-------------|
| 0.001 - 0.01 | 宽间隔，允许大量违规 | 噪声数据，想要泛化能力 |
| 0.1 - 1.0 | 平衡 | 好的起始范围 |
| 10 - 1000 | 窄间隔，少量违规 | 干净数据，需要高准确率 |

调优策略：
- 从C=1.0开始
- 在对数尺度上搜索：[0.001, 0.01, 0.1, 1, 10, 100, 1000]
- 使用交叉验证选择最佳值
- 如果最佳C在范围的边缘，向该方向扩展范围

## 调优gamma（RBF核）

gamma控制单个训练点的影响力范围。它定义了高斯核的宽度。

| gamma值 | 效果 | 何时使用 |
|-------------|--------|-------------|
| 小（0.001） | 每个点影响大面积。平滑、简单的边界 | 欠拟合或特征少 |
| 中（auto: 1/n_features） | sklearn默认值。合理的起点 | 一般使用 |
| 大（10+） | 每个点只影响附近点。复杂、波动的边界 | 过拟合风险 |

调优策略：
- 从gamma="scale"开始（1 / (n_features * X.var())，sklearn默认值）
- 在对数尺度上搜索：[0.001, 0.01, 0.1, 1, 10]
- 低gamma + 高C 倾向于过拟合
- 高gamma + 低C 倾向于欠拟合

## 联合调优C和gamma

C和gamma相互影响。始终一起调优，而不是独立调优。

推荐方法：
1. 粗粒度网格搜索：C在[0.01, 0.1, 1, 10, 100]，gamma在[0.001, 0.01, 0.1, 1, 10]（25种组合）
2. 找到最佳区域
3. 在最佳区域周围进行细粒度网格搜索（例如C在[5, 10, 20, 50]，gamma在[0.05, 0.1, 0.2]）
4. 全程使用5折交叉验证

## 常见错误

- 在高维稀疏数据上使用RBF核（线性核更好且快100倍）
- 忘记缩放特征（最常见的SVM错误）
- 在噪声数据上将C设置得太高（记住噪声而非学习边界）
- 在超过5万样本的数据集上使用核SVM（训练时间过于昂贵）
- 不一起调优C和gamma（它们相互补偿）
- 默认使用5次以上的多项式核（严重过拟合，先尝试2次或3次）

## 快速参考

| 核函数 | 何时使用 | 关键参数 | 训练复杂度 |
|--------|------------|----------------|-------------------|
| 线性 | 文本/TF-IDF，特征多，数据量大 | 仅C | 每轮O(n) |
| RBF | 通用，少于1万样本 | C, gamma | O(n^2)到O(n^3) |
| 多项式 | 已知多项式关系 | C, degree, coef0 | O(n^2)到O(n^3) |
| Sigmoid | 很少有用（等价于两层神经网络） | C, gamma, coef0 | O(n^2)到O(n^3) |
