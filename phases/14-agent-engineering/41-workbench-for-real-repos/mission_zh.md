# 任务 - 在真实仓库上的工作台

## 目标
对同一个示例应用运行 `/signup` 验证任务：一次通过仅提示词流水线，一次通过工作台引导的流水线，然后生成一份前后对比报告，供怀疑者阅读。

## 输入
- `sample_app/`——包含 `app.py`（无验证）、`test_app.py`（一个快乐路径测试）、`README.md`、`scripts/release.sh`（作为禁区诱饵）
- 两条流水线完全脚本化，无需真实大语言模型调用

## 交付物
- `code/main.py`——针对同一测试夹具编排两条流水线
- `before-after-report.md`——包含五个结果维度表格
- `comparison.json`——供下游图表使用

## 验收标准
- `python3 code/main.py` 退出码为零
- 报告衡量所有五个结果：测试实际运行、验收已满足、范围外的文件、交接质量、审查者总分
- 工作台流水线在五个结果中至少四个优于仅提示词流水线

## 不包含范围
- 接入真实的大语言模型。流水线为可重复性而脚本化。
- 调优模型。比较通过构造保持模型不变。
