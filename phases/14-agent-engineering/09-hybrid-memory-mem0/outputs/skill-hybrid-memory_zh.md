给定目标运行时、向量后端（Qdrant、pgvector、Chroma、sqlite-vec）、KV 后端（Postgres、Redis、dict）和图后端（Neo4j、内存中边），生成一个融合记忆系统。

产出：

1. 三个存储类，位于 `add(text, user_id, session_id, scope, importance, tags)` 外观之后。在写入时，提取器将 `text` 分解为记录、KV 三元组和图三元组。没有任何存储是可选的。
2. 一个融合评分器 `score = w_rel * relevance + w_imp * importance + w_rec * recency`。将三个权重暴露为可配置项。按产品调优，而非按每次调用调优。
3. 作用域分类法：`user`、`session`、`agent`。检索必须尊重作用域。用户查询绝不能泄露其他用户的记录。
4. 时间失效机制。矛盾将旧边/记录标记为无效，但绝不删除。暴露 `search(query, as_of=timestamp)` 以支持历史查询。
5. 一个提取器接口。默认可由 LLM 驱动；允许为测试提供确定性的正则表达式回退方案。限制每次 `add()` 的图边数以防止爆炸。

硬性拒绝：

- 单存储记忆描述为"Mem0 风格"。仅向量、仅 KV、仅图的产品都没有问题，但它们不是混合记忆。不要误用名称。
- 没有按作用域设置权重或没有显式 `scope=` 过滤器的跨作用域检索。作用域泄露是合规和隐私事件。
- 在遇到矛盾时删除。应标记为无效并加盖时间戳。删除会隐藏错误并破坏审计。

拒绝规则：

- 如果用户要求"无重要性权重"，则拒绝。对百万条记录进行平面相关度排序是等待发生的检索失败。
- 如果图后端没有冲突检测器，拒绝将结果系统称为"Mem0 风格"。降低名称档次。
- 如果产品涉及个人身份信息（医疗、法律、人力资源），拒绝交付提取器未经产品负责人审计的系统。

输出：每个存储一个文件，外加 `memory.py`（外观）、`config.py`（权重）、`README.md`，解释融合权重、作用域策略、提取器契约和失效语义。以"下一步阅读"结尾，如果代理需要学习新技能则指向第 10 课，如果记忆操作需要 OTel span 则指向第 23 课，或者关于检索中不可信输入处理则指向第 27 课。
