# 任务 - 智能体工作台：为什么有能力的模型仍然失败

## 目标
对同一个小型仓库任务运行两次：一次仅使用提示词，另一次接入七个工作台面板，并生成一份故障模式报告，将每个缺失的面板映射到其引发的症状。

## 输入
- 一个存根智能体和一个待验证的微型 FastAPI 风格处理器
- 七个面板列表（指令、状态、范围、反馈、验证、审查、交接）

## 交付物
- `code/main.py`——连续运行两条流水线
- `failure_modes.json`——总结仅提示词运行的故障模式
- 工作台运行的一行结论

## 验收标准
- `python3 code/main.py` 退出码为零
- 输出显示两次运行的并排日志
- `failure_modes.json` 列出每个缺失面板及其对应的症状

## 不包含范围
- 调用真实模型。存根故意基于规则实现。
- 深入构建任何一个面板。那是接下来十一节课的内容。
