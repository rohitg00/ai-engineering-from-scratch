# AGENTS.md

你正在一个使用智能体工作台运行的仓库中工作。

在行动前阅读以下内容：

1. `agent_state.json`——上次会话停止的位置。
2. `task_board.json`——哪些正在进行中，接下来是什么。
3. `docs/agent-rules.md`——启动、禁止、完成、不确定、审批。
4. `docs/reliability-policy.md`——此工作台设计用于吸收的失败模式。
5. `docs/handoff-protocol.md`——会话结束必须生成的内容。
6. `docs/reviewer-rubric.md`——已完成工作如何被评判。

验证命令：参见活动任务在面板上的 `acceptance_criteria`。

包版本：1.0.0
