**错误信息：** [在此粘贴错误信息]

**我的张量形状：**
- [名称]：[形状]
- [名称]：[形状]

**我正在尝试执行的操作：** [描述它]

---

调试时，请遵循以下精确流程：

**第1步：确定操作类型。**
哪个操作产生了错误？将其映射为以下之一：
- 矩阵乘法 / 线性层（内部维度必须匹配）
- 广播（从右对齐，每个维度必须相等或为1）
- 拼接（除拼接维度外，所有维度都匹配）
- 卷积（需要特定的秩和通道位置）
- 重塑（总元素数必须保持不变）

**第2步：写出形状约束。**
对于识别出的操作，显式写出期望的形状：
```
matmul(A, B): A 是 (..., m, k), B 是 (..., k, n) -> (..., m, n)
broadcast(A, B): 从右对齐，每一对必须（相等）或（其中一个为1）
cat([A, B], dim=d): 除dim d外所有维度匹配
Linear(in_f, out_f): 输入的最后一维必须等于in_f
Conv2d(in_c, out_c, k): 输入必须是 (B, in_c, H, W)
```

**第3步：找到不匹配。**
将实际形状与约束进行比较。识别违反规则的确切维度。

**第4步：选择最小的修复。**
从下表中选择：

| 症状 | 修复 |
|---|---|
| 缺少批次维度 | `.unsqueeze(0)` |
| 缺少通道维度 | `.unsqueeze(1)` |
| 多余的尺寸为1的维度 | `.squeeze(dim)` |
| matmul内部维度错误 | `.transpose(-1, -2)` 或检查权重形状 |
| 需要NCHW格式（来自NHWC） | `.permute(0, 3, 1, 2)` |
| 需要NHWC格式（来自NCHW） | `.permute(0, 2, 3, 1)` |
| 为线性层展平空间维度 | `.flatten(1)` 或 `.reshape(B, -1)` |
| 分离注意力头：(B,T,D)到(B,H,T,D/H) | `.reshape(B, T, H, D//H).transpose(1, 2)` |
| 合并注意力头：(B,H,T,D/H)到(B,T,D) | `.transpose(1, 2).reshape(B, T, H*(D//H))` |
| 对非连续张量使用.view() | `.contiguous().view(...)` 或使用 `.reshape(...)` |

**第5步：验证修复。**
展示每一步的结果形状。确认任何reshape操作中总元素数保持不变。确认操作的形状约束现在已满足。

**第6步：检查静默bug。**
即使形状匹配，也验证：
- 广播是否沿着预期轴发生（而非意外）
- 归约是否在正确的维度上求和
- 批次维度（dim 0）是否贯穿整个前向传播
- 当维度顺序重要时，是否使用了transpose + reshape（而不仅仅是reshape）

按以下格式回答：
```
操作：[哪个操作失败了]
期望：[形状约束]
实际：[提供了什么形状]
不匹配：[哪个维度，为什么]
修复：[精确代码]
结果：[修复后的形状]
```
