# 用于ML的统计检验

如何在对模型进行比较、运行A/B实验或验证结果时选择正确的检验方法。

## 决策清单

1. 你在比较什么？均值、比例、分布还是相关性？
2. 有多少个组？单样本与参考、两组还是多组？
3. 观测是配对的（相同测试集、相同折）还是独立的？
4. 数据是否正态分布？如果n < 30且不明确正态，使用非参数检验。
5. 数据是连续的、有序的还是分类的？
6. 你在运行多少个检验？如果超过一个，应用校正。

## 决策树

```text
比较均值？
  两组？
    配对（相同数据划分）？--> 配对t检验（若非正态则用Wilcoxon符号秩检验）
    独立？--> Welch's t检验（若非正态则用Mann-Whitney U检验）
  多组？
    配对？--> 重复测量方差分析（或Friedman检验）
    独立？--> 单因素方差分析（或Kruskal-Wallis检验）

比较比例？
  两组？--> 卡方检验或Fisher精确检验（小样本n）
  多组？--> 卡方检验

比较分布？
  一个分布是参考？--> Kolmogorov-Smirnov检验
  两者都是经验分布？--> 双样本KS检验

测量关联性？
  两者连续、大致正态？--> Pearson相关
  有序或非正态？--> Spearman秩相关
  分类 x 分类？--> 独立性卡方检验

运行多个检验？
  应用Bonferroni校正：alpha_adjusted = alpha / 检验次数
  或使用Holm-Bonferroni（不那么保守，仍控制族系误差率）
```

## 何时使用每种检验

| 检验 | 数据类型 | 假设 | ML用例 |
|---|---|---|---|
| 配对t检验 | 连续、配对 | 差值正态 | 在相同k折划分上比较2个模型 |
| Wilcoxon符号秩 | 连续/有序、配对 | 无（非参数） | 比较2个模型，小k（5-10折） |
| Welch's t检验 | 连续、独立 | 大致正态 | 在两个独立数据集上比较模型 |
| Mann-Whitney U | 连续/有序、独立 | 无 | 比较延迟分布 |
| 方差分析 | 连续、3+组 | 正态、方差相等 | 比较多个模型架构 |
| Kruskal-Wallis | 连续/有序、3+组 | 无 | 比较多个模型，非正态指标 |
| 卡方检验 | 分类计数 | 期望计数 >= 5 | 比较类别分布、混淆矩阵 |
| Fisher精确检验 | 分类计数 | 小样本 | 稀有事件比较 |
| KS检验 | 连续 | 无 | 检查预测是否遵循预期分布 |
| Bootstrap CI | 任何统计量 | 无 | AUC、F1、任何指标的置信区间 |
| McNemar检验 | 配对二元 | 无 | 在相同测试集上比较两个分类器 |

## 模型比较方法

1. 在运行实验之前定义指标和显著性水平（alpha = 0.05）。
2. 在两个模型上使用相同的k折交叉验证划分（k = 5或10）。
3. 收集配对分数：(a_1, b_1), (a_2, b_2), ..., (a_k, b_k)。
4. 计算差值：d_i = b_i - a_i。
5. 运行配对检验（k <= 10时用Wilcoxon，k > 10或差值正态时用配对t检验）。
6. 报告：p值、均值差、95%置信区间、效应量（Cohen's d）。
7. 如果p < alpha 且 效应量有意义，则差异是真实的且值得采取行动。

## 常见错误

- 数据配对时使用独立检验。如果两个模型在相同的测试折上进行了评估，必须使用配对检验。独立检验会丢弃配对信息并损失统计功效。
- 报告p < 0.05而不报告效应量。统计上显著的0.1%准确率提升不值得部署。始终计算Cohen's d或原始均值差。
- 跨不同测试集比较模型。测试集必须对两个模型完全相同。不同的测试集使比较毫无意义。
- 运行20次比较并报告最好的一次而不做Bonferroni校正。在alpha = 0.05下进行20次检验，预计会有1个假阳性偶然出现。
- 在不平衡数据上使用准确率。在99%的多数类上，一个平凡分类器就能达到99%。使用F1、精确率-召回率AUC或Matthews相关系数。
- 将交叉验证折视为独立样本。它们共享训练数据，违反了独立性假设。校正的重采样t检验考虑到了这一点。

## 快速参考：效应量解读

| Cohen's d | 解读 |
|---|---|
| 0.2 | 小效应 |
| 0.5 | 中效应 |
| 0.8 | 大效应 |
| > 1.0 | 非常大的效应 |

| 需要报告的内容 | 原因 |
|---|---|
| p值 | 差异是真实的吗？ |
| 置信区间 | 差异可能有多大？ |
| 效应量（Cohen's d） | 差异有意义吗？ |
| 样本量（n或k折） | 我们能相信结果吗？ |
