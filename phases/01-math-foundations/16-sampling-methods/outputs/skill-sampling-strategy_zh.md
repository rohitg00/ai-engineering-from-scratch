# 采样策略选择

如何为文本生成、贝叶斯推理、蒙特卡洛估计和训练选择正确的采样方法。

## 决策清单

1. 你是生成输出（文本、图像）还是估计数量（积分、期望）？
2. 你能直接从目标分布采样，还是只能评估其密度？
3. 目标分布是离散的还是连续的？
4. 样本空间的维度是多少？低（< 5）、中（5-100）还是高（> 100）？
5. 你需要精确样本还是近似样本？
6. 你需要通过采样操作的梯度吗？

## 何时使用每种方法

| 方法 | 何时使用 | 复杂度 | 精确？ |
|---|---|---|---|
| 直接采样 | 你有CDF或可以使用库函数 | 每样本O(1) | 是 |
| 逆CDF | 已知闭式CDF逆（指数分布、柯西分布） | 每样本O(1) | 是 |
| Box-Muller | 无需库即可获得正态样本 | 每样本O(1) | 是 |
| 拒绝采样 | 可以评估目标PDF，低维度（1-3） | 每样本O(1/接受率) | 是 |
| 重要性采样 | 需要期望而非个体样本 | n个样本O(n) | 近似 |
| 分层采样 | 蒙特卡洛估计，希望方差更小 | n个样本O(n) | 近似 |
| Metropolis-Hastings | 高维，可评估未归一化密度 | 每步O(1) + 预热期 | 渐近精确 |
| Gibbs采样 | 可以从每个条件分布采样 | 每次完整扫描O(d) | 渐近精确 |
| HMC/NUTS | 高维连续、光滑密度 | 每步O(L * d) | 渐近精确 |
| 温度采样 | LLM文本生成，控制创造性 | 词表大小V时O(V) | N/A |
| Top-k采样 | LLM生成，移除不太可能的token | O(V log k) | N/A |
| Top-p（核采样） | LLM生成，自适应候选集 | O(V log V) | N/A |
| 重参数化技巧 | 需要高斯采样的梯度（VAE） | O(d) | 是 |
| Gumbel-Softmax | 需要类别采样的梯度 | k个类别时O(k) | 近似 |

## LLM生成设置

| 用例 | 温度 | Top-p | Top-k | 备注 |
|---|---|---|---|---|
| 事实性问答 | 0.0（贪婪） | -- | -- | 确定性，无随机性 |
| 代码生成 | 0.2-0.5 | 0.9 | -- | 低创造性，高一致性 |
| 通用对话 | 0.7 | 0.9 | -- | 平衡 |
| 创意写作 | 0.9-1.2 | 0.95 | -- | 较高多样性 |
| 头脑风暴 | 1.0-1.5 | 0.95 | -- | 最大多样性，可能失去连贯性 |

温度和top-p可以组合使用。先应用温度（缩放logits），然后应用top-p过滤。

## MCMC方法选择

| 属性 | Metropolis-Hastings | Gibbs | HMC/NUTS |
|---|---|---|---|
| 维度 | 任意 | 任意（最佳< 100） | 高（100+） |
| 需要条件分布 | 否 | 是 | 否 |
| 需要梯度 | 否 | 否 | 是 |
| 接受率 | 调整到约23% | 始终100% | 调整到约65% |
| 相关性 | 高（随机游走） | 中等 | 低 |
| 预热期 | 长 | 中等 | 短 |
| 最适合 | 探索、简单模型 | 共轭模型、贝叶斯网络 | 连续后验、深度概率模型 |

## 常见错误

- 在高维中使用拒绝采样。接受率随维度呈指数下降。超过5维，切换到MCMC。
- MCMC提议方差设置过高或过低。过高：大多数提议被拒绝，链卡住。过低：所有提议被接受，链移动缓慢。随机游走MH的目标接受率约23%。
- 忘记预热。MCMC的前N个样本受起始点偏置影响。丢弃至少1000步（或对于复杂分布更多）。
- 使用与目标差异很大的提议分布进行重要性采样。少数样本获得巨大权重，使估计不可靠。监控有效样本量：ESS = (sum w_i)^2 / sum(w_i^2)。
- 对需要确定性输出的任务（如分类、结构化提取）使用温度 > 0。改用贪婪（T=0）或束搜索。
- 不将top-p与温度结合使用。单独的温度不能从长尾中移除垃圾token。top-p可以。
- 通过标准采样操作进行反向传播。对连续（高斯）使用重参数化技巧，对离散（类别）使用Gumbel-Softmax。

## 快速参考：方差缩减技术

| 技术 | 原理 | 方差缩减 |
|---|---|---|
| 分层采样 | 将空间划分为层，每层采样 | 始终 <= 标准MC |
| 对偶变量 | 同时使用U和1-U | 对单调函数有效 |
| 控制变量 | 减去一个已知均值的变量 | 与相关性成正比 |
| 重要性采样 | 从更好的提议分布重新加权样本 | 取决于提议质量 |
| 拉丁超立方 | 独立地对每个维度分层 | 在高维中优于分层采样 |
