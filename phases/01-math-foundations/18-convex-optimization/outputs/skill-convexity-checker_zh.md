# 凸性检查器

如何验证优化问题是否为凸，以及如何处理结论。

## 决策清单

1. 目标函数是凸的吗？（检查Hessian半正定性或使用组合规则。）
2. 所有不等式约束是否形如 g_i(x) <= 0 且每个 g_i 是凸函数？
3. 所有等式约束是否都是仿射的（线性的）？
4. 如果以上三个都是肯定的，则问题是凸的。使用具有收敛保证的凸求解器。
5. 如果任何一个是否定的，则问题是非凸的。使用SGD/Adam并接受局部最优。

## 如何测试函数的凸性

| 测试 | 适用范围 | 方法 |
|---|---|---|
| 二阶导数 >= 0 | 标量函数 f(x) | 计算 f''(x)。如果对所有x有 f''(x) >= 0，则凸。 |
| Hessian是PSD | 多变量函数 f(x) | 计算 H(x)。如果所有特征值处处 >= 0，则凸。 |
| 定义测试 | 任意函数 | 对采样的x、y、t检查 f(tx+(1-t)y) <= t*f(x)+(1-t)*f(y)。 |
| 组合规则 | 组合函数 | 见下方组合表。 |
| 限制到直线 | 多变量 f | f凸当且仅当对所有x、v，g(t)=f(x+tv)在t上是凸的。 |

## 组合规则（保持凸性）

| 操作 | 结果 |
|---|---|
| f + g（两者都凸） | 凸 |
| c * f（c > 0，f凸） | 凸 |
| max(f, g)（两者都凸） | 凸 |
| f(Ax + b) 其中 f 是凸的 | 凸 |
| g(f(x)) 其中 g 凸非减且 f 凸 | 凸 |
| g(f(x)) 其中 g 凸非增且 f 凹 | 凸 |
| 凸函数之和 | 凸 |
| 凸函数的逐点上确界 | 凸 |

## 常见ML目标：凸还是不凸？

| 目标 | 凸？ | 原因 |
|---|---|---|
| MSE：(1/n) sum(y - Xw)^2 | 是 | 在w上是二次的，Hessian = (2/n) X^T X 是PSD |
| 逻辑损失：sum(log(1 + exp(-y_i * w^T x_i))) | 是 | 凸函数之和（log-sum-exp族） |
| Hinge损失：sum(max(0, 1 - y_i * w^T x_i)) | 是 | 凸（线性）函数的最大值 |
| L2正则化：lambda * \|\|w\|\|^2 | 是 | 二次型，Hessian = 2*lambda*I |
| L1正则化：lambda * \|\|w\|\|_1 | 是 | 绝对值之和（凸但不可微） |
| 岭回归：MSE + L2 | 是 | 两个凸函数之和 |
| LASSO：MSE + L1 | 是 | 两个凸函数之和 |
| Elastic net：MSE + L1 + L2 | 是 | 凸函数之和 |
| SVM（原始）：hinge + L2 | 是 | 凸函数之和 |
| 带softmax的交叉熵 | 是（在logits上） | log-sum-exp是凸的 |
| 神经网络（任何损失） | 否 | 非线性激活产生非凸组合 |
| k-means目标 | 否 | 离散分配步骤 |
| 矩阵分解：\|\|X - UV^T\|\|^2 | 否 | 在U和V上是双线性的 |
| GAN损失 | 否 | 极小化极大，生成器中非凸 |
| 对比损失（InfoNCE） | 否 | 指数之比的对数，含负样本 |

## 基于凸性的求解器选择

| 问题类型 | 求解器 | 收敛保证 |
|---|---|---|
| 凸、光滑、无约束 | 梯度下降 | 全局最优O(1/k) |
| 凸、光滑、无约束 | L-BFGS | 全局最优，超线性 |
| 凸、光滑、无约束 | 牛顿法 | 最小值附近二次收敛（如果Hessian可处理） |
| 凸、光滑、有约束 | 内点法 | 多项式时间 |
| 凸、非光滑（L1） | 近端梯度 / ISTA | 全局最优O(1/k) |
| 凸、非光滑（L1） | ADMM | 灵活，处理约束 |
| 凸、二次 | 共轭梯度 | n步内精确 |
| 非凸、光滑 | SGD / Adam | 收敛到局部最小值 |
| 非凸、光滑 | SGD + 重启 | 平均更好的局部最小值 |
| 非凸、光滑 | 过参数化 + SGD | 平坦最小值，良好泛化 |

## 常见错误

- 因为损失函数是凸的就认为问题是凸的。损失必须在你要优化的参数上是凸的。交叉熵在logits上是凸的，但从输入到logits的完整神经网络映射是非凸的。
- 在非凸问题上使用牛顿法。Hessian可能有负特征值，导致牛顿法朝鞍点或最大值而非最小值移动。
- 忘记L1正则化使目标在零点处不可微。标准梯度下降效果不佳。使用近端梯度下降或次梯度方法。
- 通过形成A^T A来平方条件数。如果需要求解最小二乘问题且A是病态的，使用QR或SVD而非正规方程。
- 不经检查就宣布问题是非凸的。许多ML问题（线性模型、SVM、逻辑回归）是凸的，受益于更强的求解器。

## 快速测试：我的问题是凸的吗？

```
1. 写出目标：最小化 f(w) 满足约束条件
2. 对于 f(w) 中的每一项：
   - 是带有PSD矩阵的二次型？-> 凸
   - 是范数？-> 凸
   - 是log-sum-exp？-> 凸
   - 涉及非线性地使用w（sigmoid(w)、w1*w2）？-> 可能非凸
3. 所有约束是线性或凸不等式吗？
4. 如果所有项都是凸的且约束是凸的/线性的 -> 问题是凸的
5. 如果任何项是非凸的 -> 问题是非凸的
```
