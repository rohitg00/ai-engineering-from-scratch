# 用于ML的信息论

何时在机器学习系统中使用熵、交叉熵、KL散度和互信息。

## 决策清单

1. 测量单一分布的不确定性？使用**熵**。
2. 衡量模型逼近真实标签的效果？使用**交叉熵**（这是你的分类损失）。
3. 测量两个分布之间的距离？使用**KL散度**。
4. 检查两个变量是否相关？使用**互信息**。
5. 报告语言模型质量？使用**困惑度**（交叉熵的指数）。
6. 将一个模型蒸馏到另一个模型？最小化从教师到学生的**KL散度**。

## 何时使用每种度量

| 度量 | 公式 | 用途 | ML应用 |
|---|---|---|---|
| 熵 H(P) | -sum(p log p) | 这个分布的不确定性有多大？ | 数据复杂度、最大熵模型 |
| 交叉熵 H(P,Q) | -sum(p log q) | 模型Q预测真实P的效果如何？ | 分类损失、语言模型损失 |
| KL散度 D(P\|\|Q) | sum(p log(p/q)) | P和Q有多大的不同？ | VAE损失(ELBO)、知识蒸馏、RLHF |
| 互信息 I(X;Y) | H(X) - H(X\|Y) | Y告诉我们多少关于X的信息？ | 特征选择、表示学习 |
| 困惑度 | exp(H(P,Q)) 或 2^H | 模型有多困惑？ | 语言模型评估 |
| 条件熵 H(X\|Y) | -sum(p(x,y) log p(x\|y)) | 知道Y后X的剩余不确定性 | 特征信息量 |

## 关键关系

```
交叉熵 = 熵 + KL散度
H(P, Q) = H(P) + D_KL(P || Q)

由于训练时H(P)是常数：
  最小化交叉熵 = 最小化KL散度

互信息 = 熵 - 条件熵
I(X; Y) = H(X) - H(X|Y) = H(Y) - H(Y|X)

困惑度 = exp(交叉熵，单位nats)
       = 2^(交叉熵，单位bits)
```

## 快速参考：公式与单位

| 公式 | Bits（以2为底的对数） | Nats（以e为底的对数） |
|---|---|---|
| 信息量：-log(p) | -log2(p) | -ln(p) |
| 熵：-sum(p log p) | bits | nats |
| 1 nat = | 1.4427 bits | 1 nat |
| PyTorch默认 | -- | nats |
| 信息论论文 | bits | -- |

## 数值解读

| 熵值 | 含义 |
|---|---|
| 0 | 确定性的。一个结果的概率为1。 |
| log(n) | 最大不确定性。n个结果上的均匀分布。 |
| 低 | 分布是尖峰状的。模型很有信心。 |
| 高 | 分布是平坦的。模型不确定。 |

| 困惑度值 | 语言模型质量 |
|---|---|
| 1 | 完美预测（实践中不会发生） |
| 10 | 平均在约10个等可能的token中选择 |
| 50 | 标准基准上GPT-2的水平 |
| < 10 | 良好覆盖领域的最先进水平 |

## 常见错误

- 计算KL散度并将其视为对称量。D_KL(P||Q) != D_KL(Q||P)。对于对称度量，使用JS散度：JS = 0.5 * KL(P||M) + 0.5 * KL(Q||M)，其中 M = 0.5*(P+Q)。
- 忘记当标签为one-hot时，交叉熵简化为 -log(p_true_class)。当真实分布是one-hot时，不需要对所有类别求和。
- 在代码中使用以2为底的对数，但报告的是nats（或反之）。PyTorch默认使用自然对数。乘以 log2(e) = 1.4427 可将nats转换为bits。
- 计算空事件或零概率事件的熵。约定：0 * log(0) = 0，因为 lim(p->0) p*log(p) = 0。
- 跨不同词表比较困惑度。词表大小50k且困惑度30的模型，与词表大小10k且困惑度30的模型不可直接比较。

## 每个概念在生产ML中的出现位置

| 概念 | 你在哪里看到它 |
|---|---|
| 交叉熵损失 | 每个分类模型（nn.CrossEntropyLoss） |
| KL散度 | VAE ELBO、PPO裁剪、知识蒸馏 |
| 熵正则化 | RL中的探索奖励（高熵=更多探索） |
| 互信息 | 特征选择、InfoNCE损失（对比学习） |
| 困惑度 | 语言模型基准（越低越好） |
| 标签平滑 | 用软目标替代one-hot，减少交叉熵过度自信 |
| 温度缩放 | 在softmax之前将logits除以T，控制输出熵 |
