# 大语言模型的差分隐私

> DP-SGD 仍是标准方法——注入噪声的梯度更新提供了形式化的 (ε, δ) 保证。计算、内存和效用方面的开销相当大；参数高效的差分隐私微调（LoRA + DP-SGD）是 2025 年的常见配置（ACM 2025）。两组证据存在张力：基于金丝雀的成员推理（Duan 等人，2024）报告对语言模型的效果有限；训练数据提取（Carlini 等人，2021；Nasr 等人，2025）则恢复了大量逐字记忆。解决方案（arXiv:2503.06808，2025 年 3 月）：差异在于测量对象的不同——插入的金丝雀 vs "最可提取"的数据。新的金丝雀设计使得无需影子模型即可进行基于损失的 MIA，并首次实现了对使用真实数据和现实 DP 保证训练的大语言模型进行有意义的差分隐私审计。替代方案：PMixED（arXiv:2403.15638）——在推理时通过下一词元分布的专家混合实现私有预测；DP 合成数据生成（Google Research 2024）。新兴攻击：通过大语言模型反馈的差分隐私逆转——置信度分数泄露。

## 问题

大语言模型会记忆。Carlini 等人 2021 年展示了生产环境语言模型能够按需逐字复现训练文本。差分隐私是形式化的防御手段：训练时确保输出对任意单个训练示例均不敏感。2024-2025 年的证据表明 DP-SGD 是必要的，但实际部署的 ε 值可能与威胁模型不匹配。

## 概念

### (ε, δ)-差分隐私

一个随机化算法 M 是 (ε, δ)-DP 的，如果对于任意两个仅相差一个示例的数据集以及任意事件 S：
P(M(D) ∈ S) ≤ e^ε · P(M(D') ∈ S) + δ

解释：输出分布足够接近（由 ε 参数化），使得任何单个个体的贡献无法被可靠推断，除非以概率 δ 为代价。

### DP-SGD

Abadi 等人 2016 年提出。标准配方：
1. 采样一个小批量。
2. 计算每个示例的梯度。
3. 将每个示例梯度裁剪到阈值 C。
4. 对裁剪后的梯度求和并加入标准差为 σ·C 的高斯噪声。
5. 使用加噪后的和更新参数。

隐私成本由会计（矩会计、Rényi DP 会计）追踪。大语言模型文献中报告的 ε 值因威胁模型、数据敏感性和效用目标的不同而差异很大；不存在通用的"安全"默认 ε。已发表示例大致涵盖 ε ≈ 1–10 的某些大语言模型训练场景，但这些仅为示意——并非推荐默认值。较低的 ε 通常需要更多噪声，并可能导致更大的效用损失。

### LoRA + DP-SGD

对前沿模型进行全量 DP-SGD 是不可行的。LoRA（Hu 等人 2022）将梯度更新限制在一个小型适配器上，减少了每个示例梯度的存储需求。LoRA + DP-SGD 是 2025 年的常见配置。差分隐私保证适用于适配器；基础模型保持固定。

### 2024-2025 年的张力

两套证据：

- **金丝雀 MIA（Duan 等人，2024）。** 在训练数据中插入唯一的金丝雀，衡量成员推理攻击者能否识别出它们。报告在语言模型上效果有限。表明 MIA 是困难的。
- **训练数据提取（Carlini 2021，Nasr 等人，2025）。** 向模型提供前缀提示，衡量其能否复现训练数据中的逐字文本。报告存在大量记忆。表明 MIA 在相关意义上是容易的。

2025 年 3 月的解决方案（arXiv:2503.06808）：两者测量的是不同的事物。MIA 针对插入的金丝雀询问"示例 e 是否在数据集 D 中？"。提取则询问"我能从 D 中恢复什么？"。"最可提取"的示例才是隐私问题的关键；金丝雀低估了这一指标，因为它们并非针对可提取性进行优化。

新的金丝雀设计。基于损失的 MIA，无需影子模型。首次对使用真实数据和现实 DP 保证的大语言模型进行有意义的差分隐私审计。

### DP 训练的替代方案

- **PMixED（arXiv:2403.15638）。** 推理时的私有预测。对下一词元分布使用专家混合；每个专家看到训练数据的一个分片；聚合时加入噪声以实现差分隐私。完全避免了 DP 训练。
- **DP 合成数据生成（Google Research 2024）。** 使用 DP-SGD 进行 LoRA 微调，采样合成数据，在合成数据上训练下游分类器。

两者都以不同的威胁模型为代价，规避了全量 DP 训练的效用成本。

### 通过大语言模型反馈的差分隐私逆转

2025 年新兴攻击。利用 DP 训练模型的置信度分数作为oracle来重新识别个体。即使输出不泄露信息，置信度分布也可能泄露。

防御措施：不暴露置信度，或在暴露前对其进行截断/量化。这是除 (ε, δ)-DP 训练之外的额外要求。

## 关键术语

| 术语 | 人们所说的 | 实际含义 |
|------|-----------|---------|
| DP | "(ε, δ)-差分隐私" | 形式化隐私：相邻数据集下输出分布接近 |
| DP-SGD | "注入噪声的 SGD" | 梯度裁剪 + 高斯噪声添加；标准 DP 训练 |
| LoRA + DP-SGD | "高效的私有微调" | 在低秩适配器上进行 DP-SGD；2025 年标准配置 |
| MIA | "成员推理" | 确定某个示例是否在训练数据中的攻击 |
| 金丝雀 | "插入的水印示例" | 用于测量 DP 泄露的唯一训练示例 |
| PMixED | "私有推理混合" | 通过下一词元分布的专家混合实现推理时 DP |
| DP 逆转 | "置信度泄露攻击" | 利用模型置信度作为重识别 oracle 的攻击 |
