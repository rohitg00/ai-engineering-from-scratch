# 給 LLM 用的差分隱私

> DP-SGD 仍然是標準做法 —— 注入雜訊的梯度更新提供形式化的 (epsilon, delta) 保證。它在運算、記憶體與效用上的開銷都很可觀；參數高效的 DP 微調（LoRA + DP-SGD）是 2025 年常見的組態（ACM 2025）。有兩批彼此拉扯的證據：以誘餌為基礎的成員推論（Duan 等人，2024）回報對語言模型的成效有限；而訓練資料萃取（Carlini 等人，2021；Nasr 等人，2025）卻救回了大量逐字記憶。調和之道（arXiv:2503.06808，2025 年 3 月）：落差出在「量的是什麼」—— 是插入的誘餌，還是「最容易被萃取出來的」資料。新的誘餌設計讓「不需影子模型的、以損失為基礎的成員推論」成為可能，並產出了第一份「在真實資料上訓練、且有實際 DP 保證之 LLM」的非平凡 DP 稽核。替代方案：PMixED（arXiv:2403.15638）—— 在推論時透過對下一詞元分布做專家混合來達成隱私化預測；以及 DP 合成資料生成（Google Research 2024）。正在浮現的攻擊：透過 LLM 回饋做差分隱私逆轉 —— 信心分數的外洩。

## 問題所在

LLM 會記憶。Carlini 等人 2021 顯示，生產環境的語言模型會依要求逐字複述訓練文字。DP 是那套形式化的防禦：訓練方式要能證明輸出對任何單一訓練樣本不敏感。2024-2025 年的證據顯示，DP-SGD 是必要的，但實際部署的 ε 值可能與威脅模型對不上。

## 核心概念

### (ε, δ)-差分隱私

若對任意兩個僅相差一個樣本的資料集、以及任意事件 $S$，一個隨機化演算法 $M$ 都滿足下式，那麼 $M$ 就是 $(\varepsilon, \delta)$-DP 的：

```math
P(M(D) \in S) \le e^{\varepsilon} \cdot P(M(D') \in S) + \delta.
```

詮釋：輸出分布夠接近（以 ε 參數化），使得任何單一個體的貢獻無法被可靠地推論出來，除非發生機率為 δ 的例外。

### DP-SGD

Abadi 等人 2016。那套標準配方：
1. 抽一個小批次。
2. 計算逐樣本的梯度。
3. 把每個逐樣本梯度裁剪到門檻 C。
4. 把裁剪後的梯度加總，並加入標準差為 $\sigma \cdot C$ 的高斯雜訊。
5. 用那個帶雜訊的總和去更新參數。

隱私成本由一個帳目器追蹤（動差帳目器、Rényi DP 帳目器）。LLM 文獻中回報的 ε 值，會隨威脅模型、資料敏感度與效用目標而大幅變動；並沒有一個普世「安全」的預設 ε。已發表的例子在某些 LLM 訓練設定下大致落在 ε ≈ 1–10，但那是示例性的 —— 不是建議的預設值。ε 愈低，通常需要更多雜訊，也可能加大效用損失。

### LoRA + DP-SGD

對一個前沿模型做完整的 DP-SGD 代價高得難以承受。LoRA（Hu 等人 2022）把梯度更新限制在一個小型轉接器上，減少逐樣本梯度的儲存量。LoRA + DP-SGD 是 2025 年常見的組態。DP 保證套用在那個轉接器上；基礎模型維持固定。

### 2024-2025 年的那個張力

兩條證據路線：

- **誘餌式成員推論（Duan 等人 2024）。** 在訓練資料裡插入獨一無二的誘餌，量測成員推論攻擊者能否指認出它們。回報在語言模型上成效有限。這暗示成員推論很難。
- **訓練資料萃取（Carlini 2021、Nasr 等人 2025）。** 用一段前綴去提示模型；量測它能否逐字救回訓練中的文字。回報有大量記憶。這暗示在相關意義上成員推論很容易。

2025 年 3 月的調和（arXiv:2503.06808）：這兩者量的是不同東西。成員推論在插入的誘餌上問的是「樣本 e 在 D 裡嗎？」。萃取問的是「我能從 D 救回什麼？」。對隱私而言要緊的是那個「最容易被萃取」的樣本；而誘餌會低估這件事，因為它們並沒有被最佳化成容易被萃取。

新的誘餌設計。不需影子模型、以損失為基礎的成員推論。第一份在真實資料上、帶實際 DP 保證的 LLM 非平凡 DP 稽核。

### DP 訓練的替代方案

- **PMixED（arXiv:2403.15638）。** 在推論時做隱私化預測。對下一詞元分布做專家混合；每位專家只看訓練資料的一個分片；彙總時加入雜訊以達成 DP。完全避開了 DP 訓練。
- **DP 合成資料生成（Google Research 2024）。** 用 DP-SGD 做 LoRA 微調、抽出合成資料，再拿合成資料訓練一個下游分類器。

兩者都繞開了完整 DP 訓練的效用代價，代價則是換成另一套威脅模型。

### 透過 LLM 回饋做差分隱私逆轉

2025 年正在浮現的攻擊。把一個 DP 訓練模型的信心分數當成預言機，用來重新識別個體。就算輸出本身沒有外洩，信心分布可能會。

防禦方式：不要把信心分數暴露出來，或在暴露前先截斷／量化它們。這是在 (ε, δ)-DP 訓練之外的一項額外要求。

## 框架應用

`code/main.py` 在一個玩具型二元分類資料集上模擬 DP-SGD。你可以掃描雜訊乘數 σ 與裁剪範數 C，追蹤 (ε, δ) 預算與準確率代價。一項「誘餌攻擊」會插入一個獨一無二的訓練樣本，並量測在 DP 之前與之後，一項對數損失檢定能否偵測到它。

這一課產出 `outputs/skill-dp-audit.md`。給定一項針對語言模型部署的 DP 宣稱，它會稽核：那些 (ε, δ) 值、使用的帳目器、成員推論的評估協定，以及有沒有評估過信心暴露的向量。

## 關鍵術語

| 術語 | 大家怎麼說 | 實際是什麼意思 |
|------|-----------------|------------------------|
| DP | 「(ε, δ)-差分隱私」 | 形式化隱私：在鄰近資料集變動之下輸出分布仍相近 |
| DP-SGD | 「注入雜訊的 SGD」 | 梯度裁剪 + 加高斯雜訊；標準的 DP 訓練 |
| LoRA + DP-SGD | 「高效的隱私化微調」 | 在低秩轉接器上做 DP-SGD；2025 年的標準組態 |
| MIA | 「成員推論」 | 判定某個樣本是否在訓練資料中的攻擊 |
| 誘餌 | 「插入的浮水印樣本」 | 用來量測 DP 外洩的獨一無二訓練樣本 |
| PMixED | 「隱私化推論混合」 | 對下一詞元分布做專家混合、在推論時達成 DP |
| DP 逆轉 | 「信心外洩攻擊」 | 把模型信心當成預言機來做重新識別的攻擊 |
