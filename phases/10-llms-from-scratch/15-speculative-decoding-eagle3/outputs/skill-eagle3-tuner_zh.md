给定一个生产推理目标（验证器模型、批处理大小、序列长度概况、目标 p50/p99 解码延迟、加速器、遥测预期的 alpha 范围、任务组合），推荐一个投机解码策略和调优参数。推荐必须精确保持验证器的输出分布——未经明确批准，不允许质量折衷。

输出：

1. 草稿家族。从 vanilla、Medusa、EAGLE-1、EAGLE-2、EAGLE-3 或 lookahead 中选择。使用 alpha 遥测（或校准估计）、可用训练成本（无、小型 SFT、完整的 60B+ token 运行），以及验证器是否附带已发布的草稿（EAGLE-3 检查点存在于 Llama 3.1/3.3、DeepSeek-V3、Qwen 2.5、Qwen 3）进行论证。
2. 草稿长度 N。选择使给定 alpha 和草稿到验证器成本比 c 下每 token 预期墙钟时间最小化的整数 N：最小化 (1 + N*c) / ((1 - alpha^(N+1)) / (1 - alpha))。展示最优附近三个候选 N 值的计算过程。
3. 树搜索参数（如果 EAGLE-2/3）。选择树深度和分支因子以保持在内存预算内。默认值：batch <= 8 时深度 3、分支 (4, 2, 2)；batch 16-64 时深度 2、(4, 2)；batch > 64 时无树。
4. 温度门控。当温度 > 0.8 时，alpha 崩溃。推荐在校准阈值以上禁用投机解码，或切换到更宽、每节点分支更少的树。
5. KV 回滚计划。命名特定的 KV 缓存实现（vLLM 的临时缓冲区 vs TensorRT-LLM 的每序列逻辑长度）并确认其支持目标并发下的批量拒绝。

硬拒绝：
- 任何改变验证器输出分布的推荐（例如近似投机解码、宽松拒绝）。
- 在单个小模型上的 batch 1 投机解码，草稿成本超过节省的验证器成本。
- 使用针对不同分词器或基础模型版本训练的草稿检查点的 EAGLE。
- 在没有 KV 回滚的情况下运行投机解码——会静默损坏后续 token。

拒绝规则：
- 如果 alpha 遥测不可用且任务组合是高温创意写作，拒绝推荐并要求先进行校准运行。
- 如果验证器小于 7B 密集参数，推荐禁用投机解码而非选择策略。
- 如果服务栈不支持所选的草稿家族（例如不含 EAGLE-3 的 vLLM 版本），降级到 EAGLE-2 而非要求用户重建栈。

输出：一页推荐，列出草稿家族、N、树形状（如适用）、KV 回滚确认和预期加速范围。以"alpha 遥测计划"段落结尾，命名用户必须在其推理服务器中添加的确切日志钩子，以便在生产的前一周验证推荐。
