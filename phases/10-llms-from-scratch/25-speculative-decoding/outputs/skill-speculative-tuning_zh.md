给定目标模型（大小、家族、分词器）、工作负载遥测（任务组合、提示与解码 token 比、p50/p99 解码延迟、加速器和 HBM 余量、平均批处理大小、采样温度分布）以及可用草稿检查点，输出：

1. 草稿选择。从同家族小模型（用于 Llama-70B 的 Llama-3.2-1B）、蒸馏草稿（Qwen3-0.6B-spec）、附加在目标上的 Medusa 头，或"无投机解码"（如果没有草稿的 FLOP 成本比接近 30% 以内）中选择。逐字节确认分词器与目标匹配；拒绝不匹配的分词器。
2. 草稿长度 K。E[tokens] / (1 + K x c) 的 argmax，其中 c 是草稿到目标的成本比。展示 K 为 2、3、4、5、6 时的计算结果，使用来自 5000 个分布内 token 校准运行的测量 alpha。聊天默认 K=4，代码 K=6，高温度创意写作 K=2。
3. 温度门控。设定温度阈值，高于此值禁用投机解码。默认 0.8；如果校准显示 alpha 更早崩溃则降至 0.6。拒绝任何依赖每次请求检查且增加超过 50 微秒的温度门控。
4. 树预算。如果服务栈支持树形草稿，batch 小于 8 时选择小的固定树（深度 2，分支 3-2）；batch 超过 32 时选择扁平链。说明验证器的 KV 暂存大小（字节）并确认其适合 HBM 余量。
5. 回退策略。命名指标（过去 1000 次验证的滑动窗口测量 alpha）和阈值（alpha 低于 0.4），在此条件下服务器为该请求流回退到纯自回归解码。包括回退决策的每请求生命周期。

当批处理大小超过验证器变为计算受限的点时，拒绝投机解码。超过该点，投机器本应吸收的未使用 FLOP 不再存在；吞吐量下降。对任何测量 alpha 低于 0.4 的任务家族拒绝投机解码；草稿开销占主导，墙钟延迟变差。拒绝未在针对目标的保留 1000 token 样本上验证的草稿：未经验证的草稿是静默的 KL 漂移。

示例输入："Llama-3.3-70B on 8xH100, chat workload, batch 16, p50 decode 28 ms, p99 60 ms, temperature distribution mean 0.4 / max 1.2, calibration shows alpha 0.78 on chat, 0.61 on code."

示例输出：
- 草稿：Llama-3.2-1B-Instruct-spec。相同分词器，相同家族，成本比 c 约 0.03。
- K：4。E[tokens/verify] = 聊天 3.4，代码 2.5。K=5 聊天 token 增加 0.1 但需支付额外 0.03c；拒绝。
- 温度门控：0.8。高于 0.8 时 alpha 在校准集上降至 0.45 以下。
- 树预算：深度 2 分支 (3, 2)。batch 16 时 KV 暂存 480 MB 适合。
- 回退：过去 1000 次验证的滑动窗口 alpha 低于 0.40 时，对该流禁用投机解码 30 秒，然后再次探测。
