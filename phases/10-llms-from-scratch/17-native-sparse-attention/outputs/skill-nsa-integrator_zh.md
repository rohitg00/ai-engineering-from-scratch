给定一个长上下文预训练运行规范（目标上下文、基础架构、可用训练 token、GPU 拓扑、部署目标），生成 NSA 集成计划。

输出：

1. 压缩块大小 `l`。选择 32、64 或 128。根据目标上下文论证：`l = 32` 用于 16k-32k，`l = 64` 用于 64k-128k，`l = 128` 用于 256k+。更大的 `l` 意味着更少的压缩键但更粗糙的路由信号。
2. Top-k 选择数量。在 8 到 32 之间选择。论文默认值为 16。根据目标任务组合论证：推理密集型任务（数学、代码）受益于更高的 `k`，因为选择精度更重要。检索密集型任务可在较低的 `k` 下工作。
3. 滑动窗口 `W`。选择 256、512 或 1024。默认值 512。高度结构化内容（代码）用更短的窗口，局部上下文已足够；散文用更长的窗口。
4. 门控 MLP。指定宽度和初始化。默认值：从 `hidden` 到 3 的线性层，使用 `sigmoid` 或 `softplus` 激活。如果门控权重坍缩到偏好一个分支则发出警告——这表明 `l`、`k` 或 `W` 调优不当。
5. 内核选择。确认目标加速器上 Triton 或 CUDA 内核的可用性。在推理时拒绝回退到密集注意力（NSA 的全部意义在于节省解码计算）。如果只有前向内核而无反向内核，拒绝预训练并推荐在现有密集检查点上继续训练。

硬拒绝：
- 在未继续进行预训练的情况下对使用密集注意力预训练的模型使用 NSA。不能在推理时直接附加。
- 目标上下文低于 16k。三分支开销占主导。
- 在没有 NSA 内核支持的栈上仅限推理的部署。推荐改为 MLA 或滑动窗口注意力。

拒绝规则：
- 如果长上下文评估数据（RULER、LongBench、needle-in-haystack）不可用，拒绝并要求先提供校准数据。
- 如果训练数据上下文分布由短序列主导，拒绝并推荐在集成 NSA 之前重新加权数据。
- 如果加速器早于 A100，拒绝——NSA 的内核优势假定 H100/H200/MI300 内存层次结构。

输出：一页集成计划，列出 `l`、`k`、`W`、门控配置、内核路径和目标上下文下的预期计算节省。以"成功标准"段落结尾：特定的 RULER 或 LongBench 数值（与匹配的密集注意力基线相比的百分点）证明保留 NSA 的合理性。包括回滚触发器——低于该指标阈值应将架构恢复到 MLA 或密集 GQA。
