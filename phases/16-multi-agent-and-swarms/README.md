# Phase 16: Multi-Agent & Swarms

> Coordination, emergence, and collective intelligence.

## Start this phase on GitHub

**Prerequisites:** Phase 14 Agent Engineering. Node.js 20+ and `npx` are
needed for the first TypeScript demo.

**First lesson:** [Why Multi-Agent](01-why-multi-agent/)

Run this command from the repository root:

```bash
npx --yes tsx phases/16-multi-agent-and-swarms/01-why-multi-agent/code/single_vs_multi.ts
```

Keep the command, exit code, single-agent and multi-agent token and tool-call
totals, and one tradeoff that makes the added coordination worthwhile.

**Next action:** Change the task, compare the two approaches again, then
continue to [FIPA-ACL Heritage and Speech Acts](02-fipa-acl-heritage/).
