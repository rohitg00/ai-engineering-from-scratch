# 代理經濟、代幣誘因、聲譽

> 長時程的自主代理（METR 那條 1 小時到 8 小時的工作曲線）需要經濟上的能動性。正在成形的**五層堆疊**是：**DePIN**（實體運算）→ **身分**（W3C DID + 聲譽資本）→ **認知**（RAG + MCP）→ **結算**（帳戶抽象化）→ **治理**（代理式 DAO）。生產級的代理誘因網路包括 **Bittensor**（TAO 子網獎勵任務專屬的模型）、**Fetch.ai／ASI Alliance**（ASI-1 Mini LLM + FET 代幣），以及 **Gonka**（基於 transformer 的 PoW，把運算重新配置到有生產力的 AI 任務上）。學術工作：AAMAS 2025 的去中心化 LaMAS 用 **Shapley 值信用歸屬**公平地獎勵有貢獻的代理；Google Research 的〈Mechanism design for large language models〉在單調彙整之下提出帶次價支付的**代幣拍賣**。這一課建出一個最小的代理市集、對一條多代理管線套用 Shapley 值信用歸屬，並跑一場次價代幣拍賣，讓那套賽局理論機具落到實處。

**類型：** 學習
**程式語言：** Python (stdlib)
**先修單元：** 階段 16 · 16（談判與議價）、階段 16 · 09（平行 Swarm 網路）
**時間：** 約 75 分鐘

## 問題

當代理共同產出價值、卻需要被個別獎勵時，多代理系統就變複雜了。經典機制 —— 平均分、最後貢獻者全拿 —— 要嘛不公平，要嘛可被玩弄。用 Shapley 值做基於聯盟的獎勵在構造上是公平的，但計算很貴。2025-2026 年的文獻推出了有用的近似：Shapley 取樣、單調彙整拍賣，以及從已確認貢獻累積起來的鏈上聲譽。

在信用歸屬之外，這個領域已經轉向真正的經濟代理：Bittensor 的 TAO 獎勵挖礦運算去微調子網專屬的模型、Fetch.ai／ASI 用 FET 代幣獎勵 ASI-1 Mini LLM 的使用、Gonka 把 transformer 的工作量證明重新配置到有生產力的 AI 任務上。會自主交易的代理今天就存在；問題在於誘因怎麼對齊。

這一課把代理經濟當成一個特定的問題家族 —— 信用歸屬、機制設計與聲譽 —— 並用最低限度的數學把每一項建出來，好讓這些構想留得住。

## 概念

### 代理經濟的五層堆疊

1. **DePIN（實體運算）。** 出租 GPU、儲存、頻寬的去中心化基礎設施。Bittensor 子網、Render Network、Akash。不是代理專屬的；代理只是使用它。
2. **身分。** W3C 去中心化識別碼（DID）給每個代理一個獨立於任何平台的持久 ID。聲譽累積在那個 DID 上。Agent Network Protocol（ANP）把 DID 當成發現層。
3. **認知。** 代理的推理迴圈：LLM + RAG + MCP。這是其他階段在建的東西。
4. **結算。** 帳戶抽象化（ERC-4337）讓代理能從自己的餘額支付 gas，而不必持有 ETH。代理可以替服務、替彼此，或替運算付費。
5. **治理。** 代理式 DAO：人類*與*代理都能對協定變更投票的治理結構，投票權與聲譽掛鉤。

不是每個生產系統都用滿五層。Bittensor 用了 1、2，部分 3、部分 4，完全沒有 5。OpenAI 的代理除了 3 之外都沒用。這個堆疊是一張參考地圖，不是一項要求。

### Bittensor、Fetch.ai、Gonka —— 實際在跑的是什麼

**Bittensor（TAO）。** 子網是特化的任務（語言模型、影像生成、預測）。礦工提交模型輸出。驗證者替它們排名；依權益加權的評分分配 TAO 獎勵。每個子網有自己的評測。經濟上的教訓是：替任務專屬的輸出品質付費，不是替用掉的運算付費。

**Fetch.ai／ASI Alliance。** ASI-1 Mini LLM 跑在 Fetch.ai 的網路上；使用者付 FET 代幣做推論。這裡「代理即同儕」的敘事更強：Fetch 上的一個代理可以為某項任務呼叫另一個代理，並用 FET 付款。

**Gonka。** Transformer 工作量證明：那個「工作」就是 transformer 的前向傳遞。礦工靠著跑那些有已知正確輸出（來自訓練資料）的推論任務來賺取報酬。用資源生產性的 PoW 取代基於雜湊的 PoW。

截至 2026 年 4 月，這三者都是生產等級。報酬分配方式各不相同。Bittensor 依相對於子網驗證者的品質給獎；Fetch 依付費使用者所量測的效用給獎；Gonka 依可驗證的推論工作給獎。

### Shapley 值信用歸屬

三個代理合作完成一項任務。輸出得分 0.8。誰貢獻了什麼？

Shapley 值：滿足四條公理（效率、對稱、線性、零貢獻）的唯一信用配置。對代理 `i`：

```
shapley(i) = (1/N!) * sum over all orderings O of (v(S_i_O ∪ {i}) - v(S_i_O))
```

其中 `S_i_O` 是排序 `O` 中排在 `i` 之前的那組代理。實務上：列舉所有排列、記下每個代理在每個排列中的邊際貢獻，然後取平均。

N=3 個代理有 6 種排列。N=10 就有 360 萬 —— 所以實務上要對排序取樣，而不是列舉。

### 供彙整用的次價拍賣

Google Research（〈Mechanism design for large language models〉）為彙整 LLM 輸出提出次價代幣拍賣。設定：N 個代理各提出一份補全；每個對「被選中」有一個私人估值。拍賣者挑出估值最高的提案，並支付*第二高*的估值。在單調彙整之下（價值取決於哪份提案被選，而不是有幾份參與競標），這是誠實的 —— 代理會照真實估值出價。

這對 LLM 系統為何要緊：你可以把補全任務外包給定價不同的多個代理；拍賣挑出最好的並公平付款，而代理沒有誘因謊報。

### 聲譽資本

一個綁在 DID 上的聲譽分數，從已確認的貢獻累積起來。一條簡單的更新規則：

```math
\text{rep}(i, t+1) = \alpha \cdot \text{rep}(i, t) + (1 - \alpha) \cdot \text{contribution\_quality}(i, t)
```

衰減因子 `alpha` 接近 1。聲譽：

- 讀取起來很便宜，可用於路由決策（「把難的任務送給高聲譽代理」）。
- 偽造起來很貴（隨時間累積、綁在 DID 上）。
- 可以被削減：查證失敗的貢獻會扣分。

### AAMAS 2025 的去中心化 LaMAS

LaMAS 提案（AAMAS 2025）結合了：DID 身分、Shapley 值信用歸屬，以及一套簡單的拍賣機制。關鍵主張是：把信用歸屬那一步去中心化，能讓系統可稽核，且免疫於單點操弄。

### 經濟學在哪裡會崩

- **價格神諭操弄。** 若信用函數可以被玩弄，代理就會去玩弄它。每一套機制都需要對抗性測試。
- **女巫攻擊。** 一個營運方開出 N 個假代理來灌高自己的貢獻。DID 會拖慢但阻止不了這件事；靠「偽造聲譽的成本」來緩解。
- **查證成本。** 信用歸屬的公平度，只能跟那個查證者一樣公平。若查證很便宜（小模型），它就會被玩弄；若很貴（人類評審團），系統就擴展不了。
- **監管懸垂。** 代理經濟與金融監管交會。截至 2026 年，Bittensor、Fetch 與 Gonka 在某些法域中都運作在法律灰色地帶。

### 代理經濟什麼時候說得通

- **有異質營運方的開放網路。** 沒有單一團隊掌控所有代理。
- **可驗證的輸出。** 沒有查證，信用歸屬就是猜的。
- **長時程的工作流。** 一次性的任務不會從聲譽累積中受益。
- **代幣化支付在你的法域中合法可行。**

在封閉的企業系統中，經濟學讓位給更簡單的分配（經理指派工作、指標是內部的）。經濟學文獻主要適用於開放網路。

## 動手實作

`code/main.py` 實作了：

- `shapley(value_fn, agents)` —— 對小 N 以列舉方式做精確的 Shapley 計算。
- `second_price_auction(bids)` —— 誠實機制；贏家支付第二高價。
- `Reputation` —— 綁在 DID 上、帶指數衰減與削減的聲譽。
- 示範 1：三個代理合作，用精確 Shapley 歸屬信用。
- 示範 2：五個代理競標一個任務位；次價拍賣挑出贏家與付款額。
- 示範 3：100 輪任務指派給聲譽異質的代理；聲譽加權的路由勝過隨機。

跑：

```
python3 code/main.py
```

預期輸出：每個代理的 Shapley 值；顯示誠實出價均衡的拍賣結果；聲譽加權路由在暖機後展現 10-20% 的品質增益。

## 產出交付

在 2026 年營運一套代理經濟：

- **從聲譽開始，不是代幣。** 聲譽實作起來便宜，本身就有價值；代幣則加上法律與經濟的複雜度。
- **先查證再獎勵。** 絕不要在沒有獨立查證步驟的情況下分配信用。自我回報的品質會養出女巫遊戲。
- **用 Shapley 取樣，不要用精確 Shapley。** 取樣 100-1000 種排序；精確列舉擴展不了。
- **替衰減因子設上限、替聲譽設下限。** 無界的衰減會抹掉正當貢獻者；衰減太慢則獎勵那些吃老本的高聲譽代理。
- **用對抗方式稽核機制。** 在把網路開放之前先跑紅隊情境。每套機制都有它的賽局；你想要先找到那些洞，而不是先遇到攻擊者。

## 關鍵術語

| 術語 | 大家怎麼說 | 實際是什麼意思 |
|------|----------------|------------------------|
| DePIN | 「去中心化實體基礎設施」 | 以代幣誘因驅動的運算／儲存／頻寬。Bittensor、Akash、Render。 |
| DID | 「去中心化識別碼」 | 供可攜 ID 用的 W3C 規格。代理聲譽綁在 DID 上，不是綁在平台上。 |
| ERC-4337 | 「帳戶抽象化」 | 可以代付 gas 的合約帳戶，讓代理付款成為可能。 |
| Shapley 值 | 「公平的信用歸屬」 | 滿足效率、對稱、線性、零貢獻的唯一配置。 |
| 次價拍賣 | 「Vickrey 拍賣」 | 誠實機制：贏家支付第二高的出價。與單調彙整相容。 |
| 聲譽資本 | 「累積起來的品質分數」 | 綁在 DID 上、來自已確認貢獻的分數；隨時間衰減。 |
| 代理式 DAO | 「代理與人一起治理」 | 代理投票者是一等公民的 DAO，投票權與聲譽掛鉤。 |
| TAO／FET／GPU 點數 | 「代幣計價單位」 | Bittensor 的 TAO、Fetch.ai 的 FET，以及各種 DePIN 代幣。 |
