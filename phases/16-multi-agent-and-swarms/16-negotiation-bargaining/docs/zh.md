# 协商与议价

> 智能体就资源、价格、任务分配和条款进行协商。2026 年的基准测试结果清晰明了：NegotiationArena（arXiv:2402.05863）表明，LLM 可通过角色操纵（"绝望"）将收益提高约 20%；"Measuring Bargaining Abilities"（arXiv:2402.15813）表明买方比卖方更难，且规模扩大无济于事——其 **OG-Narrator**（确定性出价生成器 + LLM 叙述器）将成交率从 26.67% 提升至 88.88%；大规模自主协商竞赛（arXiv:2503.06416）开展了约 18 万次协商，发现 **隐藏思维链** 的智能体通过向对手隐藏推理过程获胜；Bhattacharya 等人 2025 年基于哈佛谈判项目指标对模型进行排名，Llama-3 最有效，Claude-3 最具攻击性，GPT-4 最公平。本课程实现合同网协议（FIPA 的前身，课程 02），构建 LLM 风格的买方/卖方，运行 OG-Narrator 风格的分解，并衡量每种结构选择如何影响成交率。

**类型：** 学习 + 构建
**语言：** Python（标准库）
**前置要求：** 阶段 16 · 02（FIPA-ACL 遗产），阶段 16 · 09（并行群体网络）
**时长：** 约 75 分钟

## 问题

两个智能体需要就价格达成一致。在仅凭纯语言提示的情况下，2024-2026 年的 LLM 成交率低得惊人（在 arXiv:2402.15813 的严格参数化议价中约为 27%）。规模扩大无法解决这一问题：GPT-4 在议价能力上并没有比 GPT-3.5 有结构性提升；它只是在议价的 *语言表达* 上更好。

根本问题在于 LLM 混淆了两项工作——决定出价和叙述出价。OG-Narrator 将二者分离：确定性出价生成器计算数值移动；LLM 仅负责叙述。成交率跃升至约 89%。

这反映了一个经典的多智能体发现：将机制与通信层解耦总能获胜。合同网协议（FIPA，1996；Smith，1980）是参考性的任务市场机制。将 LLM 插入叙述槽位，你就得到了一个现代化的 LLM 驱动任务市场。

## 概念

### 合同网，一句话总结

Smith 1980 年的合同网协议：**管理者** 广播 **招标书（cfp）**；**投标者** 回复包含其出价的 **建议（propose）** 消息；管理者选择获胜者，向获胜者发送 **接受建议（accept-proposal）**，向失败者发送 **拒绝建议（reject-proposal）**。获胜者执行工作。可选消息：**拒绝（refuse）**（投标者拒绝提出建议）。FIPA 将其规范化为 `fipa-contract-net` 交互协议。

### 为什么 OG-Narrator 胜出

"Measuring Bargaining Abilities of Language Models"（arXiv:2402.15813）观察到：

- LLM 经常违反议价规则（以无意义的价格出价，忽略对方的 ZOPA）。
- 锚定能力差（接受糟糕的首次出价；以象征性而非战略性金额还价）。
- 仅靠规模无法解决这些问题。更大的模型能生成更合理的语言，但战略错误相似。

OG-Narrator 的分解方式：

```
           ┌──────────────────┐        ┌──────────────────┐
  state  → │  出价生成器       │ price → │  LLM 叙述器      │ → message
           │  （确定性）       │        │  （编写人类风格   │
           │                  │        │   的附属说明）     │
           └──────────────────┘        └──────────────────┘
```

出价生成器采用经典的协商策略：Rubinstein 议价模型、Zeuthen 策略，或简单的以牙还牙式价格调整。LLM 负责叙述。消息中包含确定性价格和自然语言框架。

成交率跃升的原因在于：
- 价格保持在议价区间内。
- 锚定是战略性的，而非情绪化的。
- LLM 做它擅长的事：写作。

### NegotiationArena 的发现

arXiv:2402.05863 提供了权威基准。主要发现：

- LLM 可以通过采用特定角色（"我迫切需要在周五前卖掉这个"）将收益提高约 20%——角色操纵是一个真实的策略。
- 公平/合作的智能体会被对抗性智能体利用；防御需要明确的对抗姿态。
- 对称配对在大约 40% 的基准场景中会收敛到不公平的结果。

这并不是说"LLM 是糟糕的谈判者"。而是"LLM 的谈判方式太像人类了，包括那些容易被利用的部分。"

### 思维链隐藏

大规模自主协商竞赛（arXiv:2503.06416）开展了约 18 万次协商，涉及多种 LLM 策略。获胜者向对手隐藏了他们的推理过程：

- 如果智能体将"我只出到 75 美元；我的保留价是 70 美元"打印到公开可见的草稿区中，对手会读到它。
- 获胜者私下计算策略；输出通道仅包含出价和最少的必要叙述。

这是 2026 年对经典博弈论（Aumann 1976，关于理性与信息）的回响：泄露你的私人估值会损失收益。LLM 无法直觉地理解这一点，并乐于在推理轨迹中写下自己的保留价，而这些轨迹会暴露给对方。

工程要点：将私人草稿上下文与公共消息上下文分离。这一点不可商量。

### Bhattacharya 等人 2025 年——模型排名

基于哈佛谈判项目指标（原则性谈判、BATNA 尊重、利益互惠）：

- **Llama-3** 在达成交易方面最有效（成交率 + 收益）。
- **Claude-3** 是最具攻击性的谈判者（高锚定、晚让步）。
- **GPT-4** 是最公平的（不同配对间收益方差最小）。

这是 2025 年的快照。重点不在于 2026 年 4 月哪个模型胜出——而在于不同的基础模型具有持久的谈判风格。异质集成（课程 15）将其作为一种多样性来源。

### 通过合同网 + LLM 进行任务分配

合同网在现代 LLM 多智能体系统中的复用方式：

1. 管理者智能体将任务分解为若干单元。
2. 向工作智能体广播包含任务描述的 `cfp`。
3. 每个工作智能体返回一个出价：`(price, eta, confidence)`，其中 price 可以是 token 数、计算单元或美元。
4. 管理者选择获胜者（单个或多个，取决于任务）并分配任务。
5. 被拒绝的工作智能体可以自由竞标其他任务。

这种方式可良好扩展到 100 个以上的工作智能体，因为协调方式是广播-响应，而非同步聊天。已在生产中使用：微软智能体框架的编排模式、一些 LangGraph 实现。

### LLM-利益相关者交互式协商

NeurIPS 2024（https://proceedings.neurips.cc/paper_files/paper/2024/file/984dd3db213db2d1454a163b65b84d08-Paper-Datasets_and_Benchmarks_Track.pdf）引入了多方可评分博弈，包含 **秘密得分** 和 **最低接受阈值**。每个利益相关者都有私有效用；LLM 必须从消息中推断出这些信息。这是从两方议价到 N 方联盟形成的泛化。对于具有异构工作能力的生产任务市场具有实际意义。

### 叙述 vs 机制法则

纵观所有 2024-2026 年协商基准，一致的工程法则是：

> 让 LLM 叙述。不要让 LLM 计算报价。

如果报价需要是一个数字（价格、ETA、数量），则根据协商状态确定性地生成，并由 LLM 产生框架性描述。如果报价需要是一个提案结构（任务分解、角色分配），让 LLM 起草，但在发送前根据模式和约束检查进行验证。

## 构建

`code/main.py` 实现了：

- `ContractNetManager`、`ContractNetTask`、`Bid`——管理者 + 投标者，广播 cfp，收集建议，分配任务。
- `og_narrator_bargain(state, rng)`——OG-Narrator 买方：向中点做确定性 Zeuthen 式让步。
- `seller_response(state, rng)`——确定性卖方还价策略（两种风格的结构性事实依据）。
- `naive_llm_bargain(state, rng)`——模拟纯 LLM 谈判者：以高方差选择价格，常常超出 ZOPA。
- 测量：在 1000 次试验中的成交率，每次试验重新采样保留价。

运行：

```
python3 code/main.py
```

预期输出：纯 LLM 成交率约 65-75%；OG-Narrator 成交率约 85-95%；15-25 个百分点的差距是将出价生成与叙述分离带来的结构性优势。此外还有一个包含三个投标者和一个任务的合同网任务市场分配示例。

## 使用

`outputs/skill-bargainer-designer.md` 设计了一个议价协议：谁生成出价（确定性还是 LLM），谁叙述，私人草稿如何与公共消息分离，以及如何监控成交率。

## 交付

生产级议价检查清单：

- **分离草稿区。** 私人状态永远不会到达对方的上下文。这一点不可商量。
- **确定性出价生成。** 价格、数量、ETA：计算得出，不要用提示词生成。
- **验证所有传入出价** 是否符合模式。在协议边界拒绝超出 ZOPA 的出价。
- **限定轮次。** 最多 3-5 轮；在僵局时升级至调解人。
- **持续测量成交率和收益方差。** 成交率下降是一种症状——通常意味着提示词漂移或对方攻击。
- **记录所有被拒绝的提案** 并附上确定性理由。对于合同网管理者，失败的投标者需要了解原因。

## 练习

1. 运行 `code/main.py`。确认 OG-Narrator 在成交率上优于纯 LLM。高出多少？
2. 实现 **基于角色的收益提升**（arXiv:2402.05863）——买方在叙述中仅采用"迫切希望本周买入"的角色，出价生成器不变。成交率或收益会变化吗？
3. 实现思维链 **隐藏**：维护一个不传递给对方的私人草稿字符串。如果你意外泄露了它（通过交换信道来模拟），会发生什么？
4. 将合同网扩展为带保留价的 N 投标者拍卖。当所有投标都超过保留价时，管理者如何在最低价和最高质量之间做出决定？你选择哪种授标规则，为什么？
5. 阅读 Bhattacharya 等人 2025 年关于哈佛谈判项目指标的论文。实现两种不同风格（攻击型 vs 公平型）的谈判者。在对称和非对称配对下测量收益方差。

## 关键术语

| 术语 | 人们说的 | 实际含义 |
|------|---------|---------|
| 合同网（Contract Net） | "任务市场" | Smith 1980, FIPA 1996。cfp + propose + accept/reject。经典任务市场。 |
| ZOPA | "可能达成协议的区域" | 买方最高价与卖方最低价之间的重叠区域。超出此范围的出价无法成交。 |
| BATNA | "达成协议的最佳替代方案" | 若本交易失败时的后备方案。决定了你的保留价。 |
| OG-Narrator | "出价生成器 + 叙述器" | 分解方式：确定性出价，LLM 叙述。 |
| Zeuthen 策略 | "风险最小化让步" | 经典出价生成器，基于风险限额做出让步。 |
| Rubinstein 议价 | "交替出价均衡" | 无限期议价带折现的博弈论模型。 |
| CoT 隐藏 | "隐藏你的推理" | arXiv:2503.06416 中获胜者保留私人草稿；公共通道仅显示出价。 |
| 角色操纵 | "情绪姿态" | arXiv:2402.05863：通过绝望/紧迫角色获得约 20% 的收益提升。 |
