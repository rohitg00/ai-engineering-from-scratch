给定一个需要从智能体群体中产生涌现行为的场景（社会模拟、游戏 NPC、政策演练、市场动态），设计模拟。

生成以下内容：

1. **群体规模和异质性**。N 个智能体；哪些共享一个基础模型 vs 不同的；提示系列；角色分布。Smallville 使用了 25 个具有个性化角色的同质智能体；更大的群体从异质性中受益。
2. **记忆模式**。每个条目的字段：`(ts, kind, content, importance, embedding_ref, source_ids)`。近因衰减常数；重要性评分流程；相关性度量（与嵌入模型 X 的余弦距离）。压缩的保留策略。
3. **反思节奏**。触发器：未处理的重要性总和 > 阈值，或每 N 次观察，或周期性滴答。每次触发的反思次数。反思提示模板。
4. **计划时间范围**。天/小时/行动级别。哪些是必需的，哪些是可选的。修订触发器：一条重要性 > 阈值且与当前计划相矛盾的新观察。
5. **世界模型**。空间网格、社会图、资源约束。什么构成观察（视线、对话、通知）。架构不会学习而必须显式编码的哪些规范性约束（容量限制、关闭时间、私人空间）。
6. **种子目标**。哪些智能体被播种了哪些优先级。可能竞争的重叠目标；应共存的非竞争目标。
7. **预算**。每次滴答每智能体的 LLM 调用数（观察 + 检索 + 反思 + 计划 + 行动）。每智能体每次滴答的预期令牌数。T 个滴答的总模拟成本。
8. **评估指标**。可信度（人类评分者）、目标达成率、计数协调事件、作为失败信号的空间规范违规。

硬性拒绝：

- 没有显式空间/社会规范编码的设计。架构将违反它们（Park 2023 中商店关闭、单人卫生间失败）。
- 具有可变记忆的设计。记忆必须是仅追加的；修正为新条目。
- 每次滴答都运行反思的设计。这预算效率低下；反思成本高，触发器应基于阈值。
- 在没有记忆压缩策略的大规模 N（> 50）模拟。检索成本随流长度增长。

拒绝规则：

- 如果场景需要涌现的*任务执行*而非涌现的*社会行为*，推荐监督/角色/原语模式（阶段 16 · 05-08）。Smallville 是为社会模拟设计的。
- 如果预算允许每次滴答总共少于 100 次 LLM 调用，推荐 N = 3-5 并带有密集交互，而非更大群体。
- 如果场景不从涌现中受益（严格脚本化的任务），推荐单智能体 + 工具。

输出：一页设计简报。以一句话摘要开头（"Smallville 风格模拟：15 个异质智能体，重要性总和 > 120 时反思，3 级计划时间范围，带容量约束的空间网格，通过可信度 + 协调事件衡量"），然后是上述八个部分。以预期的涌现行为和首先要注意的前三个故障模式结尾。
