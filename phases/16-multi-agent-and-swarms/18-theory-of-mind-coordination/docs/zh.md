# 心智理論與浮現式協調

> Li 等人（arXiv:2310.10701）顯示，在合作式文字遊戲中的 LLM 代理展現出**浮現的高階心智理論**（ToM）—— 推理「另一個代理對第三個代理的信念抱持什麼信念」—— 但因脈絡管理與幻覺而在長時程規劃上失敗。Riedl（arXiv:2510.05174）跨族群量測高階綜效，發現**只有**在 ToM 提示詞的條件下，才會產生與身分掛鉤的分化與目標導向的互補性；能力較低的 LLM 只顯示出偽浮現。也就是說，協調的浮現是提示詞條件性且模型相依的，不是免費的。這一課實作一個最小的知 ToM 代理、在有與沒有 ToM 提示詞的情況下跑一項合作任務，並依 Riedl 2025 的協定量測那個協調差距。

**類型：** 學習 + 建構
**程式語言：** Python (stdlib)
**先修單元：** 階段 16 · 07（心智社會與辯論）、階段 16 · 17（生成式代理）
**時間：** 約 75 分鐘

## 問題

多代理協調常常看起來很神奇：代理分工、預期彼此、避免重複。通常這種「浮現」是提示詞工程的產物 —— 有人叫那些代理「要協調」。把提示詞拿掉，協調就沒了。

Riedl 2025 年的發現更嚴格：在受控條件下，只有當代理被提示去推理**其他代理的心智**（ToM）時，協調才會浮現。沒有 ToM 提示詞，就算是強模型展現的協調樣式，也撐不過統計控制。這對生產環境很要緊：團隊出貨的「多代理協調」功能，是提示詞相依而且脆弱的。

這一課把 ToM 當成一項特定能力（推理關於信念的信念）來處理、建出一個最小的知 ToM 代理，並量測真正的協調長什麼樣子、相對於只是提示詞包裝長什麼樣子。

## 概念

### ToM 是什麼意思

發展心理學：3 歲小孩認為每個人的內心世界都跟自己一樣。5 歲小孩理解別人有不同的信念。7 歲小孩會推理關於信念的信念（「她以為我以為球在杯子底下」）。這分別是第零階、第一階與第二階 ToM。

對 LLM 代理來說，ToM 的階數對映到：

- **第零階：** 沒有他人的模型。代理只依自己的觀察行動。
- **第一階：** 代理對每個其他代理的信念有一份模型。「Alice 相信 X。」
- **第二階：** 代理模型化遞迴的信念。「Alice 相信 Bob 相信 X。」

Li 等人 2023 年發現，第一階與第二階 ToM 在合作式遊戲中的 LLM 代理上會浮現，但會隨長時程與不可靠的通訊而退化。

### 簡述 Sally-Anne 測驗

一項 1985 年的錯誤信念測驗：Sally 把彈珠放進籃子 A，然後離開。Anne 把它移到籃子 B。Sally 回來時會去哪裡找？有第一階 ToM 的小孩會說籃子 A（Sally 的信念與現實不同）。沒有的小孩會說籃子 B。

GPT-4 世代的 LLM 在題目被直白地問出來時，通得過 Sally-Anne 式的測驗。當敘事很長、場景變了好幾次，或問題以間接方式表述時，它們就會失敗。那就是 2026 年生產級 LLM 在 ToM 上的實務現況。

### Riedl 的協調量測

Riedl（arXiv:2510.05174）建了一個族群規模的測試：N 個代理、一個合作目標、可變的提示詞條件。量測：

1. **與身分掛鉤的分化。** 代理隨時間有沒有發展出穩定的角色區分？
2. **目標導向的互補性。** 代理的行動彼此互補（不同子任務），還是彼此重複？
3. **高階綜效。** 一項統計量測，看這個群體是否達成了任何子集都達不到的成果。

結果：只有在 ToM 提示詞條件下，這三項指標才產出高於基線的訊號。沒有 ToM 提示詞時，中等能力模型的指標徘徊在隨機水準附近。大模型在沒有明確 ToM 提示詞時展現一些協調，但效果比明確提示詞時小。

### 那個協調的幻覺

沒有統計控制，示範中的「浮現式協調」往往反映的是：

- 把協調烘進去的提示詞工程（系統提示詞寫著「一起合作」）。
- 觀察者偏誤（我們看見自己預期的樣式）。
- 事後挑出成功的那幾趟。

那些行銷「浮現式協調」卻沒有可量測訊號的生產系統，應該被當成行銷。要先量測再宣稱。

### 一個最小的知 ToM 代理

結構：

```
agent state:
  own_beliefs:    {facts the agent believes}
  other_models:   {other_agent_id -> {beliefs_the_agent_attributes_to_them}}
  actions_last_N: [history of others' actions]

observation update:
  - update own_beliefs from direct observation
  - update other_models[agent_id] from their action + prior beliefs

action selection:
  - enumerate candidate actions
  - for each, predict what each other agent will do next given their modeled beliefs
  - pick action that maximizes joint outcome under those predictions
```

`other_models` 這個屬性就是那份 ToM 狀態。第一階 ToM 只保留一層。第二階則加上 `other_models[i][other_models_of_j]` —— 我認為代理 i 認為代理 j 相信什麼。

### 為什麼長時程會傷害它

Li 等人記錄了：脈絡限制讓代理忘記哪個信念屬於誰。幻覺則替其他代理的模型加上假信念。兩者都產生「我以為他以為 X」的錯誤，並隨時間複利。

論文與 2024-2026 年後續工作記錄的緩解方式：

- **在提示詞中明寫 ToM 狀態。** 結構化格式：`{agent_id: belief_list}`。強迫檢索保住「身分—信念」的綁定。
- **更短的推理鏈。** 每輪更少的 ToM 更新，減少幻覺複利。
- **外部 ToM 儲存。** 把那份模型維護在 LLM 脈絡之外；每輪只注入相關的部分。

### ToM 在生產環境失敗的地方

- **對抗性場景。** ToM 好的代理更容易被操弄（你可以模型化「它對你的模型化」，然後加以利用）。
- **異質團隊。** 當模型不同時，對某個對手管用的 ToM 模型並不一般化。
- **依賴基準真值的任務。** ToM 談的是信念；若正確性取決於事實，ToM 可能是一種干擾。

### 你真正量得到的協調

三種實務訊號，用來判斷一個團隊的協調是真的、而不是提示詞包裝出來的：

1. **隨時間的互補性。** 在一項多輪任務中，代理的行動有沒有覆蓋互不重疊的子任務？
2. **預期。** 代理 A 在第 T+1 輪的行動，是否取決於一項關於 B 在第 T+2 輪行動、而且後來被證實正確的預測？
3. **修正。** 當 A 在第 T 輪誤讀了 B 的信念時，A 有沒有在第 T+2 輪之前修正過來？

這些在一套有記錄的多代理系統中都量得到。它們才是「協調」這套敘事的實質版本。

## 建構它

`code/main.py` 實作了：

- `ToMAgent` —— 追蹤自己的信念，以及對每個其他代理的信念模型。
- 一項合作任務：三個代理必須從三個箱子裡收集三個代幣；每個箱子只能放一個代幣。代理不能通訊；它們從彼此的行動推斷意圖。
- 兩種設定：`zeroth_order`（沒有 ToM）與 `first_order`（帶一層信念模型的 ToM）。
- 跨 200 次隨機化試驗的量測：完成率、重複率（兩個代理瞄準同一個箱子）、平均完成輪數。

跑：

```
python3 code/main.py
```

預期輸出：第零階代理以約 35% 的比率重複工作，並在 10 輪內完成約 60% 的試驗。第一階 ToM 代理重複率約 5%，完成率約 95%。那個差距就是可量測的協調效應。

## 框架應用

`outputs/skill-tom-auditor.md` 是一項技能，會稽核某套多代理系統對「浮現式協調」的宣稱。檢查提示詞包裝、相對於對照組的統計顯著性，以及量測到的互補性。

## 產出交付

協調宣稱的檢查清單：

- **對照條件。** 你系統中不帶協調提示詞的版本。兩者都要量。
- **統計檢定。** 在你的指標上，系統與對照的差異是否在 `p < 0.05` 顯著？
- **互補性量測。** 隨時間的行動互斥程度，不只是最終成功與否。
- **失敗案例日誌。** 代理協調失誤時，那份 ToM 狀態長什麼樣子？
- **模型能力揭露。** 若這個效果在較小的模型上消失，就說出來。

## 練習

1. 跑 `code/main.py`。確認第一階 ToM 把重複率降低約 7 倍。當你放大到 5 個代理與 5 個箱子時，那個差距還在嗎？
2. 實作第二階 ToM（代理 A 模型化 B 對 C 的想法）。它有比第一階更好嗎？在什麼任務上？
3. 對那份 ToM 狀態注入一個**幻覺**：每輪隨機翻轉一個信念。這讓第一階的表現退化多少？
4. 讀 Li 等人（arXiv:2310.10701）。重現那個「長時程退化」的發現：當輪數從 10 增加到 30 時，你的第一階 ToM 表現怎麼變？
5. 讀 Riedl 2025（arXiv:2510.05174）。在你的模擬日誌上實作那個高階綜效統計量。在沒有 ToM 提示詞條件時，那個效果存在嗎？
