# 心智社会与多智能体辩论

> 明斯基 1986 年的前提——智能是一个专家构成的"社会"——每十年就会被重新发现一次。2023 年，Du 等人将其转化为一个具体的算法：多个 LLM 实例各自提出答案、互相阅读彼此的答案、进行批评并更新。经过 N 轮后，它们收敛到一个共识，在六项推理和事实性任务上击败了零样本思维链（CoT）和自我反思。两个发现很重要：**多个智能体**和**多轮交流**各自独立贡献了收益。智能体社会击败了单一智能体的独白；多轮交流击败了单次投票。

**类型：** 学习 + 构建
**语言：** Python（标准库）
**前置要求：** 阶段 16 · 04（原始模型）
**时长：** 约 60 分钟

## 问题

自洽性——对一个模型多次采样并取多数答案——是你能加装的最廉价的推理改进。它有效，但很快就会饱和。即使样本数量翻倍，也看不到另一个有意义的提升。

辩论打破了这种饱和。与从一个模型独立采样 N 个不同，N 个智能体阅读彼此的推理并进行修正。样本之间的相关性降低了（它们不再是独立同分布的），而收敛点往往在独立同分布的投票曾自信地犯错时是正确的。

## 概念

### Du 等人 2023 年的算法

来自 arXiv:2305.14325（ICML 2024）：

1. N 个智能体各自对问题产生一个初始答案。
2. 对于第 r = 2..R 轮：每个智能体被展示其他智能体在第 r-1 轮的答案，并被要求"考虑这些，给出你更新后的答案。"
3. 经过 R 轮后，对最终答案进行多数投票。

该论文在 MMLU、GSM8K、传记、MATH 和事实性基准上进行了测试。辩论始终优于思维链和自我反思。

### 两个独立的调节旋钮

来自同一论文的消融实验：

- **仅增加智能体数量**（1 轮，N 个智能体多数投票）在大多数任务上优于单一智能体，但会趋于平稳。
- **仅增加轮数**（1 个智能体看到自己之前的推理）几乎没有帮助——这是已知的自我反思的弱点。
- **两者结合**则产生了大幅提升。多个智能体之间的多轮交流驱动了增益。

### 为什么有效

两种机制：

1. **暴露于分歧。** 当一个智能体看到另一个智能体得出不同结论的推理链时，它必须要么论证自己的观点，要么更新。无论哪种方式，第 r+1 轮的上下文都比第 r 轮更丰富。
2. **相关误差减少。** 在自洽性中，所有样本来自同一个模型，因此误差是相关的——你会平均出一个自信的错误答案。不同的模型或不同的种子可以消除相关性。不同的**辩论观点**进一步消除了相关性。

### 异构辩论

A-HMAD 及相关的后续工作为不同的智能体使用**不同的基础模型**。Llama + Claude + GPT 进行辩论可以减少单一文化崩溃（课程 26），因为一个模型家族的相关误差不会被其他模型共享。

缺点：一个参与辩论的弱模型可能会将共识拖向它的错误答案（参见《Should we be going MAD?》，arXiv:2311.17371）。

### NLSOM——129 智能体扩展

Zhuge 等人（《Mindstorms in Natural Language-Based Societies of Mind》，arXiv:2305.17066）将这个想法扩展到 129 名成员的社会。结果是：随着规模扩大，专业化和自组织涌现，该系统在视觉问答等任务上优于单一智能体。

### 失败模式

- **谄媚级联。** 所有智能体都服从于听起来最自信的那个。辩论沦为了最响亮的声音。提示设置对抗性角色（"一个智能体必须论证相反立场"）会有所帮助。
- **主题偏移。** 多轮辩论会偏离原始问题。缓解方法：每轮重新注入问题。
- **计算量爆炸。** N 个智能体 × R 轮 = N·R 次 LLM 调用，每次调用的上下文都在增长。一个 5 智能体、5 轮的辩论需要 25 次调用，且上下文不断增长。每个问题的成本可能超过单次思维链调用的 10 倍。

## 构建它

`code/main.py` 运行一个 3 智能体 × 3 轮的数学问题辩论，每个智能体从一个不同（可能是错误）的答案开始。智能体是脚本化的——每个智能体通过按脚本化置信度加权平均邻居的答案来"更新"。收敛在逐轮日志中可见。

该演示展示了两个关键效果：

- 单轮交流使智能体更接近正确答案。
- 第 2 轮之后的额外轮次收益递减（与 Du 等人的平台期吻合）。

运行：

```
python3 code/main.py
```

## 使用它

`outputs/skill-debate-configurator.md` 为新的任务配置辩论：智能体数量、轮数、异构性（相同模型 vs 混合模型）、角色分配（对称 vs 一个对抗性角色）。它还会在运行前估算 token 成本。

## 交付它

如果你要交付辩论系统：

- **轮数限制在 3 轮。** Du 等人的研究表明 3 轮可以捕获大部分增益。更多轮次只会增加成本，而非质量。
- **智能体数量限制在 5 个。** 超过 5 个，上下文膨胀和成本将占主导地位。
- **默认使用异构模型。** 池中至少使用两种不同的基础模型。
- **设置对抗性角色。** 提示一个智能体无论情况如何都要持反对意见。这可以打破谄媚效应。
- **记录每一轮。** 隐藏中间轮次的辩论系统无法调试或审计。

## 练习

1. 运行 `code/main.py`，然后将轮数设置为 5，观察收益递减。从第几轮开始，额外的收敛停止了？
2. 添加第四个智能体，赋予其对抗性角色：始终反对当前的多数意见。这会破坏还是改善收敛？
3. 绘制（打印）每轮的一致分数（持多数答案的智能体比例）。它何时达到 1.0，这是否等同于"正确"？
4. 阅读 Du 等人的论文第 4 节消融实验。使用此代码复现"仅智能体" vs "仅轮次" vs "两者结合"的结果。
5. 阅读《Should we be going MAD?》（arXiv:2311.17371），列出两种超越轮询的辩论变体——例如，裁判主导式、辩论链式、对抗式。

## 关键术语

| 术语 | 人们怎么说 | 实际含义 |
|------|-----------|---------|
| 心智社会（Society of Mind） | "明斯基的想法" | 智能是相互作用的专家；1986 年的框架现在通过 LLM 辩论得以操作化。 |
| 多智能体辩论（Multi-agent debate） | "智能体互相争论" | N 个智能体提出答案、互相批评、经过 R 轮修订、多数投票。 |
| 共识（Consensus） | "他们达成一致" | 不是认知真理——仅仅是持多数答案的比例。可能自信地犯错。 |
| 轮次（Rounds） | "交换步骤" | 一轮 = 每个智能体阅读其他智能体的答案并更新一次。 |
| 异构辩论（Heterogeneous debate） | "混合模型家族" | 使用不同的基础模型来消除误差相关性。 |
| 谄媚级联（Sycophancy cascade） | "所有人都同意最响亮的那个" | 辩论失败模式，智能体服从于最自信的智能体，无论其是否正确。 |
| NLSOM | "129 智能体社会" | 自然语言心智社会；Zhuge 等人的扩展版本。 |
| 相关误差（Correlated error） | "相同模型，相同缺陷" | 自洽性饱和的原因；跨不同观点的辩论消除了相关性。 |
