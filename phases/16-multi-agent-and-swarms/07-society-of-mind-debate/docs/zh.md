# 心智社會與多代理辯論

> Minsky 1986 年的前提 —— 智慧是一個由專家組成的社會 —— 每隔十年就被重新發現一次。2023 年 Du 等人把它變成一套具體演算法：多個 LLM 實例提出答案、讀彼此的答案、批評，並更新。經過 N 回合，它們收斂到一份共識，在六項推理與事實性任務上勝過零樣本 CoT 與反思。有兩項發現很要緊：**多個代理**與**多個回合**各自獨立地有貢獻。社會勝過單一代理的獨白；多回合交換勝過一次性投票。

**類型：** 學習 + 實作
**程式語言：** Python (stdlib)
**先修單元：** 階段 16 · 04（原語模型）
**時間：** 約 60 分鐘

## 問題

自我一致性 —— 對同一個模型取樣很多次然後取多數答案 —— 是你能栓上去、最便宜的推理改善。它有效，但很快就飽和。你把樣本數翻倍，也不會再看到另一次有意義的躍升。

辯論打破那個飽和。不是從一個模型取 N 個獨立樣本，而是 N 個代理讀彼此的推理並修訂。樣本之間的相關性下降（它們不再是獨立同分布），而那個收斂點，往往在「獨立同分布投票很有自信地答錯」之處是正確的。

## 概念

### Du 等人 2023 年的演算法

出自 arXiv:2305.14325（ICML 2024）：

1. N 個代理各自對問題產出一個初始答案。
2. 對於回合 r = 2..R：把其他代理在第 r-1 回合的答案給每個代理看，並問「考慮這些之後，給出你更新後的答案」。
3. R 回合之後，對最終答案做多數投票。

論文在 MMLU、GSM8K、人物傳記、MATH 與事實性基準上測試。辯論一貫地勝過 CoT 與自我反思。

### 兩個獨立的旋鈕

同一篇論文的消融實驗：

- **只有代理數**（1 回合、N 個答案多數投票）在多數任務上勝過單一代理，但會停在高原。
- **只有回合數**（1 個代理看到自己先前的推理）幾乎沒幫助 —— 這是反思眾所周知的弱點。
- **兩者一起**才產生大躍升。多個代理之間的多回合交換，才是那份收穫的驅動力。

### 它為什麼有效

兩種機制：

1. **暴露於分歧。** 當一個代理看到另一個代理的推理鏈導向不同結論時，它就必須替自己辯護或更新。無論哪一種，第 r+1 回合的脈絡都比第 r 回合更豐富。
2. **降低相關誤差。** 在自我一致性裡，所有樣本都來自同一個模型，所以誤差是相關的 —— 你會平均出一個很有自信的錯答案。不同模型或不同種子會去相關化。不同的*被辯論過的觀點*去相關化得更徹底。

### 異質辯論

A-HMAD 與相關的後續工作，替不同代理使用*不同的基礎模型*。Llama + Claude + GPT 一起辯論，可以減少單一栽培式的塌縮（第 26 課），因為某個模型家族的相關誤差，並不被其他家族共有。

缺點：一個弱模型參與辯論，可能把共識拖向它那個錯答案（見〈Should we be going MAD?〉，arXiv:2311.17371）。

### NLSOM —— 那個 129 代理的延伸

Zhuge 等人（〈Mindstorms in Natural Language-Based Societies of Mind〉，arXiv:2305.17066）把這個構想放大到 129 名成員的社會。結果是：特化與自我組織隨規模浮現，而該系統在視覺問答等任務上勝過單一代理。

### 失敗模式

- **奉承連鎖。** 所有代理都順從那個聽起來最有自信的代理。辯論塌陷成最大聲的那個聲音。用提示詞指派對抗性角色（「必須有一個代理論證反面立場」）會有幫助。
- **主題漂移。** 跨很多回合的辯論會從原始問題飄走。緩解：每一回合都把問題重新注入。
- **運算爆炸。** N 個代理 × R 回合 = N·R 次 LLM 呼叫，而且每次的脈絡都在長大。5 代理、5 回合的辯論就是 25 次呼叫，脈絡遞增。每個問題的成本可能超過單次 CoT 呼叫的 10 倍。

## 動手實作

`code/main.py` 在一道數學題上跑 3 代理 × 3 回合的辯論，每個代理一開始都帶著不同的（可能錯的）答案。代理是腳本化的 —— 每個都靠「用腳本化的信心去加權平均鄰居的答案」來「更新」。收斂在逐回合的日誌裡看得見。

這個示範顯示兩個關鍵效果：

- 單單一回合的交換，就把代理拉近正確答案。
- 第 2 回合之後多加的回合呈現報酬遞減（與 Du 等人的高原相符）。

跑：

```
python3 code/main.py
```

## 框架應用

`outputs/skill-debate-configurator.md` 替一項新任務設定辯論：代理數、回合數、異質性（同模型或混合）、角色指派（對稱或一個對抗者）。它也會在你執行之前估算詞元成本。

## 產出交付

若你要出貨辯論：

- **回合上限設 3。** Du 等人顯示 3 回合就捕捉到大部分收穫。再多是成本，不是品質。
- **代理上限設 5。** 超過 5，脈絡肥大與成本就會主導一切。
- **預設異質。** 池子裡至少要有兩種不同的基礎模型。
- **一個對抗席次。** 一個被提示詞要求無論如何都要唱反調的代理。打破奉承。
- **每一回合都記錄。** 把中間回合藏起來的辯論系統，既除不了錯也稽核不了。

## 練習

1. 跑 `code/main.py`，接著把回合數設成 5，看報酬遞減。到第幾回合，額外的收斂就停了？
2. 加上第四個帶對抗角色的代理：永遠不同意當前的多數。這是打破還是改善了收斂？
3. 畫出（印出）每回合的一致度分數（站在多數答案那一邊的代理比例）。它什麼時候會打到 1.0，而那等同於「正確」嗎？
4. 讀 Du 等人第 4 節的消融實驗。用這份程式碼重現「只有代理」對「只有回合」對「兩者」那個結果。
5. 讀〈Should we be going MAD?〉（arXiv:2311.17371），列出兩種輪替制以外的辯論變體 —— 例如由裁判主持、辯論鏈、對抗式。

## 關鍵術語

| 術語 | 大家怎麼說 | 實際是什麼意思 |
|------|----------------|------------------------|
| 心智社會 | 「Minsky 的構想」 | 智慧就是彼此互動的專家；1986 年的框架如今透過 LLM 辯論被操作化。 |
| 多代理辯論 | 「代理在吵架」 | N 個代理提出答案、互相批評、跨 R 回合修訂，再多數投票。 |
| 共識 | 「它們同意了」 | 不是知識論上的真理 —— 只是「站在多數答案的比例」。可能很有自信地錯。 |
| 回合 | 「交換步驟」 | 一回合 = 每個代理讀過其他人並更新一次。 |
| 異質辯論 | 「混不同的模型家族」 | 用不同的基礎模型來去相關化誤差。 |
| 奉承連鎖 | 「大家都同意那個最大聲的」 | 一種辯論失敗：代理不論正確與否都順從最有自信的那個。 |
| NLSOM | 「129 代理的社會」 | 自然語言式的心智社會；Zhuge 等人放大後的版本。 |
| 相關誤差 | 「同一個模型、同一個臭蟲」 | 自我一致性為何飽和；跨不同觀點的辯論會去相關化。 |
