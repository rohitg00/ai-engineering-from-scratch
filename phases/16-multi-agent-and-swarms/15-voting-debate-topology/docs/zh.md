# 投票、自我一致性與辯論拓撲

> 最便宜的彙整方式：取樣 N 個獨立代理，多數決。Wang 等人 2022 年的自我一致性，是用一個模型取樣 N 次來做這件事。多代理則用**異質**代理把它延伸出去，藉此逃離單一栽培 —— 不同模型、不同提示詞、不同溫度、不同脈絡。在多數決之外，辯論拓撲也很要緊：MultiAgentBench（arXiv:2503.01935，ACL 2025）評測了星形／鏈形／樹形／圖形的協調，發現**圖形對研究最好**，而且超過約 4 個代理就出現「協調稅」。AgentVerse（ICLR 2024）記錄了兩種浮現樣式 —— 自願行為與從眾行為 —— 而從眾既是功能（找到共識）也是風險（團體迷思，第 24 課）。這一課把拓撲空間畫出來、把每種變體建出來，並量測那筆協調稅。

**類型：** 學習 + 實作
**程式語言：** Python (stdlib)
**先修單元：** 階段 16 · 07（心智社會與辯論）、階段 16 · 14（共識與 BFT）
**時間：** 約 75 分鐘

## 問題

辯論可以改善準確率（Du 等人，arXiv:2305.14325）。它也可以讓準確率退化。辯論有沒有幫助，取決於四項結構性選擇：

1. 誰跟誰講話（拓撲）。
2. 幾回合（Du 2023：回合數與代理數各自獨立地要緊）。
3. 代理是否異質（不同的基礎模型會打破單一栽培）。
4. 有沒有對抗性的聲音（把對方論點做強 vs 做稻草人）。

那些把「跑 5 個代理然後投票」栓到任務上的團隊，往往退步到比單一代理還差。那些失敗不是隨機的。它們跟拓撲與異質性走。這一課就是那張拓撲地圖。

## 概念

### 自我一致性，那條單一模型基線

Wang 等人 2022 年（〈Self-Consistency Improves Chain of Thought Reasoning〉）在 temperature > 0 下對同一個模型取樣 N 次，並對推理路徑的答案做多數決。在 GSM8K 上的結果：N=40 個樣本相對於單次貪婪解碼有相當大的收穫。自我一致性是多代理投票的單一代理前身。

侷限：自我一致性只用一個基礎模型。誤差在構造上就是相關的。若那個模型有系統性偏誤，全部 N 個樣本都共享它。

### 多代理投票，那個異質延伸

把 N 個樣本換成 N 個*不同的*代理。不同的基礎模型（Claude、GPT、Llama）、不同的提示詞、不同的工具存取。好處：誤差不相關。代價：不同代理成本不同；協調它們會增加開銷。

異質辯論在 2026 年的典範名稱是 **A-HMAD** —— 對抗式異質多代理辯論。並非人人採用，但論文用這個詞指「不同模型辯論，藉此降低單一栽培塌縮造成的相關誤差」。

### 四種拓撲

```
star                chain               tree                graph

    ┌─A─┐           A─B─C─D         ┌──A──┐              A───B
    │   │                           │     │              │ × │
    B   C                           B     C              D───C
    │   │                          / \   / \
    D   E                         D   E F   G           (fully connected)
```

星形：一個樞紐，其他人只跟樞紐講話。等同於沒有回頭通道的 supervisor-worker。
鏈形：線性，每個代理看到前一個的輸出。像管線。
樹形：階層式，被階層式代理系統使用（第 06 課）。
圖形：任意對任意。包含完全連通的團與任意 DAG。

### 那筆協調稅（MultiAgentBench）

MultiAgentBench（MARBLE，ACL 2025，arXiv:2503.01935）在一組涵蓋研究、寫程式與規劃的任務套組上，替星形、鏈形、樹形、圖形做了基準測試。量到的關鍵結果：

- **圖形**拓撲在研究任務上勝出。資訊任意對任意地流動；代理可以互相批評。
- **星形**在講求快答的事實性任務上勝出。樞紐負責過濾與整合。
- **鏈形**在逐步管線（分階段精修）上勝出。
- **協調稅**在圖形拓撲超過約 4 個代理時出現。牆鐘與詞元成本長得比品質快。

那個 4 代理天花板是經驗性的，不是根本性的。它反映的是 2026 年 LLM 的脈絡容量：每個代理的脈絡都被同儕的輸出填滿，而一旦大家都看得到大家，加上第 N+1 個代理的邊際價值就下降。

### 多代理辯論策略（〈Should we be going MAD?〉）

arXiv:2311.17371 是 2023 年那份 MAD 策略綜述。被其他人重現的關鍵發現是：那些在*結構上類似*自我一致性（獨立取樣 + 彙整）的 MAD 變體，在同樣預算下往往不如自我一致性。MAD 最有幫助的時候，是代理真的異質、而且辯論帶有對抗性結構（有一個代理站反面論證）。

### AgentVerse 的浮現樣式

AgentVerse（ICLR 2024，https://proceedings.iclr.cc/paper_files/paper/2024/file/578e65cdee35d00c708d4c64bce32971-Paper-Conference.pdf）記錄了兩種即使沒有明確設計、也會從多代理辯論中浮現的行為：

- **自願。** 一個代理未經提示就主動提供協助（「我可以接下一步」）。有用：它把工作分配給某個子任務上最有能力的代理。
- **從眾。** 一個代理調整自己的立場去迎合批評者，就算批評者是錯的。這是辯論版的奉承（第 14 課）。

從眾正是「辯到達成一致」會獎勵霸凌者的原因。用有界回合加一個獨立裁判來緩解。

### 異質性：那個真正會撥動準確率的旋鈕

2024-2026 年實務文獻中的一個樣式：把你 N 個代理中的一個換成不同的基礎模型，帶來的準確率提升，比把 N 加 1 還大。直覺就是單一栽培 —— 每一個新的獨立誤差源，都比多一個相關樣本更值錢。

在極限上，異質性勝過數量。在多數有乾淨基準真值的任務上，三個不同模型勝過同一個模型的五份副本。

### 陪審團方法

Sibyl 框架（在 Minsky-LLM 文獻中被引用）把「陪審團」形式化 —— 一小組特化的代理，在每個階段用投票精修答案。與單純的多數決不同，陪審團有角色：一個代理交叉詰問、一個提供脈絡、一個替可信度評分。陪審團方法介於單純投票（便宜、易陷單一栽培）與完整 MAD（昂貴、易陷從眾）之間。

### 投票加辯論占上風的時候

- 問題有基準真值（事實、數學、程式碼行為）。投票收斂才有意義。
- 代理能存取不同來源或工具（異質性可得）。
- 回合有界（典型 2-3），而且有獨立的裁判或查證者。
- 預算容得下 3-5 個代理。在圖形拓撲上超過 5-7 個，協調稅就主導一切。

### 投票加辯論有害的時候

- 問題是意見型的。代理會收斂到看起來最有自信、而不是最正確的那個答案。
- 所有代理共用一個基礎模型。單一栽培讓共識毫無意義。
- 回合無界。從眾每次都贏。
- 任務很簡單。單一代理配 N=5 的自我一致性又便宜又一樣準。

## 動手實作

`code/main.py` 實作了：

- `run_star(agents, hub, question)` —— 樞紐輪詢每個 worker，然後彙整。
- `run_chain(agents, question)` —— 循序精修。
- `run_tree(root, children, question)` —— 深度 2 彙整的階層式。
- `run_graph(agents, question, rounds)` —— 全對全辯論，回合有界。
- 一個腳本化的異質性旋鈕：每個代理有一個 `error_bias`，表示它的系統性錯誤傾向。
- 一套量測執行框架，讓每種拓撲在 N=3、5、7 各跑一次，並回報 (accuracy, total_tokens, wallclock_simulated)。

跑：

```
python3 code/main.py
```

預期輸出：一張 拓撲 × N → (準確率, 詞元, 延遲) 的表格。在研究型任務上，圖形在 N=3-5 時勝出；在快答事實型任務上，星形勝出；N=7 的圖形則顯示出協調稅（延遲膨脹得比準確率快）。

## 框架應用

`outputs/skill-topology-picker.md` 是一項技能，會讀一段任務描述，並建議一種拓撲（星形／鏈形／樹形／圖形）、一個 N（代理數）、一份異質性輪廓（要用哪些基礎模型），以及一個回合上限。

## 產出交付

對任何集成：

- 先從用單一強基礎模型的 **N=5 自我一致性**開始。那是便宜的基線。
- 若準確率要緊，就升級到 **N=3 的異質投票**。量那個差距。
- 只有在任務有結構（研究、多步驟）且有界回合可行時，才升級到**辯論拓撲**。
- 永遠記錄那個少數群。當少數持續是對的，你就有了一個多樣性訊號。
- 把牆鐘與詞元跟準確率一起做基準測試。「準確率更好，但成本 10 倍」是一項商業決策。

## 練習

1. 跑 `code/main.py`。替圖形拓撲畫出協調稅曲線：準確率對 N、詞元對 N。曲線在哪個 N 出現反曲？
2. 實作 A-HMAD：三個帶刻意不同偏誤的代理。在第 14 課那個單一栽培攻擊上，全同偏誤的基線跟 A-HMAD 相比如何？
3. 替圖形拓撲加一個「裁判」角色：它不投票，只替最終共識評分。這會改變那個浮現的從眾行為嗎？
4. 讀 AgentVerse 論文（ICLR 2024）。指認出你的實作最強烈展現哪一種浮現行為。你能靠改提示詞誘導出相反的行為嗎？
5. 讀 MultiAgentBench（arXiv:2503.01935）第 4 節（拓撲實驗）。用你的執行框架，在論文中的一項任務上重現那個「圖形贏研究」的結果。

## 關鍵術語

| 術語 | 大家怎麼說 | 實際是什麼意思 |
|------|----------------|------------------------|
| 自我一致性 | 「取樣 N 次然後投票」 | Wang 2022。單一模型、N 個 temperature>0 的樣本，對推理路徑做多數決。 |
| 異質性 | 「不同的模型」 | 由不同基礎模型或提示詞家族組成的集成。打破單一栽培。 |
| MAD | 「多代理辯論」 | 代理跨回合交換批評的通稱。見 Du 2023。 |
| A-HMAD | 「對抗式異質 MAD」 | 強調不同模型 + 對抗性結構的 MAD 變體。 |
| 拓撲 | 「誰跟誰講話」 | 星形、鏈形、樹形、圖形。決定資訊怎麼流。 |
| 協調稅 | 「報酬遞減」 | 在圖形上超過約 4 個代理，成本長得比品質快。 |
| 自願行為 | 「未經提示的協助」 | AgentVerse 的浮現樣式：一個代理主動提出要接手一步。 |
| 從眾行為 | 「壓力下的同意」 | AgentVerse 的浮現樣式：一個代理去迎合批評者。 |
| 陪審團 | 「小型的特化評審團」 | Sibyl 式、帶角色（詰問者、脈絡提供者、評分者）的集成。 |
