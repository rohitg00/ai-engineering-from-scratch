给定一个任务描述，推荐多智能体拓扑和规模。

生成以下内容：

1. **任务指纹**。研究型（长时间、开放式）、快速事实型（封闭式答案）、逐步细化型（阶段式流水线）或观点型（无真实依据）。选择其一；如果跨越两个，选择主导形态。
2. **拓扑**。星型、链型、树型或图型。根据指纹说明理由：
   - 研究型 → 图型（任意对任意批评）
   - 快速事实型 → 星型（中心聚合）
   - 逐步细化型 → 链型（或树型，如果是分治法）
   - 观点型 → 以上皆非；推荐单智能体 + 人类决策
3. **智能体数量 N**。3 是最便宜的有用集成；5 是常见的最佳点；7+ 是特例。在图型拓扑上超过 5 时，警告协调税。
4. **异质性概况**。如果单一文化很重要（研究、推理），至少一个智能体必须来自不同的基础模型系列。N=5 时更喜欢 3 个不同的基础模型。
5. **轮次上限**。1 轮 = 投票。2 轮 = 一次细化。3 轮 = 从众主导前的最大值。永远不要无界。
6. **聚合**。多数制（便宜）、置信度加权（第 14 课的 CP-WBFT）、中位数几何稳健性（DecentLLMs）或裁判评分。默认为置信度加权，除非成本限制要求多数制。
7. **升级**。低于阈值的共识 → 升级到哪里？人工、另一个具有不同基础模型的集成，还是弃权？

硬性拒绝：

- 任何在图型拓扑上推荐 10+ 个智能体的方案。协调税占主导；先测量。
- 针对开放研究问题的星型拓扑。星型失去了任意对任意批评的好处。
- 任何将同一基础模型运行 N 次并称之为多智能体的推荐。那是伪装的自一致性；正确标记。
- 无界轮次。奖励从众；辩论时间越长，智能体越趋于通过压力而非逻辑达成一致。

拒绝规则：

- 如果任务没有真实依据（观点、综合、创意），说明投票是建议性的。推荐单智能体 + 人类决策。
- 如果用户无法访问多个基础模型，标记单一文化上限并推荐带有温度变化的自一致性作为后备。
- 如果任务很简单（单次事实查找，< 100 令牌的推理），推荐使用自一致性 N=5 的单智能体。

输出：一页简报。以一句话推荐开头（"图型拓扑，来自 3 个不同基础模型的 N=5 智能体，2 轮，置信度加权聚合，低于阈值时升级给人类"），然后是上述七个部分。以预算估算结尾：每次查询的预期令牌数和预期延迟秒数。
