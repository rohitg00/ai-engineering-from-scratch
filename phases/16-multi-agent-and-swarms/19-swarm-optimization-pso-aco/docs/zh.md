# 面向LLM的群体智能优化（PSO、ACO）

> 仿生优化正在LLM领域卷土重来。**LMPSO**（arXiv:2504.09247）将PSO应用于提示词优化——每个粒子的速度就是一个提示词，LLM根据该提示生成下一个候选解；该方法在结构化序列输出（数学表达式、程序）上表现良好。**Model Swarms**（arXiv:2410.11163）将每个LLM专家视为模型权重流形上的一个PSO粒子，在9个数据集上仅用200个实例就实现了**相比12个基线平均提升13.3%**。**SwarmPrompt**（ICAART 2025）将PSO与灰狼优化混合用于提示词优化。**AMRO-S**（arXiv:2603.12933）提出了一种受ACO启发的信息素专家机制用于多智能体LLM路由——实现**4.7倍加速**、可解释的路由证据，以及将推理与学习解耦的质量门控异步更新。本课程在提示词参数空间上实现PSO，在智能体路由上实现ACO，评测这些经典算法为何适合LLM时代，以及何时不适合。

**类型：** 学习 + 构建
**语言：** Python（标准库）
**前置课程：** 阶段 16 · 09（并行群体网络），阶段 16 · 14（共识与BFT）
**时长：** 约75分钟

## 问题

你有一条提示词，在任务评估中得分为62%。你想改进它。最直接的方式是无梯度的手动调优，但这难以扩展。强化学习需要奖励信号和足够的采样回合来训练。通过提示词进行反向传播实际上是不可能的——提示词是离散字符串，不是可微参数。

经典的仿生优化——PSO用于连续搜索空间，ACO用于路径选择——正是为这种场景设计的：无梯度、基于种群、单次评估成本低廉。将它们与LLM结合用于无梯度搜索步骤，你就得到了一个出奇实用的优化器。

同样的模式也适用于多智能体系统中的智能体*路由*。ACO风格的信息素轨迹记录了哪个智能体在哪种任务类型上表现最佳，让路由器可以利用该轨迹，同时信息素会衰减，使路由可以被重新发现。

## 概念

### PSO 速览（Kennedy & Eberhart 1995）

粒子群优化（Particle Swarm Optimization）：在一个连续搜索空间中有一个粒子种群。每个粒子具有位置 `x_i` 和速度 `v_i`。每次迭代：

```
v_i <- w * v_i + c1 * r1 * (p_best_i - x_i) + c2 * r2 * (g_best - x_i)
x_i <- x_i + v_i
评估适应度(x_i)
如果改进则更新 p_best_i
如果为全局最优则更新 g_best
```

其中 `p_best` 是粒子自身的最优解，`g_best` 是群体最优解，`w, c1, c2` 分别是惯性权重、认知权重和社会权重，`r1, r2` 是随机因子。

### PSO 应用于 LLM 输出——LMPSO

arXiv:2504.09247 将 PSO 适配到 LLM 生成的结构化输出（数学表达式、程序）。每个粒子是一个候选输出。速度是一个*提示词*，描述了如何修改当前输出以趋近个体/全局最优。LLM 根据速度提示词生成新的输出。速度的"惯性"由类似"做小幅增量修改"的提示词来体现。

该方法在以下情况下效果良好：
- 输出是结构化的（可解析、可评估）。
- 适应度是自动计算的（测试运行、算术评估）。
- 种群规模小（约10-30个粒子），使 LLM 调用总量保持可控。

当适应度需要人工评审时效果不佳——每轮迭代的成本会变得过高。

### Model Swarms

arXiv:2410.11163 将 PSO 从输出层移到了*模型*层。每个"粒子"是一个专家 LLM（参数）。群体通过无梯度更新将参数向集体最优移动。报告显示：在9个数据集上，相比12个基线平均提升13.3%，每轮迭代仅需200个实例。

其关键洞察是：LLM 专家模型在共享的参数流形（适配器权重、LoRA 增量）上已经彼此靠近。在这个低维子空间上进行 PSO 既廉价又有效。

### ACO 速览（Dorigo 1992）

蚁群优化（Ant Colony Optimization）：蚂蚁遍历一个图；每条路径上都有信息素轨迹。蚂蚁移动的概率由信息素强度加权。完成任务的蚂蚁根据解的质量沉积信息素。信息素随时间衰减。

### AMRO-S——用于智能体路由的 ACO

arXiv:2603.12933 将 ACO 用于多智能体路由。每种任务类型是一个"目的地"，每个智能体是一条可能的路径。信息素强化那些产生良好输出的路径。主要贡献：

- **可解释的路由证据。** 信息素强度是人类可读的信号。
- **质量门控异步更新。** 信息素仅在质量检查通过后更新，将推理与学习解耦。
- **在多智能体路由基准上实现4.7倍加速。**

质量门控很关键：没有它，快速但错误的智能体会积累信息素，系统会锁定在不良路径上。

### 何时为 LLM 使用 PSO / ACO

**使用 PSO 当：**
- 搜索空间是连续的或可以映射到连续参数（提示词嵌入、LoRA 权重、数值生成参数）。
- 适应度评估廉价且自动化。
- 种群可以很小（10-30）。

**使用 ACO 当：**
- 面临路由或路径选择问题。
- 决策会随时间强化（相同任务类型反复出现）。
- 需要路由决策的可解释证据。

**不要使用两者当：**
- 适应度需要人工评审（每轮迭代成本过高）。
- 搜索空间是离散且组合的，PSO 无法覆盖（此时应使用遗传算法）。
- 实时决策需要严格的低延迟（PSO/ACO 收敛速度慢于单次启发式方法）。

### 为什么仿生方法仍然胜出

基于梯度的方法需要可微信号。LLM 输出和路由决策并非平凡可微。伪梯度方法（强化学习路由器、DPO 风格的提示词调优器）有效但需要昂贵的训练。

PSO 和 ACO 只需要一个*评估器*函数。只要能给候选输出或路由决策打分，就能在该空间上进行优化。这使得应用门槛大大降低。

### 实际限制

- **种群预算。** N 个粒子 × T 轮迭代 × 单次评估成本。以每次 LLM 调用约 $0.02 计算，一个 20 粒子的 PSO 运行 50 次迭代大约花费 $20。请据此规划。
- **探索与利用。** 信息素衰减率和 PSO 惯性权重之间存在权衡；衰减太快会遗忘解；衰减太慢会陷入早期局部最优。
- **灾难性漂移。** 如果适应度景观发生变化（新的数据分布），两种算法都可能收敛后发散。监控最优适应度的稳定性。

## 动手构建

`code/main.py` 实现了：

- `LMPSO`——对数值型提示词参数（温度、top_k 权重）进行 PSO 优化。每个粒子的"LLM 生成"通过脚本化的适应度函数模拟。算法运行30次迭代，展示 g_best 收敛过程。
- `AMRO_S`——ACO 风格路由。3个智能体，4种任务类型，信息素矩阵，100个路由任务。输出随时间的（任务类型→智能体选择）分布，展示轨迹形成过程。
- 对比：同一任务流上的随机路由 vs ACO 路由。衡量质量和延迟。

运行：

```
python3 code/main.py
```

预期输出：
- LMPSO：g_best 适应度在30次迭代内从随机值提升到接近最优。
- AMRO-S：信息素表稳定在每种任务类型对应的正确智能体上；ACO 路由在质量上比随机路由提升约30-40%，同时延迟更低（重试次数更少）。

## 交付要点

- **从小开始。** 10-20个粒子，20-50轮迭代。只有当收敛曲线显示明显增益时才扩大规模。
- **记录每轮的信息素或 g_best。** 在没有轨迹记录的情况下调试群体优化器是痛苦的。
- **质量门控更新。** 尤其是对于 ACO 路由：快速但错误的智能体绝不能积累信息素。
- **在分布漂移时重置衰减。** 当评估分布发生变化时，老化的信息素已经过时；临时重置或加倍衰减率。
- **限制每轮迭代成本。** 输出每次迭代的成本指标。如果 PSO 每轮迭代花费 $500 而只带来 0.5% 的提升，那就不具备交付价值。

## 关键术语

| 术语 | 大家说的 | 实际含义 |
|------|----------|----------|
| PSO | "粒子群优化" | Kennedy-Eberhart 1995。基于种群的无梯度优化器。 |
| ACO | "蚁群优化" | Dorigo 1992。通过信息素轨迹进行路径/路由优化。 |
| LMPSO | "带LLM生成的PSO" | arXiv:2504.09247。速度是提示词；LLM生成候选解。 |
| Model Swarms | "专家权重的PSO" | arXiv:2410.11163。模型参数子空间上的无梯度更新。 |
| AMRO-S | "用于智能体路由的ACO" | arXiv:2603.12933。任务类型×智能体的信息素矩阵。 |
| p_best / g_best | "个体最优 / 全局最优" | 每个粒子和整个群体迄今为止发现的最优解。 |
| 信息素 | "路由记忆" | 边上的强度；随时间衰减；在高质量结果时沉积。 |
| 质量门控更新 | "只从好的运行中学习" | 信息素沉积以质量检查为条件。 |
| 灾难性漂移 | "分布偏移" | 适应度景观发生变化；旧的 p_best 和信息素变得过时。 |
