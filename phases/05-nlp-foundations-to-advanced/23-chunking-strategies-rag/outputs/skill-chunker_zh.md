给定一个语料库（文档类型、平均长度、领域）和查询分布（事实型 / 分析型 / 多跳），输出：

1. 策略。递归 / 句子 / 语义 / 父文档 / 延迟 / 上下文。说明理由。
2. 块大小。词元数量。理由与查询类型相关。
3. 重叠量。默认为0；如果大于0则说明理由。
4. 最小/最大限制。`min_tokens`、`max_tokens` 保护措施。
5. 评估计划。在50个查询的分层评估集（事实型、分析型、多跳）上的 Recall@5。

拒绝任何没有最小/最大块大小限制的分块策略。拒绝超过20%的重叠量，除非有消融实验证明其有效。将没有最小词元下限的语义分块推荐标记出来。
