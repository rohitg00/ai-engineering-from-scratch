给定一个用例（领域知识库、语言、数据量、延迟预算），输出：

1. 知识库。Wikidata / Wikipedia / 自定义知识库。版本日期。更新频率。
2. 候选生成器。别名索引、嵌入向量或混合方式。目标提及召回率 @ K。
3. 消歧器。先验 + 上下文、基于嵌入向量、生成式或 LLM 提示式。
4. NIL 策略。基于最高分数的阈值、分类器或显式 NIL 候选。
5. 评估。在保留集上的 Mention Recall @ 30、top-1 准确率、NIL 检测 F1。

拒绝任何没有提及召回率基线的实体链接流水线（不了解候选生成是否返回了正确实体就无法评估消歧器）。拒绝任何使用 LLM 提示式实体链接但不将输出约束到有效知识库 ID 的流水线。标记那些流行度偏差影响少数实体（例如名称冲突）且没有领域微调的系统。
