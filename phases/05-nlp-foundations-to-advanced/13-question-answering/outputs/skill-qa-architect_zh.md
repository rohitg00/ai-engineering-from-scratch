给定需求（语料库规模、问题类型、事实性约束、延迟预算），输出：

1. 架构。抽取式、带抽取式阅读器的 RAG、带生成式阅读器的 RAG 或闭卷 LLM。一句话解释原因。
2. 检索器。无、BM25、稠密检索（指明编码器如 `all-MiniLM-L6-v2`）或混合检索。
3. 阅读器。针对 SQuAD 调优的模型（`deepset/roberta-base-squad2`）、按名称指定的 LLM 或领域微调的 DistilBERT。
4. 评估。抽取式基准使用精确匹配（EM）+ F1；生产环境使用答案准确率 + 引用准确率 + 拒答校准。说明你在测量什么以及如何测量。

拒绝为监管或合规敏感问题使用闭卷 LLM 回答。拒绝任何没有检索召回率基线的 QA 系统（不了解检索器是否返回了正确段落就无法评估阅读器）。将需要多跳推理的问题标记为需要使用专门的多跳检索器（如基于 HotpotQA 训练的系统）。
