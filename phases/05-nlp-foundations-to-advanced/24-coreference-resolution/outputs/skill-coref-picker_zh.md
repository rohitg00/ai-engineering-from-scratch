给定一个用例（单文档 / 多文档、领域、语言），输出：

1. 方法。基于规则 / 神经跨度式 / LLM 提示式 / 混合式。一句话解释原因。
2. 模型。如果是神经方法，指定检查点。
3. 集成。操作顺序：分词 → NER → 指代消解 → 下游任务。
4. 评估。在保留集上的 CoNLL F1（MUC + B³ + CEAF-φ4 平均值）+ 在20份文档上的人工聚类检查。

拒绝在超过2000词元的文档上使用仅 LLM 的指代消解，除非采用滑动窗口合并。拒绝任何在没有提及级精确率-召回率报告的情况下运行指代消解的流水线。将在人口多样化的文本中部署基于性别启发式系统的方案标记出来。
