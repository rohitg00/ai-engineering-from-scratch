给定一个语料库（领域、语言、数据量）和下游用途（KG-RAG、分析、合规），输出：

1. 抽取器。基于模式 / 监督式 / LLM / AEVS 混合。理由与精确率 vs 召回率目标相关。
2. 本体。封闭属性列表（Wikidata / 领域）或带规范化处理的开源信息抽取。
3. 来源追踪。每个三元组携带源文本的字符跨度 + 文档 ID。对于审计不可协商。
4. 合并策略。规范化实体 ID + 关系 ID + 时间限定符；去重策略。
5. 评估。在200个人工标注三元组上的精确率/召回率 + LLM 抽取样本上的幻觉率。

拒绝任何没有跨度验证（来源追踪）的基于 LLM 的关系抽取流水线。拒绝将没有规范化的开源信息抽取输出流入生产图数据库。标记那些在有时限的关系（雇主、配偶、职位）上没有时间限定符的流水线。
