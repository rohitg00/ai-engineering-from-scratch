给定一个用例（RAG / 智能体 / 生成式任务），输出：

1. 指标。忠实度 / 相关性 / 上下文精确率 / 上下文召回率 + 任何带评估标准的自定义 G-Eval 指标。
2. 评判模型。指定模型 + 版本，说明成本 vs 准确率的权衡理由。
3. 校准。人工标注集规模，目标 Spearman ρ 与人类 > 0.7。
4. 数据集版本管理。标签策略、变更日志、分层抽样。
5. CI 门控。每个指标的阈值、回归窗口逻辑、底部四分位数告警。

拒绝依赖未经≥50个人工标注示例测试的评判模型。拒绝自我评估（同一模型既生成又评判）。拒绝仅聚合报告而不展示底部10%的数据。将任何评判模型升级未同时进行并行基线评估的流水线标记出来。
