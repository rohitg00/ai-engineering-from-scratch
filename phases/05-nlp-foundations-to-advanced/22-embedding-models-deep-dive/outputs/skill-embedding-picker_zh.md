给定一个语料库（规模、语言、领域、平均长度）、部署目标（云端 / 边缘 / 本地）、延迟预算和存储预算，输出：

1. 模型。指定检查点或 API。一句话解释原因。
2. 维度。完整 / Matryoshka 截断 / int8 量化。理由与存储预算相关。
3. 模式。稠密 / 稀疏 / 多向量 / 混合。说明理由。
4. 查询前缀/模板（如果模型卡片要求）。
5. 评估计划。与领域相关的 MTEB 任务 + 使用 nDCG@10 的保留领域评估。

拒绝在无领域验证的情况下将 Matryoshka 截断至小于64维。拒绝为少于10k段落的语料库推荐 ColBERTv2（开销不合理）。将长文档语料库（超过8k词元）路由到具有512词元窗口的模型标记出来。
