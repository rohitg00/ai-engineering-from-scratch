给定一个目标模型、目标上下文长度和用例，输出：

1. 测试。NIAH 深度 × 长度网格；RULER 多跳；自定义领域任务。
2. 采样。在每个长度上使用深度 0、0.25、0.5、0.75、1.0。
3. 指标。检索通过率；推理通过率；首词元时间；每次查询成本。
4. 截断点。有效检索长度（90%通过率）和有效推理长度（70%通过率）。两者都报告。
5. 回归。固定测试框架，每次模型升级时重新运行，展示差异。

拒绝仅信任模型卡片上的上下文窗口声明。拒绝任何多跳工作负载仅使用 NIAH 评估。拒绝将供应商自行报告的长上下文分数视为独立证据。
