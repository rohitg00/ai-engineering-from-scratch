给定源文本和候选翻译，输出：

1. 自动评分估计。预期 BLEU 和 chrF 范围。说明是否有参考译文可用。
2. 五点人工可验证检查清单：内容保留（无幻觉）、正确的目标语言、语域/正式度匹配、与词汇表（如有提供）的术语一致性、无截断或长度爆炸。
3. 一个需要探查的领域特定问题。法律：命名实体、法规引用。医疗：药物名称、剂量。用户界面：像 `{name}` 这样的占位符变量。
4. 置信标志。"可发布" / "需审核后发布" / "不可发布"。与发现问题的严重程度挂钩。

拒绝在没有输出语言身份（language-ID）检查的情况下发布。拒绝在没有参考译文的情况下评估，除非用户明确选择使用无参考评分（COMET-QE、BLEURT-QE）。将超过1000词元的内容标记为可能需要分块翻译。
