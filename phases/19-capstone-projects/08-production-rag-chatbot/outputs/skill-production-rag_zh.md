给定一个受监管领域的语料库（法律合同、临床试验方案、保险政策或类似内容），部署一个聊天机器人，以可验证的引用来回答，尊重角色和管辖区域的访问策略，并监控漂移。

构建计划：

1. 使用 docling 或 Unstructured 解析语料库；将视觉丰富的文档通过 ColPali 路由。输出带有角色和管辖区域标签的块。
2. 将稠密向量（Voyage-3 或 Nomic-embed-v2）索引到 pgvector + pgvectorscale；通过 Tantivy 进行稀疏 BM25。
3. 连接 LangGraph 对话智能体：检索（按角色 + 管辖区域过滤、混合稠密+BM25、倒数排名融合）、重新排序（bge-reranker-v2-gemma-2b 或 Voyage rerank-2）、合成（Claude Sonnet 4.7 带提示缓存）。
4. 使用稳定的前缀组装提示：系统前导 -> 策略块 -> 重新排序的上下文 -> 用户查询。目标：60-80% 的提示缓存命中率。
5. 护栏：输入和输出的 Llama Guard 4、用于域外和策略禁止问题的 NeMo Guardrails v0.12 轨道、输出的 Presidio PII 清洗、强制引用后过滤器。
6. 构建一个 200 问题的专家标记黄金集（含答案、引用）。在精确引用匹配、答案正确性、RAGAS 忠实度上评分。
7. 构建一个 50 提示的红队（PAIR、TAP、PII 提取、域外、跨管辖区域探测）。
8. Arize Phoenix 漂移仪表板，跟踪每周检索 nDCG 和引用忠实度；下降 5% 时发出警报。
9. Langfuse 成本报告：提示缓存命中率、每次查询的令牌数、按阶段划分的 $/query。

评估量规：

| 权重 | 标准 | 衡量方法 |
|:-:|---|---|
| 25 | RAGAS 忠实度 + 答案相关性 | 200 问题黄金集上的在线分数 |
| 20 | 引用正确性 | 具有可验证来源锚点的答案比例 |
| 20 | 护栏覆盖率 | Llama Guard 4 通过率 + 越狱套件结果 |
| 20 | 成本/延迟工程 | 提示缓存命中率、p95 延迟、$/query |
| 15 | 漂移监控仪表板 | 实时 Phoenix 仪表板，每周检索质量趋势 |

硬性拒绝：

- 任何泄露跨管辖区域数据的聊天机器人。角色+管辖区域过滤必须在检索前执行，而不是之后。
- 破坏缓存前缀的合成提示（在系统和上下文之间重新排序策略）。会破坏缓存经济性。
- 没有记录红队运行的护栏配置。
- 没有引用的答案；没有可验证锚点的引用。

拒绝规则：

- 拒绝在没有管辖区域标签的情况下在受监管领域部署每个块。
- 拒绝在专家标记黄金集问题上训练检索。污染会破坏评估可信度。
- 拒绝在没有 README 中明确的 SOC2/HIPAA/GDPR 适用性矩阵的情况下声称"合规"。

输出：一个包含摄取管道、LangGraph 对话智能体、200 问题黄金集、50 提示红队、Phoenix 漂移仪表板、Langfuse 成本仪表板，以及一份说明您观察到的前三大引用断裂模式及每种模式的检索或提示修复的仓库。
