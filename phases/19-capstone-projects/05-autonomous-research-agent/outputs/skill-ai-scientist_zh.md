给定一个种子想法、一个狭窄领域和 30 美元的计算预算，构建一个智能体，运行实验树搜索，编写可审阅的 LaTeX 论文，并生成可复现性包。

构建计划：

1. 文献检索：Semantic Scholar Graph API + OpenAlex；在 FAISS 中缓存摘要；生成 1 页的领域摘要。
2. 树搜索：对实验节点实现最佳优先扩展，使用 `expand(node) -> children`（每个子节点一个配置更改）和 `score(node) = novelty*0.4 + quality*0.5 + budget*0.1`。
3. 每节点沙箱：每个实验在 `docker run --network=none --memory=8g --cpus=2 --pids-limit=256 --read-only` 或 E2B 等效环境中运行；确定性种子；强制资源上限。
4. 计划-执行-验证：验证步骤检查损失是否收敛、基线是否运行、消融实验是否隔离了声明。
5. 写作者：生成 LaTeX，编译为 PDF，将 PDF 输入 Claude Opus 4.7 视觉模式进行布局和声明-证据对齐的批评，最多迭代 3 次。
6. 审稿人集成：五名评审（Opus 4.7、GPT-5.4、Gemini 3 Pro、DeepSeek R1、Qwen3-Max）按 NeurIPS 量规评分（新颖性、严谨性、清晰度、可复现性、影响力）；平均分 < 4.0 返回给写作者。
7. 红队：集成对抗性任务（fork 炸弹、文件系统逃逸、LLM 编写的网络调用）。确认全部被阻止。输出 `red_team.md`。
8. 可复现性包：paper.pdf + review.md + 树搜索跟踪 JSON + 种子 + W&B 运行链接 + 沙箱配置 + 一行重新运行命令。

评估量规：

| 权重 | 标准 | 衡量方法 |
|:-:|---|---|
| 25 | 论文质量 | 在同一种子主题上对照已发表工作坊论文进行盲审量规评审 |
| 20 | 实验严谨性 | 基线、种子、消融实验；每个声明都有结果表中的单元格支持 |
| 20 | 成本和计算纪律 | 每篇论文强制 30 美元上限，Langfuse 跟踪 |
| 20 | 安全性 | 沙箱红队通过；网络策略和终止开关已验证并记录尝试 |
| 15 | 可复现性 | 一行命令使用相同种子重新运行可复现论文 |

硬性拒绝：

- 在沙箱外运行的实验。整个顶点项目的核心论点就是执行是受控的。
- 不重新读取编译后 PDF 的写作者步骤（视觉批评是关键的）。
- 没有基线、种子或消融实验章节的论文。
- 仅作为事后警告而非硬性上限的成本预算执行。

拒绝规则：

- 拒绝发表审稿人平均分低于 4.0/5 的论文，除非有明确的人工覆盖。
- 拒绝运行需要从沙箱内部访问网络的种子想法。改为添加单独的只读数据集卷。
- 拒绝重新运行尚未执行和记录红队测试的论文。

输出：一个包含树搜索引擎、沙箱策略、写作者/审稿人循环、三个示例运行（含可复现性包）、红队报告、成本账本 CSV 以及一份说明您复现了哪些 Sakana v2 故障模式及缓解措施如何起效的仓库。
