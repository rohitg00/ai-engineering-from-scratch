# 顶点项目 17 — 个性化 AI 导师（自适应、多模态、带记忆）

> 2026 年，Khanmigo（可汗学院）、Duolingo Max、Google LearnLM / Gemini for Education、Quizlet Q-Chat 和 Synthesis Tutor 都已大规模落地自适应的多模态辅导。其共同形态是：苏格拉底策略（绝不直接抛答案）、每次交互后更新的学习者模型（贝叶斯知识追踪风格）、语音 + 文本 + 拍照输入、课程图谱检索、间隔重复调度，以及针对年龄适宜内容的严格安全过滤。本顶点项目的要求是：交付一个面向特定学科的导师（K-12 代数或 Python 入门）、开展为期两周、含 10 名学习者的效能研究，并通过内容安全审计。

**类型：** 顶点项目
**语言：** Python（后端、学习者模型）、TypeScript（Web 应用）、SQL（通过 Postgres + Neo4j 构建课程图谱）
**前置要求：** 阶段 5（NLP）、阶段 6（语音）、阶段 11（LLM 工程）、阶段 12（多模态）、阶段 14（Agent）、阶段 17（基础设施）、阶段 18（安全）
**涉及阶段：** P5 · P6 · P11 · P12 · P14 · P17 · P18
**时长：** 30 小时

## 问题

自适应辅导曾经只是教育科技的一个研究细分领域。到 2026 年，它已转化为消费级产品。Khanmigo 已部署到美国大多数学区。Duolingo Max 达到了数千万月活跃用户。Google 的 LearnLM / Gemini for Education 为 Google Classroom 提供辅导功能。Quizlet Q-Chat 与闪卡产品并列运行。Synthesis Tutor 以"为好奇孩子打造的导师"走红。共通要素包括：多模态输入（打字、说话、拍摄数学公式）、苏格拉底教学法（先提问、后讲解）、每次交互后更新的学习者模型，以及严格的年龄适宜安全机制。

你将针对特定学习群体构建这样一个系统。衡量标准是一场真实的效能研究：10 名学习者在两周内的前测与后测成绩对比。语音交互必须感觉自然（复用顶点项目 03 的子技术栈）。记忆必须尊重隐私。安全过滤必须通过面向 K-12 的 COPPA 合规红队测试。

## 概念

四个核心组件。**导师策略**是一个苏格拉底循环：当学习者索要答案时，策略会反问一个引导性问题；当学习者答对时，进入下一个概念；当学习者卡住时，提供分步提示。**学习者模型**采用贝叶斯知识追踪（或简化变体），每次交互后更新每个课程节点的掌握概率。**课程图谱**是一个 Neo4j 图，包含带前置条件边的概念节点；策略遍历该图以选择下一个概念。**记忆**是一个情节 + 语义存储（类似 agentmemory 风格），保存历史交互、错误和偏好。

用户体验是多模态的。文本输入用于打字作答。语音输入通过 LiveKit + Whisper 实现（复用顶点项目 03）。拍照输入通过 dots.ocr 或 PaliGemma 2 处理数学题。语音输出通过 Cartesia Sonic-2。安全方面使用 Llama Guard 4 加年龄适宜过滤器（屏蔽成人内容、暴力、自残），以及符合 COPPA 的记忆保留策略。

效能研究是最终交付物。10 名学习者，前测与后测，为期两周。报告学习增益的差值及置信区间。与非自适应基线（相同内容以线性方式呈现，不使用导师策略）进行对比。

## 架构

```
学习者设备
  |
  +-- 文本         -> Web 应用
  +-- 语音         -> LiveKit Agents（ASR + TTS）
  +-- 拍照解题     -> dots.ocr / PaliGemma 2
       |
       v
  导师策略（LangGraph）
       - 苏格拉底决策头
       - 下一概念选择器（课程图谱遍历）
       - 提示脚手架
       - 掌握度更新
       |
       v
  学习者模型（BKT / 项目反应理论）
       - 每个概念的掌握概率
       - 间隔重复调度器（SM-2 或 FSRS）
       |
       v
  记忆（agentmemory 风格）
       - 情节记忆：每次交互
       - 语义记忆：已学到的错误与偏好
       - 保留策略：符合 COPPA / GDPR
       |
       v
  课程图谱（Neo4j）
       - 前置条件边
       - 关联的 OER 内容
       |
       v
  安全：
    Llama Guard 4 + 年龄适宜过滤器
    记忆访问受学习者 ID 作用域保护
```

## 技术栈

- 学科选择：K-12 代数或 Python 入门（选一个做深）
- 导师策略：基于 Claude Sonnet 4.7 的 LangGraph（带提示缓存）
- 学习者模型：贝叶斯知识追踪（经典）或 FSRS（用于间隔）
- 课程图谱：Neo4j 概念图 + 前置条件边 + OER 内容
- 记忆：agentmemory 风格的持久化向量 + 情节 + 语义存储
- 语音：LiveKit Agents 1.0 + Cartesia Sonic-2（复用顶点项目 03 子技术栈）
- 拍照解题：dots.ocr 或 PaliGemma 2 用于公式识别
- 安全：Llama Guard 4 + 自定义年龄适宜过滤器
- 评估：Bloom 层级问题生成、前/后测工具、效能研究工具

## 构建步骤

1. **课程图谱。** 构建一个包含 50-150 个概念节点（例如 K-12 代数，从"数轴"到"二次方程求根公式"）的 Neo4j 图，带有前置条件边。为每个节点关联 OER 内容（Open Textbook、OpenStax）。

2. **学习者模型。** 初始化贝叶斯知识追踪的先验参数：猜测率、失误率、学习率。每次交互后更新每个概念的掌握概率。按学习者持久化。

3. **导师策略。** LangGraph，包含以下节点：`read_signal`（学习者的回答是否正确/部分正确/卡住？）、`select_concept`（遍历课程图谱，选择优先级最高的概念）、`scaffold`（苏格拉底式提示）、`update_mastery`。

4. **记忆。** 每次交互写入情节存储。错误和偏好升级为语义记忆。COPPA 感知的保留策略：1 年后自动删除，家长可访问。

5. **语音通路。** LiveKit Agents 工作进程挂接到导师策略。ASR 使用 Whisper-v3-turbo。TTS 使用 Cartesia Sonic-2。支持打断（复用顶点项目 03 的机制）。

6. **拍照解题通路。** 上传或拍摄图像；运行 dots.ocr 或 PaliGemma 2 识别公式；作为结构化输入送入导师。

7. **安全。** 每个模型输出都经过 Llama Guard 4 + 年龄适宜过滤器（屏蔽自残、成人内容、暴力）。记忆访问按学习者 ID 限定作用域；提供家长删除数据界面。

8. **效能研究。** 10 名学习者，前测（标准化 30 题基线），两周导师交互（每周 3 次），后测。与 10 名学习者的非自适应基线组（相同内容）进行对比。

9. **每周进度报告。** 按学习者自动生成 PDF 摘要，包含已探索主题、掌握度轨迹和推荐下一步。

## 使用示例

```
学习者："我不明白为什么 3x + 6 = 12 意味着 x = 2"
[信号]   卡住
[概念]   '分离变量'（前置条件：加减法等式性质）
[提示]   "你从两边减去什么数才能开始？"
学习者："6"
[信号]   正确
[掌握度] 加减法等式性质：0.62 -> 0.77
[概念]   继续 '分离变量'
[提示]   "很好。那么 3x / 3 等于什么？"
```

## 练习

1. 分别在有和没有自适应学习者模型（随机概念顺序）的情况下运行效能研究，报告差值。预期自适应方案胜出，但差值大小才是关键数字。

2. 添加一个多模态探测：以文本、语音和拍照三种方式呈现同一概念问题。测量学习者是否在使用他们偏好的模态时收敛更快。

3. 构建一个家长仪表盘：已练习主题、掌握度轨迹、即将学习的概念、安全事件（任何防护触发记录）。符合 COPPA 规范。

4. 添加语言切换模式：导师接受西班牙语输入并用西班牙语教学。测量 X-Guard 的覆盖范围。

5. 对记忆隐私进行压力测试：验证学习者 A 即使通过语音片段重放攻击也无法看到学习者 B 的数据。记录尝试访问行为并发出警报。

## 关键术语

| 术语 | 人们说的 | 实际含义 |
|------|----------|----------|
| 苏格拉底策略 | "提问，而非倾倒" | 导师提出引导性问题而非直接给出答案 |
| 贝叶斯知识追踪 | "BKT" | 用于每个概念掌握概率的经典学习者模型公式 |
| FSRS | "自由间隔重复调度器" | 2024 年间隔重复调度算法，优于 SM-2 |
| 课程图谱 | "概念有向无环图" | 带前置条件边的 Neo4j 概念图 |
| 情节记忆 | "每次交互的日志" | 存储每次交互以供后续检索 |
| 语义记忆 | "已学模式存储" | 从情节记忆中提炼的压缩错误与偏好 |
| COPPA | "儿童隐私法" | 美国限制向 13 岁以下儿童收集数据的法律 |
