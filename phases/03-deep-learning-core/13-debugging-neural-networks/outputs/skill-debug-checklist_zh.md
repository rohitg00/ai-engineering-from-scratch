# 神经网络调试清单

训练出问题时的系统性调试协议。按顺序进行——大多数bug在前3步就被捕获。

## 训练前（预防bug）

1. 打印模型架构和参数量。大小对你的数据来说合理吗？
2. 用随机输入运行一次前向传播。输出形状与你的目标形状匹配吗？
3. 检查标签的dtype是否正确（CrossEntropyLoss需要Long，BCELoss需要Float）
4. 验证数据归一化：输入应均值接近0，标准差接近1
5. 打印5个随机（输入、标签）对。标签符合你的预期吗？
6. 确认训练/测试划分没有重复样本

## 单批过拟合测试（60秒，捕获80%的bug）

1. 从训练集中取8-32个样本
2. 以合理的学习率训练200步
3. 损失应趋近于0。训练准确率应达到100%
4. 如果失败：bug在你的模型、损失函数或训练循环中——不是你的数据或超参数
5. 如果通过：进行完整训练

## 损失不下降

1. 检查学习率。尝试3个值：当前/10、当前、当前*10
2. 打印每层的梯度范数。全零表示网络死亡或图已断开
3. 检查参数上的`requires_grad=True`。检查是否调用了`loss.backward()`
4. 检查在`loss.backward()`之前是否调用了`optimizer.zero_grad()`
5. 检查在`loss.backward()`之后是否调用了`optimizer.step()`
6. 验证模型参数已传递给优化器：`optimizer = Adam(model.parameters())`

## 损失为NaN或Inf

1. 将学习率降低10倍
2. 在所有log()调用中添加epsilon：`torch.log(x + 1e-7)`
3. 在所有除法中添加epsilon：`x / (y + 1e-8)`
4. 在BCE损失前钳制预测值：`torch.clamp(pred, 1e-7, 1 - 1e-7)`
5. 使用`torch.autograd.detect_anomaly()`找到确切操作
6. 检查输入数据中的NaN：`assert not torch.isnan(x).any()`

## 损失振荡

1. 将学习率降低3-10倍
2. 增加批量大小（减少梯度噪声）
3. 添加梯度裁剪：`torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)`
4. 从SGD切换到Adam（每个参数的自适应LR）
5. 在训练的前5-10%添加学习率预热

## 过拟合（训练准确率高，测试准确率低）

1. 添加dropout（从p=0.1开始，增加到0.5）
2. 向优化器添加权重衰减：`Adam(params, weight_decay=1e-4)`
3. 减小模型大小（更少的层或更窄的层）
4. 添加数据增强
5. 使用早停：当验证损失连续5+个epoch增加时停止
6. 检查训练集和测试集之间的数据泄漏

## 欠拟合（训练和测试准确率都低）

1. 增加模型容量（更多层，更宽层）
2. 训练更多epoch
3. 增加学习率（小心）
4. 临时移除正则化以验证模型能学习
5. 检查你的模型对任务来说是否足够表达

## 死亡ReLU神经元

1. 检查每层零激活的比例。>50%是个问题
2. 切换到LeakyReLU(0.01)或GELU
3. 对权重使用Kaiming初始化
4. 降低学习率（大的更新可能将神经元推入死亡区）
5. 在激活函数之前添加批归一化

## 快速参考：学习率起点

| 优化器 | 任务 | 起始LR |
|-----------|------|------------|
| Adam | 从头训练 | 1e-3 |
| Adam | 微调预训练 | 1e-5 |
| SGD + 动量 | 从头训练 | 1e-1 |
| SGD + 动量 | 微调预训练 | 1e-3 |
| AdamW | Transformer训练 | 3e-4 |

## 快速参考：批量大小效应

| 批量大小 | 梯度噪声 | 内存 | 泛化 |
|-----------|---------------|--------|---------------|
| 8-16 | 高（有噪声） | 低 | 通常更好 |
| 32-64 | 中等 | 中等 | 好的默认值 |
| 128-256 | 低（平滑） | 高 | 可能需要预热 |
| 512+ | 非常低 | 非常高 | 需要LR缩放 |

## 当什么都不管用时

1. 将模型简化为1个隐藏层。它能学习吗？
2. 将数据简化为100个样本。它能过拟合吗？
3. 将你的损失替换为MSE。它能收敛吗？
4. 将你的优化器替换为SGD(lr=0.01)。它能取得进展吗？
5. 将你的数据替换为合成数据（例如y = x[0] > 0）。它能学习吗？
6. 如果以上都不行：bug在你没查看的代码中（数据加载、预处理、张量形状）
