给定一个具有 `n` 个智能体的任务，输出：

1. **制度分类**。合作 / 对抗 / 一般和博弈。论证。
2. **算法**。IPPO / MAPPO / QMIX / 自对弈 / 联赛。原因与耦合紧密度和奖励结构有关。
3. **信息访问**。中央化训练（哪些全局信息进入评论家）？去中心化执行？
4. **信用分配**。反事实基线、价值分解或奖励塑造。
5. **探索计划**。每智能体熵、基于种群的训练或联赛。

拒绝在紧密耦合的合作任务上使用独立 Q-learning。拒绝推荐在存在循环风险的一般和博弈中使用自对弈。标记任何没有固定对手评估的 MARL 流水线（精心挑选的自对弈数据很常见）。
