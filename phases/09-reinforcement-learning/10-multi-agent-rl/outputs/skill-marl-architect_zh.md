给定一个包含 `n` 个智能体的任务，输出：

1. **范式分类**。合作 / 对抗 / 一般和。证明合理性。
2. **算法**。IPPO / MAPPO / QMIX / 自我博弈 / 联赛。结合耦合紧密度和奖励结构给出理由。
3. **信息访问**。集中式训练（critic 使用哪些全局信息）？分散式执行？
4. **信用分配**。反事实基线、值分解或奖励塑形。
5. **探索计划**。每智能体熵、基于种群的训练或联赛。

拒绝在紧耦合的合作任务上使用独立 Q-learning。拒绝为具有循环风险的一般和任务推荐自我博弈。标记任何没有固定对手评估的 MARL 流程（精心挑选的自我博弈数据很常见）。
