# MDP、状态、动作与奖励

> 马尔可夫决策过程由五部分组成：状态、动作、转移、奖励、折扣。强化学习中的一切——Q-learning、PPO、DPO、GRPO——都在这个框架上进行优化。学会它一次，就能免费读懂后续的强化学习内容。

**类型：** 学习
**语言：** Python
**前置要求：** 阶段 1 · 06（概率与分布）、阶段 2 · 01（机器学习分类）
**时间：** ~45 分钟

## 问题

你正在编写一个国际象棋机器人。或一个库存规划器。或一个交易智能体。或一个训练推理模型的 PPO 循环。四个不同领域，一个令人惊讶的事实：它们都归结为同一个数学对象。

监督学习给你 `(x, y)` 对，要求你拟合一个函数。强化学习不给你标签——只有一串状态、你执行的动作和一个标量奖励。这一步是否赢了比赛？补货决策是否省了钱？交易是否盈利？LLM 刚刚生成的 token 是否从评判器那里获得了更高的奖励？

在形式化之前，你无法从这串数据中学习。"我看到了什么"、"我做了什么"、"接下来发生了什么"、"那有多好"——每一个都必须成为你可以推理的对象。这种形式化就是马尔可夫决策过程。本阶段的所有 RL 算法，包括最后的 RLHF 和 GRPO 循环，都在这个框架上进行优化。

## 概念

![马尔可夫决策过程：状态、动作、转移、奖励、折扣](../assets/mdp.svg)

**五个对象。**

- **状态** `S`。智能体决策所需的一切。在 GridWorld 中，是格子。在国际象棋中，是棋盘。在 LLM 中，是上下文窗口加上任何记忆。
- **动作** `A`。可选的操作。上/下/左/右移动。走一步棋。生成一个 token。
- **转移** `P(s\' | s, a)`。给定状态 `s` 和动作 `a`，下一个状态的分布。在国际象棋中是确定性的，在库存中是随机的，在 LLM 解码中几乎是确定性的。
- **奖励** `R(s, a, s\')`。标量信号。赢 = +1，输 = -1。收入减去成本。GRPO 中的对数似然比项。
- **折扣** `γ ∈ [0, 1)`。未来奖励相对于当前奖励的权重。`γ = 0.99` 提供约 100 步的视野；`γ = 0.9` 提供约 10 步。

**马尔可夫性质** `P(s_{t+1} | s_t, a_t) = P(s_{t+1} | s_0, a_0, …, s_t, a_t)`。未来只依赖于当前状态。如果不成立，说明状态表示不完整——不是方法的失败，而是状态的失败。

**策略与回报。** 策略 `π(a | s)` 将状态映射到动作分布。回报 `G_t = r_t + γ r_{t+1} + γ² r_{t+2} + …` 是未来奖励的折扣和。价值 `V^π(s) = E[G_t | s_t = s]` 是在策略 `π` 下从 `s` 出发的期望回报。Q 值 `Q^π(s, a) = E[G_t | s_t = s, a_t = a]` 是从特定动作开始的期望回报。每个 RL 算法估计这两个之一，然后相应地改进 `π`。

**Bellman 方程。** 本阶段所有算法使用的不动点方程：

`V^π(s) = Σ_a π(a|s) Σ_{s\', r} P(s\', r | s, a) [r + γ V^π(s\')]`
`Q^π(s, a) = Σ_{s\', r} P(s\', r | s, a) [r + γ Σ_{a\'} π(a\'|s\') Q^π(s\', a\')]`

这些方程将期望回报分解为"这一步的奖励"加上"到达位置的折扣价值"。递归的。阶段 9 中的每个算法要么迭代这个方程直到收敛（动态规划），要么从中采样（蒙特卡洛），要么用一步进行自助法（时序差分）。

## 动手构建

### 步骤 1：一个微小的确定性 MDP

一个 4×4 的 GridWorld。智能体从左上角开始，终点在右下角，每步奖励 -1，动作 `{up, down, left, right}`。参见 `code/main.py`。

```python
GRID = 4
TERMINAL = (3, 3)
ACTIONS = {"up": (-1, 0), "down": (1, 0), "left": (0, -1), "right": (0, 1)}

def step(state, action):
    if state == TERMINAL:
        return state, 0.0, True
    dr, dc = ACTIONS[action]
    r, c = state
    nr = min(max(r + dr, 0), GRID - 1)
    nc = min(max(c + dc, 0), GRID - 1)
    return (nr, nc), -1.0, (nr, nc) == TERMINAL
```

五行代码。这就是整个环境。确定性转移，恒定步长惩罚，吸收终止状态。

### 步骤 2：执行策略的 rollout

策略是一个从状态到动作分布的函数。最简单的：均匀随机。

```python
def uniform_policy(state):
    return {a: 0.25 for a in ACTIONS}

def rollout(policy, max_steps=200):
    s, total, steps = (0, 0), 0.0, 0
    for _ in range(max_steps):
        a = sample(policy(s))
        s, r, done = step(s, a)
        total += r
        steps += 1
        if done:
            break
    return total, steps
```

将随机策略运行 1000 次。对于这个 4×4 棋盘，平均回报约为 -60 到 -80。最优回报是 -6（向下-向右的直线路径）。弥合这一差距就是阶段 9 的全部内容。

### 步骤 3：通过 Bellman 方程精确计算 `V^π`

对于小型 MDP，Bellman 方程是一个线性方程组。枚举所有状态，应用期望，迭代直到值不再变化。

```python
def policy_evaluation(policy, gamma=0.99, tol=1e-6):
    V = {s: 0.0 for s in all_states()}
    while True:
        delta = 0.0
        for s in all_states():
            if s == TERMINAL:
                continue
            v = 0.0
            for a, pi_a in policy(s).items():
                s_next, r, _ = step(s, a)
                v += pi_a * (r + gamma * V[s_next])
            delta = max(delta, abs(v - V[s]))
            V[s] = v
        if delta < tol:
            return V
```

这就是迭代策略评估。它是 Sutton & Barto 教材中的第一个算法，也是后续所有 RL 方法的理论基础。

### 步骤 4：`γ` 是一个具有物理含义的超参数

有效视野大致为 `1 / (1 - γ)`。`γ = 0.9` → 10 步。`γ = 0.99` → 100 步。`γ = 0.999` → 1000 步。

太低时智能体表现短视。太高时信用分配变得嘈杂，因为许多早期步骤共同对远期奖励负责。LLM RLHF 通常使用 `γ = 1`，因为回合短且有界。控制任务使用 `0.95–0.99`。长视野策略游戏使用 `0.999`。

## 常见陷阱

- **非马尔可夫状态。** 如果你需要最近三次观测才能决策，那么"状态"就不仅仅是当前观测。解决方法：堆叠帧（DQN 在 Atari 上堆叠 4 帧）或使用循环状态（在观测上使用 LSTM/GRU）。
- **稀疏奖励。** 仅获胜才给奖励在大状态空间中使学习几乎不可能。设计奖励塑形（中间信号）或使用模仿学习进行引导（阶段 9 · 09）。
- **奖励破解。** 优化代理奖励常常导致病态行为。OpenAI 的赛艇智能体原地转圈收集道具永远不完成比赛。始终基于目标结果定义奖励，而不是代理指标。
- **折扣设置错误。** 在无限视野任务上使用 `γ = 1` 会使每个价值变为无穷大。始终使用有限视野或 `γ < 1` 来限制。
- **奖励尺度。** {+100, -100} 和 {+1, -1} 的奖励给出相同的最优策略，但梯度幅度相差巨大。在输入 PPO/DQN 之前归一化到 `[-1, 1]` 左右。

## 使用场景

2026 年的技术栈在接触代码之前将每个 RL 流程简化为 MDP：

| 场景 | 状态 | 动作 | 奖励 | γ |
|-----------|-------|--------|--------|---|
| 控制（运动、操作） | 关节角度 + 速度 | 连续力矩 | 任务特定的塑形奖励 | 0.99 |
| 游戏（国际象棋、围棋、扑克） | 棋盘 + 历史 | 合法移动 | 赢=+1 / 输=-1 | 1.0（有限） |
| 库存 / 定价 | 库存 + 需求 | 订货量 | 收入 - 成本 | 0.95 |
| LLM 的 RLHF | 上下文 token | 下一个 token | 结束时的奖励模型分数 | 1.0（回合约 200 token） |
| 推理的 GRPO | 提示 + 部分响应 | 下一个 token | 结束时的验证器 0/1 | 1.0 |

在编写任何训练循环之前，先写出这五个元组。大多数"RL 不工作"的错误报告都能追溯到纸面上就已经有问题的 MDP 公式。

## 练习

1. **简单。** 在 `code/main.py` 中实现 4×4 GridWorld 和随机策略 rollout。运行 10,000 个回合。报告回报的均值和标准差。与最优回报 (-6) 比较。
2. **中等。** 使用 `γ ∈ {0.5, 0.9, 0.99}` 对均匀随机策略运行 `policy_evaluation`。将 `V` 以 4×4 网格形式打印出来。解释为什么终止状态附近的状态值随着 `γ` 增大而增长更快。
3. **困难。** 使 GridWorld 变为随机：每个动作以概率 `p = 0.1` 滑向相邻方向。重新评估均匀策略。`V[start]` 变好还是变差？为什么？

## 关键术语

| 术语 | 人们说的 | 实际意思 |
|------|-----------------|-----------------------|
| MDP | "强化学习设置" | 满足马尔可夫性质的元组 `(S, A, P, R, γ)`。 |
| 状态 | "智能体看到的东西" | 在所选策略类下对未来动态的充分统计量。 |
| 策略 | "智能体的行为" | 条件分布 `π(a \| s)` 或确定性映射 `s → a`。 |
| 回报 | "总奖励" | 从当前步开始的折扣和 `Σ γ^t r_t`。 |
| 价值 | "一个状态有多好" | 在 `π` 下从 `s` 开始的期望回报。 |
| Q 值 | "一个动作有多好" | 在 `π` 下从 `s` 开始且第一个动作是 `a` 的期望回报。 |
| Bellman 方程 | "动态规划递归" | 将价值/Q 值分解为一步奖励加上折扣的后继价值的**不动点分解**。 |
| 折扣 `γ` | "未来 vs 现在" | 远期奖励的几何权重；有效视野 `~1/(1-γ)`。 |
