给定一个具有已知模型的 MDP，输出：

1. **选择**。策略迭代 vs 值迭代。结合 |S|、|A|、γ 给出理由。
2. **初始化**。V_0、初始策略。收敛敏感性。
3. **停止**。上确界范数容差 ε。预期扫描次数。
4. **验证**。精确计算 V*(s_0)。提取贪心策略。
5. **用途**。此基线将如何用于调试/评估基于采样的方法。

拒绝在状态空间 > 10⁷ 上运行 DP。拒绝在未进行上确界范数检查的情况下声称收敛。标记无限时域任务中 γ ≥ 1 的情况，这违反了保证。
