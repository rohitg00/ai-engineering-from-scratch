给定一个具有已知模型的 MDP，输出：

1. **选择**。策略迭代 vs 价值迭代。原因与 |S|、|A|、γ 有关。
2. **初始化**。V_0、起始策略。收敛敏感性。
3. **停止**。上确界范数容差 ε。预期的扫描次数。
4. **验证**。精确计算 V*(s_0)。提取贪心策略。
5. **用途**。该基线将如何用于调试/评估基于采样的方法。

拒绝在状态空间 > 10⁷ 上运行 DP。拒绝在没有上确界范数检查的情况下声称收敛。标记任何无限时间跨度任务上的 γ ≥ 1 为对保证的违反。
