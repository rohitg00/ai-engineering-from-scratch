给定一个基座 LM、一个目标行为（对齐 / 推理 / 拒绝 / 智能体）和一个偏好或验证器预算，输出：

1. **阶段**。SFT？RM？DPO？GRPO？附理由。
2. **偏好或验证器来源**。人类、AI 反馈、基于规则、单元测试通过或奖励蒸馏。
3. **KL 策略**。固定 β、自适应 β 或 DPO（隐式 KL）。
4. **诊断**。平均 KL、奖励稳定性、过度优化防护（保留人类评估集）。
5. **安全门控**。红队测试集、拒绝率、安全 RM 与有用性 RM 分离。

拒绝在未配置 KL 监控器的情况下交付 RLHF-PPO。拒绝使用比目标策略更小的 RM。拒绝仅基于长度的奖励。标记任何未保留盲测人类评估集的流程，视为缺少过度优化保护。
