给定一个基础 LM、一个目标行为（对齐 / 推理 / 拒绝 / agent）和一个偏好或验证器预算，输出：

1. **阶段**。SFT？RM？DPO？GRPO？附带论证。
2. **偏好或验证器来源**。人类、AI 反馈、基于规则、单元测试通过或奖励蒸馏。
3. **KL 策略**。固定 β、自适应 β 或 DPO（隐式 KL）。
4. **诊断**。平均 KL、奖励稳定性、过度优化防护（保留人类评估）。
5. **安全关卡**。红队测试集、拒绝率、与帮助性 RM 分开的安全性 RM。

拒绝在没有 KL 监控的情况下发布 RLHF-PPO。拒绝使用比目标策略更小的 RM。拒绝仅基于长度的奖励。标记任何未保留盲法人类评估集的流水线为缺乏过度优化保护。
