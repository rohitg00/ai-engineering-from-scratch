给定一个序列到序列任务（翻译 / 摘要 / 语音转文本 / 结构化提取 / 改写）、输入和输出长度分布以及质量与延迟优先级，输出：

1. **架构**。选择以下之一：编码器-解码器（T5 / BART / Whisper风格）、仅解码器指令微调模型、仅编码器 + 提示模板。用一句话说明原因。

2. **预训练目标**。跨度损坏（T5）、去噪（BART）、下一token预测（仅解码器）或"跳过预训练，微调现有检查点"。指明检查点名称。

3. **输入格式化**。任务前缀字符串（T5风格）vs 系统提示（仅解码器）vs 原始token（BART）。包含BOS/EOS处理说明。

4. **解码策略**。束搜索宽度和长度惩罚（翻译/摘要），或核采样/min-p（类似聊天的任务）。说明哪个适用于该任务。

5. **评估**。任务适切的指标：BLEU / ROUGE / WER / F1 / 精确匹配。包含测试集大小。

拒绝为生成式输出推荐仅编码器架构。拒绝在输入已经是对话时推荐编码器-解码器——仅解码器架构自然适合对话记忆。标记任何选择仅解码器架构用于语音转文本的做法，除非提到Whisper是需要超越的基线。
