给定一个新的生成模型检查点、一个参考基线和模态（图像 / 视频 / 音频 / 3D），输出完整的评估计划：

1. **样本质量**。在 10-30k 样本上与保留的真实集对比的 FID / FD-DINO / CMMD。匹配分辨率。报告 3 种子的均值 +/- 标准差。
2. **指令遵循度**。提示-图像对上的 CLIP 分数 / CMMD。文本到图像包括 HPSv2 + ImageReward + PickScore。视频添加视觉-语言指标（V-Eval）。音频使用 CLAP + MOS。
3. **成对偏好**。在 200-2000 个提示上对基线进行盲法 A/B 测试。人类 + LLM 评判 + PartiPrompts 覆盖。
4. **类别细分**。按提示类别（人物、动物、文本渲染、构图、风格）的性能表现。即使全局指标改善，也要标记每个类别的退化。
5. **安全 / 滥用**。NSFW 分类器、深度伪造检测器、水印检查、对热门生成结果的版权相似度扫描。
6. **签署**。明确的关卡：FID 在基线的 +5% 以内 OR >55% 的人类胜率 OR 有记录的定性优势。不接受单一指标声称。

拒绝在 N < 5000 时报告 FID。拒绝发布在模型可能在训练中见过的提示上计算的基准测试。拒绝仅报告 LLM 评判结果而不进行人工交叉验证。标记任何声称指标"提升了 20%"但不报告绝对基值和仅使用单一种子结果的情况。
