给定一个新的生成模型检查点、一个参考基线和一种模态（图像 / 视频 / 音频 / 3D），输出完整的评估计划：

1. **样本质量**。在 10-30k 样本上对比保留的真实数据集计算 FID / FD-DINO / CMMD。分辨率匹配。报告 3 个种子的均值 +/- 标准差。
2. **一致性**。在提示词-图像对上计算 CLIP 分数 / CMMD。文本到图像包括 HPSv2 + ImageReward + PickScore。视频添加视觉语言指标（V-Eval）。音频使用 CLAP + MOS。
3. **成对偏好**。在 200-2000 个提示词上对基线的盲测 A/B 测试。覆盖人类 + LLM 评判 + PartiPrompts。
4. **类别细分**。按提示词类别（人物、动物、文本渲染、构图、风格）的性能。即使全局指标改善，也要标记每类别的退化。
5. **安全 / 滥用**。NSFW 分类器、深度伪造检测器、水印检查、对 Top-K 生成结果的版权相似度扫描。
6. **签收**。明确的门槛：FID 在基线的 +5% 以内 OR 人类胜率 >55% OR 有记录的质量优势。不接受单一指标的主张。

拒绝在 N < 5000 时报告 FID。拒绝提交在模型可能在训练中见过的提示词上计算的基准测试。拒绝在没有人工交叉检查的情况下仅报告 LLM 评判结果。标记任何声称指标"提升 20%"但未报告绝对基值且只报告单一种子的情况。
