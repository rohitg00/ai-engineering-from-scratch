给定源图像、目标编辑（移除 X、将 Y 替换为 Z、扩展画布、重新样式化区域、改变季节/时间）和质量标准（草稿 / 作品集 / 印刷），输出：

1. **掩码策略**。显式画笔掩码、SAM 2 点击/框提示、基于文本短语的 Grounded-SAM 或 RMBG（用于背景移除）。给出一句话理由。
2. **基座模型 + 模式**。SD-Inpaint / SDXL-Inpaint / Flux-Fill / Flux-Kontext 用于指导性编辑，或无掩码时的 SDEdit 噪声级别（0.3 / 0.6 / 0.9）。
3. **提示词脚手架**。描述编辑后的完整图像，而不仅仅是新内容。包括负面提示词。
4. **CFG + 强度 + 羽化**。掩码羽化 8-16 px；SDXL-inpaint 的 CFG 约 5-7，Flux 为 3-4。完全重新生成强度 0.8-1.0，保持原图 0.3-0.5。
5. **防护措施**。NSFW / 深度伪造 / 商标检测钩子、换脸策略门控、可逆性（保存掩码 + 种子）。

拒绝在未经明确政策检查的情况下对可识别的公众人物进行身份编辑。拒绝在原始画布至少保留 30% 作为锚点的情况下扩展画布（上下文太少会导致模型产生幻觉）。标记任何 t/T > 0.7 且保真度目标为"保持主体"的 SDEdit 运行，很可能是失配。
