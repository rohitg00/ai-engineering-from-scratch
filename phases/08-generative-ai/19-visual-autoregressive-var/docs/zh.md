# 視覺自迴歸建模（VAR）：下一尺度預測

> 擴散模型是在時間上迭代取樣（去噪步驟）。VAR 則是在尺度上迭代取樣 —— 它先預測一個 1x1 的詞元，再來 2x2，再來 4x4，一路到最終解析度，每個尺度都以前面的尺度為條件。2024 年那篇論文顯示，VAR 在影像生成上符合 GPT 式的縮放律，並且在同樣的計算預算下勝過 DiT。這個單元要打造它的核心機制。

**類型：** 實作
**程式語言：** Python（搭配 PyTorch）
**先修單元：** 階段 7 · 單元 03（多頭注意力）、階段 8 · 單元 06（DDPM）
**時間：** 約 90 分鐘

## 問題所在

自迴歸生成之所以主宰語言建模，是因為它縮放得很可預測：更多計算量、更多參數、更低的困惑度、更好的輸出。2024 年之前，影像生成主要有兩次自迴歸的嘗試：PixelRNN／PixelCNN（逐像素）以及 DALL-E 1／Parti／MuseGAN（在 VQ-VAE 編碼上逐詞元）。

兩者都吃了生成順序的虧。像素與詞元排在一個 2D 網格上，自迴歸模型卻得照 1D 的光柵順序去走訪它們。角落那個早早生成的像素，根本不知道這張影像最後會長成什麼樣子。生成品質的縮放表現比 GPT 在文字上差，而且在同等計算量下始終追不上擴散模型的品質。

VAR 靠著改變「生成的對象是什麼」來修掉生成順序的問題。它不是在空間上逐一預測影像詞元，而是以逐步提高的解析度預測整張影像。步驟 1：預測一個 1x1 的詞元（整張影像的「摘要」）。步驟 2：預測一個 2x2 的詞元網格（較粗的特徵）。步驟 3：預測一個 4x4 的網格。步驟 K：預測最終的 (H/8)x(W/8) 網格。

每個尺度都會注意到前面所有的尺度（在「尺度順序」上是因果的），而在自己這個尺度內部則是平行的。順序問題就此消失：尺度 k 的整張影像是在一次 transformer 前向傳遞裡一口氣產生的。

## 核心概念

### VQ-VAE 多尺度分詞器

VAR 需要一個**多尺度離散分詞器**。對一張影像 x，它產出一串解析度逐級提高的詞元網格：

```
x -> encoder -> latent f
f -> tokenize at 1x1: token grid z_1 of shape (1, 1)
f -> tokenize at 2x2: token grid z_2 of shape (2, 2)
...
f -> tokenize at (H/p)x(W/p): token grid z_K of shape (H/p, W/p)
```

每一個 z_k 都用同一本碼書（典型大小 4096 到 16384）。各尺度的量化並不是彼此獨立的 —— 訓練的方式是讓各尺度的殘差加總起來能重建出 f：

```math
f \approx \mathop{\mathrm{upsample}}(\mathop{\mathrm{embed}}(z_1), \text{target\_size}) + \cdots + \mathop{\mathrm{upsample}}(\mathop{\mathrm{embed}}(z_K), \text{target\_size})
```

這是**殘差 VQ**（residual VQ）的一種變體。尺度 k 補的是尺度 1..k-1 漏掉的東西。解碼器吃下所有尺度嵌入的總和，產生影像。

這個多尺度 VQ 分詞器只訓練一次（就像 VQGAN），之後就凍結。所有生成的工作都由架在上面的自迴歸模型負責。

### 下一尺度預測

生成模型是一個 transformer，它看得到前面所有尺度的詞元，並預測下一個尺度的詞元。

輸入序列的結構：
```
[START, z_1 tokens, z_2 tokens, z_3 tokens, ..., z_K tokens]
```

位置嵌入同時編碼尺度索引與該尺度內部的空間位置。注意力在尺度順序上是因果的：位於尺度 k、位置 (i, j) 的詞元，可以注意到尺度 1..k 的所有詞元，以及尺度 k 自身中在所採用的尺度內順序上更早的詞元（VAR 用的是固定的位置注意力，尺度內部沒有因果性 —— 一個尺度裡的所有位置都是平行預測出來的）。

訓練損失：在每個尺度 k，給定所有前面尺度的詞元去預測 z_k 的詞元。對離散的 VQ 編碼算交叉熵損失。結構跟 GPT 一模一樣，只是「序列」現在是按尺度組織的。

### 生成

推論時：
```
generate z_1 = sample from p(z_1)                    # 1 token
generate z_2 = sample from p(z_2 | z_1)              # 4 tokens in parallel
generate z_3 = sample from p(z_3 | z_1, z_2)         # 16 tokens in parallel
...
decode: f = sum of embed-and-upsample scales 1..K
image = VAE_decoder(f)
```

K = 10 個尺度的話，生成就是 10 次 transformer 前向傳遞。每一次傳遞平行產出它那整個尺度 —— 尺度內部沒有逐詞元的自迴歸。對一張 256x256 的影像來說，這大約是 10 次傳遞，對比 DiT 的 28 到 50 次。

### 為什麼下一尺度勝過下一詞元

三個結構上的優勢：
1. **由粗到細契合自然影像的統計特性。** 人類視覺感知與影像資料集都呈現出隨尺度而異的規律性：低頻結構穩定且可預測，高頻細節則以低頻內容為條件。下一尺度預測正好吃到這一點。
2. **尺度內平行生成。** 不像 GPT 式的詞元自迴歸，VAR 一步就產出一個尺度的所有詞元。有效生成長度從線性變成對數等級。
3. **沒有生成順序偏誤。** 尺度 k 的詞元看得到整個尺度 k-1；不存在「在左邊」或「在上面」這種偏誤逼著早期詞元在後文脈絡出現之前就先定案。

### 縮放律

Tian 等人證明了 VAR 在 ImageNet 上的 FID 遵循冪次律的縮放曲線 —— 就跟 GPT 的困惑度一樣。參數或計算量翻倍，誤差就可靠地減半。這是第一個把這種縮放行為表現得跟語言模型一樣乾淨的影像生成模型。結果就是 VAR 規模下的預測可以從計算量推算出來，而不再是每套架構各憑經驗猜測。

### 與擴散的關係

VAR 與擴散共享同一套資料壓縮的敘事：兩者都把生成問題拆成一連串比較簡單的子問題。

- 擴散：逐步加入雜訊，學會把其中一步還原回去。
- VAR：逐步加入解析度，學會預測下一個尺度。

它們是穿過同一個問題的不同軸線。兩者都得出可處理的條件分布。經驗上 VAR 的推論比較快（傳遞次數更少，而且尺度內部全平行），在類別條件的 ImageNet 上追平或勝過 DiT。文字條件的 VAR（VARclip、HART）是活躍的研究方向。

## 動手實作

在 `code/main.py` 裡你會：
1. 在合成的「影像」資料（2D 高斯環）上打造一個迷你的**多尺度 VQ 分詞器**。
2. 訓練一個 **VAR 風格的 transformer** 去做詞元的下一尺度預測。
3. 呼叫 transformer 4 次（4 個尺度）並解碼來取樣。
4. 驗證按尺度排序的訓練確實讓生成在尺度內部是平行的。

這是一份玩具實作。重點是親眼看到按尺度組織的注意力遮罩，以及尺度內平行生成真的跑起來。

## 產出交付

這個單元會產出 `outputs/skill-var-tokenizer-designer.md` —— 一項用來設計多尺度分詞器的技能：尺度數量、尺度比例、碼書大小、殘差共享、解碼器架構。

## 練習

1. **尺度數量消融。** 分別用 4、6、8、10 個尺度訓練 VAR。量測重建品質相對於自迴歸傳遞次數的變化。尺度越多 = 殘差越細 = 品質越好，但傳遞次數也越多。

2. **碼書大小。** 分別用 512、4096、16384 的碼書大小訓練分詞器。碼書越大重建越好，但預測越難。找出那個轉折點。

3. **尺度內平行性檢查。** 對一個訓練好的 VAR，明確量測它的注意力樣態。在尺度 k 內部，模型是不是只注意跨尺度的位置而不注意尺度內的位置？驗證遮罩的實作是否正確。

4. **VAR 對比 DiT 的縮放。** 在同一個 ImageNet 類別條件任務上，以相同的參數預算（例如 33M、130M、458M）訓練 VAR 與 DiT。畫出 FID 對計算量的曲線。VAR 在每個規模上都應該領先 DiT —— 在小規模上複現那篇論文的結果。

5. **文字條件控制。** 擴充 VAR，透過 adaLN 把一個文字嵌入（CLIP 池化後的向量）當成額外的條件輸入。這就是 HART 的配方。文字對齊取樣的 FID 能改善多少？

## 關鍵術語

| 術語 | 大家怎麼說 | 實際上是什麼 |
|------|----------------|----------------------|
| VAR | 「視覺自迴歸」 | 在一座 VQ 詞元網格金字塔上以下一尺度預測來生成影像 |
| 下一尺度預測 | 「先粗再細地預測」 | 模型以逐步提高的解析度尺度預測詞元，並以前面所有尺度為條件 |
| 多尺度 VQ 分詞器 | 「殘差 VQ」 | 產出 K 個解析度遞增的詞元網格的 VQ-VAE，解碼器把所有尺度加總起來 |
| 尺度 k | 「金字塔第 k 層」 | K 個解析度層級之一，從 k=1 的 1x1 到 k=K 的 (H/p)x(W/p) |
| 尺度內平行 | 「一個尺度一次前向」 | 尺度 k 的所有詞元在一次 transformer 傳遞裡預測完，不是自迴歸逐一產生 |
| 跨尺度因果 | 「按尺度排序的注意力」 | 尺度 k 的詞元可以注意到尺度 1..k 的全部，但注意不到尺度 k+1..K |
| 殘差 VQ | 「加法式量化」 | 每個尺度的詞元編碼的是較低尺度留下的殘差；解碼器把所有尺度嵌入相加 |
| VAR 縮放律 | 「影像版的 GPT 縮放」 | FID 隨計算量遵循可預測的冪次律，就像語言模型的困惑度 |
| HART | 「VAR + 文字的混合體」 | 文字條件的 VAR 變體，把 MaskGIT 式的迭代解碼與 VAR 的尺度結構結合起來 |
| 尺度位置嵌入 | 「(尺度, 列, 行) 三元組」 | 位置編碼同時攜帶尺度索引與該尺度內部的空間座標 |
