给定图像目标（分辨率、通道数、彩色 vs 灰度、数据集大小、下游 LM 计算预算、目标 FID），输出：

1. **尺度调度**。列出从 1x1 到 (H/p) x (W/p) 的 K 个分辨率级别。256x256 默认为 10 个尺度，512x512 为 14 个。根据 LM 的有效序列长度（各尺度面积之和）和每次并行处理尺度的预算来证明 K 的合理性。
2. **代码本**。跨所有尺度共享的单一代码本大小 V（典型 4096 / 8192 / 16384）。根据数据集大小和解码器容量选择 V。确认在校准批次上代码本使用率保持在 50% 以上，否则缩小 V。
3. **残差共享**。确认尺度 1..K 通过求和的上采样嵌入共同重建潜在表示（残差 VQ）。说明补丁大小 p 和 VAE 主干（VQGAN 风格判别器开/关、感知损失权重）。
4. **解码器**。将求和后的潜在表示映射回像素的 VAE 解码器。从 VQGAN 解码器、VAR 论文解码器或更轻量的 MAGVIT 风格解码器中选择。根据 FID 目标和解码器 VRAM 证明合理性。
5. **位置嵌入**。确认使用（scale_index, row, col）三元组，每个尺度有一个学习到的嵌入，尺度内部使用 2D 正余弦。拒绝平坦的 1D 位置——LM 需要尺度标签以应用正确的条件。

拒绝为 VAR 使用非残差的多尺度分词器。没有求和残差，下一尺度条件将变得定义不清，LM 优化的目标与论文证明的不同。拒绝使用每个尺度独立的代码本，除非 V 已根据较小尺度的像素数进行了校准且代码本坍缩已得到缓解。当 K × 平均尺度面积超过 LM 的最大序列长度减去文本条件的余量时，完全拒绝下一尺度预测。

示例输入："ImageNet 类别条件 256x256，数据集 1.2M，LM 预算 1.5B 参数，目标 FID 低于 5.0。"

示例输出：
- 尺度调度：K=10，大小为 1, 2, 3, 4, 5, 6, 8, 10, 13, 16。总 token 数 671。
- 代码本：共享，V=4096。ImageNet 256 上预期使用率 70-80%。
- 残差共享：已确认；p=16，VQGAN 主干 + 感知损失和对抗损失，残差和重建 f。
- 解码器：VQGAN 解码器，4 个上采样块，无额外优化器。
- 位置嵌入：（scale, row, col）三元组，学习到的尺度 token + 尺度内的 2D 正余弦。
