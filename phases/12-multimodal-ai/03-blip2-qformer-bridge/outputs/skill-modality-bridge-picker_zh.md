给定视觉编码器每张图像的 token 数、LLM 的上下文预算、每个提示的目标图像数以及训练计算预算，推荐使用哪种模态桥接器，并用参数数量和 token 经济性论证。

输出：

1. Token 预算审计。报告来自视觉编码器的每张图像原始 token 数、每种桥接器选项后每张图像的 token 数，以及在声明的每提示图像数下消耗的 LLM 上下文比例。
2. 桥接器比较。对 Q-Former（32 token，约 1.88 亿参数）、MLP 投影器（所有补丁，约 2000 万参数）和 Perceiver 重采样器（通过 N 层交叉注意力的 K 个可学习查询，可变）给出参数、质量代理和训练成本大致范围。
3. 推荐。在所述约束下的单一最佳选择，附一句话论证。当约束矛盾时（高质量 + 紧 token 预算 + 低训练计算）标记冲突。
4. 两阶段训练轨迹。如果选择 Q-Former，概述第一阶段 ITC + ITM + ITG 损失和第二阶段 LM 损失。为每个命名一个代表性数据集（COCO、LAION、Visual Genome）。
5. 消融检查清单。调用者在锁定桥接器前应运行的五个实验（查询数量、两阶段 vs 单阶段、投影器深度、冻结计划、微调子集）。

硬拒绝：
- 任何忽略 token 预算的推荐。在 4k 上下文中，"使用 MLP"对 10 张图像每张 576 token 会失败。
- 声称 Q-Former 严格主导 MLP。在单图像高质量任务且上下文无限制时，MLP 胜出。
- 将 Perceiver 重采样器视为等同于 Q-Former。Flamingo 在每个 LLM 层应用它；BLIP-2 只应用一次。

拒绝规则：
- 如果调用者要求一个能处理视频的桥接器但没有指定帧数和帧率，拒绝——视频桥接器与单图像桥接器的区别在于规范，而不仅仅是规模。
- 如果范围内的 LLM 是随视觉塔从头训练的（早期融合，Chameleon 风格），拒绝——第 12.11 课单独涵盖该情况。
- 如果未说明训练计算，拒绝并询问调用者是否负担得起 BLIP-2 的第二阶段（约几百 A100 小时）或仅投影器训练。

输出：一页桥接器推荐，包含 token 计算、参数计数、推荐架构、训练大纲和消融检查清单。以"接下来阅读什么"段落结尾，指向第 12.04 课（Flamingo）了解处处交叉注意力、第 12.05 课（LLaVA）了解仅 MLP、或第 12.07 课（消融）了解数据与架构的权衡。
