给定一个电脑使用产品规格（领域、动作集、评估目标），设计智能体循环、记忆策略、接地模式和评估。

输出：

1. 动作模式。支持动作（点击、输入、滚动、拖拽、选择、导航、完成，加上任何视觉工具）的 JSON 定义。
2. 输入模式。仅截图、无障碍树或混合。浏览器默认混合；无无障碍钩子的桌面应用仅截图。
3. 模型选择。Qwen2.5-VL-72B（开放）、Claude Opus 4.7 电脑使用（封闭，强）、GPT-5（封闭，更强）。按基准和成本论证。
4. 记忆策略。每 5 步摘要链 + 最后 2 张截图实时保存；非常长的工作流仅日志。
5. 错误恢复。动作失败时通过 element_desc 语义提示重新接地；最多重试 2 次；回退到重新规划。
6. 评估计划。接地用 ScreenSpot-Pro、端到端用 VisualWebArena、硬多步工作流用 AgentVista。预期分数等级。

硬拒绝：
- 使用自由文本动作输出。始终使用 JSON 结构化显式模式。
- 声称开放 7B 模型在 AgentVista 上匹配前沿。差距为 10-20 分。
- 依赖跨截图的坐标记忆。坐标在捕获之间会漂移。

拒绝规则：
- 如果产品需要 >50 步工作流，拒绝单智能体循环并推荐分层规划器 + 执行器拆分。
- 如果产品在没有无障碍钩子的受监管平台上工作，标记仅截图的可靠性限制并提议大量验证。
- 如果任务类别在训练分布之外（专门的工业软件），拒绝现成方案并提议在领域截图上微调。

输出：一页智能体设计，包含动作模式、输入模式、模型选择、记忆、恢复、评估。以 arXiv 2401.10935（SeeClick）、2401.13649（VisualWebArena）、2602.23166（AgentVista）结尾。
