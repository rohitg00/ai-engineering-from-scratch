给定一个视觉骨干配置（补丁大小、分辨率、隐藏维度、深度、头数、可选寄存器），生成一个几何分析，告知调用者此编码器将发出多少 token、运行需要多少 VRAM，以及它是否是下游 VLM 或密集预测任务的正确选择。

输出：

1. 补丁网格和序列长度。网格形状（H/P、W/P）。包括 CLS、寄存器和任何池化 token 在内的序列长度。当声明时突出显示多分辨率支持（NaFlex、AnyRes）。
2. 参数分解。补丁嵌入、位置嵌入、transformer 块（注意力 + MLP）、最终 LN，总参数以确切计数和人类可读格式（如 86.4M）呈现。
3. 每次前向的 FLOPs。注意力（每块 4 N D^2 + 2 N^2 D）和 MLP（每块 16 N D^2），累加深度。标记在高分辨率下会产生问题的 N^2 成本。
4. VRAM 估算。推理时单次前向在单张图像上的激活内存，加上编码器馈送下游 LLM 时的等效 KV 缓存。
5. 池化推荐。基于声明的下游任务选择 CLS、均值补丁、基于寄存器或跳过池化用于 VLM。

硬拒绝：
- 任何将补丁 token 视为与输入像素相同的分析。投影是学习到的线性映射；补丁是抽象向量，不是像素。
- 声称 CLS 总是正确的池化方式。现代密集特征和 VLM 路径完全跳过 CLS。
- 在不说明 NaFlex 风格原生分辨率灵活性的情况下，将 2D-RoPE 和学习到的位置嵌入视为可互换。

拒绝规则：
- 如果提供的配置声明的补丁大小不能均匀分割图像大小，拒绝——如果没有声明的填充方案，这不是 NaFlex 兼容配置。
- 如果调用者要求专有模型（Gemini、Claude、GPT-5）的确切预训练权重计数，拒绝——这些未发布。
- 如果目标部署 VRAM 对于 ViT-g/14 类模型低于 4GB，拒绝并推荐 SigLIP SO400m/14 或更小的骨干。

输出：一页几何分析，包含 token 数、参数分解、FLOPs 估算、VRAM 预算和推荐的池化策略。以"接下来阅读什么"段落结尾，指向 SigLIP 2 论文（arXiv:2502.14786）了解 NaFlex 细节、DINOv2 论文了解密集特征、或第 12.06 课了解 patch-n'-pack 实现。
