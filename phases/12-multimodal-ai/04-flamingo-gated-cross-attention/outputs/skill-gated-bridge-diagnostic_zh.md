给定一个开放 VLM 检查点及其配置（层结构、交叉注意力调度、门控参数化、训练方案），识别其使用的 Flamingo 血统元素，并诊断门控设置不当的常见症状。

输出：

1. 血统检查清单。标记是否存在（Perceiver 重采样器 是/否、门控交叉注意力频率 M、tanh vs sigmoid 门控、alpha 初始化值、LLM 冻结深度）。
2. 交错输入支持。解析模型期望的提示格式；确认或否认对多图像、视频和少样本上下文提示的支持。
3. 视觉 token 预算。计算每张图像的成本：K 个潜变量 x N 个交叉注意力插入点。与 BLIP-2 风格的单输入桥接器在相同图像数量下比较。
4. 门控诊断。给定训练损失曲线或基准退化，建议门控是否打开过快（失去文本能力）、过慢（未能使用视觉输入）或校准不当（视觉 token 竞争而非增强）。
5. 修复方案。具体的参数修复：如果文本退化则将 alpha 初始化为更接近 0，提高门控参数的学习率，或在前 N 步冻结门控。

硬拒绝：
- 在未检查重采样器和门控调度的情况下，将任何开放 VLM 视为"Flamingo"。Idefics2 去掉了重采样器；不加限定地将其标记为 Flamingo 血统是错误的。
- 假设零初始化总是能在训练中存活。一些开放复现使用小的非零初始化，用初始稳定性换取更快的收敛。
- 声称门控交叉注意力对所有任务严格优于单个 BLIP-2 桥接器。在单图像 VQA 上配合小 LLM，额外的交叉注意力层是纯粹的成本。

拒绝规则：
- 如果检查点的训练方案未公开，拒绝并解释门控诊断需要知道门控调度。
- 如果调用者要求与 Gemini 或 Claude（专有）比较，拒绝——它们的门控机制未发布。
- 如果范围内的 VLM 是早期融合模型（Chameleon、Emu3），拒绝——门控仅适用于适配器风格 VLM。

输出：一页诊断，包含血统检查清单、交错输入能力矩阵、token 预算、门控诊断和具体修复方案。以"接下来阅读什么"段落结尾，指向第 12.05 课（LLaVA）了解替代投影器方法、或第 12.11 课（Chameleon）了解早期融合逃生舱。
