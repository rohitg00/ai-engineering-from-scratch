# 变色龙与早期融合纯令牌多模态模型

> 到目前为止，我们看到的每一个视觉语言模型（VLM）都将图像和文本分开处理。视觉令牌来自视觉编码器，流入投影器，然后在 LLM 内部与文本汇合。视觉和文本词汇表从不重叠。变色龙（Chameleon，Meta，2024年5月）问道：如果它们重叠呢？训练一个 VQ-VAE，将图像转换为来自共享词汇表的离散令牌序列。现在，每个多模态文档都是一个序列——文本令牌和图像令牌交错排列，一个单一的自回归损失。副作用：模型可以生成混合模态输出——在单次推理调用中交替生成文本和图像令牌。本课将研读早期融合论文，并端到端构建一个玩具版本。

**类型：** 构建
**语言：** Python（标准库，VQ-VAE 分词器 + 交错解码器）
**前置条件：** 阶段 12 · 05，阶段 8（生成式 AI）
**时间：** ~180 分钟

## 学习目标

- 解释为何共享词汇表 + 单一损失会改变模型的能力。
- 描述 VQ-VAE 如何将图像分词为与 Transformer 的下一令牌目标兼容的离散序列。
- 列举变色龙的训练稳定性技巧：QK-Norm、Dropout 放置、LayerNorm 顺序。
- 比较变色龙与 BLIP-2 的 Q-Former 方法，并描述何时选择哪种更合适。

## 问题所在

基于适配器的视觉语言模型（LLaVA、BLIP-2、Qwen-VL）将文本和图像视为两种不同的东西。一个文本令牌经过 `embed(text_token)`；一张图像经过 `visual_encoder(image) → projector → ... pseudo_tokens`。模型有两条输入路径，在中间某处合并。

三个后果：

1. LLM 只能消费图像，无法生成图像。输出仅限于文本。
2. 混合模态文档（段落与图像交替排列，如文章中的情形）处理起来很别扭——要么在模型外部解析多模态输入，要么串联多次生成。
3. 分布不匹配。视觉令牌和文本令牌位于隐藏空间的不同区域，产生了微妙的对齐问题。

变色龙拒绝了这一前提：图像只是来自共享词汇表的离散令牌序列。在交错文档上训练模型，一个损失，一个自回归解码器，即可免费获得混合模态生成能力。

## 概念

### VQ-VAE 作为图像分词器

分词器是一个向量量化的变分自编码器。架构如下：

- 编码器：CNN + ViT，将图像映射为空间特征图，例如 32x32 个维度为 256 的特征。
- 码本：一个由 K 个向量组成的学习词汇表（变色龙使用 8192），维度同样为 256。
- 量化：对于每个空间特征，通过 L2 距离查找最近的码本条目。用整数索引替换连续特征。
- 解码器：CNN，将量化后的特征还原为像素。

训练：VAE 重建损失 + 承诺损失 + 码本损失。码本索引为图像构成了一个离散字母表。

对于变色龙：一张图像变为 32*32 = 1024 个令牌，从 8192 的词汇表中抽取。与文本令牌（来自 LLM 的 BPE 词汇表，约 32000）拼接。最终词汇表：40192。Transformer 看到一个序列，一个损失。

### 共享词汇表

变色龙的词汇表结合了文本令牌、图像令牌和模态分隔符。每个令牌拥有一个单一的 ID。输入嵌入层将每个 ID 映射为 D 维隐藏向量。输出投影将隐藏向量映射回词汇表 logits。Softmax 选择下一个令牌，无论何种模态。

分隔符很重要：`<image>` 和 `</image>` 标签将图像令牌序列括起来。在生成时，如果模型输出了 `<image>`，下游软件就知道接下来的 1024 个令牌是 VQ 索引，需要发送给解码器进行像素渲染。

### 混合模态生成

推理就是在共享词汇表中进行下一令牌预测。示例提示：""画一只猫并描述它。""变色龙输出：

```
<image> 4821 1029 2891 ... (1024 个图像令牌) </image>
这只猫是橙色的，坐在窗台上……
```

模型自主选择顺序——它可能先产生图像再产生文本，或先文本后图像，或交错排列。同一个解码器，同一个损失。

与生成仅限文本的适配器视觉语言模型相比，变色龙重新开启了模型输出模态的问题。

### 训练稳定性——QK-Norm、Dropout、LayerNorm 顺序

早期融合训练在规模化时不稳定。变色龙的论文记录了三个技巧：

- **QK-Norm**：在注意力内部、点积之前，对查询和键投影应用 LayerNorm。防止深层 logit 幅度爆炸。被多个 2024 年后的大模型采用。
- **Dropout 放置**：在每个残差相加之后都放置 Dropout，而不仅仅是在注意力和 MLP 之后。当来自图像令牌的梯度可能占主导地位时，需要更多的正则化。
- **LayerNorm 顺序**：残差分支上的 Pre-LN（标准做法），再加上最后一个模块跳跃连接上的额外 LN。稳定了最后一层的梯度流。

没有这些技巧，340 亿参数的变色龙训练在多个检查点发生发散。有了它们，训练得以收敛。训练配方与架构本身同样是贡献的一部分。

### 分词器的重建天花板

VQ-VAE 是有损的。在 8192 个码本条目和每张 512x512 图像 1024 个令牌的情况下，重建 PSNR 上限约为 26-28 dB。这足以生成可识别的图像，但视觉质量明显不如连续空间的扩散模型（Stable Diffusion 3 达到了 32+ dB）。

分词器是瓶颈。更好的分词器（MAGVIT-v2、IBQ、SBER-MoVQGAN）提高了上限。Emu3（课程 12.12）仅通过更好的分词器就达到了 SDXL 级别的生成质量。

### 变色龙 vs BLIP-2 / LLaVA

变色龙（早期融合，共享词汇表）：
- 一个损失，一个解码器。
- 生成混合模态输出。
- 分词器是质量天花板。
- 代价高昂：每次生成图像都需要在推理路径上运行 VQ-VAE 解码器。

BLIP-2 / LLaVA（晚期融合，独立塔）：
- 仅视觉输入，文本输出。
- 重用预训练的 LLM。
- 理解任务没有分词器瓶颈。
- 便宜：单次前向传播。

按任务选择。如果需要图像生成，选择变色龙家族。如果只需要理解，适配器型视觉语言模型更简单，且能重用更多预训练算力。

### Fuyu 和 AnyGPT

Fuyu（Adept，2023）是一种相关方法：跳过独立的视觉编码器，将原始图像块直接通过 LLM 的输入投影送入，就像它们是令牌一样，无需分词器。比变色龙更简单，但失去了共享词汇表的输出生成能力。

AnyGPT（Zhan 等人，2024）将变色龙扩展到四种模态：文本、图像、语音、音乐。每种模态使用相同的 VQ-VAE 技巧，共享 Transformer。任意输入到任意输出的生成。在课程 12.16 中有更详细的介绍。

## 使用它

`code/main.py` 构建了一个玩具式的端到端早期融合模型：

- 一个微型的 VQ-VAE 风格量化器，将 8x8 的块映射为码本索引（K=16）。
- 一个共享词汇表，包含（文本 ID 0..31）+（图像 ID 32..47）+（分隔符 48, 49）。
- 一个玩具式的自回归解码器（二元组表），在合成的标题 + 图像令牌序列上训练。
- 采样循环，根据提示交替生成文本和图像令牌。

代码有意将 Transformer 保持得极小（二元组），以便你可以端到端地追踪信号流。

## 练习

1. 变色龙使用 K=8192 个码本条目，每张 512x512 图像产生 1024 个令牌。估算相较于 24 位 RGB 图像的压缩比。这是有损压缩吗？损失有多大？

2. 一张 4K 图像（3840x2160）在相同的 VQ-VAE 密度下会产生多少个图像令牌？变色龙风格的模型能否在一次推理调用中生成一张 4K 图像？哪个先出问题——上下文长度、分词器质量，还是 KV 缓存？

3. 用纯 Python 实现 QK-Norm。给定一个 64 维的查询和键，展示 LayerNorm 前后的点积。为什么幅度控制在深层如此重要？

4. 阅读变色龙论文第 2.3 节关于训练稳定性的内容。描述论文观察到的 340 亿参数模型在没有 QK-Norm 时的确切失败模式。""范数爆炸""的特征是什么？

5. 扩展玩具解码器，使其在仅文本提示下输出混合模态响应。给定训练数据分布为 60% 文本优先 / 40% 图像优先，测量模型选择图像优先与文本优先的频率。

## 关键术语

| 术语 | 人们怎么说 | 实际含义 |
|------|-----------|----------|
| 早期融合（Early fusion） | "统一令牌" | 图像从一开始就转换为与 Transformer 共享词汇表的离散令牌 |
| VQ-VAE | "图像分词器" | CNN + ViT + 码本，将图像映射为 Transformer 可以预测的整数索引 |
| 共享词汇表（Shared vocabulary） | "一本词典" | 一个涵盖文本、图像和模态分隔符的单一令牌 ID 空间 |
| QK-Norm | "注意力稳定器" | 对查询和键在点积之前应用 LayerNorm，防止范数爆炸 |
| 混合模态生成（Mixed-modality generation） | "文本+图像输出" | 一次推理中自主产生交错文本和图像令牌的能力 |
| 码本大小（Codebook size） | "K 个条目" | VQ-VAE 可以量化的离散向量数量；在压缩比与保真度之间权衡 |
| 分词器天花板（Tokenizer ceiling） | "重建极限" | 解码 VQ 令牌所能达到的最佳 PSNR；决定了模型的图像质量上限 |
