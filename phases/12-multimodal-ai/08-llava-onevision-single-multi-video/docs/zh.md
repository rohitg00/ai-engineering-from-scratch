# LLaVA-OneVision：单图、多图、视频，一个模型通吃

> 在 LLaVA-OneVision（Li 等人，2024 年 8 月）之前，开源 VLM 世界分裂成了不同的谱系：LLaVA-1.5 专攻单图，Mantis 和 VILA 等模型专攻多图，Video-LLaVA 和 Video-LLaMA 等模型专攻视频。每个都在自己的基准上独占鳌头，却在其他场景上一败涂地。LLaVA-OneVision 认为，一个精心设计的课程（Curriculum）就能训练出在所有三种场景下都擅长的单一模型，而且由此涌现的任务迁移效应（单图技能迁移到视频、多图推理迁移到单图）胜过各个专家模型的总和。其秘诀出奇地简单：一个跨场景保持恒定的视觉令牌预算，再加上一个明确的课程——从单图到 OneVision（多图）再到视频。本课程将深入解读这个预算、课程以及涌现行为。

**类型：** 构建（Build）
**语言：** Python（标准库，令牌预算求解器 + 课程规划器）
**前置条件：** 阶段 12 · 05（LLaVA），阶段 12 · 06（任意分辨率）
**预计耗时：** ~180 分钟

## 学习目标

- 设计一个在单图、多图和视频输入中保持恒定的视觉令牌预算。
- 编排一个训练课程，使技能从单图迁移到视频而不会灾难性遗忘。
- 解释为什么在课程编排得当的情况下，单一模型在相同参数量下能胜过专家模型。
- 说出 LLaVA-OneVision 报告的三种涌现能力：多摄像头推理、标记集提示（Set-of-Mark Prompting）、iPhone 截图智能体。

## 问题所在

图片、多图和视频各自对模型提出了不同的压力。

单图场景需要高分辨率令牌（AnyRes，约 2880 个视觉令牌）以捕捉 OCR 和细粒度细节。每个样本的预算：一张图，2880 个令牌。

多图场景需要多张中等分辨率图像（每张约 576 个令牌），以便跨图像推理能放入上下文。每个样本的预算：4-8 张图，每张 576 个令牌，共 2300-4600 个令牌。

视频场景需要大量低分辨率帧（池化后每帧约 196 个令牌），以捕捉时间动态。每个样本的预算：8-32 帧，每帧 196 个令牌，共 1600-6200 个令牌。

如果训练独立的模型，你可以为每个模型选择一个预算。但如果训练一个模型，就需要预算能跨场景合理缩放，同时不撑爆上下文。

在 OneVision 之前，默认的答案是"只训练一个场景，忽略其他"。Video-LLaVA 通过额外的训练阶段将视频能力改造到了图像模型上。LLaVA-NeXT 通过分块（tiling）增加了多图支持。但没有一个模型能干净利落地处理全部三种场景。

## 核心概念

### OneVision 令牌预算

LLaVA-OneVision 为每个样本选择了一个统一的大约 3000-4000 个令牌的视觉预算，按场景进行不同分配：

- **单图：** AnyRes-9（3×3 瓦片 + 缩略图），每个瓦片 384 分辨率，729 个补丁，激进的 2×2 双线性池化 → 每个瓦片 182 个令牌。总计：9 × 182 + 182 = 1820 个令牌。或者 AnyRes-4，每瓦片 729 个令牌 = 2916 + 729。
- **多图：** 每张图像中等分辨率（384，不分块），729 个令牌，无池化。6 张图像的预算 → 4374 个令牌。
- **视频：** 32 帧，384 分辨率，激进的 3×3 双线性池化 → 每帧 81 个令牌。总计：32 × 81 = 2592 个令牌。

这种分配保持了大致恒定的总令牌数。LLM 永远不会看到一个撑爆其上下文的批次。编码器按场景产生不同的几何结构，但 LLM 消耗的是相同的预算。

### 三阶段课程

LLaVA-OneVision 分三个阶段进行训练：

1. **单图 SFT（阶段 SI）。** 所有数据都是单图加文本。在高分辨率 AnyRes 输入上训练。这教会模型感知、OCR 和细粒度理解。使用 LLaVA-NeXT 数据加上 OneVision 专属的单图数据。
2. **OneVision SFT（阶段 OV）。** 混合单图 + 多图 + 视频（均匀采样帧）。在统一的令牌预算上训练。这会教会模型处理异构的批量形状。不重置权重——从阶段 SI 继续训练。
3. **任务迁移（阶段 TT）。** 按目标任务混合继续训练，通常根据产品需求加重多图或视频的比例。可选的精调阶段用于部署。

**关键点：** 课程顺序至关重要。先训练视频或多图，即使数据相同，也会比先训练单图产生更差的图像性能。论文对此进行了明确的消融实验验证。

### 课程为什么有效

单图训练建立了感知基础。补丁令牌携带细粒度的视觉特征；LLM 学会将它们与文本整合。多图和视频引入了结构性挑战（哪张图是哪张，哪个事件先发生），在没有强大感知基础的情况下很难学会。

如果你从一开始就一起训练所有场景，模型会欠拟合感知（每个批次中有限的单图数据）而过度拟合结构（大量的多图/视频数据）。结果是：模型能遵循跨图像推理模式，但视觉能力很浅。

课程编排给你阶段 SI 带来的感知强度，再加上阶段 OV 带来的组合/时间推理能力，且不会丢失任何一方。

### 涌现的跨场景技能

LLaVA-OneVision 论文报告了三种涌现能力：

1. **多摄像头推理。** 分别在多图和视频上训练；在推理时，要求模型推理一个多摄像头驾驶场景。尽管从未在训练中见过这种确切格式，模型仍能正确整合多个视角。
2. **标记集提示（Set-of-Mark Prompting）。** 用户在图像中用编号标记标注物体；模型推理"标记 3 相对于标记 7 在做什么"。从未在标记或标注上训练过；从空间定位 + 多图引用的组合中学会。
3. **iPhone 截图智能体。** 用户提供一张 iPhone 屏幕截图并询问下一步点击计划。在 UI 截图、用户操作流程视频以及多图操作前后对比对上训练。泛化到智能体用例。

这些不是训练过的任务，而是从课程的组合结构中涌现出来的。

### 视觉令牌池化

令牌预算需要池化。OneVision 在 2D 补丁网格上使用双线性插值：24×24 = 576 个补丁变成 12×12 = 144（2 倍因子）或 8×8 = 64（3 倍因子）。池化在补丁网格空间而非令牌空间中进行，以保持局部性。

每个场景的池化因子选择本身就是一个超参数。池化越少 = 令牌越多 = 表示越丰富。池化越多 = 令牌越少 = 能容纳更多帧/图像。

### LLaVA-OneVision-1.5

2025 年的后续工作（LLaVA-OneVision-1.5，arXiv 2509.23661）在训练数据、模型权重和代码上做到了"完全开放"。缩小了与闭源模型的差距，并将这一配方民主化。相同的课程，更多的数据，更好的基础 LLM。没有架构变化。

### 与 Qwen2.5-VL 的对比

Qwen2.5-VL（课程 12.09）做出了不同的选择。它使用 M-RoPE 和动态 FPS，而不是固定池化。其预算随输入缩放——1 分钟的视频比 5 秒的视频使用更多令牌。LLaVA-OneVision 则固定预算，缩放池化。两者都有效；它们在可配置性与可预测性之间做出了不同的取舍。

## 如何使用

`code/main.py` 是一个面向 OneVision 风格 VLM 的课程与预算规划器。给定每个样本的令牌预算和目标场景混合比例（例如 40% 单图、30% 多图、30% 视频），它将：

- 为每个场景分配分辨率、池化因子和帧数。
- 检查每个场景是否都在共享预算之内。
- 报告预期的令牌数量、LLM 的 FLOPs 以及哪些场景的令牌数不足。
- 输出一个分阶段的训练计划。

用它来规划 OneVision 的精调，或检查 VLM 部署的每请求成本是否合理。

## 成果交付

本课程会产生 `outputs/skill-onevision-budget-planner.md`。给定目标任务分布和每个样本的预算，它会输出 AnyRes 因子、每帧池化方式、视频帧数和课程阶段权重。当你训练或精调一个统一场景的 VLM 时，随时可以使用这份产出。

## 练习

1. 你的产品支持 80% 单图、10% 多图（2-4 张图）、10% 视频（8-16 帧）。设计令牌预算。你会把从非重多图场景中省下的额外预算用在哪里？

2. 阅读 LLaVA-OneVision 第 4.3 节（涌现能力）。提出一个课程很可能会解锁但论文未报告的第四种涌现技能。

3. 交换课程顺序——先训练多图，然后是单图，最后是视频。预测哪些基准会下降以及为什么。

4. 论文报告的视频基准只用了每个样本 8 帧进行训练。这能泛化到推理时的 30 秒视频吗？哪个会先出问题——令牌预算还是时间推理？

5. 将 24×24 的补丁双线性池化到 12×12 是每个维度 4 倍的缩减。用标准库 Python 实现该池化，并验证每个 2×2 块上的均值与双线性输出一致。

## 关键术语

| 术语 | 大家说的 | 实际含义 |
|------|---------|---------|
| OneVision 场景 | "单图、多图或视频" | 统一 VLM 处理的三种输入形态之一；预算在不同场景间保持恒定 |
| 令牌预算 | "每个样本有多少令牌" | LLM 在每个训练/推理样本中看到的视觉令牌总数，通常为 3000-4000 |
| 课程 | "训练顺序" | 为涌现式迁移而选的阶段顺序（单图 → 多图 → 视频） |
| 双线性池化 | "令牌压缩" | 对补丁网格（2D）应用双线性插值以减少令牌数量，同时保持局部性 |
| 涌现技能 | "没训练过，但仍然有效" | 在推理时出现的、没有匹配训练数据的能力，源于课程的组合结构 |
| AnyRes-k | "k 瓦片配置" | k 个固定分辨率的子瓦片加一个缩略图，典型的 k ∈ {4, 9} |
| 任务迁移 | "跨场景泛化" | 通过共享主干从单图学习并应用于视频（反之亦然）的技能 |
