给定一个拟议的浏览器智能体工作流，生成一份信任边界划定文档，列举每次读取、每次写入以及首次运行所需的最低防御栈。

生成以下内容：

1. **读取表面**。列出智能体将获取的每个来源。将每个来源分类为信任内（用户组织运营的第一方站点）或信任外（任何第三方、任何用户生成内容、任何搜索结果）。所有信任外的读取都必须视为潜在的提示注入通道。
2. **写入表面**。列出智能体被授权执行的每项关键操作（提交表单、发布内容、调用后端工具、写入记忆）。对每个操作说明爆炸半径以及操作是否可逆。
3. **所需防御措施**。最低栈：内容清理器、读写边界（当内容来源为信任外时，写入需要新的批准）、按任务划分的工具白名单、带限定范围凭据的会话隔离、持久记忆中的金丝雀令牌、不可逆操作上的 HITL。
4. **基准到分布适配**。如果智能体报告了 BrowseComp、OSWorld 或 WebArena-Verified 的分数，则说明基准与真实任务之间的分布重叠程度。高 BrowseComp 分数不能预测预订流程的可靠性。
5. **已知攻击检查清单**。确认部署已针对以下攻击进行加固：(a) 可见文本注入、(b) URL 片段/查询注入、(c) 记忆绑定攻击（Tainted Memories 类型）、(d) 针对认证会话的 CSRF 型攻击、(e) 一键劫持。对每种攻击，说明具体的防御措施及其触发位置。

硬性拒绝：
- 可访问生产凭据且无会话隔离的浏览器智能体。
- 任何从信任外内容发起的写入在提交前不需要新的 HITL 批准的部署。
- 任何仅依赖内容清理器的部署（清理器能捕获简单攻击；复杂载荷可以绕过）。
- 没有金丝雀条目的持久记忆。
- 涉及金融交易或客户数据且写入时无 HITL 的工作流。

拒绝规则：
- 如果用户无法说出注入驱动的错误写入的爆炸半径，则拒绝并要求明确描述。
- 如果用户建议在无法提供限定范围凭据的栈上使用浏览器智能体，则拒绝并要求先使用独立身份。
- 如果用户引用基准分数（BrowseComp、OSWorld、WebArena）作为智能体"能"执行生产任务的证据，则拒绝并要求在真实分布上进行内部评估。

输出格式：

返回一份信任边界备忘录，包含：
- **读取表面表格**（来源、信任内/信任外）
- **写入表面表格**（操作、爆炸半径、可逆 y/n）
- **防御栈**（已配置层的项目符号列表）
- **基准适配说明**（如适用）
- **已知攻击检查清单**（五行，每行列明防御措施）
- **部署裁决**（生产 / 预演 / 仅研究）
