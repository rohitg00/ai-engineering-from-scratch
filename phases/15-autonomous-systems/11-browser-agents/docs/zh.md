# 浏览器代理与长周期网络任务

> ChatGPT 代理（2025 年 7 月）将 Operator 与深度研究融合为一个浏览器/终端代理，并将 BrowseComp 的 SOTA 推至 68.9%。OpenAI 于 2025 年 8 月 31 日关闭 Operator——产品层面的整合。Anthropic 收购 Vercept 后将 Claude Sonnet 在 OSWorld 上的成绩从不足 15% 提升至 72.5%。WebArena-Verified（ServiceNow，ICLR 2026）修复了原始 WebArena 中 11.3 个百分点的假阴性率，并发布了包含 258 个任务的 Hard 子集。这些数字是真实的。攻击面同样真实：OpenAI 的防备主管公开表示，针对浏览器代理的间接提示注入"不是一个可以完全修补的漏洞"。2025-2026 年已记录的攻击包括：Tainted Memories（Atlas CSRF）、HashJack（Cato Networks），以及 Perplexity Comet 中的一键劫持。

**类型：** 学习
**语言：** Python（标准库，间接提示注入攻击面模型）
**前置条件：** 阶段 15 · 10（权限模式），阶段 15 · 01（长周期代理）
**时间：** 约 45 分钟

## 问题

浏览器代理是一种读取不可信内容并执行重要操作的长周期代理。代理访问的每个页面都是用户未曾编写的输入。每个页面上的每个表单都是潜在的指令通道。2025-2026 年的攻击实例表明这并非假设：Tainted Memories 让攻击者通过精心构造的页面将恶意指令绑定到代理的記憶中；HashJack 将指令隐藏在代理访问的 URL 片段中；Perplexity Comet 在单次点击中就能完成劫持。

防御的形势令人不安。OpenAI 的防备主管直言不讳：间接提示注入"不是一个可以完全修补的漏洞"。这是因为攻击存在于代理的"读取与执行"边界上，而这在架构上是模糊的——模型读取的每一个 token 原则上都可以被解读为指令。

本节课命名了攻击面，命名了基准测试格局（BrowseComp、OSWorld、WebArena-Verified），并对一个最小化的间接提示注入场景进行建模，以便你在第 14 课和第 18 课中思考真正的防御策略。

## 概念

### 2026 年格局，每个系统一段话

**ChatGPT 代理（OpenAI）。** 于 2025 年 7 月推出。统一了 Operator（浏览器操作）和深度研究（多小时研究）。2025 年 8 月 31 日关闭独立的 Operator。BrowseComp 上的 SOTA 为 68.9%；在 OSWorld 和 WebArena-Verified 上表现强劲。

**Claude Sonnet + Vercept（Anthropic）。** Anthropic 收购 Vercept 专注于计算机使用能力。将 Claude Sonnet 在 OSWorld 上的成绩从 <15% 提升至 72.5%。Claude Computer Use 以工具 API 形式提供。

**Gemini 3 Pro + Browser Use（DeepMind）。** Browser Use 集成提供了计算机使用控制；FSF v3（2026 年 4 月，第 20 课）专门跟踪机器学习研发领域的自主性。

**WebArena-Verified（ServiceNow，ICLR 2026）。** 修复了一个有据可查的问题：原始 WebArena 存在约 11.3% 的假阴性率（任务被标记为失败但实际上已解决）。Verified 版本使用人工整理的成功标准重新评分，并增加了包含 258 个任务的 Hard 子集（ICLR 2026 论文，openreview.net/forum?id=94tlGxmqkN）。

### BrowseComp vs OSWorld vs WebArena

| 基准测试 | 测量内容 | 时间跨度 |
|---|---|---|
| BrowseComp | 在时间压力下在开放网络上寻找特定事实 | 分钟级 |
| OSWorld | 代理操作完整桌面（鼠标、键盘、终端） | 数十分钟 |
| WebArena-Verified | 在模拟站点中完成事务性网络任务 | 分钟级 |
| Hard 子集 | 需要跨多页面状态转换的 WebArena-Verified 任务 | 数十分钟 |

不同维度。高分 BrowseComp 说明代理能找事实；但不能说明代理能订机票。OSWorld 分数更接近"它能在我的桌面上工作吗"。WebArena-Verified 更接近"它能完成一个完整流程吗"。任何生产决策都需要使用与任务分布匹配的基准测试。

### 攻击面，逐一命名

1. **间接提示注入。** 不可信的页面内容包含指令。代理读取这些指令。代理执行这些指令。公开示例：2024 年 Kai Greshake 等人，2025 年 Tainted Memories 论文，2026 年 HashJack（Cato Networks）。
2. **URL 片段/查询注入。** 被爬取 URL 的 `#fragment` 或查询字符串中包含指令。从不以可视方式呈现；但仍存在于代理的上下文中。
3. **記憶绑定攻击。** 页面指示代理写入持久化記憶（第 12 课涵盖持久化状态）。下次会话时，该記憶在没有可见触发条件的情况下执行载荷。
4. **针对已认证会话的 CSRF 式攻击。** Tainted Memories 类别：代理已在某处登录；攻击者的页面发出状态更改请求，代理使用用户的 Cookie 执行该请求。
5. **一键劫持。** 一个视觉上无害的按钮承载着代理会跟随的载荷。Comet 类别。
6. **代理主机表面上的内容安全策略漏洞。** 渲染层和工具层本身可能成为攻击媒介；浏览器中的浏览器代理堆栈非常宽泛。

### 为什么"无法完全修补"

攻击与代理的能力同构。代理必须读取不可信内容才能完成其工作。代理读取的任何内容都可能包含指令。代理遵循的任何指令都可能与用户的真实请求不一致。防御措施（信任边界、分类器、工具白名单、重要操作的人工确认）提高了攻击成本并缩小了其影响范围。但它们并不能从根本上消灭这类攻击。

这与 Lob 定理（第 8 课）的推理模式相同：代理无法证明下一个 token 是安全的；它只能建立一个系统，使不安全的 token 更易于被检测到。

### 实际落地的防御策略

- **读/写边界。** 读取永远不产生实质性后果。写入（提交表单、发布内容、调用有副作用的工具）需要重新获得人工批准，前提是发起内容来自信任边界之外。
- **按任务制定的工具白名单。** 代理可以浏览网页；但除非该任务明确启用了转账工具，否则代理不能发起银行转账。第 13 课涵盖预算。
- **会话隔离。** 浏览器代理会话仅使用作用域凭据运行。无生产环境认证，无个人邮箱。每次 HTTP 请求的日志均保留以供审计。
- **内容清理器。** 在获取的 HTML 拼接到模型上下文之前，剥离已知的恶意模式。（减少简单攻击；无法阻止复杂载荷。）
- **重要操作的人工确认。** "提议后提交"模式（第 15 课）。
- **記憶的金丝雀标记。** 如果某条記憶条目被触发，用户会看到它（第 14 课）。

## 使用它

`code/main.py` 模拟了一个小型浏览器代理在三个合成页面上的运行。一个页面是良性的，一个在可见文本中包含直接的提示注入代码块，一个包含 URL 片段注入（不可见但存在于代理上下文中）。该脚本展示了 (a) 一个朴素的代理会做什么，(b) 读/写边界能捕获什么，(c) 清理器能捕获什么，(d) 两者都无法捕获什么。

## 交付它

`outputs/skill-browser-agent-trust-boundary.md` 界定了一个拟议的浏览器代理部署范围：它触及哪些信任区域、它被授权写入什么、以及在首次运行前必须部署哪些防御措施。

## 练习

1. 运行 `code/main.py`。识别哪些攻击是清理器能捕获但读/写边界不能捕获的，以及哪些攻击只有读/写边界才能捕获。

2. 扩展清理器，使其能检测一类 HashJack 风格的 URL 片段注入。测量在包含合法片段的良性 URL 上的假阳性率。

3. 选择一个你了解的真实的浏览器代理工作流（例如"预订机票"）。列出每一次读取和每一次写入。标记哪些写入需要人工确认并说明原因。

4. 阅读 WebArena-Verified ICLR 2026 论文。找出原始 WebArena 评分不可靠的一类任务，并解释 Verified 子集如何解决该问题。

5. 为浏览器代理场景设计一个記憶金丝雀标记。你会存储什么、存储在哪里，以及什么会触发警报？

## 关键术语

| 术语 | 人们说的 | 实际含义 |
|---|---|---|
| 间接提示注入 | "坏页面文本" | 代理读取的页面中的不可信内容包含代理执行的指令 |
| Tainted Memories | "記憶攻击" | 代理将攻击者提供的指令写入持久化記憶；下次会话触发 |
| HashJack | "URL 片段攻击" | 载荷隐藏在 URL 片段/查询字符串中，存在于代理上下文中但不以可视方式呈现 |
| 一键劫持 | "坏按钮" | 可见的操作界面承载着代理随后执行的载荷 |
| BrowseComp | "网络搜索基准" | 在开放网络上寻找特定事实；分钟级时间跨度 |
| OSWorld | "桌面基准" | 完整的操作系统控制；多步骤 GUI 任务 |
| WebArena-Verified | "修复的网络任务基准" | ServiceNow 重新评分的 WebArena，包含 Hard 子集 |
| 读/写边界 | "副作用闸门" | 读取从不产生实质性后果；如果内容来自信任边界之外，写入需要重新获得批准 |
