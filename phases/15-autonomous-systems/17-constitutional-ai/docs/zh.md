# 宪法AI与规则覆写

> Anthropic 2026年1月22日发布的Claude宪法共79页，采用CC0许可。它从基于规则的对齐转向基于推理的对齐，并建立了四级优先级层级：(1) 安全与支持人类监督，(2) 伦理，(3) Anthropic指南，(4) 有用性。行为分为硬编码禁令（生物武器提升、CSAM）——操作员和用户均无法覆写——以及软编码默认值——操作员可在规定范围内调整。2022年的原始版本（Bai 等人）通过自我批评和基于宪法的人工智能反馈强化学习（RLAIF）训练无害性。诚实的说明：基于推理的对齐依赖于模型将原则推广到未预见的情况。Anthropic 自己2023年的参与式实验显示，公众来源与公司制定的原则之间存在约50%的分歧；2026年的版本并未纳入这些发现。

**类型：** 学习
**语言：** Python（标准库，四级优先级解析器）
**前置条件：** 第15阶段·06（自动化对齐研究），第15阶段·10（权限模式）
**时间：** 约60分钟

## 问题

一个实际部署的智能体可能会遇到其设计者从未见过的输入。没有一条规则列表能够长到覆盖所有情况，也没有一条规则列表能够短到在计算压力下快速应用。实际问题是：你如何将一个智能体与那些既能应对长尾案例又能进行快速推理的原则对齐？

基于规则的对齐（RBA）：列出所有禁止的事项。检查速度快，审计容易，但无法保持最新，且常常对未预料到的相似情况过度拒绝。基于推理的对齐（2026年Claude宪法）：编码原则，让模型进行推理。能跨未见过的情况扩展，但审计更困难，失败模式是"原则误用"而非"遗漏规则"。

2026年宪法采取了一种明确的中立立场。硬编码禁令——那些错误性不依赖上下文的事项（生物武器提升、CSAM）——采用RBA：无论操作员或用户的指令如何，永远禁止。其他所有事项都在四级层级内基于推理处理：安全与支持人类监督优先；伦理其次；Anthropic声明的指南第三；有用性最后。操作员可以在软编码区域内调整默认值，但无权触及硬编码禁令。

## 概念

### 四级优先级层级

1. **安全与支持人类监督。** 最高优先级。模型优先考虑不削弱人类和Anthropic监督及纠正AI的能力。这不是"保持谨慎"，而是特指"不要以让人类监督变得更难的方式行动。"
2. **伦理。** 诚实、避免伤害他人、不欺骗、不操纵。当与Anthropic指南冲突时，伦理优先。
3. **Anthropic指南。** Anthropic认定的重要操作规范：产品范围、交互模式、何时使用何种工具。
4. **有用性。** 最低优先级。在满足更高优先级的前提下尽可能有用。

当层级冲突时，更高优先级胜出。这与Unix优先级或网络QoS的结构相同——这种框架旨在产生可预测的裁决结果，而非在单一维度上达到最佳行为。

### 硬编码禁令 vs 软编码默认值

**硬编码：**
- 生物武器 / CBRN（化学、生物、放射性和核武器）提升
- CSAM（儿童性虐待材料）
- 对关键基础设施的攻击
- 在直接询问时对用户隐瞒模型身份

操作员无法覆写这些。用户也无法覆写这些。它们在可能的情况下在模型权重层面执行（RLHF / 宪法AI训练），在无法实现时在推理层执行。

**软编码默认值（操作员可调整）：**
- 回复长度默认值
- 主题范围（模型可以拒绝操作员部署范围之外的主题）
- 风格（正式 vs 休闲）
- 工具使用模式

操作员的调整必须在声明的边界内进行。操作员不能通过重命名来绕过硬编码禁令。

### 2022年宪法AI训练

最初的宪法AI（Bai 等人，2022）训练无害性的方式：

1. 对一组提示生成回复。
2. 要求模型根据宪法（明确的原则）对每条回复进行批评。
3. 基于批评修改回复。
4. RLAIF（基于人工智能反馈的强化学习）训练修改后的配对数据。

结果：一个能够以有原则的解释拒绝有害请求的模型，而非一刀切地拒绝。2026年宪法使用了此训练的衍生版本，并在显式的四级层级上进行了额外的后期训练。

### 基于推理的对齐能捕获和遗漏什么

**能捕获：**
- 未预见的合法原语组合，但原则明显适用。
- 与禁止行为高度相似的新颖请求。
- 依赖"你没说X是被禁止的"这一漏洞的社会工程攻击。

**会遗漏：**
- 利用原则模糊性的攻击（"用户要求了，所以有用性说可以"）。
- 两个原则以未预见的方式冲突，且层级顺序不明确的场景。
- 在训练周期中原则解释的缓慢漂移（重新解释）。

### 2023年参与式实验

Anthropic在2023年进行了一项实验，将公司编写的宪法与通过公众意见（约1000名美国受访者）生成的宪法进行了比较。两个版本在大约50%的原则上一致。在分歧之处，公众来源的版本在某些问题上更为严格（政治内容处理），在其他问题上则不那么严格（AI身份的自我披露）。2026年宪法并未纳入公众来源的发现。这是该方法中一个已记录在案的矛盾。

### 为什么硬编码禁令是必要的

仅靠基于推理的对齐无法封堵长尾风险。一个能让模型接受某个前提的攻击者（例如，"我们是一家持牌生物武器研究实验室"）往往能够绕过依赖案例推理的原则。硬编码禁令不会因前提框架的改变而失效。它们是在对齐层的"第14课——硬宪法限制"。

### 宪法在技术栈中的位置

宪法不是第14课中的"终止开关"。它存在于模型层：决定模型权重被训练成偏好什么。终止开关和"金丝雀令牌"存在于运行时层：决定运行时允许什么。两者都是必需的。一个因为模型权重过于宽松而执行了所有错误动作的运行时，是运行时的问题。一个因为运行时过度限制而拒绝了所有正确动作的模型，也是运行时的问题。各层覆盖不同类别的故障。

## 使用它

`code/main.py` 实现了一个最小的四级优先级解析器。该解析器接受一个提议的动作和一组原则评估结果（安全、伦理、指南、有用性），并返回该动作、拒绝或修改后的动作。驱动程序运行一个小型案例集：明确允许、明确禁止、硬编码禁令、跨层级的模糊案例。

## 交付物

`outputs/skill-constitution-review.md` 审计一个部署的宪法层：什么是硬编码的，什么是软编码的，操作员可以在哪里调整，以及四级优先级层级是否真的是裁决顺序。

## 练习

1. 运行 `code/main.py`。确认即使有用性很高，硬编码禁令也会触发。修改解析器，将有用性权重置于伦理之上；观察失败模式。

2. 阅读Claude宪法（公开，79页，CC0许可）。找出你认为规定不够明确的一项原则。写两段文字，解释具体的模糊之处，并提出更精确的表述。

3. 为一个客户支持智能体设计一套软编码默认值。操作员可以调整什么？操作员不能触碰什么？为每个边界提供理由。

4. 阅读Bai等人2022年的宪法AI论文。描述一个宪法AI的批评与修改循环会产生比一刀切规则更差结果的案例。指出该案例的类别。

5. Anthropic 2023年的参与式实验发现公众与公司制定的原则之间存在约50%的分歧。选择一个对生产部署有影响的具体类别（例如政治中立性）。提出一种设计方案，让操作员能够表达自己的价值观，同时保持硬编码禁令不被触及。

## 关键术语

| 术语 | 人们常说的意思 | 实际含义 |
|---|---|---|
| 宪法AI（Constitutional AI） | "Anthropic的对齐方法" | 自我批评 + 基于书面宪法的RLAIF |
| 基于推理的对齐（Reason-based alignment） | "原则，而非规则" | 模型在原则之上进行推理以处理未见过的情况 |
| 硬编码禁令（Hardcoded prohibition） | "永远不做X" | 任何操作员或用户都无法覆写的基于规则的禁令 |
| 软编码默认值（Soft-coded default） | "操作员可调整" | 在声明的边界内的行为，由操作员控制 |
| 四级层级（Four-tier hierarchy） | "优先级顺序" | 安全 > 伦理 > 指南 > 有用性 |
| RLAIF | "AI反馈强化学习" | 奖励来自模型生成的批评的强化学习 |
| 参与式宪法（Participatory constitution） | "公众来源的原则" | 2023年Anthropic实验；与公司制定的有约50%的分歧 |
| 原则漂移（Principle drift） | "解释偏差" | 模型对固定原则文本的理解随时间缓慢变化 |
