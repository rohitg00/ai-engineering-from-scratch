FIG_SKL · Skills for your coding agent

Skills

A skill is a short instruction file. Your agent reads it when your request matches the skill, then follows its steps. These 17 skills teach the course, test your level, and make figures and manuals.

Install all 17
npx skills add rohitg00/ai-engineering-from-scratch

One skill: add --skill <name>. List them first: add --list. Works with Claude, Cursor, Codex, OpenClaw, Hermes, or any agent that reads SKILL.md.

06

Lesson artifacts

Many lessons end with a skill or prompt file. You can install them by phase or by tag.

409 skills and 100 prompts live next to the lessons that teach them, under phases/**/outputs/. Clone the repo, then copy the ones you want into your agent's skills folder.

python3 scripts/install_skills.py ~/.claude/skills --phase 14
python3 scripts/install_skills.py ~/.cursor/skills --tag rag
python3 scripts/install_skills.py .skills --type all --dry-run

Browse the lessons in the catalog →

Ask for a figure

Tell the skill what the reader must understand and where the figure goes: a lesson, a README, a manual, or a standalone page. Give real numbers when you have them. The figure then computes its result from those numbers.

Example: Make a figure for the skills lesson that shows how an agent loads a skill. Use the real file sizes.
