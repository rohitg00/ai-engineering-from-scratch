How this works

The horizontal coordinates are two weights. Each update subtracts the learning rate times the gradient. Choose a rate to restart at (−1.9, 1.7), then compare how many updates it takes to settle.

w ← w − η∇L
L = (w₁ − 1)² + 0.5(w₂ + 0.8)² + 0.2 sin²(2w₁)

This small illustrative loss function stops when the gradient norm is below 0.01. Its minimum does not have to be zero.

How this works

Choose a query token to change the six attention weights. The sources follow the sentence order from top to bottom. Lower score temperature concentrates the weights; higher temperature spreads them out.

weights = softmax(q · k / (√2 × T))
output = Σ weightⱼ × vⱼ

This tiny head uses hand-chosen, two-dimensional Q/K/V vectors, not trained embeddings. The stream widths and light represent weights; the output above is the actual weighted sum.
