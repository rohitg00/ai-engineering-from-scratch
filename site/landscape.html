    Listing rules
    
        
      
          
    • Open source tools need a public repository with 2,500 or more stars. Closed source tools need a live product on their own domain and public documentation.
      • 
          
    • One entry per tool, in the one category where it fits best.
      • 
          
    • The description says what the tool does in one plain sentence. No rankings, no claims.
      • 
          
    • Someone who works on the tool submits it, or a maintainer adds it.
      • 
          
    • Listing is free and is separate from sponsorship. Sponsors of the course are shown at a larger size and marked as sponsors. Links carry rel="nofollow".
      • 
          
    • Entries with no release or commit for 12 months are removed.
