# Распознавание речи (ASR) — CTC, RNN-T, внимание

> Распознавание речи — это классификация аудио на каждом временном шаге, объединённая моделью последовательностей, которая учитывает закономерности английского языка и тишину. CTC, RNN-T и внимание — три способа решить эту задачу. Выберите один из них и разберитесь, почему он работает.

**Тип:** Build
**Языки:** Python
**Предварительные требования:** Этап 6 · 02 (Спектрограммы и мел-шкала), Этап 5 · 08 (CNN и RNN для текста), Этап 5 · 10 (Внимание)
**Время:** ~45 минут

## Проблема

У вас есть 10-секундный клип с частотой дискретизации 16 кГц. Вы хотите получить строку: «включи свет на кухне». Проблема носит структурный характер: аудиокадры не выравниваются один к одному с символами. Слово «хорошо» может занимать 200 мс или 1200 мс. Тишина расставляет паузы внутри высказывания. Одни фонемы длиннее других. Число выходных токенов заранее неизвестно.

Эту задачу решают три формулировки:

1. **CTC (коннекционистская временная классификация, Connectionist Temporal Classification).** Выдаёт вероятности токенов для каждого кадра, включая специальный *пустой* (blank) токен. При декодировании схлопывает повторы и пустые токены. Это быстрый неавторегрессионный подход. Используется в wav2vec 2.0 и MMS.
2. **RNN-T (рекуррентный нейросетевой трансдьюсер, Recurrent Neural Network Transducer).** Совместная сеть (joint network) предсказывает следующий токен по кадру энкодера и предыдущим токенам. Поддерживает потоковую обработку. Используется в локальных системах ASR Google и NVIDIA Parakeet.
3. **Энкодер-декодер с вниманием.** Энкодер сжимает аудио в скрытые состояния, а декодер применяет перекрёстное внимание (cross-attention) к этим состояниям и авторегрессионно генерирует токены. Используется в Whisper и SeamlessM4T.

В 2026 году лучшие показатели WER на LibriSpeech test-clean составляют 1,4% (Parakeet-TDT-1.1B, NVIDIA) и 1,58% (Whisper-Large-v3-turbo). Различия в качестве крошечные, а в требованиях к развёртыванию — огромные.

## Концепция

![Три формулировки ASR: CTC, RNN-T, энкодер-декодер с вниманием](../assets/asr-formulations.svg)

**Интуиция CTC.** Пусть энкодер выдаёт `T` покадровых распределений по `V+1` токенам (V символов + пустой токен). Для целевой строки `y` длины `U < T` засчитывается любое покадровое выравнивание, которое схлопывается в `y`. Функция потерь CTC суммирует по всем таким выравниваниям. Инференс: покадровый argmax, схлопывание повторов, удаление пустых токенов.

Преимущества: неавторегрессионный подход, поддержка потоковой обработки и отсутствие упреждения. Недостаток: *допущение об условной независимости* — предсказание каждого кадра не зависит от остальных, поэтому внутренней языковой модели нет. Проблему решают подключением внешней языковой модели (LM) через поиск лучом (beam search) или поверхностное объединение (shallow fusion).

**Интуиция RNN-T.** Добавляет сеть-*предиктор*, которая создаёт эмбеддинг истории токенов, и *объединяющую сеть* (joiner), которая объединяет состояние предиктора с кадром энкодера в совместное распределение по `V+1` (`+1` — пустой исход, то есть отсутствие эмиссии). Явно моделирует условную зависимость, которую CTC игнорирует. Поддерживает потоковую обработку, потому что каждый шаг обусловлен только прошлыми кадрами и прошлыми токенами.

Преимущества: потоковая обработка и внутренняя языковая модель. Недостаток: обучение сложнее и требовательнее к памяти (трёхмерная решётка потерь); ядрам для расчёта потерь RNN-T посвящена отдельная категория библиотек.

**Энкодер-декодер с вниманием.** Энкодер (6-32 слоя трансформера) обрабатывает кадры логарифмической мел-спектрограммы. Декодер (6-32 слоя трансформера) применяет перекрёстное внимание к выходам энкодера, чтобы авторегрессионно генерировать токены. Ограничений на выравнивание нет: внимание может обращаться к любой точке аудио. Потоковая обработка невозможна, если не ограничить внимание (Whisper-Streaming с обработкой по фрагментам, 2024).

Преимущества: наивысшее качество при офлайн-распознавании речи, простое обучение со стандартными инструментами seq2seq. Недостаток: авторегрессионная задержка пропорциональна длине вывода; без дополнительной инженерии потоковая обработка невозможна.

### WER: одно число

**Доля ошибок в словах (Word Error Rate, WER)** = `(S + D + I) / N`, где S — подстановки, D — удаления, I — вставки, N — число слов в эталоне. Соответствует расстоянию Левенштейна на уровне слов. Чем меньше, тем лучше. WER выше 20% обычно означает непригодный результат, а ниже 5% — паритет с человеком при распознавании чтения вслух. Показатели 2026 года на стандартных бенчмарках:

| Модель | LibriSpeech test-clean | LibriSpeech test-other | Размер |
|-------|------------------------|------------------------|------|
| Parakeet-TDT-1.1B | 1.40% | 2.78% | 1.1B параметров |
| Whisper-Large-v3-turbo | 1.58% | 3.03% | 809M |
| Canary-1B Flash | 1.48% | 2.87% | 1B |
| Seamless M4T v2 | 1.7% | 3.5% | 2.3B |

Все эти модели основаны на энкодер-декодере или RNN-T. Чистые CTC-системы (wav2vec 2.0) держатся около 1,8–2,1% на test-clean.

## Реализация

### Шаг 1: жадное декодирование CTC

```python
def ctc_greedy(frame_logits, blank=0, vocab=None):
    # frame_logits: list of per-frame probability vectors
    preds = [max(range(len(p)), key=lambda i: p[i]) for p in frame_logits]
    out = []
    prev = -1
    for p in preds:
        if p != prev and p != blank:
            out.append(p)
        prev = p
    return "".join(vocab[i] for i in out) if vocab else out
```

Два правила: схлопывать последовательные повторы и отбрасывать пустые токены. Пример: `a a _ _ a b b _ c` → `a a b c`.

### Шаг 2: декодирование CTC поиском лучом

```python
def ctc_beam(frame_logits, beam=8, blank=0):
    import math
    beams = [([], 0.0)]  # (tokens, log_prob)
    for p in frame_logits:
        log_p = [math.log(max(pi, 1e-10)) for pi in p]
        candidates = []
        for seq, lp in beams:
            for t, lpt in enumerate(log_p):
                new = seq[:] if t == blank else (seq + [t] if not seq or seq[-1] != t else seq)
                candidates.append((new, lp + lpt))
        candidates.sort(key=lambda x: -x[1])
        beams = candidates[:beam]
    return beams[0][0]
```

В продакшене используется поиск лучом по префиксному дереву с объединением языковой модели; здесь показан лишь концептуальный каркас.

### Шаг 3: WER

```python
def wer(ref, hyp):
    r, h = ref.split(), hyp.split()
    dp = [[0] * (len(h) + 1) for _ in range(len(r) + 1)]
    for i in range(len(r) + 1):
        dp[i][0] = i
    for j in range(len(h) + 1):
        dp[0][j] = j
    for i in range(1, len(r) + 1):
        for j in range(1, len(h) + 1):
            cost = 0 if r[i - 1] == h[j - 1] else 1
            dp[i][j] = min(
                dp[i - 1][j] + 1,
                dp[i][j - 1] + 1,
                dp[i - 1][j - 1] + cost,
            )
    return dp[len(r)][len(h)] / max(1, len(r))
```

## Ловушки, которые всё ещё встречаются в продакшене в 2026 году

- **Отсутствие VAD.** Запуск Whisper на тишине порождает галлюцинации («Спасибо за просмотр!»). Всегда фильтруйте вход через VAD.
- **WER на уровне символов, слов и подслов.** Отчитывайтесь по WER на уровне слов *после* нормализации (нижний регистр, удаление пунктуации).
- **Дрейф определения языка.** Автоматическое определение языка (LID) у Whisper ошибочно направляет шумные клипы в японский или валлийский; принудительно задавайте `language="en"`, когда язык известен.
- **Длинные клипы без разбиения на фрагменты.** У Whisper окно в 30 секунд. Для всего, что длиннее, используйте `chunk_length_s=30, stride=5`.

## Ключевые термины

| Термин | Как обычно говорят | Что это означает на самом деле |
|------|-----------------|-----------------------|
| CTC | Функция потерь с пустым токеном | Маргинализация по всем выравниваниям кадров с токенами; неавторегрессионный подход. |
| RNN-T | Потоковая функция потерь | CTC + предиктор следующего токена; учитывает порядок слов. |
| Энкодер-декодер с вниманием | В духе Whisper | Энкодер + декодер с перекрёстным вниманием; лучшее качество в офлайн-режиме. |
| WER | Число, которое вы отчитываете | `(S+D+I)/N` на уровне слов. |
| Пустой токен | Пустота | Специальный токен в CTC, сигнализирующий: «На этом кадре эмиссии нет». |
| Объединение с LM | Внешняя языковая модель | Добавление взвешенных логарифмических вероятностей LM во время поиска лучом. |
| VAD | Фильтр тишины | Детектор голосовой активности; отсекает участки без речи. |
