# Постройте конвейер голосового ассистента — итоговый проект фазы 6

> Всё из уроков 01-11, собранное воедино. Постройте голосового ассистента, который слушает, рассуждает и отвечает голосом. В 2026 году это решённая инженерная задача, а не исследовательская — но именно детали интеграции определяют, выйдет ли продукт в продакшен.

**Тип:** Build
**Языки:** Python
**Пререквизиты:** Фаза 6 · 04, 05, 06, 07, 11; Фаза 11 · 09 (вызов функций); Фаза 14 · 01 (цикл агента)
**Время:** ~120 минут

## Проблема

Постройте сквозного ассистента:

1. Захватывает вход с микрофона (16 кГц, моно).
2. Определяет начало/конец речи пользователя.
3. Транскрибирует в потоковом режиме.
4. Передаёт транскрипт LLM, которая умеет вызывать инструменты (таймер, погода, календарь).
5. Стримит текст LLM в TTS.
6. Воспроизводит аудио пользователю.
7. Останавливается, если пользователь прерывает ответ на середине.

Целевая задержка: первый байт аудио TTS в пределах 800 мс после того, как пользователь закончил высказывание, на CPU ноутбука. Целевое качество: ни одного пропущенного слова, ни одних галлюцинированных субтитров на тишине, никакой утечки клонирования голоса, никакого успешного выполнения инъекции промпта.

## Концепция

![Конвейер голосового ассистента: микрофон → VAD → STT → LLM+инструменты → TTS → динамик](../assets/voice-assistant.svg)

### Семь компонентов

1. **Захват аудио.** Микрофон → 16 кГц, моно → фрагменты по 20 мс. Обычно `sounddevice` в Python или нативный AudioUnit/ALSA/WASAPI в продакшене.
2. **VAD (урок 11).** Silero VAD с порогом 0.5, минимальная речь 250 мс, задержка на тишину 500 мс. Сигнализирует «начало» и «конец».
3. **Потоковый STT (уроки 4-5).** Whisper-streaming, Parakeet-TDT или Deepgram Nova-3 (API). Частичные и финальные транскрипты.
4. **LLM с вызовом инструментов.** GPT-4o / Claude 3.5 / Gemini 2.5 Flash. JSON-схема для инструментов. Потоковая передача токенов.
5. **Потоковый TTS (урок 7).** Kokoro-82M (самый быстрый открытый) или Cartesia Sonic (коммерческий). Запуск TTS после 20 токенов LLM.
6. **Воспроизведение.** Вывод на динамик; кодирование в opus для сетей с низкой пропускной способностью.
7. **Обработчик прерывания.** Если VAD срабатывает во время воспроизведения TTS, остановить воспроизведение, отменить LLM, перезапустить STT.

### Три режима отказа, с которыми вы столкнётесь

1. **Обрезка первого слова.** VAD запускается на такт позже, чем нужно. Слово «hey» пользователя пропадает. Установите порог запуска 0.3, а не 0.5.
2. **Путаница при прерывании в середине ответа.** LLM продолжает генерацию после того, как пользователь прервал; ассистент говорит поверх пользователя. Соедините VAD → отмену LLM.
3. **Галлюцинация на тишине.** Whisper выводит «Thanks for watching» на тихих разогревочных кадрах. Всегда фильтруйте через VAD.

## Постройте это

### Шаг 1: захват с микрофона с разбиением на фрагменты (псевдокод)

```python
import sounddevice as sd

def mic_stream(chunk_ms=20, sr=16000):
    q = queue.Queue()
    def cb(indata, frames, time, status):
        q.put(indata.copy().flatten())
    with sd.InputStream(channels=1, samplerate=sr, blocksize=int(sr * chunk_ms/1000), callback=cb):
        while True:
            yield q.get()
```

### Шаг 2: захват реплики с затвором VAD

```python
def capture_turn(stream, vad, pre_roll_ms=300, silence_ms=500):
    buf, pre, triggered = [], collections.deque(maxlen=pre_roll_ms // 20), False
    silent = 0
    for chunk in stream:
        pre.append(chunk)
        if vad(chunk):
            if not triggered:
                buf = list(pre)
                triggered = True
            buf.append(chunk)
            silent = 0
        elif triggered:
            silent += 20
            buf.append(chunk)
            if silent >= silence_ms:
                return b"".join(buf)
```

### Шаг 3: потоковый STT → LLM → TTS

```python
async def turn(audio_bytes):
    transcript = await stt.transcribe(audio_bytes)
    async for token in llm.stream(transcript):
        async for audio in tts.stream(token):
            await speaker.play(audio)
```

### Шаг 4: вызов инструментов внутри цикла LLM

```python
tools = [
    {"name": "get_weather", "parameters": {"location": "string"}},
    {"name": "set_timer", "parameters": {"seconds": "int"}},
]

async for chunk in llm.stream(user_text, tools=tools):
    if chunk.type == "tool_call":
        result = dispatch(chunk.name, chunk.args)
        continue_streaming(result)
    if chunk.type == "text":
        await tts.stream(chunk.text)
```

### Шаг 5: обработка прерывания

```python
tts_task = asyncio.create_task(tts_loop())
while True:
    chunk = await mic.get()
    if vad(chunk):
        tts_task.cancel()
        await speaker.stop()
        await new_turn()
```

## Используйте это

См. `code/main.py` — рабочую симуляцию, которая соединяет все семь компонентов с заглушками моделей, чтобы вы могли увидеть форму конвейера даже без оборудования. Для реальной реализации замените заглушки на:

- `silero-vad` (`pip install silero-vad`)
- `deepgram-sdk` или `openai-whisper`
- `openai` (`gpt-4o`) или `anthropic`
- `kokoro` или `cartesia`
- `sounddevice` для ввода-вывода

## Подводные камни

- **Бессрочное логирование персональных данных.** Полное аудио реплики — это персональные данные (PII) в большинстве юрисдикций. Храните 30 дней, шифруйте в состоянии покоя.
- **Отсутствие barge-in.** Пользователи будут прерывать. Ваш ассистент обязан замолкать.
- **TTS, который блокирует.** Синхронный TTS блокирует цикл событий. Используйте асинхронность или отдельный поток.
- **Отсутствие обработки ошибок вызова инструментов.** Инструменты дают сбой. LLM должна получать ошибку обратно и повторять попытку один раз, затем корректно деградировать.
- **Чрезмерно ретивые фильтры галлюцинаций.** Перефильтруете — и ассистент повторяет «I can't help with that». Недофильтруете — и он говорит что угодно. Калибруйте на отложенном наборе.
- **Отсутствие опции wake-слова.** Постоянное прослушивание — угроза приватности. Добавьте затвор по wake-слову (Porcupine или openWakeWord).

## Ключевые термины

| Термин | Что говорят люди | Что это значит на самом деле |
|------|-----------------|-----------------------|
| Turn (реплика) | Обмен пользователь + ассистент | Одна ограниченная VAD речь пользователя + один ответ LLM-TTS. |
| Barge-in | Прерывание | Пользователь говорит, пока ассистент говорит; ассистент замолкает. |
| Wake word (слово пробуждения) | «Hey assistant» | Детектор короткого ключевого слова; Porcupine, Snowboy, openWakeWord. |
| End-pointing (определение конца реплики) | Завершение реплики | Решение VAD + минимальной тишины о том, что пользователь закончил. |
| Pre-roll (буфер перед речью) | Буфер перед речью | Хранить 200-400 мс аудио до срабатывания VAD, чтобы избежать обрезки первого слова. |
| Tool call (вызов инструмента) | Вызов функции | LLM выдаёт JSON; runtime диспетчеризует; результат возвращается в цикл. |
