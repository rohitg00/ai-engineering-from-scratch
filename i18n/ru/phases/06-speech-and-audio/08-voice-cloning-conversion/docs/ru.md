# Клонирование и конверсия голоса

> Клонирование голоса читает ваш текст чужим голосом. Конверсия голоса переписывает ваш голос в чужой, сохраняя при этом сказанное. Обе задачи опираются на одну и ту же декомпозицию: отделить идентичность говорящего от содержания.

**Тип:** Build**Языки:** Python**Предварительные требования:** Фаза 6 · 06 (Speaker Recognition), Фаза 6 · 07 (TTS)**Время:** ~75 минут
## Проблема

В 2026 году 5-секундного аудиоклипа достаточно, чтобы получить качественный клон чьего угодно голоса на потребительском GPU. ElevenLabs, F5-TTS, OpenVoice v2, VoiceBox — все они поставляют zero-shot или few-shot клонирование. Эта технология одновременно благо (доступность TTS, дубляж, ассистивные голоса) и оружие (мошеннические звонки, политические дипфейки, кража интеллектуальной собственности).

Две тесно связанные задачи:

- **Клонирование голоса (TTS-сторона):** текст + 5-секундный референсный голос → аудио этим голосом.
- **Конверсия голоса (сторона речи):** исходное аудио (человек A говорит X) + референсный голос человека B → аудио, где B говорит X.

Обе разлагают волновую форму на (содержание, говорящий, просодия) и пересобирают содержание из одного источника с говорящим из другого.

Ключевое ограничение, под которым вы теперь работаете в 2026 году: **водяные знаки и шлюзы согласия юридически обязательны в ЕС (AI Act, вступает в силу с августа 2026 года) и в Калифорнии (AB 2905, действует с 2025 года)**. Ваш конвейер обязан ставить неслышимый водяной знак и отказывать в клонировании без согласия.

## Концепция

![Клонирование голоса против конверсии: декомпозиция, замена говорящего, пересборка](../assets/voice-cloning.svg)

**Zero-shot клонирование.** Передайте 5-секундный клип модели, обученной на тысячах говорящих. Энкодер говорящего отображает клип в эмбеддинг говорящего; TTS-декодер обуславливается на этом эмбеддинге плюс текст.

Используется в: F5-TTS (2024), YourTTS (2022), XTTS v2 (2024), OpenVoice v2 (2024).

**Few-shot дообучение.** Запишите 5-30 минут целевого голоса. LoRA-дообучите базовую модель за час. Качество скачком переходит от «сносно» к «неотличимо». Coqui и ElevenLabs поддерживают этот паттерн; сообщество применяет его с F5-TTS.

**Конверсия голоса (VC).** Два семейства:

- **Распознавание-синтез (recognition-synthesis).** Запустите ASR-подобную модель, чтобы извлечь представление содержания (например, мягкие фонемные постериоры, PPG), затем ресинтезируйте с эмбеддингом целевого говорящего. Устойчиво к языку и акценту. Используется в KNN-VC (2023), Diff-HierVC (2023).
- **Дизентанглмент.** Обучите автоэнкодер, который разделяет содержание, говорящего и просодию в латентном пространстве на бутылочном горлышке. Замените эмбеддинг говорящего на этапе инференса. Качество ниже, но быстрее. Используется в AutoVC (2019), вариантах VITS-VC.

**Клонирование на основе нейросетевых кодеков (2024+).** VALL-E, VALL-E 2, NaturalSpeech 3, VoiceBox — трактуют аудио как дискретные токены из SoundStream / EnCodec, обучают большую авторегрессионную модель или модель на flow matching поверх кодек-токенов. Качество сопоставимо с ElevenLabs на коротких промптах.

### Этика — не довесок, а часть системы

**Водяные знаки.** PerTh (Perth) и SilentCipher (2024) незаметно встраивают в аудио ID размером ~16-32 бита. Переживают повторное кодирование, стриминг и типичное редактирование. Готовы к продакшену, открытый исходный код.

**Шлюзы согласия.** Каждый клонированный вывод обязан сопровождаться проверяемой записью согласия. «Я, Рохит, 2026-04-22, разрешаю использовать этот голос для цели X». Храните в защищённом от подделки журнале.

**Детекция.** AASIST, RawNet2 и Wav2Vec2-AASIST поставляются как детекторы. Челлендж ASVspoof 2025 опубликовал EER 0,8–2,3% для детекторов уровня SOTA против выводов ElevenLabs, VALL-E 2 и Bark.

## Постройте это

### Шаг 1: декомпозиция через recognition-synthesis (демонстрация в коде в main.py)

```python
def clone_pipeline(ref_audio, text, target_embedder, tts_model):
    speaker_emb = target_embedder.encode(ref_audio)
    mel = tts_model(text, speaker=speaker_emb)
    return vocoder(mel)
```

Концептуально просто; вся сложность реализации — в `tts_model` и энкодере говорящего.

### Шаг 2: zero-shot клонирование с F5-TTS

```python
from f5_tts.api import F5TTS
tts = F5TTS()
wav = tts.infer(
    ref_file="rohit_5s.wav",
    ref_text="The quick brown fox jumps over the lazy dog.",
    gen_text="Please add milk and bread to my list.",
)
```

Референсный транскрипт должен в точности совпадать с аудио; несовпадение ломает выравнивание.

### Шаг 3: конверсия голоса с KNN-VC

```python
import torch
from knnvc import KNNVC  # 2023 model, https://github.com/bshall/knn-vc
vc = KNNVC.load("wavlm-base-plus")
out_wav = vc.convert(source="my_voice.wav", target_pool=["alice_1.wav", "alice_2.wav"])
```

KNN-VC запускает WavLM, чтобы извлечь покадровые эмбеддинги для источника и целевого пула, затем заменяет каждый исходный кадр его ближайшим соседом в пуле. Непараметрический метод, работает при наличии минуты целевой речи.

### Шаг 4: встраивание водяного знака

```python
from silentcipher import SilentCipher
sc = SilentCipher(model="2024-06-01")
payload = b"consent_id:abc123;ts:1745353200"
watermarked = sc.embed(wav, sr=24000, message=payload)
detected = sc.detect(watermarked, sr=24000)   # returns payload bytes
```

~32 бита полезной нагрузки, обнаруживается после перекодирования в MP3 и лёгкого шума.

### Шаг 5: шлюз согласия

```python
def cloned_inference(text, ref_audio, consent_record):
    assert verify_signature(consent_record), "Signed consent required"
    assert consent_record["speaker_id"] == hash_speaker(ref_audio)
    wav = tts.infer(ref_file=ref_audio, gen_text=text)
    wav = watermark(wav, payload=consent_record["id"])
    return wav
```

## Применение

Стек 2026 года:

| Ситуация | Выбор |
|-----------|------|
| 5-сек zero-shot клон, open-source | F5-TTS или OpenVoice v2 |
| Коммерческое продакшен-клонирование | ElevenLabs Instant Voice Clone v2.5 |
| Конверсия голоса (переписывание) | KNN-VC или Diff-HierVC |
| Дообучение под много говорящих | StyleTTS 2 + speaker-адаптер |
| Кросс-языковое клонирование | XTTS v2 или VALL-E X |
| Детекция дипфейков | Wav2Vec2-AASIST |

## Ловушки

- **Несовпадающий референсный транскрипт.** F5-TTS и аналоги требуют, чтобы референсный текст в точности совпадал с референсным аудио, включая пунктуацию.
- **Реверберирующий референс.** Эхо убивает клон. Записывайте сухо, с близко расположенным микрофоном.
- **Эмоциональное несовпадение.** Референс с обучением на «жизнерадостности» даёт жизнерадостные клоны чего угодно. Подбирайте эмоцию референса под целевое применение.
- **Утечка языка.** Клонирование англоязычного говорящего с последующей просьбой к модели говорить по-французски часто всё равно несёт акцент; используйте кросс-языковые модели (XTTS, VALL-E X).
- **Отсутствие водяного знака.** С августа 2026 года юридически не подлежит поставке в ЕС.

## Упражнения

1. **Лёгкое.** Запустите `code/main.py`. Демонстрирует замену эмбеддинга говорящего, вычисляя косинус между двумя «говорящими» до и после замены.
2. **Среднее.** Используйте OpenVoice v2, чтобы клонировать собственный голос. Измерьте SECS между референсом и клоном. Измерьте CER через Whisper.
3. **Сложное.** Примените водяной знак SilentCipher к 20 клонам, пропустите их через кодирование+декодирование MP3 на 128 кбит/с, обнаружьте полезную нагрузку. Приведите точность по битам.

## Ключевые термины

| Термин | Что говорят люди | Что это на самом деле означает |
|------|-----------------|-----------------------|
| Zero-shot clone | 5 секунд достаточно | Предобученная модель + эмбеддинг говорящего; без обучения. |
| PPG | Phonetic posteriorgram | Покадровые ASR-постериоры, используемые как языково-независимое представление содержания. |
| KNN-VC | Конверсия по ближайшим соседям | Заменяет каждый исходный кадр ближайшим кадром из целевого пула. |
| Neural codec TTS | В стиле VALL-E | Авторегрессионная модель поверх токенов EnCodec/SoundStream. |
| Watermark | Неслышимая подпись | Биты, встроенные в аудио, переживают перекодирование. |
| SECS | Точность клонирования | Косинус между эмбеддингами целевого и клонированного говорящего. |
| AASIST | Детектор дипфейков | Модель против подделки; обнаруживает синтезированную речь. |
