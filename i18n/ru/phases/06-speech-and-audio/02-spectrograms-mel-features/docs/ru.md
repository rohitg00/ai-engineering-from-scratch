# Спектрограммы, мел-шкала и аудиопризнаки

> Нейросети плохо работают с исходными волновыми формами (waveform). Они гораздо лучше работают со спектрограммами. С мел-спектрограммами — ещё лучше. Любая ASR-система, TTS-система и аудиоклассификатор в 2026 году живут или умирают из-за этого единственного выбора на этапе предобработки.

**Тип:** Build**Языки:** Python**Предварительные требования:** Фаза 6 · 01 (Audio Fundamentals)**Время:** ~45 минут
## Проблема

Возьмём 10-секундный клип с частотой дискретизации 16 кГц. Это 160 000 чисел с плавающей точкой, все в диапазоне `[-1, 1]`, практически никак не коррелирующие с меткой «лай собаки» или «слово cat». Исходная волновая форма содержит нужную информацию, но в форме, из которой модель не может её легко извлечь. Две одинаковые фонемы, произнесённые с разницей в 100 мс, дают совершенно разные сырые отсчёты.

Спектрограмма решает эту проблему. Она схлопывает временну́ю детализацию там, где человеческое восприятие её игнорирует (джиттер на уровне микросекунд), и сохраняет структуру там, где восприятие фокусируется (какие частоты энергетически выражены на временных окнах ~10–25 мс).

Мел-спектрограммы идут ещё дальше. Человек воспринимает высоту тона (pitch) логарифмически: разница между 100 Гц и 200 Гц звучит «на таком же расстоянии», как разница между 1000 Гц и 2000 Гц. Мел-шкала деформирует ось частот так, чтобы это учитывать. Спектрограмма, масштабированная по мел-шкале, — самый важный признак в речевом ML с 2010 по 2026 год.

## Концепция

![Путь от волновой формы к STFT, мел-спектрограмме и MFCC](../assets/mel-features.svg)

**STFT (Short-Time Fourier Transform, кратковременное преобразование Фурье).** Разрежьте волновую форму на перекрывающиеся кадры (типично: окно 25 мс, шаг (hop) 10 мс = 400 отсчётов / 160 отсчётов при 16 кГц). Умножьте каждый кадр на оконную функцию (по умолчанию — окно Ханна; окно Хэмминга даёт немного другой компромисс). Примените FFT к каждому кадру. Соберите спектры амплитуд в матрицу формы `(n_frames, n_freq_bins)`. Это и есть ваша спектрограмма.

**Логарифм амплитуды (log-magnitude).** Сырые амплитуды охватывают 5–6 порядков величины. Возьмите `log(|X| + 1e-6)` или `20 * log10(|X|)`, чтобы сжать динамический диапазон. Каждый продакшен-конвейер использует логарифм амплитуды, а не сырую амплитуду.

**Мел-шкала.** Частота `f` в Гц отображается в мел `m` по формуле `m = 2595 * log10(1 + f / 700)`. Ниже 1 кГц отображение примерно линейно, выше — примерно логарифмично. 80 мел-полос, покрывающих диапазон 0–8 кГц, — стандартный вход для ASR.

**Мел-фильтробанк (mel filterbank).** Набор треугольных фильтров, равномерно распределённых по мел-шкале. Каждый фильтр — это взвешенная сумма соседних бинов FFT. Умножение амплитуды STFT на матрицу фильтробанка даёт мел-спектрограмму за одно матричное умножение.

**Лог-мел-спектрограмма.** `log(mel_spec + 1e-10)`. Вход Whisper. Вход Parakeet. Вход SeamlessM4T. Универсальный аудиофронтенд 2026 года.

**MFCC.** Возьмите лог-мел-спектрограмму, примените DCT (II рода), оставьте первые 13 коэффициентов. Это декоррелирует признаки и дополнительно их сжимает. Доминирующий признак примерно до 2015 года, когда CNN/трансформеры на сырых лог-мелах их догнали. По-прежнему используется в распознавании дикторов (x-vectors, ECAPA).

**Компромисс разрешений.** Больший размер FFT = лучшее частотное разрешение, но худшее временное. 25 мс / 10 мс — стандарт для аудио-ML; 50 мс / 12,5 мс — для музыки; 5 мс / 2 мс — для обнаружения переходных процессов (удары барабана, взрывные согласные).

## Постройте это

### Шаг 1: разбейте волновую форму на кадры

```python
def frame(signal, frame_len, hop):
    n = 1 + (len(signal) - frame_len) // hop
    return [signal[i * hop : i * hop + frame_len] for i in range(n)]
```

10-секундный клип с частотой 16 кГц при `frame_len=400, hop=160` даёт 998 кадров.

### Шаг 2: окно Ханна

```python
import math

def hann(N):
    return [0.5 * (1 - math.cos(2 * math.pi * n / (N - 1))) for n in range(N)]
```

Умножьте поэлементно перед FFT. Это устраняет спектральную утечку (spectral leakage), вызванную обрезанием сигнала в точках с ненулевым значением на границах.

### Шаг 3: амплитуда STFT

```python
def stft_magnitude(signal, frame_len=400, hop=160):
    win = hann(frame_len)
    frames = frame(signal, frame_len, hop)
    return [magnitudes(dft([w * s for w, s in zip(win, f)])) for f in frames]
```

В продакшене используется `torch.stft` или `librosa.stft` (на основе FFT, векторизованные). Цикл здесь приведён в учебных целях; он выполняется на коротких клипах в `code/main.py`.

### Шаг 4: мел-фильтробанк

```python
def hz_to_mel(f):
    return 2595.0 * math.log10(1.0 + f / 700.0)

def mel_to_hz(m):
    return 700.0 * (10 ** (m / 2595.0) - 1)

def mel_filterbank(n_mels, n_fft, sr, fmin=0, fmax=None):
    fmax = fmax or sr / 2
    mels = [hz_to_mel(fmin) + (hz_to_mel(fmax) - hz_to_mel(fmin)) * i / (n_mels + 1)
            for i in range(n_mels + 2)]
    hzs = [mel_to_hz(m) for m in mels]
    bins = [int(h * n_fft / sr) for h in hzs]
    fb = [[0.0] * (n_fft // 2 + 1) for _ in range(n_mels)]
    for m in range(n_mels):
        for k in range(bins[m], bins[m + 1]):
            fb[m][k] = (k - bins[m]) / max(1, bins[m + 1] - bins[m])
        for k in range(bins[m + 1], bins[m + 2]):
            fb[m][k] = (bins[m + 2] - k) / max(1, bins[m + 2] - bins[m + 1])
    return fb
```

80 мел-полос, покрывающих диапазон 0–8 кГц, при `n_fft=400` дают матрицу `(80, 201)`. Умножьте амплитуду STFT размера `(n_frames, 201)` на транспонированную матрицу, чтобы получить мел-спектрограмму `(n_frames, 80)`.

### Шаг 5: лог-мел

```python
def log_mel(mel_spec, eps=1e-10):
    return [[math.log(max(v, eps)) for v in frame] for frame in mel_spec]
```

Распространённые альтернативы: `librosa.power_to_db` (нормализованные относительно опорного значения дБ), `10 * log10(power + eps)`. Whisper использует более сложную процедуру обрезки и нормализации (см. `log_mel_spectrogram` в Whisper).

### Шаг 6: MFCC

```python
def dct_ii(x, n_coeffs):
    N = len(x)
    return [
        sum(x[n] * math.cos(math.pi * k * (2 * n + 1) / (2 * N)) for n in range(N))
        for k in range(n_coeffs)
    ]
```

Примените DCT к каждому лог-мел-кадру, оставьте первые 13 коэффициентов. Это и есть ваша матрица MFCC. Первый коэффициент обычно отбрасывают (он кодирует общую энергию).

## Применение

Стек 2026 года:

| Задача | Признаки |
|------|----------|
| ASR (Whisper, Parakeet, SeamlessM4T) | 80 лог-мел, шаг 10 мс, окно 25 мс |
| Акустическая модель TTS (VITS, F5-TTS, Kokoro) | 80 мел-полос, шаг 5–12 мс для точного временного контроля |
| Аудиоклассификация (AST, PANNs, BEATs) | 128 лог-мел, шаг 10 мс |
| Эмбеддинг диктора (ECAPA-TDNN, WavLM) | 80 лог-мел или SSL на сырой волновой форме |
| Музыка (MusicGen, Stable Audio 2) | Дискретные токены EnCodec (не мел-признаки) |
| Обнаружение ключевых слов | 40 MFCC для миниатюрных устройств |

Эмпирическое правило: **если вы не работаете с музыкой, начинайте с 80 лог-мел.** Бремя доказательства лежит на любом отклонении от этого правила.

## Ловушки, которые всё ещё встречаются в 2026 году

- **Несовпадение числа мел-полос.** Обучение на 80 мел-полосах, инференс на 128. Тихий отказ. Логируйте форму признаков на обоих концах.
- **Несовпадение частоты дискретизации выше по конвейеру.** Мел-признаки, посчитанные при 22,05 кГц, выглядят иначе, чем при 16 кГц. Исправляйте частоту дискретизации (SR) *до* извлечения признаков.
- **дБ против log.** Whisper ожидает лог-мел, а не дБ-мел. Некоторые пайплайны HF определяют это автоматически; ваш собственный код — нет.
- **Дрейф нормализации.** Нормализация по каждому произнесённому фрагменту при обучении, глобальная нормализация при инференсе. Продакшен-баг, который удваивает WER.
- **Утечка из-за паддинга.** Заполнение конца клипа нулями (zero-padding) даёт плоский спектр в завершающих кадрах. Дополняйте симметрично или методом репликации.

## Ключевые термины

| Термин | Что говорят люди | Что это на самом деле означает |
|------|-----------------|-----------------------|
| Frame | Срез | Фрагмент волновой формы длиной 25 мс, подаваемый на один FFT. |
| Hop | Шаг | Количество отсчётов между соседними кадрами; 10 мс — стандарт для ASR. |
| Window | Штука типа Ханна/Хэмминга | Поэлементный множитель, сглаживающий края кадра до нуля. |
| STFT | Генератор спектрограммы | FFT по кадрам с оконной функцией; даёт матрицу время × частота. |
| Mel | Искажённая частота | Шкала логарифмического восприятия; `m = 2595·log10(1 + f/700)`. |
| Filterbank | Та самая матрица | Треугольные фильтры, проецирующие STFT на мел-полосы. |
| Log-mel | Вход Whisper | `log(mel_spec + eps)`; стандартизировано к 2026 году. |
| MFCC | Старая школа признаков | DCT от лог-мел; 13 коэффициентов, декоррелированы. |
