## Проблема

Модель не может прочитать «Кошки бежали». Она читает целые числа.

Каждая система NLP начинается с одних и тех же трёх вопросов. Где начинается слово. Какой у слова корень. Как обращаться с «run», «running», «ran» как с одним и тем же словом, когда это полезно, и как с разными словами, когда это не так.

Ошибка в токенизации — и модель учится на мусоре. Если ваш токенизатор считает `don't` одним токеном, а `do n't` — двумя, распределение обучающих данных расходится. Если ваш стеммер сводит `organization` и `organ` к одной и той же основе, тематическое моделирование ломается. Если вашему лемматизатору нужен контекст части речи, а вы его не передаёте, глаголы обрабатываются как существительные.

Этот урок строит три шага предобработки с нуля, а затем показывает, как ту же работу выполняют NLTK и spaCy, чтобы вы увидели компромиссы.

## Концепция

Три операции. У каждой своя задача и свой режим отказа.

**Токенизация (tokenization)** разбивает строку на токены. Слово «токен» намеренно расплывчато, потому что нужная гранулярность зависит от задачи. Уровень слов — для классического NLP. Субслова — для трансформеров. Символы — для языков без пробелов.

**Стемминг (stemming)** отсекает суффиксы по правилам. Быстро, агрессивно, тупо. `running -> run`. `organization -> organ`. Второй пример — это и есть режим отказа.

**Лемматизация (lemmatization)** приводит слово к его словарной форме, используя знания о грамматике. Медленнее, точнее, требует таблицы соответствий или морфологического анализатора. `ran -> run` (нужно знать, что «ran» — это прошедшее время «run»). `better -> good` (нужно знать сравнительные формы).

Эмпирическое правило. Используйте стемминг, когда важна скорость и допустим шум (индексация для поиска, грубая классификация). Используйте лемматизацию, когда важен смысл (ответы на вопросы, семантический поиск, всё, что прочитает пользователь).

## Создаём

### Шаг 1: токенизатор слов на регулярных выражениях

Самый простой полезный токенизатор разбивает строку по неалфавитно-цифровым символам, сохраняя пунктуацию как отдельные токены. Не идеально, не окончательно, но работает в одну строку.

```python
import re

def tokenize(text):
    return re.findall(r"[A-Za-z]+(?:'[A-Za-z]+)?|[0-9]+|[^\sA-Za-z0-9]", text)
```

Три шаблона в порядке приоритета. Слова с необязательным внутренним апострофом (`don't`, `it's`). Чистые числа. Любой одиночный не-пробельный не-алфавитно-цифровой символ как отдельный токен (пунктуация).

```python
>>> tokenize("The cats weren't running at 3pm.")
['The', 'cats', "weren't", 'running', 'at', '3', 'pm', '.']
```

Обратите внимание на режимы отказа. `3pm` разбивается на `['3', 'pm']`, потому что мы чередовали последовательности букв и последовательности цифр. Для большинства задач этого достаточно. URL, email-адреса, хэштеги — всё это ломается. Для продакшена добавляйте специфичные шаблоны перед общими.

### Шаг 2: стеммер Портера (только шаг 1a)

Полный алгоритм Портера состоит из пяти фаз правил. Один только шаг 1a покрывает самые частые английские суффиксы и показывает общий паттерн.

```python
def stem_step_1a(word):
    if word.endswith("sses"):
        return word[:-2]
    if word.endswith("ies"):
        return word[:-2]
    if word.endswith("ss"):
        return word
    if word.endswith("s") and len(word) > 1:
        return word[:-1]
    return word
```

```python
>>> [stem_step_1a(w) for w in ["caresses", "ponies", "caress", "cats"]]
['caress', 'poni', 'caress', 'cat']
```

Читайте правила сверху вниз. Правило `ies -> i` — вот почему `ponies -> poni`, а не `pony`. В настоящем алгоритме Портера есть шаг 1b, который бы это исправил. Правила конкурируют между собой. Побеждают более ранние правила. Порядок важнее, чем любое отдельное правило.

### Шаг 3: лемматизатор на основе таблицы соответствий

Настоящая лемматизация требует морфологии. Учебная версия, с которой можно работать, использует небольшую таблицу лемм и запасной вариант.

```python
LEMMA_TABLE = {
    ("running", "VERB"): "run",
    ("ran", "VERB"): "run",
    ("runs", "VERB"): "run",
    ("better", "ADJ"): "good",
    ("best", "ADJ"): "good",
    ("cats", "NOUN"): "cat",
    ("cat", "NOUN"): "cat",
    ("were", "VERB"): "be",
    ("was", "VERB"): "be",
    ("is", "VERB"): "be",
}

def lemmatize(word, pos):
    key = (word.lower(), pos)
    if key in LEMMA_TABLE:
        return LEMMA_TABLE[key]
    if pos == "VERB" and word.endswith("ing"):
        return word[:-3]
    if pos == "NOUN" and word.endswith("s"):
        return word[:-1]
    return word.lower()
```

```python
>>> lemmatize("running", "VERB")
'run'
>>> lemmatize("cats", "NOUN")
'cat'
>>> lemmatize("better", "ADJ")
'good'
>>> lemmatize("watched", "VERB")
'watched'
```

Последний случай — ключевой обучающий момент. `watched` отсутствует в нашей таблице, а наш запасной вариант обрабатывает только `ing`. Настоящая лемматизация покрывает `ed`, неправильные глаголы, сравнительные формы прилагательных, множественное число со сменой звука (`children -> child`). Именно поэтому продакшен-системы используют WordNet, морфологизатор spaCy или полноценный морфологический анализатор.

### Шаг 4: собираем всё в конвейер

```python
def preprocess(text, pos_tagger=None):
    tokens = tokenize(text)
    stems = [stem_step_1a(t.lower()) for t in tokens]
    tags = pos_tagger(tokens) if pos_tagger else [(t, "NOUN") for t in tokens]
    lemmas = [lemmatize(word, pos) for word, pos in tags]
    return {"tokens": tokens, "stems": stems, "lemmas": lemmas}
```

Недостающая часть — тегер части речи (POS tagger). Фаза 5, урок 07 (POS-тегирование) строит такой тегер. Пока что по умолчанию присваивайте всему тег `NOUN` и учитывайте это ограничение.

## Применяем

NLTK и spaCy поставляют готовые к продакшену версии. Несколько строк на каждую.

### NLTK

```python
import nltk
nltk.download("punkt_tab")
nltk.download("wordnet")
nltk.download("averaged_perceptron_tagger_eng")

from nltk.tokenize import word_tokenize
from nltk.stem import PorterStemmer, WordNetLemmatizer
from nltk import pos_tag

text = "The cats were running."
tokens = word_tokenize(text)
stems = [PorterStemmer().stem(t) for t in tokens]
lemmatizer = WordNetLemmatizer()
tagged = pos_tag(tokens)


def nltk_pos_to_wordnet(tag):
    if tag.startswith("V"):
        return "v"
    if tag.startswith("J"):
        return "a"
    if tag.startswith("R"):
        return "r"
    return "n"


lemmas = [lemmatizer.lemmatize(t, nltk_pos_to_wordnet(tag)) for t, tag in tagged]
```

`word_tokenize` обрабатывает сокращения, Unicode, крайние случаи, которые ваша регулярка пропускает. `PorterStemmer` выполняет все пять фаз. `WordNetLemmatizer` требует перевода POS-тега из схемы Penn Treebank, принятой в NLTK, в набор сокращений WordNet. Код перевода выше — это как раз то, что пропускает большинство туториалов.

### spaCy

```python
import spacy

nlp = spacy.load("en_core_web_sm")
doc = nlp("The cats were running.")

for token in doc:
    print(token.text, token.lemma_, token.pos_)
```

```
The      the     DET
cats     cat     NOUN
were     be      AUX
running  run     VERB
.        .       PUNCT
```

spaCy прячет весь конвейер за вызовом `nlp(text)`. Токенизация, POS-тегирование и лемматизация выполняются одновременно. Быстрее NLTK на больших объёмах. Точнее «из коробки». Компромисс в том, что отдельные компоненты нельзя легко заменить.

### Что выбрать

| Ситуация | Выбор |
|-----------|------|
| Обучение, исследования, замена отдельных компонентов | NLTK |
| Продакшен, мультиязычность, важна скорость | spaCy |
| Конвейер трансформера (токенизировать всё равно будете токенизатором модели) | Используйте `tokenizers` / `transformers` и пропустите классическую предобработку |

### Два режима отказа, о которых никто не предупреждает

Большинство туториалов учат алгоритмам и на этом останавливаются. Две вещи ударят по настоящему конвейеру предобработки, и их почти никогда не освещают.

**Дрейф воспроизводимости.** NLTK и spaCy меняют поведение токенизации и лемматизатора между версиями. То, что в spaCy 2.x давало `['do', "n't"]`, в 3.x может дать `["don't"]`. Ваша модель обучалась на одном распределении. Инференс теперь работает на другом. Точность незаметно деградирует, и никто не понимает почему. Фиксируйте версии библиотек в `requirements.txt`. Напишите регрессионный тест предобработки, который фиксирует ожидаемую токенизацию 20 примеров предложений. Запускайте его при каждом обновлении.

**Расхождение между обучением и инференсом.** Обучаете с агрессивной предобработкой (нижний регистр, удаление стоп-слов, стемминг), разворачиваете на сырых пользовательских данных, наблюдаете обвал качества. Это самый распространённый сбой продакшен-NLP. Если вы применяете предобработку при обучении, вы обязаны запускать идентичную функцию при инференсе. Поставляйте предобработку как функцию внутри пакета модели, а не как ячейку ноутбука, которую команда обслуживания переписывает по-своему.

## Упражнения

1. **Лёгкое.** Расширьте `tokenize`, чтобы URL сохранялись как единый токен. Тест: `tokenize("Visit https://example.com today.")` должен дать один токен для URL.
2. **Среднее.** Реализуйте шаг 1b алгоритма Портера. Если слово содержит гласную и заканчивается на `ed` или `ing`, удалите окончание. Обработайте правило удвоенной согласной (`hopping -> hop`, а не `hopp`).
3. **Сложное.** Постройте лемматизатор, который использует WordNet как таблицу соответствий, но переключается на ваш стеммер Портера, когда в WordNet нет записи. Измерьте точность на размеченном корпусе в сравнении с чистым WordNet и чистым Портером.

## Ключевые термины

| Термин | Как обычно говорят | Что это на самом деле означает |
|------|-----------------|-----------------------|
| Токен | Слово | Единица, которую потребляет модель. Может быть словом, субсловом, символом или байтом. |
| Основа | Корень слова | Результат отсечения суффиксов по правилам. Не всегда настоящее слово. |
| Лемма | Словарная форма | Форма, которую вы бы искали в словаре. Требует грамматического контекста для корректного вычисления. |
| POS-тег | Часть речи | Категория вроде NOUN, VERB, ADJ. Нужна для точной лемматизации. |
| Морфология | Правила формы слова | Как слово меняет форму в зависимости от времени, числа, падежа. Лемматизация зависит от этого. |
