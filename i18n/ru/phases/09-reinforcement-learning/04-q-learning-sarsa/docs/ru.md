# Временная разница — Q-обучение и SARSA

> Метод Монте-Карло ждёт окончания эпизода. TD обновляется после каждого шага, бутстрапируя оценку следующей ценности. Q-обучение — внеполитическое и оптимистичное; SARSA — на основе своей политики и осторожное. Оба умещаются в одну строку кода. Оба лежат в основе каждого метода глубокого RL в этой фазе.

**Тип:** Build**Языки:** Python**Предварительные требования:** Фаза 9 · 01 (MDPs), Фаза 9 · 02 (Dynamic Programming), Фаза 9 · 03 (Monte Carlo)**Время:** ~75 минут
## Проблема

Метод Монте-Карло работает, но у него два дорогостоящих требования. Ему нужны завершающиеся эпизоды, и он обновляется только после того, как получена финальная отдача. Если ваш эпизод длится 1000 шагов, MC ждёт 1000 шагов, прежде чем что-либо обновить. Это высокая дисперсия, низкое смещение и медленная работа на практике.

У динамического программирования противоположный профиль — бутстрапированные бэкапы с нулевой дисперсией, — но нужна известная модель.

Обучение по временной разнице (TD) делит разницу пополам. Из одного перехода `(s, a, r, s')` формируется одношаговая цель `r + γ V(s')`, к которой подталкивается `V(s)`. Модель не нужна. Полные эпизоды не нужны. Есть смещение из-за использования приближённого `V` в правой части, но дисперсия драматически ниже, чем у MC, и обновления идут онлайн с первого же шага.

Это тот стержень, вокруг которого вращается всё современное RL — DQN, A2C, PPO, SAC. Остальная часть Фазы 9 — это слои аппроксимации функций и трюки, надстроенные над одношаговым обновлением TD, которое вы напишете в этом уроке.

## Концепция

![Q-обучение против SARSA: внеполитический max против Q(s', a') на основе своей политики](../assets/td.svg)

**Обновление TD(0) для V:**

`V(s) ← V(s) + α [r + γ V(s') - V(s)]`

Величина в скобках — это ошибка TD `δ = r + γ V(s') - V(s)`. Это онлайн-аналог `G_t - V(s_t)` в MC. Сходимость требует, чтобы `α` удовлетворяла условию Роббинса-Монро (`Σ α = ∞`, `Σ α² < ∞`) и чтобы все состояния посещались бесконечно часто.

**Q-обучение.** Внеполитический метод TD для управления:

`Q(s, a) ← Q(s, a) + α [r + γ max_{a'} Q(s', a') - Q(s, a)]`

`max` предполагает, что начиная с `s'` будет следовать *жадная* политика, независимо от того, какое действие агент реально предпримет. Эта развязка позволяет Q-обучению учить `Q*`, пока агент исследует через ε-жадность. Mnih и др. (2015) превратили это в глубокое Q-обучение на Atari (Урок 05).

**SARSA.** Метод TD на основе своей политики:

`Q(s, a) ← Q(s, a) + α [r + γ Q(s', a') - Q(s, a)]`

Название — это кортеж `(s, a, r, s', a')`. SARSA использует действие `a'`, которое агент *реально* совершит следующим, а не жадный `argmax`. Сходится к `Q^π` для той ε-жадной `π`, которая сейчас выполняется, что в пределе `ε → 0` становится `Q*`.

**Различие на задаче с обрывом (cliff-walking).** На классической задаче cliff-walking (падение с обрыва = вознаграждение -100) Q-обучение выучивает оптимальный путь вдоль края обрыва, но иногда получает штраф во время исследования. SARSA выучивает более безопасный путь на один шаг дальше от обрыва, потому что учитывает шум исследования в своих Q-значениях. После обучения оба достигают оптимума при `ε → 0`. На практике это важно: когда исследование реально происходит на этапе развёртывания, поведение SARSA более консервативно.

**Expected SARSA.** Замените `Q(s', a')` его математическим ожиданием под `π`:

`Q(s, a) ← Q(s, a) + α [r + γ Σ_{a'} π(a'|s') Q(s', a') - Q(s, a)]`

Дисперсия ниже, чем у SARSA (нет сэмплирования `a'`), при той же цели на основе своей политики. Часто выступает вариантом по умолчанию в современных учебниках.

**n-шаговый TD и TD(λ).** Интерполяция между TD(0) и MC за счёт ожидания `n` шагов перед бутстрапингом. `n=1` — это TD, `n=∞` — это MC. TD(λ) усредняет по всем `n` с геометрическими весами `(1-λ)λ^{n-1}`. В большинстве глубокого RL `n` берут между 3 и 20.

## Реализация

### Шаг 1: SARSA на ε-жадной политике

```python
def sarsa(env, episodes, alpha=0.1, gamma=0.99, epsilon=0.1):
    Q = defaultdict(lambda: {a: 0.0 for a in ACTIONS})

    def choose(s):
        if random() < epsilon:
            return choice(ACTIONS)
        return max(Q[s], key=Q[s].get)

    for _ in range(episodes):
        s = env.reset()
        a = choose(s)
        while True:
            s_next, r, done = env.step(s, a)
            a_next = choose(s_next) if not done else None
            target = r + (gamma * Q[s_next][a_next] if not done else 0.0)
            Q[s][a] += alpha * (target - Q[s][a])
            if done:
                break
            s, a = s_next, a_next
    return Q
```

Восемь строк. *Единственное* отличие от Q-обучения — строка с целью.

### Шаг 2: Q-обучение

```python
def q_learning(env, episodes, alpha=0.1, gamma=0.99, epsilon=0.1):
    Q = defaultdict(lambda: {a: 0.0 for a in ACTIONS})
    for _ in range(episodes):
        s = env.reset()
        while True:
            a = choose(s, Q, epsilon)
            s_next, r, done = env.step(s, a)
            target = r + (gamma * max(Q[s_next].values()) if not done else 0.0)
            Q[s][a] += alpha * (target - Q[s][a])
            if done:
                break
            s = s_next
    return Q
```

`max` развязывает цель от поведения. Именно этот один символ — разница между обучением на основе своей политики и внеполитическим.

### Шаг 3: кривые обучения

Отслеживайте среднюю отдачу на каждые 100 эпизодов. Q-обучение сходится быстрее на простом детерминированном GridWorld; SARSA более консервативна на cliff-walking. На GridWorld 4×4 в `code/main.py` оба алгоритма близки к оптимуму после ~2000 эпизодов при `α=0.1, ε=0.1`.

### Шаг 4: сравнение с истиной DP

Запустите итерацию по ценности (Урок 02), чтобы получить `Q*`. Проверьте `max_{s,a} |Q_learned(s,a) - Q*(s,a)|`. Здоровый табличный TD-агент попадает в пределы `~0.5` на GridWorld 4×4 после 10 000 эпизодов.

## Подводные камни

- **Начальные значения Q имеют значение.** Оптимистичная инициализация (`Q = 0` для задачи с отрицательным вознаграждением) стимулирует исследование. Пессимистичная инициализация может навсегда запереть жадную политику.
- **Расписание α.** Постоянная `α` подходит для нестационарных задач. Затухающая `α_n = 1/n` даёт сходимость в теории, но слишком медленна на практике — закрепите `α` в диапазоне `[0.05, 0.3]` и следите за кривой обучения.
- **Расписание ε.** Начните высоко (`ε=1.0`), затухайте до `ε=0.05`. «GLIE» (жадность в пределе с бесконечным исследованием) — условие сходимости.
- **Максимизационное смещение в Q-обучении.** Оператор `max` смещён вверх, когда `Q` зашумлена. Приводит к переоценке — Double Q-обучение Хасселта (используется DDQN в Уроке 05) исправляет это с помощью двух таблиц Q.
- **Незавершающиеся эпизоды.** TD может обучаться без терминалов, но нужно либо ограничить число шагов, либо корректно обработать бутстрапинг на границе. Стандарт: считать границу нетерминальной, продолжать бутстрапинг.
- **Хеширование состояний.** Если состояния — кортежи/тензоры, используйте хешируемый ключ (кортеж, а не список; кортеж округлённых чисел с плавающей точкой, а не сырых).

## Применение

Ландшафт TD в 2026 году:

| Task | Method | Reason |
|------|--------|--------|
| Малые табличные среды | Q-обучение | Напрямую выучивает оптимальную политику. |
| Критичное к безопасности на основе своей политики | SARSA / Expected SARSA | Консервативность во время исследования. |
| Высокоразмерное состояние | DQN (Фаза 9 · 05) | Нейросетевая Q-функция с воспроизведением и целевой сетью. |
| Непрерывные действия | SAC / TD3 (Фаза 9 · 07) | TD-обновление на Q-сети; сеть политики выдаёт действия. |
| RL для LLM (на основе модели вознаграждения) | PPO / GRPO (Фаза 9 · 08, 12) | Актор-критик с преимуществом в стиле TD через GAE. |
| Офлайн-RL | CQL / IQL (Фаза 9 · 08) | Q-обучение с консервативной регуляризацией. |

## Ключевые термины

| Term | Что говорят люди | Что это на самом деле означает |
|------|-----------------|-----------------------|
| TD error | «Сигнал обновления» | `δ = r + γ V(s') - V(s)`, бутстрапированный остаток. |
| TD(0) | «Одношаговый TD» | Обновление после каждого перехода, используя только оценку следующего состояния. |
| Q-learning | «Внеполитический RL 101» | TD-обновление с `max` по действиям следующего состояния; учит `Q*` независимо от поведенческой политики. |
| SARSA | «Q-обучение на основе своей политики» | TD-обновление с использованием реального следующего действия; учит `Q^π` для текущей ε-жадной π. |
| Expected SARSA | «SARSA с низкой дисперсией» | Замена сэмплированного `a'` его математическим ожиданием под π. |
| GLIE | «Правильное расписание исследования» | Жадность в пределе с бесконечным исследованием; необходимо для сходимости Q-обучения. |
| Bootstrapping | «Использование текущей оценки в цели» | То, что отличает TD от MC. Источник смещения, но огромное снижение дисперсии. |
| Maximization bias | «Q-обучение переоценивает» | `max` по зашумлённым оценкам смещён вверх; исправляется Double Q-обучением. |
