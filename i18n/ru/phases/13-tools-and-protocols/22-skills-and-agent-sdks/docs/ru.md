# Навыки и SDK для агентов — Anthropic Skills, AGENTS.md, OpenAI Apps SDK

> MCP говорит «какие инструменты существуют». Навыки (Skills) говорят «как выполнить задачу». Стек 2026 года объединяет оба слоя. Agent Skills от Anthropic (открытый стандарт, декабрь 2025) поставляются как SKILL.md с постепенным раскрытием информации. Apps SDK от OpenAI — это MCP плюс метаданные виджетов. AGENTS.md (теперь в более чем 60 000 репозиториев) находится в корне репозитория как контекст агента на уровне проекта. В этом уроке называется то, что покрывает каждый слой, и собирается минимальный пакет SKILL.md + AGENTS.md, переносимый между агентами.

**Тип:** Learn**Языки:** Python (stdlib, парсер и загрузчик SKILL.md)**Предварительные требования:** Фаза 13 · 07 (MCP server)**Время:** ~45 минут
## Цели обучения

- Различать три слоя: AGENTS.md (контекст проекта), SKILL.md (переиспользуемое know-how), MCP (инструменты).
- Написать SKILL.md с YAML-frontmatter и постепенным раскрытием информации.
- Загружать навыки в среду выполнения агента в файловом стиле.
- Скомпоновать навык с MCP-сервером и AGENTS.md так, чтобы один пакет работал в Claude Code, Cursor и Codex.

## Проблема

Инженер сводит рабочий процесс написания release notes в многошаговый промпт: «Прочитай последние смёрженные PR. Сгруппируй по областям. Суммируй каждый. Напиши запись changelog по стилю команды. Опубликуй черновик в Slack». Он кладёт это в документ Notion для своей команды.

Теперь он хочет использовать этот рабочий процесс из Claude Code, Cursor и Codex CLI. У каждого агента свой способ загрузки инструкций: слэш-команды Claude Code, правила Cursor, `.codex.md` Codex. Инженер копирует рабочий процесс трижды и поддерживает три копии.

AGENTS.md и SKILL.md вместе это решают:

- **AGENTS.md** находится в корне репозитория. Каждый совместимый агент читает его в начале сессии. «Как устроен этот проект? Какие приняты соглашения? Какими командами запускаются тесты?»
- **SKILL.md** — это переносимый пакет: YAML-frontmatter (имя, описание) + тело в markdown + опциональные ресурсы. Агенты, поддерживающие навыки, загружают их по имени по запросу.
- **MCP** (Phase 13 · 06-14) обрабатывает инструменты, которые нужно вызвать навыку.

Три слоя, один переносимый артефакт.

## Концепция

### AGENTS.md (agents.md)

Запущен в конце 2025 года, принят более чем 60 000 репозиториями к апрелю 2026 года. Один файл в корне репозитория. Формат:

```markdown
# Project: my-service

## Conventions
- TypeScript with strict mode.
- Use Pydantic for models on the Python side.
- Tests run with `pnpm test`.

## Build and run
- `pnpm dev` for local dev server.
- `pnpm build` for production bundle.
```

Агенты читают этот файл в начале сессии и используют его, чтобы откалибровать своё поведение для данного проекта. Каждый кодовый агент в 2026 году поддерживает AGENTS.md: Claude Code, Cursor, Codex, Copilot Workspace, opencode, Windsurf, Zed.

### Формат SKILL.md

Agent Skills от Anthropic (выпущены как открытый стандарт в декабре 2025):

```markdown
---
name: release-notes-writer
description: Write a changelog entry for the latest merged PRs following this project's style.
---

# Release notes writer

When invoked, run these steps:

1. List PRs merged since the last tag. Use `gh pr list --base main --state merged`.
2. Group by label: feature, fix, chore, docs.
3. For each PR in each group, write one line: `- <title> (#<num>)`.
4. Draft the release notes and stage them in CHANGELOG.md.

If the user says "ship", run `git tag vX.Y.Z` and `gh release create`.

## Notes

- Never include commits without a PR.
- Skip "chore" entries from the public changelog.
```

Frontmatter декларирует идентичность навыка. Тело — это промпт, показываемый модели при загрузке навыка.

### Постепенное раскрытие информации

Навыки могут ссылаться на дополнительные ресурсы, которые агент получает только при необходимости. Пример:

```
skills/
  release-notes-writer/
    SKILL.md
    style-guide.md
    template.md
    scripts/
      generate.sh
```

SKILL.md говорит: «см. style-guide.md для правил стиля». Агент получает style-guide.md только тогда, когда навык активно выполняется. Это избавляет от раздувания промпта деталями, которые модели могут не понадобиться.

### Обнаружение через файловую систему

Среды выполнения агентов сканируют известные каталоги на предмет файлов SKILL.md:

- `~/.anthropic/skills/*/SKILL.md`
- Проектный `./skills/*/SKILL.md`
- `~/.claude/skills/*/SKILL.md`

Загрузка происходит по имени папки и полю `name` во frontmatter. Claude Code, Anthropic Claude Agent SDK и SkillKit (кросс-агентный) следуют этому паттерну.

### Anthropic Claude Agent SDK

`@anthropic-ai/claude-agent-sdk` (TypeScript) и `claude-agent-sdk` (Python) загружают навыки в начале сессии, предоставляя их как вызываемых «агентов» внутри среды выполнения. Цикл агента передаёт управление навыку, когда пользователь его вызывает.

### OpenAI Apps SDK

Запущен в октябре 2025 года; построен непосредственно на MCP. Объединяет прежние Connectors и Custom GPT Actions от OpenAI под единой поверхностью для разработчиков. Приложение Apps SDK — это:

- MCP-сервер (инструменты, ресурсы, промпты).
- Плюс метаданные виджетов для UI ChatGPT.
- Плюс опциональный ресурс MCP Apps `ui://` для интерактивных поверхностей.

Тот же протокол, более богатый UX.

### Кросс-агентная переносимость через SkillKit

Инструменты вроде SkillKit и похожие слои кросс-агентного распространения транслируют один SKILL.md в нативный формат каждого из 32+ ИИ-агентов (Claude Code, Cursor, Codex, Gemini CLI, OpenCode и др.). Один источник истины; много потребителей.

### Трёхслойный стек

| Слой | Файл | Когда загружается | Назначение |
|-------|------|-------------|---------|
| AGENTS.md | корень репозитория | начало сессии | соглашения на уровне проекта |
| SKILL.md | каталог навыков | навык вызван | переиспользуемый рабочий процесс |
| MCP server | внешний процесс | нужны инструменты | вызываемые действия |

Все три компонуются: агент читает AGENTS.md в начале сессии, пользователь вызывает навык, инструкции навыка включают вызовы MCP-инструментов, агент передаёт их через MCP-клиент.

```figure
t3-skill-layers
```

## Практика

`code/main.py` поставляет парсер и загрузчик SKILL.md на stdlib. Он обнаруживает навыки в `./skills/`, разбирает YAML-frontmatter и тело в markdown, и производит словарь с ключом по имени навыка. Затем он симулирует цикл агента, вызывающий `release-notes-writer` по имени.

На что смотреть:

- YAML-frontmatter разбирается минимальным парсером на stdlib (без зависимости от `pyyaml`).
- Тело навыка хранится дословно; агент добавляет его в начало системного промпта при вызове.
- Постепенное раскрытие информации демонстрируется через функцию `read_subresource`, которая получает указанные файлы по запросу.

## Поставка

Этот урок производит `outputs/skill-agent-bundle.md`. По заданному рабочему процессу навык производит объединённый пакет SKILL.md + AGENTS.md + чертёж MCP-сервера, переносимый между агентами.

## Упражнения

1. Запустите `code/main.py`. Добавьте второй навык в `skills/` и убедитесь, что загрузчик его подхватывает.

2. Напишите AGENTS.md для этого курса-репозитория. Включите команды тестирования, соглашения по стилю и ментальную модель Phase 13.

3. Перенесите многошаговый рабочий процесс из внутренней документации вашей команды в SKILL.md. Убедитесь, что он загружается в Claude Code.

4. Переведите навык в нативные форматы правил Cursor и Codex вручную. Посчитайте разницу между форматами — это и есть поверхность трансляции, которую автоматизирует SkillKit.

5. Прочитайте пост в блоге Anthropic об Agent Skills. Найдите одну функцию в Claude Agent SDK, которую загрузчик этого урока не покрывает. (Подсказка: суб-вызов агента.)

## Ключевые термины

| Термин | Что говорят люди | Что это на самом деле означает |
|------|----------------|------------------------|
| SKILL.md | «Файл навыка» | YAML-frontmatter плюс тело в markdown, загружаемое средой выполнения агента |
| AGENTS.md | «Контекст агента в корне репозитория» | Файл соглашений уровня проекта, читаемый в начале сессии |
| Progressive disclosure | «Ленивая загрузка дополнительных ресурсов» | Тело навыка ссылается на файлы, получаемые только при необходимости |
| Frontmatter | «Блок YAML сверху» | Метаданные (имя, описание) в разделителях `---` |
| Claude Agent SDK | «Среда выполнения навыков от Anthropic» | `@anthropic-ai/claude-agent-sdk`, загружает навыки и маршрутизирует их |
| OpenAI Apps SDK | «MCP + метаданные виджетов» | Поверхность разработчика OpenAI, построенная на MCP плюс хуки UI ChatGPT |
| Skill discovery | «Сканирование файловой системы» | Обход известных каталогов в поиске SKILL.md, ключ по имени |
| Cross-agent portability | «Один навык — много агентов» | Трансляция одного SKILL.md в 32+ агента через инструменты вроде SkillKit |
| Agent Skill | «Переносимое know-how» | Переиспользуемый шаблон задачи вне концепции инструментов MCP |
| Apps SDK | «MCP плюс UI ChatGPT» | Connectors и Custom GPTs, объединённые на MCP |
