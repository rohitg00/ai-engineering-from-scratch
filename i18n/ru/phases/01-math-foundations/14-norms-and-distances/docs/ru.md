# Нормы и расстояния

> Ваша функция расстояния определяет, что значит «похожий». Выберете её неправильно — и всё, что построено дальше, сломается.

**Тип:** Build
**Язык:** Python
**Предварительные требования:** Фаза 1, Уроки 01 (Интуиция линейной алгебры), 02 (Векторы, матрицы и операции)
**Время:** ~90 минут

## Цели обучения

- Реализовать с нуля функции L1, L2, косинусного, Махаланобиса, Жаккара расстояний и расстояния редактирования
- Выбрать подходящую метрику расстояния для конкретной ML-задачи и объяснить, почему альтернативы не подходят
- Связать нормы L1 и L2 с регуляризацией LASSO и Ridge и их геометрическими областями ограничений
- Продемонстрировать, как один и тот же набор данных даёт разных ближайших соседей при разных метриках

## Проблема

У вас есть два вектора. Может быть, это эмбеддинги слов. Может быть, профили пользователей. Может быть, массивы пикселей. Вам нужно знать: насколько они близки?

Ответ полностью зависит от того, какую функцию расстояния вы выберете. Две точки данных могут быть ближайшими соседями по одной метрике и далеки друг от друга по другой. Ваш классификатор KNN, ваш рекомендательный движок, ваша векторная база данных, ваш алгоритм кластеризации, ваша функция потерь — все они зависят от этого выбора. Ошибётесь — и ваша модель оптимизирует не то, что нужно.

Не существует универсально лучшего расстояния. L2 работает для пространственных данных. Косинусное сходство доминирует в NLP. Жаккар обрабатывает множества. Расстояние редактирования обрабатывает строки. Махаланобис учитывает корреляции. Вассерштейн перемещает вероятностную массу. Каждое из них кодирует своё представление о том, что значит «похожий».

Этот урок строит с нуля каждую основную функцию расстояния, показывает, когда каждая из них — правильный инструмент, и демонстрирует, как одни и те же данные дают совершенно разных ближайших соседей в зависимости от используемой метрики.

## Концепция

### Нормы: измерение величины вектора

Норма измеряет «размер» вектора. Любую функцию расстояния между двумя векторами можно записать как норму их разности: d(a, b) = ||a - b||. Так что понимание норм — это понимание расстояний.

### Норма L1 (манхэттенское расстояние)

Норма L1 суммирует абсолютные значения всех компонентов.

```
||x||_1 = |x_1| + |x_2| + ... + |x_n|
```

Её называют манхэттенским расстоянием, потому что она измеряет, сколько вы пройдёте по городской сетке, где можно двигаться только вдоль осей. Никаких диагоналей.

```
Point A = (1, 1)
Point B = (4, 5)

L1 distance = |4-1| + |5-1| = 3 + 4 = 7

On a grid, you walk 3 blocks east and 4 blocks north.
```

Когда использовать L1:
- Высокоразмерные разреженные данные (текстовые признаки, one-hot-кодирование)
- Когда нужна устойчивость к выбросам (одно огромное различие не доминирует)
- Задачи отбора признаков (регуляризация L1 способствует разреженности)

Связь с регуляризацией L1 (Lasso): добавление ||w||_1 к функции потерь штрафует сумму абсолютных значений весов. Это подталкивает маленькие веса ровно к нулю, выполняя автоматический отбор признаков. Штраф L1 создаёт ромбовидные области ограничений в пространстве весов, и углы ромбов лежат на осях, где некоторые веса равны нулю.

Связь с функциями потерь: средняя абсолютная ошибка (MAE) — это среднее L1-расстояние между предсказаниями и целевыми значениями. Она штрафует все ошибки линейно, что делает её устойчивой к выбросам по сравнению с MSE.

### Норма L2 (евклидово расстояние)

Норма L2 — это расстояние по прямой линии. Квадратный корень из суммы квадратов компонентов.

```
||x||_2 = sqrt(x_1^2 + x_2^2 + ... + x_n^2)
```

Это расстояние, которое вы изучали на геометрии. Теорема Пифагора в n измерениях.

```
Point A = (1, 1)
Point B = (4, 5)

L2 distance = sqrt((4-1)^2 + (5-1)^2) = sqrt(9 + 16) = sqrt(25) = 5.0

The straight line, cutting diagonally through the grid.
```

Когда использовать L2:
- Непрерывные данные низкой-средней размерности
- Когда масштабы признаков сопоставимы
- Физические расстояния (пространственные данные, показания датчиков)
- Сходство изображений на уровне пикселей

Связь с регуляризацией L2 (Ridge): добавление ||w||_2^2 к функции потерь штрафует большие веса. В отличие от L1, она не подталкивает веса к нулю. Она пропорционально сжимает все веса к нулю. Штраф L2 создаёт круговые области ограничений, поэтому углов на осях нет. Веса становятся маленькими, но редко становятся ровно нулём.

Связь с функциями потерь: среднеквадратичная ошибка (MSE) — это среднее квадратов L2-расстояний. Возведение в квадрат штрафует большие ошибки сильнее, чем маленькие.

```
MAE (L1 loss):  |y - y_hat|         Linear penalty. Robust to outliers.
MSE (L2 loss):  (y - y_hat)^2       Quadratic penalty. Sensitive to outliers.
```

### Нормы Lp: общее семейство

L1 и L2 — частные случаи нормы Lp:

```
||x||_p = (|x_1|^p + |x_2|^p + ... + |x_n|^p)^(1/p)
```

Разные значения p дают «единичные шары» разной формы (множество всех точек на расстоянии 1 от начала координат):

```
p=1:    Diamond shape      (corners on axes)
p=2:    Circle/sphere      (the usual round ball)
p=3:    Superellipse       (rounded square)
p=inf:  Square/hypercube   (flat sides along axes)
```

### Норма L-бесконечность (расстояние Чебышёва)

Когда p стремится к бесконечности, норма Lp сходится к максимальному абсолютному компоненту.

```
||x||_inf = max(|x_1|, |x_2|, ..., |x_n|)
```

Расстояние между двумя точками определяется единственным измерением, где они различаются больше всего. Все остальные измерения игнорируются.

```
Point A = (1, 1)
Point B = (4, 5)

L-inf distance = max(|4-1|, |5-1|) = max(3, 4) = 4
```

Когда использовать L-бесконечность:
- Когда важно наихудшее отклонение по любому отдельному измерению
- Игровые поля (король в шахматах ходит по L-бесконечности: один шаг в любом направлении стоит 1)
- Производственные допуски (каждое измерение должно быть в пределах спецификации)

### Косинусное сходство и косинусное расстояние

Косинусное сходство измеряет угол между двумя векторами, игнорируя их величины.

```
cos_sim(a, b) = (a . b) / (||a||_2 * ||b||_2)
```

Оно варьируется от -1 (противоположные направления) до +1 (одинаковое направление). Перпендикулярные векторы имеют косинусное сходство 0.

Косинусное расстояние преобразует это в расстояние: cosine_distance = 1 - cosine_similarity. Оно варьируется от 0 (идентичное направление) до 2 (противоположное направление).

```
a = (1, 0)    b = (1, 1)

cos_sim = (1*1 + 0*1) / (1 * sqrt(2)) = 1/sqrt(2) = 0.707
cos_dist = 1 - 0.707 = 0.293
```

Почему косинус доминирует в NLP и эмбеддингах: в тексте длина документа не должна влиять на сходство. Документ о кошках, который вдвое длиннее другого документа о кошках, всё равно должен быть «похожим». Косинусное сходство игнорирует величину (длину) и заботится только о направлении. Два документа с одинаковым распределением слов, но разной длиной, направлены в одну сторону и получают косинусное сходство 1.0.

Когда использовать косинусное сходство:
- Сходство текстов (TF-IDF-векторы, эмбеддинги слов, эмбеддинги предложений)
- Любая область, где величина — это шум, а направление — сигнал
- Рекомендательные системы (векторы предпочтений пользователей)
- Поиск по эмбеддингам (векторные базы данных почти всегда используют косинус или скалярное произведение)

### Сходство по скалярному произведению против косинусного сходства

Скалярное произведение двух векторов:

```
a . b = a_1*b_1 + a_2*b_2 + ... + a_n*b_n
      = ||a|| * ||b|| * cos(angle)
```

Косинусное сходство — это скалярное произведение, нормализованное обеими величинами. Когда оба вектора уже нормализованы до единичной длины (величина = 1), скалярное произведение и косинусное сходство идентичны.

```
If ||a|| = 1 and ||b|| = 1:
    a . b = cos(angle between a and b)
```

Когда они различаются: скалярное произведение включает информацию о величине. Вектор с большей величиной получает более высокую оценку скалярного произведения. Это важно в некоторых системах поиска, где вы хотите, чтобы «популярные» объекты ранжировались выше. Величина действует как неявный сигнал качества или важности.

```
a = (3, 0)    b = (1, 0)    c = (0, 1)

dot(a, b) = 3     dot(a, c) = 0
cos(a, b) = 1.0   cos(a, c) = 0.0

Both agree on direction, but dot product also reflects magnitude.
```

На практике:
- Используйте косинусное сходство, когда нужно чистое направленное сходство
- Используйте скалярное произведение, когда величины несут значимую информацию
- Многие векторные базы данных (Pinecone, Weaviate, Qdrant) позволяют выбирать между ними
- Если ваши эмбеддинги L2-нормализованы, выбор не имеет значения

### Расстояние Махаланобиса

Евклидово расстояние относится ко всем измерениям одинаково. Но если ваши признаки коррелированы или имеют разные масштабы, L2 даёт вводящие в заблуждение результаты.

Расстояние Махаланобиса учитывает структуру ковариации данных.

```
d_M(x, y) = sqrt((x - y)^T * S^(-1) * (x - y))
```

где S — ковариационная матрица данных.

Интуитивно: расстояние Махаланобиса сначала декоррелирует и нормализует данные (отбеливание), затем вычисляет L2-расстояние в этом преобразованном пространстве. Если S — единичная матрица (некоррелированные признаки с единичной дисперсией), расстояние Махаланобиса сводится к евклидову расстоянию.

```
Example: height and weight are correlated.
Someone 6'2" and 180 lbs is not unusual.
Someone 5'0" and 180 lbs is unusual.

Euclidean distance might say they are equally far from the mean.
Mahalanobis distance correctly identifies the second as an outlier
because it accounts for the height-weight correlation.
```

Когда использовать расстояние Махаланобиса:
- Обнаружение выбросов (точки с большим расстоянием Махаланобиса от среднего — это выбросы)
- Классификация, когда признаки имеют разные масштабы и корреляции
- Когда у вас достаточно данных, чтобы надёжно оценить ковариационную матрицу
- Контроль качества на производстве (многомерный мониторинг процессов)

### Сходство Жаккара (для множеств)

Сходство Жаккара измеряет пересечение между двумя множествами.

```
J(A, B) = |A intersect B| / |A union B|
```

Оно варьируется от 0 (нет пересечения) до 1 (идентичные множества). Расстояние Жаккара = 1 - сходство Жаккара.

```
A = {cat, dog, fish}
B = {cat, bird, fish, snake}

Intersection = {cat, fish}         size = 2
Union = {cat, dog, fish, bird, snake}  size = 5

Jaccard similarity = 2/5 = 0.4
Jaccard distance = 0.6
```

Когда использовать Жаккара:
- Сравнение наборов тегов, категорий или признаков
- Сходство документов на основе присутствия слов (не частоты)
- Обнаружение почти дубликатов (приближение Жаккара через MinHash)
- Сравнение бинарных векторов признаков (данные присутствия/отсутствия)
- Оценка моделей сегментации (отношение пересечения к объединению = Жаккар)

### Расстояние редактирования (расстояние Левенштейна)

Расстояние редактирования подсчитывает минимальное число односимвольных операций, необходимых для преобразования одной строки в другую. Операции: вставка, удаление или замена.

```
"kitten" -> "sitting"

kitten -> sitten  (substitute k -> s)
sitten -> sittin  (substitute e -> i)
sittin -> sitting (insert g)

Edit distance = 3
```

Вычисляется методом динамического программирования. Заполняется матрица, где элемент (i, j) — это расстояние редактирования между первыми i символами строки A и первыми j символами строки B.

```
        ""  s  i  t  t  i  n  g
    ""   0  1  2  3  4  5  6  7
    k    1  1  2  3  4  5  6  7
    i    2  2  1  2  3  4  5  6
    t    3  3  2  1  2  3  4  5
    t    4  4  3  2  1  2  3  4
    e    5  5  4  3  2  2  3  4
    n    6  6  5  4  3  3  2  3
```

Когда использовать расстояние редактирования:
- Проверка и исправление орфографии
- Выравнивание последовательностей ДНК (со взвешенными операциями)
- Нечёткое сопоставление строк
- Дедупликация неаккуратных текстовых данных

### KL-дивергенция (не расстояние, но используется как оно)

KL-дивергенция измеряет, насколько одно распределение вероятностей отличается от другого. Рассмотрена в Уроке 09, но она принадлежит этому обсуждению, потому что её используют как «расстояние», хотя она им не является.

```
D_KL(P || Q) = sum(p(x) * log(p(x) / q(x)))
```

Критическое свойство: KL-дивергенция НЕ симметрична.

```
D_KL(P || Q) != D_KL(Q || P)
```

Это значит, что она не удовлетворяет базовому требованию метрики расстояния. Она также не удовлетворяет неравенству треугольника. Это дивергенция, а не расстояние.

Прямая KL (D_KL(P || Q)) — «ищущая среднее»: Q пытается охватить все моды P.
Обратная KL (D_KL(Q || P)) — «ищущая моду»: Q фокусируется на одной моде P.

Когда вы видите KL-дивергенцию:
- VAE (член KL в ELBO подталкивает латентное распределение к априорному)
- Дистилляция знаний (студент пытается сопоставить распределение учителя)
- RLHF (штраф KL удерживает дообученную модель близко к базовой модели)
- Методы градиента политики (ограничение обновлений политики)

### Расстояние Вассерштейна (расстояние землекопа)

Расстояние Вассерштейна измеряет минимальную «работу», необходимую для преобразования одного распределения вероятностей в другое. Представьте это так: если одно распределение — куча земли, а другое — яма, сколько земли нужно переместить и на какое расстояние?

```
W(P, Q) = inf over all transport plans gamma of E[d(x, y)]
```

Для одномерных распределений оно упрощается до интеграла абсолютной разности кумулятивных функций распределения:

```
W_1(P, Q) = integral |CDF_P(x) - CDF_Q(x)| dx
```

Почему Вассерштейн важен:
- Это истинная метрика (симметричная, удовлетворяет неравенству треугольника)
- Она даёт градиенты, даже когда распределения не пересекаются (KL-дивергенция уходит в бесконечность)
- Это свойство сделало её центральной для Wasserstein GAN (WGAN), которые решили проблему нестабильности обучения оригинальных GAN

```
Distributions with no overlap:

P: [1, 0, 0, 0, 0]    Q: [0, 0, 0, 0, 1]

KL divergence: infinity (log of zero)
Wasserstein: 4 (move all mass 4 bins)

Wasserstein gives a meaningful gradient. KL does not.
```

Когда использовать Вассерштейна:
- Обучение GAN (WGAN, WGAN-GP)
- Сравнение распределений, которые могут не пересекаться
- Задачи оптимального транспорта
- Поиск изображений (сравнение гистограмм цвета)

### Почему разным задачам нужны разные расстояния

| Задача | Лучшее расстояние | Почему |
|------|--------------|-----|
| Сходство текстов | Косинусное | Величина — это шум, направление — смысл |
| Попиксельное сравнение изображений | L2 | Важны пространственные отношения, а масштабы признаков сопоставимы |
| Разреженные признаки высокой размерности | L1 | Устойчиво и не усиливает редкие большие различия |
| Пересечение множеств (теги, категории) | Жаккара | Данные по своей природе представлены множествами, а не векторами |
| Сопоставление строк | Редактирования | Операции соответствуют интуитивному представлению человека о редактировании |
| Обнаружение выбросов | Махаланобиса | Учитывает корреляции и масштабы признаков |
| Сравнение распределений | KL-дивергенция | Измеряет потерю информации при использовании Q вместо P |
| Обучение GAN | Вассерштейна | Даёт градиенты, даже когда распределения не пересекаются |
| Эмбеддинги (векторная БД) | Косинусное или скалярное произведение | Эмбеддинги обучены кодировать смысл в направлении |
| Рекомендации | Скалярное произведение | Величина может кодировать популярность или уверенность |
| Последовательности ДНК | Взвешенное расстояние редактирования | Стоимость замены зависит от пары нуклеотидов |
| Контроль качества на производстве | L-бесконечность | Важно наихудшее отклонение по любому измерению |

### Связь с функциями потерь

Функции потерь — это функции расстояния, применённые к предсказаниям относительно целевых значений.

```
Loss function       Distance it uses       Behavior
MSE                 L2 squared             Penalizes large errors heavily
MAE                 L1                     Penalizes all errors equally
Huber loss          L1 for large errors,   Best of both: robust to outliers,
                    L2 for small errors    smooth gradient near zero
Cross-entropy       KL divergence          Measures distribution mismatch
Hinge loss          max(0, margin - d)     Only penalizes below margin
Triplet loss        L2 (typically)         Pulls positives close, pushes
                                           negatives away
Contrastive loss    L2                     Similar pairs close, dissimilar
                                           pairs beyond margin
```

### Связь с регуляризацией

Регуляризация добавляет к функции потерь штраф в виде нормы весов.

```
L1 regularization (Lasso):   loss + lambda * ||w||_1
  -> Sparse weights. Some weights become exactly zero.
  -> Automatic feature selection.
  -> Solution has corners (non-differentiable at zero).

L2 regularization (Ridge):   loss + lambda * ||w||_2^2
  -> Small weights. All weights shrink toward zero.
  -> No feature selection (nothing goes to exactly zero).
  -> Smooth solution everywhere.

Elastic Net:                  loss + lambda_1 * ||w||_1 + lambda_2 * ||w||_2^2
  -> Combines sparsity of L1 with stability of L2.
  -> Groups of correlated features are kept or dropped together.
```

Почему L1 даёт разреженность, а L2 — нет: представьте область ограничения в 2D-пространстве весов. L1 — ромб, L2 — круг. Контуры функции потерь (эллипсы) с наибольшей вероятностью касаются ромба в углу, где один вес равен нулю. Круга они касаются в гладкой точке, где оба веса ненулевые.

### Поиск ближайших соседей

Каждая функция расстояния подразумевает задачу поиска ближайших соседей: для данной точки запроса найти ближайшие точки в наборе данных.

Точный поиск ближайших соседей выполняется за O(n * d) на запрос в наборе данных из n точек с d измерениями. Для больших наборов данных это слишком медленно.

Алгоритмы приближённого поиска ближайших соседей (ANN) обменивают небольшую долю точности на огромный прирост скорости:

```
Algorithm         Approach                      Used by
KD-trees          Axis-aligned space partition   scikit-learn (low-dim)
Ball trees        Nested hyperspheres            scikit-learn (medium-dim)
LSH               Random hash projections        Near-duplicate detection
HNSW              Hierarchical navigable         FAISS, Qdrant, Weaviate
                  small-world graph
IVF               Inverted file index with       FAISS (billion-scale)
                  cluster-based search
Product quant.    Compress vectors, search       FAISS (memory-constrained)
                  in compressed space
```

HNSW (Hierarchical Navigable Small World) — доминирующий алгоритм в современных векторных базах данных. Он строит многослойный граф, где каждый узел соединён со своими приблизительно ближайшими соседями. Поиск начинается на верхнем слое (разреженном, с длинными переходами) и спускается к нижнему слою (плотному, с короткими переходами).

## Применяем

Наиболее распространённое практическое применение: поиск похожих объектов в векторной базе данных.

```python
import numpy as np

def cosine_similarity_matrix(X):
    norms = np.linalg.norm(X, axis=1, keepdims=True)
    norms = np.where(norms == 0, 1, norms)
    X_normalized = X / norms
    return X_normalized @ X_normalized.T

embeddings = np.random.randn(1000, 768)

sim_matrix = cosine_similarity_matrix(embeddings)

query_idx = 0
similarities = sim_matrix[query_idx]
top_k = np.argsort(similarities)[::-1][1:6]
print(f"Top 5 most similar to item 0: {top_k}")
print(f"Similarities: {similarities[top_k]}")
```

Когда вы вызываете `model.encode(text)`, а затем ищете в векторной базе данных, именно это и происходит под капотом. Модель эмбеддингов отображает текст в векторы. Векторная база данных вычисляет косинусное сходство (или скалярное произведение) между вашим вектором запроса и каждым сохранённым вектором, используя ANN-алгоритмы, чтобы избежать проверки всех из них.

## Ключевые термины

| Термин | Что говорят | Что это на самом деле означает |
|------|----------------|----------------------|
| Норма | «Размер вектора» | Функция, отображающая вектор в неотрицательный скаляр, удовлетворяющая неравенству треугольника, абсолютной однородности и равная нулю только для нулевого вектора |
| Норма L1 | «Манхэттенское расстояние» | Сумма абсолютных значений компонентов. Создаёт разреженность при оптимизации. Устойчива к выбросам |
| Норма L2 | «Евклидово расстояние» | Квадратный корень из суммы квадратов компонентов. Расстояние по прямой линии в евклидовом пространстве |
| Норма Lp | «Обобщённая норма» | Корень p-й степени из суммы p-х степеней абсолютных значений компонентов. L1 и L2 — частные случаи |
| Норма L-бесконечность | «Максимальная норма» или «расстояние Чебышёва» | Максимальное абсолютное значение компонента. Предел Lp при p, стремящемся к бесконечности |
| Косинусное сходство | «Угол между векторами» | Скалярное произведение, нормализованное обеими величинами. Варьируется от -1 до +1. Игнорирует длину вектора |
| Косинусное расстояние | «1 минус косинусное сходство» | Преобразует косинусное сходство в расстояние. Варьируется от 0 до 2 |
| Скалярное произведение | «Ненормализованный косинус» | Сумма покомпонентных произведений. Равно косинусному сходству, умноженному на обе величины |
| Расстояние Махаланобиса | «Расстояние с учётом корреляций» | L2-расстояние в пространстве, которое было отбелено (декоррелировано и нормализовано) с помощью ковариационной матрицы данных |
| Сходство Жаккара | «Пересечение множеств» | Размер пересечения, делённый на размер объединения. Для множеств, не для векторов |
| Расстояние редактирования | «Расстояние Левенштейна» | Минимальное число вставок, удалений и замен для преобразования одной строки в другую |
| KL-дивергенция | «Расстояние между распределениями» | Не является истинным расстоянием (не симметрична). Измеряет лишние биты от использования Q для кодирования P |
| Расстояние Вассерштейна | «Расстояние землекопа» | Минимальная работа для перемещения массы из одного распределения в другое. Истинная метрика |
| Приближённый поиск ближайших соседей (ANN) | «ANN-поиск» | Алгоритмы (HNSW, LSH, IVF), которые находят приблизительно ближайшие точки намного быстрее точного поиска |
| HNSW | «Алгоритм векторных баз данных» | Граф Hierarchical Navigable Small World. Многослойный граф для быстрого приближённого поиска ближайших соседей |
| Регуляризация L1 | «Lasso» | Добавление нормы L1 весов к функции потерь. Подталкивает веса к нулю (разреженность) |
| Регуляризация L2 | «Ridge» или «затухание весов» | Добавление квадрата нормы L2 весов к функции потерь. Сжимает веса к нулю без разреженности |
| Elastic Net | «L1 + L2» | Сочетает регуляризацию L1 и L2. Лучше справляется с группами коррелированных признаков, чем каждая по отдельности |
