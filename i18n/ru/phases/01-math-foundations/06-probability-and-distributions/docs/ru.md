## Проблема

Классификатор выдаёт `[0.03, 0.91, 0.06]`. Языковая модель выбирает следующее слово из 50 000 кандидатов. Диффузионная модель генерирует изображения, сэмплируя из выученных распределений. Всё это — вероятность в действии.

Каждое предсказание модели — это распределение вероятностей. Каждая функция потерь измеряет, насколько предсказанное распределение отличается от истинного. Каждый шаг обучения корректирует параметры так, чтобы одно распределение стало больше похоже на другое. Без вероятности вы не сможете прочитать ни одной статьи по ML, отладить ни одну модель и понять, почему ваша потеря при обучении стала NaN.

## Концепция

### События, пространства элементарных исходов и вероятность

Пространство элементарных исходов S — это множество всех возможных исходов. Событие — это подмножество пространства элементарных исходов. Вероятность отображает события в числа от 0 до 1.

```
Coin flip:
  S = {H, T}
  P(H) = 0.5,  P(T) = 0.5

Single die roll:
  S = {1, 2, 3, 4, 5, 6}
  P(even) = P({2, 4, 6}) = 3/6 = 0.5
```

Всю вероятность определяют три аксиомы:
1. P(A) >= 0 для любого события A
2. P(S) = 1 (что-то всегда происходит)
3. P(A или B) = P(A) + P(B), когда A и B не могут произойти одновременно

Всё остальное (теорема Байеса, математические ожидания, распределения) следует из этих трёх правил.

### Условная вероятность и независимость

P(A|B) — это вероятность A при условии, что B произошло.

```
P(A|B) = P(A and B) / P(B)

Example: deck of cards
  P(King | Face card) = P(King and Face card) / P(Face card)
                      = (4/52) / (12/52)
                      = 4/12 = 1/3
```

Два события независимы, когда знание об одном ничего не говорит о другом:

```
Independent:   P(A|B) = P(A)
Equivalent to: P(A and B) = P(A) * P(B)
```

Подбрасывания монеты независимы. Вытягивание карт без возврата — нет.

### Функции вероятности масс и функции плотности вероятности

У дискретных случайных величин есть функция вероятности масс (PMF). У каждого исхода есть конкретная вероятность, которую можно прочитать напрямую.

```
PMF: P(X = k)

Fair die:
  P(X = 1) = 1/6
  P(X = 2) = 1/6
  ...
  P(X = 6) = 1/6

  Sum of all probabilities = 1
```

У непрерывных случайных величин есть функция плотности вероятности (PDF). Плотность в одной точке — это не вероятность. Вероятность получается интегрированием плотности по интервалу.

```
PDF: f(x)

P(a <= X <= b) = integral of f(x) from a to b

f(x) can be greater than 1 (density, not probability)
integral from -inf to +inf of f(x) dx = 1
```

Это различие важно в ML. Выходы классификации — это PMF (дискретный выбор). Латентные пространства VAE используют PDF (непрерывность).

### Распространённые распределения

**Бернулли:** одно испытание, два исхода. Моделирует бинарную классификацию.

```
P(X = 1) = p
P(X = 0) = 1 - p
Mean = p,  Variance = p(1-p)
```

**Категориальное:** одно испытание, k исходов. Моделирует многоклассовую классификацию (выход softmax).

```
P(X = i) = p_i,  where sum of p_i = 1
Example: P(cat) = 0.7,  P(dog) = 0.2,  P(bird) = 0.1
```

**Равномерное:** все исходы равновероятны. Используется для случайной инициализации.

```
Discrete: P(X = k) = 1/n for k in {1, ..., n}
Continuous: f(x) = 1/(b-a) for x in [a, b]
```

**Нормальное (гауссово):** колоколообразная кривая. Параметризуется средним (mu) и дисперсией (sigma^2).

```
f(x) = (1 / sqrt(2*pi*sigma^2)) * exp(-(x - mu)^2 / (2*sigma^2))

Standard normal: mu = 0, sigma = 1
  68% of data within 1 sigma
  95% within 2 sigma
  99.7% within 3 sigma
```

**Пуассона:** количество редких событий в фиксированном интервале. Моделирует частоту событий.

```
P(X = k) = (lambda^k * e^(-lambda)) / k!
Mean = lambda,  Variance = lambda
```

### Математическое ожидание и дисперсия

Математическое ожидание — это средневзвешенный исход.

```
Discrete:   E[X] = sum of x_i * P(X = x_i)
Continuous: E[X] = integral of x * f(x) dx
```

Дисперсия измеряет разброс вокруг среднего.

```
Var(X) = E[(X - E[X])^2] = E[X^2] - (E[X])^2
Standard deviation = sqrt(Var(X))
```

В ML математическое ожидание проявляется как функция потерь (средняя потеря по распределению данных). Дисперсия говорит о стабильности модели. Высокая дисперсия градиентов означает шумное обучение.

### Совместные и маргинальные распределения

Совместное распределение P(X, Y) описывает две случайные величины вместе.

Пример совместной PMF (X = погода, Y = зонт):

| | Y=0 (без зонта) | Y=1 (с зонтом) | Маргинальная P(X) |
|---|---|---|---|
| X=0 (солнце) | 0.40 | 0.10 | P(X=0) = 0.50 |
| X=1 (дождь) | 0.05 | 0.45 | P(X=1) = 0.50 |
| **Маргинальная P(Y)** | P(Y=0) = 0.45 | P(Y=1) = 0.55 | 1.00 |

Маргинальное распределение суммирует по другой переменной:

```
P(X = x) = sum over all y of P(X = x, Y = y)
```

Суммы по строкам и столбцам в таблице выше и есть маргинальные распределения.

### Почему нормальное распределение встречается повсюду

Центральная предельная теорема: сумма (или среднее) многих независимых случайных величин сходится к нормальному распределению независимо от исходного распределения.

```
Roll 1 die:  uniform distribution (flat)
Average of 2 dice:  triangular (peaked)
Average of 30 dice: nearly perfect bell curve

This works for ANY starting distribution.
```

Именно поэтому:
- Ошибки измерений приблизительно нормальны (много малых независимых источников)
- Инициализация весов в нейронных сетях использует нормальные распределения
- Шум градиента в SGD приблизительно нормален (сумма многих выборочных градиентов)
- Нормальное распределение — это распределение максимальной энтропии для заданного среднего и дисперсии

### Логарифмы вероятностей

Необработанные вероятности вызывают численные проблемы. Перемножение множества маленьких вероятностей быстро приводит к underflow до нуля.

```
P(sentence) = P(word1) * P(word2) * ... * P(word_n)
            = 0.01 * 0.003 * 0.02 * ...
            -> 0.0 (underflow after ~30 terms)
```

Логарифмы вероятностей решают эту проблему. Умножения становятся сложениями.

```
log P(sentence) = log P(word1) + log P(word2) + ... + log P(word_n)
                = -4.6 + -5.8 + -3.9 + ...
                -> finite number (no underflow)
```

Правила:
- log(a * b) = log(a) + log(b)
- логарифмы вероятностей всегда <= 0 (поскольку 0 < P <= 1)
- чем более отрицательное значение, тем менее вероятен исход
- потеря перекрёстной энтропии — это отрицательный логарифм вероятности правильного класса

### Softmax как распределение вероятностей

Нейронные сети выдают необработанные оценки (логиты). Softmax преобразует их в корректное распределение вероятностей.

```
softmax(z_i) = exp(z_i) / sum(exp(z_j) for all j)

Properties:
  - All outputs are in (0, 1)
  - All outputs sum to 1
  - Preserves relative ordering of inputs
  - exp() amplifies differences between logits
```

Приём softmax: вычесть максимальный логит перед экспонированием, чтобы предотвратить переполнение.

```
z = [100, 101, 102]
exp(102) = overflow

z_shifted = z - max(z) = [-2, -1, 0]
exp(0) = 1  (safe)

Same result, no overflow.
```

Log-softmax объединяет softmax и логарифм для численной устойчивости. PyTorch использует это внутри для потери перекрёстной энтропии.

### Сэмплирование

Сэмплирование означает извлечение случайных значений из распределения. В ML:
- Дропаут случайным образом выбирает, какие нейроны обнулить
- Аугментация данных сэмплирует случайные преобразования
- Языковые модели сэмплируют следующий токен из предсказанного распределения
- Диффузионные модели сэмплируют шум и постепенно его убирают

Сэмплирование из произвольных распределений требует таких техник, как сэмплирование методом обратного преобразования, сэмплирование с отклонением (rejection sampling) или reparameterization trick (используется в VAE).

## Создаём

### Шаг 1: Основы вероятности

```python
import math
import random

def factorial(n):
    result = 1
    for i in range(2, n + 1):
        result *= i
    return result

def combinations(n, k):
    return factorial(n) // (factorial(k) * factorial(n - k))

def conditional_probability(p_a_and_b, p_b):
    return p_a_and_b / p_b

p_king_given_face = conditional_probability(4/52, 12/52)
print(f"P(King | Face card) = {p_king_given_face:.4f}")
```

### Шаг 2: PMF и PDF с нуля

```python
def bernoulli_pmf(k, p):
    return p if k == 1 else (1 - p)

def categorical_pmf(k, probs):
    return probs[k]

def poisson_pmf(k, lam):
    return (lam ** k) * math.exp(-lam) / factorial(k)

def uniform_pdf(x, a, b):
    if a <= x <= b:
        return 1.0 / (b - a)
    return 0.0

def normal_pdf(x, mu, sigma):
    coeff = 1.0 / (sigma * math.sqrt(2 * math.pi))
    exponent = -0.5 * ((x - mu) / sigma) ** 2
    return coeff * math.exp(exponent)
```

### Шаг 3: Математическое ожидание и дисперсия

```python
def expected_value(values, probabilities):
    return sum(v * p for v, p in zip(values, probabilities))

def variance(values, probabilities):
    mu = expected_value(values, probabilities)
    return sum(p * (v - mu) ** 2 for v, p in zip(values, probabilities))

die_values = [1, 2, 3, 4, 5, 6]
die_probs = [1/6] * 6
mu = expected_value(die_values, die_probs)
var = variance(die_values, die_probs)
print(f"Die: E[X] = {mu:.4f}, Var(X) = {var:.4f}, SD = {var**0.5:.4f}")
```

### Шаг 4: Сэмплирование из распределений

```python
def sample_bernoulli(p, n=1):
    return [1 if random.random() < p else 0 for _ in range(n)]

def sample_categorical(probs, n=1):
    cumulative = []
    total = 0
    for p in probs:
        total += p
        cumulative.append(total)
    samples = []
    for _ in range(n):
        r = random.random()
        for i, c in enumerate(cumulative):
            if r <= c:
                samples.append(i)
                break
    return samples

def sample_normal_box_muller(mu, sigma, n=1):
    samples = []
    for _ in range(n):
        u1 = random.random()
        u2 = random.random()
        z = math.sqrt(-2 * math.log(u1)) * math.cos(2 * math.pi * u2)
        samples.append(mu + sigma * z)
    return samples
```

### Шаг 5: Softmax и логарифмы вероятностей

```python
def softmax(logits):
    max_logit = max(logits)
    shifted = [z - max_logit for z in logits]
    exps = [math.exp(z) for z in shifted]
    total = sum(exps)
    return [e / total for e in exps]

def log_softmax(logits):
    max_logit = max(logits)
    shifted = [z - max_logit for z in logits]
    log_sum_exp = max_logit + math.log(sum(math.exp(z) for z in shifted))
    return [z - log_sum_exp for z in logits]

def cross_entropy_loss(logits, target_index):
    log_probs = log_softmax(logits)
    return -log_probs[target_index]
```

### Шаг 6: Демонстрация центральной предельной теоремы

```python
def demonstrate_clt(dist_fn, n_samples, n_averages):
    averages = []
    for _ in range(n_averages):
        samples = [dist_fn() for _ in range(n_samples)]
        averages.append(sum(samples) / len(samples))
    return averages
```

## Ключевые термины

| Термин | Что говорят | Что это на самом деле означает |
|------|----------------|----------------------|
| Пространство элементарных исходов (Sample space) | «Все возможности» | Множество S всех возможных исходов эксперимента |
| PMF | «Функция вероятности» | Функция, которая даёт точную вероятность каждого дискретного исхода, сумма которых равна 1 |
| PDF | «Кривая вероятности» | Функция плотности для непрерывных переменных. Проинтегрируйте её по интервалу, чтобы получить вероятность |
| Условная вероятность (Conditional probability) | «Вероятность при условии» | P(A\|B) = P(A и B) / P(B). Основа байесовского мышления и теоремы Байеса |
| Независимость (Independence) | «Они не влияют друг на друга» | P(A и B) = P(A) * P(B). Знание одного события ничего не говорит о другом |
| Математическое ожидание (Expected value) | «Среднее» | Взвешенная по вероятности сумма всех исходов. Функция потерь — это математическое ожидание |
| Дисперсия (Variance) | «Насколько разбросано» | Ожидаемое квадратичное отклонение от среднего. Высокая дисперсия = шумные, нестабильные оценки |
| Нормальное распределение (Normal distribution) | «Колоколообразная кривая» | f(x) = (1/sqrt(2*pi*sigma^2)) * exp(-(x-mu)^2/(2*sigma^2)). Встречается повсюду благодаря центральной предельной теореме |
| Центральная предельная теорема (Central Limit Theorem) | «Средние становятся нормальными» | Среднее многих независимых выборок сходится к нормальному распределению независимо от источника |
| Совместное распределение (Joint distribution) | «Две переменные вместе» | P(X, Y) описывает вероятность каждой комбинации исходов X и Y |
| Маргинальное распределение (Marginal distribution) | «Просуммировать другую переменную» | P(X) = sum_y P(X, Y). Восстанавливает распределение одной переменной из совместного |
| Логарифм вероятности (Log probability) | «Логарифм вероятности» | log P(x). Превращает произведения в суммы, предотвращая численный underflow в длинных последовательностях |
| Softmax | «Превратить оценки в вероятности» | softmax(z_i) = exp(z_i) / sum(exp(z_j)). Отображает вещественные логиты в корректное распределение вероятностей |
| Перекрёстная энтропия (Cross-entropy) | «Функция потерь» | -sum(p_true * log(p_predicted)). Измеряет, насколько различаются два распределения. Чем меньше, тем лучше |
| Логиты (Logits) | «Необработанные выходы модели» | Ненормированные оценки до softmax. Названы в честь логистической функции |
| Сэмплирование (Sampling) | «Извлечение случайных значений» | Генерация значений в соответствии с распределением вероятностей. То, как модели генерируют выход |
