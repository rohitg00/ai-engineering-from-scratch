## Цели обучения

- Реализовать сэмплирование методом обратной функции распределения, сэмплирование с отклонением и сэмплирование по значимости с нуля, используя только равномерные случайные числа
- Построить температурное, top-k и top-p (nucleus) сэмплирование для генерации токенов языковой моделью
- Объяснить трюк репараметризации и почему он позволяет выполнять обратное распространение ошибки через сэмплирование в VAE
- Запустить MCMC Метрополиса — Гастингса для сэмплирования из ненормированного целевого распределения

## Проблема

Языковая модель заканчивает обработку вашего промпта и выдаёт вектор из 50 000 логитов. По одному на каждый токен в её словаре. Теперь ей нужно выбрать один. Как?

Если она всегда выбирает токен с наибольшей вероятностью, каждый ответ идентичен. Детерминированно. Скучно. Если она выбирает равномерно случайно, вывод — бессмыслица. Ответ находится где-то между этими крайностями, и это «где-то» контролируется сэмплированием.

Сэмплирование не ограничивается генерацией текста. Обучение с подкреплением оценивает градиенты политики путём сэмплирования траекторий. VAE учат латентные представления, сэмплируя из изученных распределений и выполняя обратное распространение через случайность. Диффузионные модели генерируют изображения, сэмплируя шум и итеративно его убирая. Методы Монте-Карло оценивают интегралы, не имеющие решения в замкнутой форме. Алгоритмы MCMC исследуют многомерные апостериорные распределения, которые невозможно перечислить.

Каждая генеративная система ИИ — это система сэмплирования. Стратегия сэмплирования определяет качество, разнообразие и управляемость вывода. Этот урок строит с нуля все основные методы сэмплирования, начиная с равномерных случайных чисел и заканчивая техниками, которые лежат в основе современных LLM и генеративных моделей.

## Концепция

### Почему сэмплирование важно

Сэмплирование играет четыре фундаментальные роли в ИИ и машинном обучении:

**Генерация.** Языковые модели, диффузионные модели и GAN — все производят вывод путём сэмплирования. Алгоритм сэмплирования напрямую контролирует креативность, связность и разнообразие. Температура, top-k и nucleus-сэмплирование — это ручки, которые инженеры крутят каждый день.

**Обучение.** Стохастический градиентный спуск сэмплирует мини-пакеты. Дропаут сэмплирует нейроны для отключения. Аугментация данных сэмплирует случайные преобразования. Сэмплирование по значимости перевзвешивает образцы, чтобы уменьшить дисперсию градиента в обучении с подкреплением (PPO, TRPO).

**Оценивание.** Многие величины в ML не имеют решения в замкнутой форме. Ожидаемые потери по распределению данных, статистическая сумма энергетической модели, свидетельство (evidence) в байесовском выводе. Оценка методом Монте-Карло аппроксимирует всё это усреднением по образцам.

**Исследование.** Алгоритмы MCMC исследуют апостериорные распределения в байесовском выводе. Эволюционные стратегии сэмплируют возмущения параметров. Сэмплирование Томпсона балансирует между исследованием и использованием в задачах о многоруких бандитах.

Основной вызов: вы можете сэмплировать напрямую только из простых распределений (равномерного, нормального). Для всего остального вам нужен метод преобразования простых образцов в образцы из вашего целевого распределения.

### Равномерное случайное сэмплирование

Каждый метод сэмплирования начинается здесь. Генератор равномерных случайных чисел выдаёт значения в [0, 1), где каждый подынтервал равной длины имеет равную вероятность.

```
U ~ Uniform(0, 1)

P(a <= U <= b) = b - a    for 0 <= a <= b <= 1

Properties:
  E[U] = 0.5
  Var(U) = 1/12
```

Чтобы сэмплировать равномерно из дискретного набора из n элементов, сгенерируйте U и верните floor(n * U). Чтобы сэмплировать из непрерывного диапазона [a, b], вычислите a + (b - a) * U.

Ключевая идея: одно равномерное случайное число содержит ровно нужное количество случайности, чтобы произвести один образец из любого распределения. Хитрость в том, чтобы найти правильное преобразование.

### Метод обратной функции распределения (inverse transform sampling)

Функция распределения (CDF) отображает значения в вероятности:

```
F(x) = P(X <= x)

Properties:
  F is non-decreasing
  F(-inf) = 0
  F(+inf) = 1
  F maps the real line to [0, 1]
```

Обратная функция распределения отображает вероятности обратно в значения. Если U ~ Uniform(0, 1), то X = F_inverse(U) следует целевому распределению.

```
Algorithm:
  1. Generate u ~ Uniform(0, 1)
  2. Return F_inverse(u)

Why it works:
  P(X <= x) = P(F_inverse(U) <= x) = P(U <= F(x)) = F(x)
```

**Пример с экспоненциальным распределением:**

```
PDF: f(x) = lambda * exp(-lambda * x),   x >= 0
CDF: F(x) = 1 - exp(-lambda * x)

Solve F(x) = u for x:
  u = 1 - exp(-lambda * x)
  exp(-lambda * x) = 1 - u
  x = -ln(1 - u) / lambda

Since (1 - U) and U have the same distribution:
  x = -ln(u) / lambda
```

Это отлично работает, когда вы можете записать F_inverse в замкнутой форме. Для нормального распределения замкнутой формы обратной CDF не существует, поэтому используются другие методы (Бокса — Мюллера или численное приближение).

**Дискретная версия:** для дискретных распределений постройте CDF как накопленную сумму, сгенерируйте U и найдите первый индекс, в котором накопленная сумма превышает U. Именно так работает `sample_categorical` в Уроке 06.

### Сэмплирование с отклонением (rejection sampling)

Когда вы не можете инвертировать CDF, но можете вычислить целевую PDF с точностью до константы, работает сэмплирование с отклонением.

```
Target distribution: p(x)  (can evaluate, possibly unnormalized)
Proposal distribution: q(x)  (can sample from)
Bound: M such that p(x) <= M * q(x) for all x

Algorithm:
  1. Sample x ~ q(x)
  2. Sample u ~ Uniform(0, 1)
  3. If u < p(x) / (M * q(x)), accept x
  4. Otherwise, reject and go to step 1

Acceptance rate = 1/M
```

Чем точнее граница M, тем выше частота принятия. В низких размерностях (1–3) сэмплирование с отклонением работает хорошо. В высоких размерностях частота принятия падает экспоненциально, потому что большая часть объёма предложенного распределения отклоняется. Это проклятие размерности для сэмплирования с отклонением.

**Пример: сэмплирование из усечённого нормального распределения.** Используйте равномерное предложенное распределение по усечённому диапазону. Огибающая M — это максимум нормальной PDF в этом диапазоне.

**Пример: сэмплирование из полукруга.** Предлагайте точки равномерно в ограничивающем прямоугольнике. Принимайте, если точка попадает внутрь полукруга. Именно так метод Монте-Карло вычисляет pi: частота принятия равна отношению площадей pi/4.

### Сэмплирование по значимости (importance sampling)

Иногда вам не нужны образцы из целевого распределения p(x). Вам нужно оценить математическое ожидание при p(x), а у вас есть образцы из другого распределения q(x).

```
Goal: estimate E_p[f(x)] = integral of f(x) * p(x) dx

Rewrite:
  E_p[f(x)] = integral of f(x) * (p(x)/q(x)) * q(x) dx
            = E_q[f(x) * w(x)]

where w(x) = p(x) / q(x)  are the importance weights.

Estimator:
  E_p[f(x)] ~ (1/N) * sum(f(x_i) * w(x_i))    where x_i ~ q(x)
```

Это критически важно в обучении с подкреплением. В PPO (Proximal Policy Optimization) вы собираете траектории при старой политике pi_old, но хотите оптимизировать новую политику pi_new. Вес значимости — это pi_new(a|s) / pi_old(a|s). PPO обрезает эти веса, чтобы предотвратить слишком сильное расхождение новой политики со старой.

Дисперсия оценщика сэмплирования по значимости зависит от того, насколько q похоже на p. Если q сильно отличается от p, несколько образцов получают огромные веса и доминируют в оценке. Самонормализованное сэмплирование по значимости делит на сумму весов, чтобы уменьшить эту проблему:

```
E_p[f(x)] ~ sum(w_i * f(x_i)) / sum(w_i)
```

### Оценка методом Монте-Карло

Оценка методом Монте-Карло аппроксимирует интегралы усреднением случайных образцов. Закон больших чисел гарантирует сходимость.

```
Goal: estimate I = integral of g(x) dx over domain D

Method:
  1. Sample x_1, ..., x_N uniformly from D
  2. I ~ (Volume of D / N) * sum(g(x_i))

Error: O(1 / sqrt(N))   regardless of dimension
```

Скорость ошибки не зависит от размерности. Именно поэтому методы Монте-Карло доминируют в высоких размерностях, где интегрирование на сетке невозможно.

**Оценка pi:**

```
Sample (x, y) uniformly from [-1, 1] x [-1, 1]
Count how many fall inside the unit circle: x^2 + y^2 <= 1
pi ~ 4 * (count inside) / (total count)
```

**Оценка математических ожиданий:**

```
E[f(X)] ~ (1/N) * sum(f(x_i))    where x_i ~ p(x)

The sample mean converges to the true expectation.
Variance of the estimator = Var(f(X)) / N
```

### Марковские цепи Монте-Карло (MCMC): Метрополис — Гастингс

MCMC строит марковскую цепь, стационарное распределение которой — целевое распределение p(x). После достаточного числа шагов образцы из цепи (приближённо) являются образцами из p(x).

```
Target: p(x)  (known up to a normalizing constant)
Proposal: q(x'|x)  (how to propose the next state given the current state)

Metropolis-Hastings algorithm:
  1. Start at some x_0
  2. For t = 1, 2, ..., T:
     a. Propose x' ~ q(x'|x_t)
     b. Compute acceptance ratio:
        alpha = [p(x') * q(x_t|x')] / [p(x_t) * q(x'|x_t)]
     c. Accept with probability min(1, alpha):
        - If u < alpha (u ~ Uniform(0,1)): x_{t+1} = x'
        - Otherwise: x_{t+1} = x_t
  3. Discard first B samples (burn-in)
  4. Return remaining samples
```

Для симметричных предложенных распределений (q(x'|x) = q(x|x')) отношение упрощается до p(x')/p(x). Это оригинальный алгоритм Метрополиса.

**Почему это работает.** Правило принятия обеспечивает детальный баланс: вероятность находиться в x и перейти в x' равна вероятности находиться в x' и перейти в x. Детальный баланс подразумевает, что p(x) является стационарным распределением цепи.

**Практические соображения:**
- Прогрев (burn-in): отбросьте ранние образцы до того, как цепь достигнет равновесия
- Прореживание (thinning): оставляйте каждый k-й образец, чтобы уменьшить автокорреляцию
- Масштаб предложенного распределения: слишком маленький — и цепь движется медленно (высокая частота принятия, медленное исследование); слишком большой — и большинство предложений отклоняется (низкая частота принятия, застревание на месте)
- Оптимальная частота принятия для гауссовского предложенного распределения в высоких размерностях составляет примерно 0.234

### Сэмплирование Гиббса

Сэмплирование Гиббса — это частный случай MCMC для многомерных распределений. Вместо того чтобы предлагать движение сразу по всем измерениям, оно обновляет по одной переменной за раз из её условного распределения.

```
Target: p(x_1, x_2, ..., x_d)

Algorithm:
  For each iteration t:
    Sample x_1^{t+1} ~ p(x_1 | x_2^t, x_3^t, ..., x_d^t)
    Sample x_2^{t+1} ~ p(x_2 | x_1^{t+1}, x_3^t, ..., x_d^t)
    ...
    Sample x_d^{t+1} ~ p(x_d | x_1^{t+1}, x_2^{t+1}, ..., x_{d-1}^{t+1})
```

Сэмплирование Гиббса требует, чтобы вы могли сэмплировать из каждого условного распределения p(x_i | x_{-i}). Для многих моделей это несложно:
- Байесовские сети: условные распределения следуют из структуры графа
- Смеси гауссиан: условные распределения гауссовы
- Модели Изинга: условное распределение каждого спина зависит только от его соседей

Частота принятия всегда равна 1 (каждое предложение принимается), потому что сэмплирование из точного условного распределения автоматически удовлетворяет детальному балансу.

**Ограничение.** Когда переменные сильно коррелированы, сэмплирование Гиббса смешивается медленно, потому что обновление одной переменной за раз не может совершать большие диагональные перемещения по распределению.

### Температурное сэмплирование (используется в LLM)

Языковые модели выдают логиты z_1, ..., z_V для каждого токена в словаре. Softmax преобразует их в вероятности. Температура масштабирует логиты перед softmax:

```
p_i = exp(z_i / T) / sum(exp(z_j / T))

T = 1.0: standard softmax (original distribution)
T -> 0:  argmax (deterministic, always picks highest logit)
T -> inf: uniform (all tokens equally likely)
T < 1.0: sharpens the distribution (more confident, less diverse)
T > 1.0: flattens the distribution (less confident, more diverse)
```

**Почему это работает.** Деление логитов на T < 1 усиливает различия между логитами. Если z_1 = 2 и z_2 = 1, деление на T = 0.5 даёт z_1/T = 4 и z_2/T = 2, увеличивая разрыв. После softmax токен с наибольшим логитом получает намного большую долю.

**На практике:**
- T = 0.0: жадное декодирование, лучше всего для фактических вопросов-ответов
- T = 0.3–0.7: слегка креативно, хорошо для генерации кода
- T = 0.7–1.0: сбалансировано, хорошо для общего диалога
- T = 1.0–1.5: креативное письмо, брейнсторминг
- T > 1.5: всё более случайно, редко полезно

Температура не меняет, какие токены возможны. Она меняет вероятностную массу, выделенную каждому токену.

### Top-k сэмплирование

Top-k сэмплирование ограничивает набор кандидатов k токенами с наибольшими вероятностями, затем перенормирует и сэмплирует из этого ограниченного набора.

```
Algorithm:
  1. Compute softmax probabilities for all V tokens
  2. Sort tokens by probability (descending)
  3. Keep only the top k tokens
  4. Renormalize: p_i' = p_i / sum(p_j for j in top-k)
  5. Sample from the renormalized distribution

k = 1:  greedy decoding
k = V:  no filtering (standard sampling)
k = 40: typical setting, removes long tail of unlikely tokens
```

Top-k предотвращает выбор моделью крайне маловероятных токенов (опечаток, бессмыслицы), находящихся в длинном хвосте распределения словаря. Проблема: k фиксировано независимо от контекста. Когда модель уверена (один токен имеет вероятность 95%), k = 40 всё равно допускает 39 альтернатив. Когда модель не уверена (вероятность распределена по 1000 токенов), k = 40 отсекает правдоподобные варианты.

### Top-p (nucleus) сэмплирование

Top-p сэмплирование динамически подстраивает размер набора кандидатов. Вместо того чтобы удерживать фиксированное число токенов, оно удерживает наименьший набор токенов, чья накопленная вероятность превышает p.

```
Algorithm:
  1. Compute softmax probabilities for all V tokens
  2. Sort tokens by probability (descending)
  3. Find smallest k such that sum of top-k probabilities >= p
  4. Keep only those k tokens
  5. Renormalize and sample

p = 0.9:  keeps tokens covering 90% of probability mass
p = 1.0:  no filtering
p = 0.1:  very restrictive, nearly greedy
```

Когда модель уверена, nucleus-сэмплирование удерживает мало токенов (возможно, 2–3). Когда модель не уверена, оно удерживает много (возможно, 200). Именно это адаптивное поведение объясняет, почему nucleus-сэмплирование обычно производит текст лучше, чем top-k.

**Распространённые комбинации:**
- Температура 0.7 + top-p 0.9: хорошая универсальная настройка
- Температура 0.0 (жадное декодирование): лучше всего для детерминированных задач
- Температура 1.0 + top-k 50: настройка из оригинальной статьи Fan et al. (2018)

Top-k и top-p можно комбинировать. Сначала примените top-k, затем top-p к оставшемуся набору.

### Трюк репараметризации (используется в VAE)

Вариационные автокодировщики (VAE) обучаются, кодируя входные данные в распределение в латентном пространстве, сэмплируя из этого распределения и декодируя образец обратно. Проблема: вы не можете выполнить обратное распространение ошибки через операцию сэмплирования.

```
Standard sampling (not differentiable):
  z ~ N(mu, sigma^2)

  The randomness blocks gradient flow.
  d/d_mu [sample from N(mu, sigma^2)] = ???
```

Трюк репараметризации отделяет случайность от параметров:

```
Reparameterized sampling:
  epsilon ~ N(0, 1)          (fixed random noise, no parameters)
  z = mu + sigma * epsilon   (deterministic function of parameters)

  Now z is a deterministic, differentiable function of mu and sigma.
  d(z)/d(mu) = 1
  d(z)/d(sigma) = epsilon

  Gradients flow through mu and sigma.
```

Это работает, потому что N(mu, sigma^2) имеет то же распределение, что и mu + sigma * N(0, 1). Ключевая идея: перенести случайность в источник без параметров (epsilon), затем выразить образец как дифференцируемое преобразование параметров.

**В цикле обучения VAE:**
1. Энкодер выдаёт mu и log(sigma^2) для каждого входа
2. Сэмплируйте epsilon ~ N(0, 1)
3. Вычислите z = mu + sigma * epsilon
4. Декодируйте z, чтобы восстановить вход
5. Выполните обратное распространение через шаги 4, 3, 2, 1 (возможно, потому что шаг 3 дифференцируем)

Без трюка репараметризации VAE нельзя обучить стандартным обратным распространением ошибки. Именно эта идея сделала VAE практически применимыми.

### Gumbel-Softmax (дифференцируемое категориальное сэмплирование)

Трюк репараметризации работает для непрерывных распределений (гауссовского). Для дискретных категориальных распределений нужен другой подход. Gumbel-Softmax обеспечивает дифференцируемое приближение к категориальному сэмплированию.

**Трюк Gumbel-Max (недифференцируемый):**

```
To sample from a categorical distribution with log-probabilities log(p_1), ..., log(p_k):
  1. Sample g_i ~ Gumbel(0, 1) for each category
     (g = -log(-log(u)), where u ~ Uniform(0, 1))
  2. Return argmax(log(p_i) + g_i)

This produces exact categorical samples.
```

**Gumbel-Softmax (дифференцируемое приближение):**

```
Replace the hard argmax with a soft softmax:
  y_i = exp((log(p_i) + g_i) / tau) / sum(exp((log(p_j) + g_j) / tau))

tau (temperature) controls the approximation:
  tau -> 0:  approaches a one-hot vector (hard categorical)
  tau -> inf: approaches uniform (1/k, 1/k, ..., 1/k)
  tau = 1.0: soft approximation
```

Gumbel-Softmax производит непрерывное ослабление дискретного образца. Вывод — это вектор вероятностей (мягкий one-hot) вместо жёсткого one-hot. Градиенты проходят через softmax. Во время прямого прохода при обучении можно использовать оценщик «straight-through»: использовать жёсткий argmax для прямого прохода, но мягкие градиенты Gumbel-Softmax для обратного прохода.

**Применения:**
- Дискретные латентные переменные в VAE
- Поиск нейронной архитектуры (выбор дискретных операций)
- Механизмы жёсткого внимания
- Обучение с подкреплением с дискретными действиями

### Стратифицированное сэмплирование

Стандартное сэмплирование методом Монте-Карло может случайно оставлять пробелы в пространстве образцов. Стратифицированное сэмплирование обеспечивает равномерное покрытие, разделяя пространство на страты и сэмплируя из каждой.

```
Standard Monte Carlo:
  Sample N points uniformly from [0, 1]
  Some regions may have clusters, others gaps

Stratified sampling:
  Divide [0, 1] into N equal strata: [0, 1/N), [1/N, 2/N), ..., [(N-1)/N, 1)
  Sample one point uniformly within each stratum
  x_i = (i + u_i) / N   where u_i ~ Uniform(0, 1),  i = 0, ..., N-1
```

Стратифицированное сэмплирование всегда имеет дисперсию не выше, чем у стандартного метода Монте-Карло:

```
Var(stratified) <= Var(standard Monte Carlo)

The improvement is largest when f(x) varies smoothly.
For piecewise-constant functions, stratified sampling is exact.
```

**Применения:**
- Численное интегрирование (квази-Монте-Карло)
- Разбиения обучающих данных (обеспечение баланса классов в каждом фолде)
- Сэмплирование по значимости со стратификацией (сочетание обеих техник)
- NeRF (Neural Radiance Fields) использует стратифицированное сэмплирование вдоль лучей камеры

### Связь с диффузионными моделями

Диффузионные модели генерируют изображения через процесс сэмплирования. Прямой процесс добавляет гауссовский шум к изображению за T шагов, пока оно не станет чистым шумом. Обратный процесс учится убирать шум, восстанавливая исходное изображение шаг за шагом.

```
Forward process (known):
  x_t = sqrt(alpha_t) * x_{t-1} + sqrt(1 - alpha_t) * epsilon
  where epsilon ~ N(0, I)

  After T steps: x_T ~ N(0, I)  (pure noise)

Reverse process (learned):
  x_{t-1} = (1/sqrt(alpha_t)) * (x_t - (1 - alpha_t)/sqrt(1 - alpha_bar_t) * epsilon_theta(x_t, t)) + sigma_t * z
  where z ~ N(0, I)

  Each denoising step is a sampling step.
```

Связь с методами этого урока:
- Каждый шаг устранения шума использует трюк репараметризации (сэмплирование шума, применение детерминированного преобразования)
- Расписание шума {alpha_t} управляет формой отжига температуры
- Обучение использует оценку методом Монте-Карло для аппроксимации ELBO (evidence lower bound)
- Ancestral-сэмплирование в диффузионных моделях — это марковская цепь (каждый шаг зависит только от текущего состояния)

Весь процесс генерации изображения — это итеративное сэмплирование: начните с шума и на каждом шаге сэмплируйте слегка менее шумную версию, обусловленную обученной моделью устранения шума.

def monte_carlo_pi(n):
    inside = 0
    for _ in range(n):
        x = random.uniform(-1, 1)
        y = random.uniform(-1, 1)
        if x*x + y*y <= 1:
            inside += 1
    return 4 * inside / n

### Шаг 5: MCMC Метрополиса — Гастингса

```python
def metropolis_hastings(target_log_pdf, proposal_sample, proposal_log_pdf, x0, n_samples, burn_in):
    samples = []
    x = x0
    for i in range(n_samples + burn_in):
        x_new = proposal_sample(x)
        log_alpha = (target_log_pdf(x_new) + proposal_log_pdf(x, x_new)
                     - target_log_pdf(x) - proposal_log_pdf(x_new, x))
        if math.log(random.random()) < log_alpha:
            x = x_new
        if i >= burn_in:
            samples.append(x)
    return samples
```

def gibbs_sampling_2d(conditional_x_given_y, conditional_y_given_x, x0, y0, n_samples, burn_in):

    samples = []

        y = conditional_y_given_x(x)
        if i >= burn_in:
            samples.append((x, y))

### Шаг 8: Top-k и top-p сэмплирование

```python
def top_k_sample(logits, k):
    indexed = sorted(enumerate(logits), key=lambda x: -x[1])
    top = indexed[:k]
    top_logits = [l for _, l in top]
    probs = softmax(top_logits)
    idx = sample_from_probs(probs)
    return top[idx][0]

def top_p_sample(logits, p):
    probs = softmax(logits)
    indexed = sorted(enumerate(probs), key=lambda x: -x[1])
    cumsum = 0
    selected = []
    for token_idx, prob in indexed:
        cumsum += prob
        selected.append((token_idx, prob))
        if cumsum >= p:
            break
    sel_probs = [pr for _, pr in selected]
    total = sum(sel_probs)
    sel_probs = [pr / total for pr in sel_probs]
    idx = sample_from_probs(sel_probs)
    return selected[idx][0]
```

def gumbel_sample():
    u = random.random()
    return -math.log(-math.log(u))

def gumbel_softmax(logits, temperature):
    gumbels = [math.log(p) + gumbel_sample() for p in logits]

## Ключевые термины

| Термин | Что говорят люди | Что это на самом деле означает |
|------|----------------|----------------------|
| Sampling | «Извлечение случайных значений» | Генерация значений в соответствии с распределением вероятностей. Механизм, лежащий в основе всего генеративного ИИ |
| Uniform distribution | «Всё равновероятно» | Каждое значение в [a, b] имеет равную плотность вероятности 1/(b-a). Отправная точка для всех методов сэмплирования |
| Inverse CDF | «Вероятностное преобразование» | F_inverse(U) преобразует равномерный образец в образец из любого распределения с известной CDF. Точно и эффективно |
| Rejection sampling | «Предложить и принять/отклонить» | Сгенерировать из простого предложенного распределения, принять с вероятностью, пропорциональной отношению target/proposal. Точно, но расходует образцы впустую |
| Importance sampling | «Перевзвесить образцы» | Оценить математические ожидания при p(x), используя образцы из q(x), взвешивая каждый образец по p(x)/q(x). Основа PPO в RL |
| Monte Carlo | «Усреднить случайные образцы» | Аппроксимировать интегралы как средние по образцам. Ошибка O(1/sqrt(N)) независимо от размерности |
| MCMC | «Случайное блуждание, которое сходится» | Построить марковскую цепь, стационарное распределение которой — целевое. Метрополис — Гастингс — основополагающий алгоритм |
| Metropolis-Hastings | «Принимать движение вверх, иногда вниз» | Предлагать перемещения, принимать на основе отношения плотностей. Детальный баланс обеспечивает сходимость к целевому распределению |
| Gibbs sampling | «По одной переменной за раз» | Обновлять каждую переменную из её условного распределения, удерживая остальные фиксированными. Частота принятия 100% |
| Temperature | «Ручка уверенности» | Делит логиты на T перед softmax. T<1 заостряет распределение (больше уверенности), T>1 сглаживает (больше разнообразия) |
| Top-k sampling | «Оставить k лучших» | Обнулить все токены, кроме k с наибольшей вероятностью, перенормировать, сэмплировать. Фиксированный размер набора кандидатов |
| Nucleus sampling (top-p) | «Оставить вероятные» | Оставить наименьший набор токенов, чья накопленная вероятность превышает p. Адаптивный размер набора кандидатов |
| Reparameterization trick | «Вынести случайность наружу» | Записать z = mu + sigma * epsilon, где epsilon ~ N(0,1). Делает сэмплирование дифференцируемым. Необходим для обучения VAE |
| Gumbel-Softmax | «Мягкое категориальное сэмплирование» | Дифференцируемое приближение к категориальному сэмплированию с использованием шума Gumbel и softmax с температурой |
| Stratified sampling | «Принудительное покрытие» | Разделить пространство образцов на страты, сэмплировать из каждой. Всегда меньшая дисперсия, чем у наивного Монте-Карло |
| Burn-in | «Период разогрева» | Начальные образцы MCMC, отбрасываемые до того, как цепь достигнет своего стационарного распределения |
| Detailed balance | «Условие обратимости» | p(x) * T(x->y) = p(y) * T(y->x). Достаточное условие для того, чтобы p было стационарным распределением марковской цепи |
| Diffusion sampling | «Итеративное устранение шума» | Генерировать данные, начиная с шума и применяя обученные шаги устранения шума. Каждый шаг — операция условного сэмплирования |
