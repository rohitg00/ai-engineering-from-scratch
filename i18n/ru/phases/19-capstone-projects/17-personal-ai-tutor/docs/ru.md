# Капстоун 17 — Персональный ИИ-репетитор (адаптивный, мультимодальный, с памятью)

> Khanmigo (Khan Academy), Duolingo Max, LearnLM / Gemini for Education от Google, Quizlet Q-Chat и Synthesis Tutor — все они в 2026 году поставили адаптивное мультимодальное репетиторство в промышленном масштабе. Общая форма — это сократическая политика (никогда не выдавать готовый ответ сразу), модель учащегося, которая обновляется после каждого взаимодействия (в стиле байесовского отслеживания знаний), ввод голосом + текстом + фото-математикой, поиск по графу учебного плана, планирование интервальных повторений и жёсткие фильтры безопасности для контента, соответствующего возрасту. Задача капстоуна — выпустить репетитора по конкретному предмету (алгебра K-12 или базовый Python), провести двухнедельное исследование эффективности с 10 учащимися и пройти аудит безопасности контента.

**Время:** 30 часов
## Проблема

Адаптивное репетиторство раньше было нишевой темой edtech-исследований. К 2026 году это уже потребительский продукт. Khanmigo развёрнут в большинстве школьных округов США. Duolingo Max набрал десятки миллионов MAU. LearnLM / Gemini for Education от Google обеспечивает репетиторство в Google Classroom. Quizlet Q-Chat стоит рядом с карточками для запоминания. Synthesis Tutor приобрёл вирусную популярность как репетитор для любознательных детей. Общие элементы: мультимодальный ввод (набор текста, речь, фотографирование уравнений), сократическая педагогика (сначала спросить, затем объяснить), модель учащегося, которая обновляется после каждого взаимодействия, и строгая возрастная безопасность.

Вам предстоит построить одну из таких систем для конкретной когорты. Планка измерения — реальное исследование эффективности: показатели входного и итогового тестирования за две недели с 10 учащимися. Голосовой цикл должен ощущаться естественным (под-стек капстоуна 03). Память должна уважать приватность. Фильтр безопасности должен пройти COPPA-совместимую red-team-проверку для аудитории K-12.

## Концепция

Четыре компонента. **Политика репетитора (tutor policy)** — это сократический цикл: когда учащийся просит дать ответ, политика задаёт наводящий вопрос; когда он отвечает правильно, она переходит к следующему понятию; когда он застревает, она предлагает пошаговую подсказку. **Модель учащегося (learner model)** — это байесовское отслеживание знаний (или его упрощённый вариант), которое обновляет вероятность освоения по каждому узлу учебного плана после каждого взаимодействия. **Граф учебного плана (curriculum graph)** — это Neo4j из понятий с рёбрами предварительных требований; политика обходит граф, чтобы выбрать следующее понятие. **Память** — это эпизодическое и семантическое хранилище (в стиле agentmemory), которое хранит прошлые взаимодействия, ошибки и предпочтения.

UX мультимодален. Текстовый ввод для набранных ответов. Голосовой ввод через LiveKit + Whisper (переиспользование капстоуна 03). Фотоввод для математических задач через dots.ocr или PaliGemma 2. Голосовой вывод через Cartesia Sonic-2. Безопасность обеспечивается Llama Guard 4 в сочетании с возрастным фильтром (блокирует контент для взрослых, насилие, самоповреждение) и COPPA-совместимой политикой хранения памяти.

Исследование эффективности — это результат работы (deliverable). 10 учащихся, входное и итоговое тестирование, две недели. В отчёте указываются дельта прироста результатов обучения и доверительный интервал. Сравнение проводится с неадаптивным базовым сценарием (тот же контент, поданный линейно, без политики репетитора).

## Архитектура

```
learner device
  |
  +-- text         -> web app
  +-- voice        -> LiveKit Agents (ASR + TTS)
  +-- photo math   -> dots.ocr / PaliGemma 2
       |
       v
  tutor policy (LangGraph)
       - Socratic decision head
       - next-concept chooser (curriculum graph walk)
       - hint scaffolder
       - mastery update
       |
       v
  learner model (BKT / item-response theory)
       - per-concept mastery probability
       - spaced-repetition scheduler (SM-2 or FSRS)
       |
       v
  memory (agentmemory-style)
       - episodic: every interaction
       - semantic: learned mistakes, preferences
       - retention policy: COPPA / GDPR aware
       |
       v
  curriculum graph (Neo4j)
       - prerequisite edges
       - OER content attached
       |
       v
  safety:
    Llama Guard 4 + age-appropriate filter
    memory access guarded by learner ID scope
```

## Стек

- Выбор предмета: алгебра K-12 или базовый Python (выберите один для глубины проработки)
- Политика репетитора: LangGraph поверх Claude Sonnet 4.7 (с кешированием промптов)
- Модель учащегося: байесовское отслеживание знаний (классическое) или FSRS для интервального повторения

- Память: персистентное векторное + эпизодическое + семантическое хранилище в стиле agentmemory

- Фотоматематика: dots.ocr или PaliGemma 2 для распознавания уравнений

## Реализация

1. **Граф учебного плана.** Постройте Neo4j из 50–150 узлов понятий (например, алгебра K-12 от «числовой прямой» до «формулы корней квадратного уравнения») с рёбрами предварительных требований. Прикрепите к каждому узлу контент OER (Open Textbook, OpenStax).

2. **Модель учащегося.** Инициализируйте байесовское отслеживание знаний с априорными параметрами: guess, slip, learn-rate. Обновляйте освоение по каждому понятию после каждого взаимодействия. Сохраняйте состояние для каждого учащегося.

3. **Политика репетитора.** LangGraph с узлами: `read_signal` (ответ учащегося был верным / частичным / он застрял?), `select_concept` (обход графа учебного плана с выбором понятия наивысшего приоритета), `scaffold` (сократический промпт), `update_mastery`.

4. **Память.** Каждое взаимодействие записывается в эпизодическое хранилище. Ошибки и предпочтения переходят в семантическую память. COPPA-совместимая политика хранения: автоматическое удаление через 1 год, доступ для родителей.

5. **Голосовой путь.** Воркер LiveKit Agents, подключённый к политике репетитора. ASR через Whisper-v3-turbo. TTS через Cartesia Sonic-2. Поддерживается прерывание (barge-in) (переиспользование механики капстоуна 03).

6. **Путь фотоматематики.** Загрузите или сфотографируйте изображение; запустите dots.ocr или PaliGemma 2 для распознавания уравнения; передайте репетитору как структурированный ввод.

7. **Безопасность.** Каждый вывод модели проходит через Llama Guard 4 + возрастной фильтр (блокирует самоповреждение, контент для взрослых, насилие). Доступ к памяти ограничен идентификатором учащегося (learner ID); родителям предоставляется поверхность доступа для удаления данных.

8. **Исследование эффективности.** 10 учащихся, входное тестирование (стандартизированный базовый набор из 30 вопросов), две недели взаимодействия с репетитором (3 занятия в неделю), итоговое тестирование. Сравнение с неадаптивной базовой когортой из 10 учащихся на том же контенте.

9. **Еженедельные отчёты о прогрессе.** Для каждого учащегося автоматически формируйте PDF-сводку с изученными темами, траекториями освоения и рекомендованными следующими шагами.

## Применение

```
learner: "I don't understand why 3x + 6 = 12 means x = 2"
[signal]   stuck
[concept]  'isolating variables' (prerequisite: addition-subtraction-equality)
[scaffold] "what number would you subtract from both sides to start?"
learner: "6"
[signal]   correct
[mastery]  addition-subtraction-equality: 0.62 -> 0.77
[concept]  continue 'isolating variables'
[scaffold] "great. now what is 3x / 3 equal to?"
```

## Упражнения

1. Проведите исследование эффективности с адаптивной моделью учащегося и без неё (случайный порядок понятий). Сообщите дельту. Ожидайте, что адаптивный вариант победит, но интересное число — это размер разрыва.

2. Добавьте мультимодальный зонд: один и тот же вопрос по понятию подаётся в виде текста, голоса и фото. Измерьте, сходятся ли учащиеся быстрее к ответу при использовании предпочитаемой модальности.

3. Постройте родительскую панель: отработанные темы, траектории освоения, предстоящие понятия, события безопасности (любые срабатывания защитных ограничений). В соответствии с COPPA.

4. Добавьте режим переключения языка: репетитор принимает ввод на испанском и обучает на испанском. Измерьте покрытие X-Guard.

5. Проверьте приватность памяти на прочность: убедитесь, что учащийся A не может увидеть данные учащегося B даже через атаку повторной загрузки голосового клипа (voice-clip re-ingest). Логируйте попытку доступа и отправляйте оповещение.

## Ключевые термины

| Термин | Что говорят люди | Что это означает на самом деле |
|------|-----------------|------------------------|
| Socratic policy (сократическая политика) | «Спрашивай, не вываливай ответ» | Репетитор задаёт наводящий вопрос вместо того, чтобы дать ответ |
| Bayesian knowledge tracing (байесовское отслеживание знаний) | «BKT» | Классические уравнения модели учащегося для вероятности освоения по каждому понятию |
| FSRS | «Бесплатный планировщик интервальных повторений» | Планировщик интервальных повторений 2024 года, лучше, чем SM-2 |
| Curriculum graph (граф учебного плана) | «DAG понятий» | Neo4j из понятий с рёбрами предварительных требований |
| Episodic memory (эпизодическая память) | «Журнал по каждому взаимодействию» | Каждое взаимодействие сохраняется для последующего извлечения |
| Semantic memory (семантическая память) | «Хранилище усвоенных паттернов» | Сжатые ошибки и предпочтения, переведённые из эпизодической памяти |
| COPPA | «Закон о приватности детей» | Закон США, ограничивающий сбор данных о детях младше 13 лет |
