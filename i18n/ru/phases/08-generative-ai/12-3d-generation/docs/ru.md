# Генерация 3D

> 3D — это модальность, где потенциал перехода от 2D к 3D наиболее силён. Прорывом 2023 года стал 3D Gaussian Splatting. Генеративный рывок 2024-2026 годов накладывает поверх него многоракурсную диффузию (multi-view diffusion) + 3D-реконструкцию, чтобы создавать объекты и сцены по одному промпту или фотографии.

**Тип:** Обучение
**Языки:** Python
**Предварительные требования:** Этап 4 (Компьютерное зрение), этап 8 · 07 (Латентная диффузия)
**Время:** ~45 минут

## Проблема

3D-контент — это боль:

- **Представление.** Меши, облака точек, воксельные сетки, функции знаковых расстояний (signed distance fields, SDF), нейронные поля излучения (neural radiance fields, NeRF), 3D-гауссианы. У каждого свои компромиссы.
- **Дефицит данных.** В ImageNet 14 млн изображений. Крупнейший чистый 3D-набор данных (Objaverse-XL, 2023) содержит ~10 млн объектов, большинство низкого качества.
- **Память.** Воксельная сетка 512³ — это 128 млн вокселей; полезный NeRF сцены требует 1 млн сэмплов на луч. Генерация сложнее реконструкции.
- **Обучающий сигнал.** Для 2D-изображения у вас есть пиксели. Для 3D обычно есть лишь несколько 2D-ракурсов, и их нужно поднять в 3D.

Стек 2026 года разделяет эти две задачи. Сначала генерируются *2D-изображения с нескольких ракурсов* диффузионной моделью. Затем к этим изображениям подгоняется *3D-представление* (обычно Gaussian splatting).

## Концепция

### Представление: 3D Gaussian Splatting (Kerbl et al., 2023)

Представьте сцену как облако из ~1 млн 3D-гауссианов. У каждого 59 параметров: позиция (3), ковариация (6, либо кватернион 4 + масштаб 3), непрозрачность (1), цвет в сферических гармониках (48 при степени 3, 3 при степени 0).

Рендеринг = проекция + альфа-композитинг. Быстро (~100 fps при 1080p на 4090). Дифференцируемо. Подгоняется градиентным спуском по эталонным фотографиям. Сцена подгоняется за 5-30 минут на потребительском GPU.

Две инновации 2023-2024 годов поверх этого:
- **Генеративные гауссовы сплаты.** Модели вроде LGM, LRM, InstantMesh предсказывают облако гауссианов напрямую по одному или нескольким изображениям.
- **4D Gaussian Splatting.** Гауссианы со смещениями для каждого кадра для динамических сцен.

### Многоракурсная диффузия

Дообучение предобученной диффузионной модели изображений для генерации нескольких согласованных ракурсов одного объекта по текстовому промпту или одному изображению. Zero123 (Liu et al., 2023), MVDream (Shi et al., 2023), SV3D (Stability, 2024), CAT3D (Google, 2024). Обычно выдаётся 4-16 ракурсов вокруг объекта, поднимаемых в 3D через Gaussian splatting или NeRF.

### NeRF (для контекста)

Нейронное поле излучения (Neural Radiance Field; Mildenhall et al., 2020). Крошечный MLP принимает `(x, y, z, view direction)` и выдаёт `(color, density)`. Рендеринг выполняется интегрированием вдоль лучей. По качеству превосходит синтез новых ракурсов на основе мешей, но рендерится в 100-1000 раз медленнее. Вытеснен Gaussian splatting в большинстве применений реального времени, но всё ещё доминирует в исследованиях.

## Реализация

`code/main.py` реализует игрушечную подгонку 2D-«Gaussian splatting»: представить синтетическое целевое изображение (плавный градиент) как сумму 2D-гауссовых сплатов. Оптимизировать позиции, цвета и ковариации градиентным спуском для соответствия цели. Вы увидите две базовые операции: прямой рендеринг (сплат + альфа-композитинг) и подгонку градиентным спуском.

### Шаг 1: 2D-гауссов сплат

```python
def gaussian_at(x, y, gaussian):
    px, py = gaussian["pos"]
    sigma = gaussian["sigma"]
    d2 = (x - px) ** 2 + (y - py) ** 2
    return math.exp(-d2 / (2 * sigma * sigma))
```

### Шаг 2: рендеринг суммированием сплатов

```python
def render(image_size, gaussians):
    img = [[0.0] * image_size for _ in range(image_size)]
    for g in gaussians:
        for y in range(image_size):
            for x in range(image_size):
                img[y][x] += g["color"] * gaussian_at(x, y, g)
    return img
```

Настоящий 3D Gaussian splatting сортирует гауссианы по глубине и выполняет альфа-композитинг по порядку. Наша 2D-игрушка просто суммирует.

### Шаг 3: подгонка градиентным спуском

```python
for step in range(steps):
    pred = render(size, gaussians)
    loss = mse(pred, target)
    gradients = compute_grads(pred, target, gaussians)
    update(gaussians, gradients, lr)
```

## Подводные камни

- **Несогласованность ракурсов.** Если генерировать 4 ракурса независимо и они расходятся в структуре объекта, 3D-подгонка получается размытой. Решение: многоракурсная диффузия с общим вниманием.
- **Галлюцинации обратной стороны.** При переходе от одного изображения к 3D приходится выдумывать невидимую сторону. Качество сильно варьируется.
- **Взрывной рост гауссовых сплатов.** Неограниченное обучение разрастается до 10 млн сплатов и переобучается. Эвристики уплотнения (densification) + прунинга (из оригинальной статьи 3D-GS) необходимы.
- **Проблемы топологии.** Меши из неявных полей (SDF) часто имеют дыры или самопересечения. Запустите ремешер (например, воксельный remesh в Blender) перед публикацией.
- **Лицензия обучающих данных.** У Objaverse смешанные лицензии; коммерческое использование варьируется от модели к модели.

## Ключевые термины

| Термин | Как его называют | Что он на самом деле означает |
|------|-----------------|-----------------------|
| 3D Gaussian Splatting | «3DGS» | Сцена в виде облака 3D-гауссианов; дифференцируемый рендеринг с альфа-композитингом. |
| NeRF | «Нейронное поле излучения» | MLP, выдающий цвет + плотность в точке 3D-пространства; рендеринг выполняется интегрированием вдоль лучей. |
| Триплан | «Три 2D-плоскости» | Разложение 3D-представления на три выровненные по осям 2D-сетки признаков; дешевле объёмного представления. |
| SDS | «Сэмплирование с дистилляцией оценки» | Обучение 3D-модели с использованием оценки 2D-диффузии как псевдоградиента. |
| Многоракурсная диффузия | «Много ракурсов одновременно» | Диффузионная модель, выдающая пакет согласованных ракурсов камеры. |
| PBR | «Физически корректный рендеринг» | Материал с каналами альбедо, шероховатости, металличности и нормалей. |
| Уплотнение | «Наращивание сплатов» | Эвристика обучения 3DGS: разделение / клонирование сплатов в областях с высоким градиентом. |

## Заметка о продакшене: у 3D пока нет общей платформы

В отличие от изображений (латентная диффузия + DiT) и видео (пространственно-временной DiT), у 3D в 2026 году нет единой доминирующей среды выполнения. Продакшен-решение разветвляется в зависимости от представления:

- **NeRF / триплан.** Инференс — это марширование по лучам (ray marching) + прямой проход MLP на каждый сэмпл. Рендер 512² требует миллионов прямых проходов MLP. Агрессивно объединяйте сэмплы лучей в пакеты; здесь применимы SDPA/xformers.
- **Многоракурсная диффузия + реконструкция LRM.** Двухэтапный конвейер. Этап 1 (многоракурсный DiT) — это диффузионный сервер, как в уроке 07. Этап 2 (трансформер LRM) — это однократный прямой проход по ракурсам. Общий профиль задержки — «диффузия + однократный проход»; выбирайте примитивы обслуживания для каждого этапа соответственно.
- **SDS / DreamFusion.** Оптимизация для каждого ассета, а не инференс. Создавайте фоновые задания, а не обработчики запросов.

Для большинства продуктов 2026 года правильный ответ — «запускать многоракурсную диффузионную модель по запросу, реконструировать в 3DGS асинхронно, обслуживать 3DGS для просмотра в реальном времени». Это чисто разделяет нагрузку между сервером GPU-инференса (быстрым) и офлайн-оптимизатором (медленным).
