# GAN — генератор против дискриминатора

> Приём Гудфеллоу в 2014 году заключался в том, чтобы полностью отказаться от явного моделирования плотности распределения. Две сети. Одна создаёт подделки. Другая их ловит. Они борются, пока подделки не станут неотличимы от настоящего. Это не должно работать. Часто и не работает. Но когда работает, полученные примеры остаются самыми чёткими в литературе для узких доменов.

**Тип:** Build
**Языки:** Python
**Предварительные требования:** Этап 3 · 02 (обратное распространение ошибки), этап 3 · 08 (оптимизаторы), этап 8 · 02 (VAE)
**Время:** ~75 минут

## Проблема

VAE производят размытые примеры, потому что их MSE-потери декодера байесовски оптимальны для *среднего* изображения — а среднее множества правдоподобных цифр это размытая цифра. Вам нужна функция потерь, вознаграждающая за *правдоподобность*, а не за попиксельную близость к какой-то одной цели. Для правдоподобности нет замкнутой формы. Её приходится обучать.

Идея Гудфеллоу: обучите классификатор `D(x)` отличать настоящие изображения от подделок. Обучите генератор `G(z)` обманывать `D`. Сигнал потерь для `G` — это то, что `D` в данный момент считает похожим на настоящее. Этот сигнал меняется по мере того, как улучшается `G`, гонясь за движущейся целью. Если обе сети сходятся, `G` выучил распределение данных, ни разу не записав `log p(x)`.

Это состязательное обучение. Математически это игра минимакс:

```
min_G max_D  E_real[log D(x)] + E_fake[log(1 - D(G(z)))]
```

В 2026 году GAN больше не являются передовыми генераторами (эту корону забрали диффузия и сопоставление потоков). Но StyleGAN 2/3 остаются самыми чёткими из когда-либо выпущенных моделей лиц, дискриминаторы GAN используются как *перцептивные функции потерь* при обучении диффузии, а состязательное обучение лежит в основе быстрых одношаговых дистилляций (SDXL-Turbo, SD3-Turbo, LCM), которые позволяют применять диффузию в реальном времени.

## Концепция

![Обучение GAN: генератор и дискриминатор в игре минимакс](../assets/gan.svg)

**Генератор `G(z)`.** Отображает вектор шума `z ~ N(0, I)` в пример `x̂`. Сеть в форме декодера (полносвязная или с транспонированной свёрткой).

**Дискриминатор `D(x)`.** Отображает пример в скалярную вероятность (или оценку). Настоящее → 1, подделка → 0.

**Функция потерь.** Два чередующихся обновления:

- **Обучение `D`:** `loss_D = -[ log D(x) + log(1 - D(G(z))) ]`. Бинарная кросс-энтропия: настоящему соответствует 1, подделке — 0.
- **Обучение `G`:** `loss_G = -log D(G(z))`. Это *ненасыщающаяся* форма, которую использовал Гудфеллоу (исходная `log(1 - D(G(z)))` насыщается и убивает градиенты, когда `D` уверен).

**Цикл обучения.** Один шаг `D`, один шаг `G`. Повторить.

**Почему это работает.** Если `G` идеально совпадает с `p_data`, то `D` не может действовать лучше случайного угадывания и выдаёт 0.5 везде; `G` больше не получает градиент. Равновесие.

**Почему это ломается.** Коллапс мод (`G` находит одну моду, которую `D` не может классифицировать, и штампует её бесконечно), затухающий градиент (`D` обучается слишком быстро, и `log D` насыщается), нестабильность обучения (скорости обучения, размеры пакетов — что угодно).

## Постройте это

`code/main.py` обучает крошечный GAN на одномерных данных: смеси двух гауссиан. Генератор и дискриминатор — MLP с одним скрытым слоем. Мы реализуем прямой проход, обратный проход и цикл минимакс вручную. Цель — увидеть два ключевых режима отказа (коллапс мод + затухающий градиент) в момент их возникновения.

### Шаг 1: ненасыщающаяся функция потерь

Ванильная функция потерь Гудфеллоу `log(1 - D(G(z)))` стремится к 0, когда D с высокой уверенностью классифицирует подделку G как подделку. В этот момент градиент для G практически равен нулю — G не может улучшаться. Ненасыщающаяся форма `-log D(G(z))` имеет противоположную асимптоту: она резко растёт, когда D уверен, давая G сильный сигнал.

```python
def g_loss(d_fake):
    # maximize log D(G(z))  <=>  minimize -log D(G(z))
    return -sum(math.log(max(p, 1e-8)) for p in d_fake) / len(d_fake)
```

### Шаг 2: один шаг дискриминатора на один шаг генератора

```python
for step in range(steps):
    # train D
    real_batch = sample_real(batch_size)
    fake_batch = [G(z) for z in sample_noise(batch_size)]
    update_D(real_batch, fake_batch)

    # train G
    fake_batch = [G(z) for z in sample_noise(batch_size)]  # fresh fakes
    update_G(fake_batch)
```

Свежие подделки для G, иначе градиенты устаревают.

### Шаг 3: следите за коллапсом мод

```python
if step % 200 == 0:
    samples = [G(z) for z in sample_noise(500)]
    mode_a = sum(1 for s in samples if s < 0)
    mode_b = 500 - mode_a
    if min(mode_a, mode_b) < 50:
        print("  [!] mode collapse: one mode is starved")
```

Канонический симптом: одна из двух настоящих мод перестаёт генерироваться. Дискриминатор перестаёт её исправлять, потому что никогда не видит её как подделку.

## Ловушки

- **Дискриминатор слишком силён.** Уменьшите скорость обучения D в 2–5 раз либо добавьте шум на уровне экземпляров или слоёв. Если D достигает точности >95%, G мёртв.
- **Генератор запоминает одну моду.** Добавьте шум ко входам D, используйте слой мини-батчевой дискриминации либо переключитесь на WGAN-GP.
- **Пакетная нормализация просачивает статистику.** Настоящий пакет и пакет подделок, проходящие через один и тот же слой BN, смешивают свою статистику. Используйте вместо неё нормализацию экземпляров или спектральную нормализацию.
- **Манипуляция оценкой Inception.** FID и IS зашумлены при малом числе примеров. Используйте ≥10 тыс. примеров при оценивании.
- **Однократное сэмплирование — это ложь для условных задач.** Вам всё равно нужны масштабы CFG, приёмы усечения и повторное сэмплирование, чтобы получить пригодный результат.

## Применение

Стек GAN в 2026 году:

| Ситуация | Выбор |
|-----------|------|
| Фотореалистичные человеческие лица, фиксированная поза | StyleGAN3 (самый чёткий, самый компактный) |
| Аниме / стилизованные лица | StyleGAN-XL или Stable Diffusion LoRA |
| Преобразование одного изображения в другое | Pix2Pix / CycleGAN (этап 8 · 04) или ControlNet (этап 8 · 08) |
| Быстрая одношаговая генерация изображения по тексту | Состязательная дистилляция диффузии (SDXL-Turbo, SD3-Turbo) |
| Перцептивная функция потерь внутри тренера диффузии | Небольшой дискриминатор GAN на кропах изображений |
| Любая мультимодальная задача открытого домена | Не используйте GAN — берите диффузию или сопоставление потоков |

GAN чёткие, но узкие. Как только ваш домен расширяется — фото, произвольные текстовые промпты, видео — переключайтесь на диффузию. Состязательный приём живёт дальше как компонент (перцептивные функции потерь, дистилляция), а не как самостоятельный генератор.

## Ключевые термины

| Термин | Как его называют | Что он означает на самом деле |
|------|-----------------|-----------------------|
| Генератор | «G» | Сеть «шум → пример», `G: z → x̂`. |
| Дискриминатор | «D» | Классификатор `D: x → [0, 1]`, различающий настоящее и подделку. |
| Минимакс | «Игра» | Оптимизация совместной целевой функции по схеме `min_G max_D`. |
| Ненасыщающаяся функция потерь | «Исправление» | Использование `-log D(G(z))` для G вместо `log(1 - D(G(z)))`. |
| Коллапс мод | «G запомнил одну вещь» | Генератор производит мало различимых выходов, несмотря на разнообразие данных. |
| WGAN | «Вассерштейн» | Замена BCE на расстояние переноса массы + градиентный штраф; более гладкий градиент. |
| Спектральная нормализация | «Приём с липшицевостью» | Ограничивает нормы весов D, чтобы ограничить его наклон; стабилизирует обучение. |
| StyleGAN | «Тот, который работает» | Сеть отображения + AdaIN; лучший в своём классе для лиц, всё ещё в 2026 году. |

## Заметка о продакшене: одношаговый инференс — устойчивое преимущество GAN

GAN больше не побеждают по качеству примеров в генерации открытого домена, но всё ещё побеждают по стоимости инференса. На языке литературы по продакшен-инференсу у GAN есть:

- **Нет стадий предварительного заполнения и декодирования.** Один прямой проход `G(z)`. TTFT ≈ полная задержка.
- **Нет нагрузки на KV-кеш.** Единственное состояние — веса. Размер батча ограничен памятью активаций, а не кешем.
- **Тривиальный непрерывный батчинг.** Поскольку каждый запрос требует одинаковое фиксированное число FLOPs, статичный батч при целевой загрузке сервера обычно оптимален. Планировщик «на лету» не нужен.

Именно поэтому дистилляция GAN (SDXL-Turbo, SD3-Turbo, ADD, LCM) — доминирующая техника быстрой генерации изображений по тексту в 2026 году: она сворачивает 20–50-шаговый диффузионный конвейер в 1–4 прямых прохода в стиле GAN, сохраняя при этом распределение диффузионной базовой модели. Состязательная функция потерь остаётся средством настройки на этапе обучения, превращающим медленные генераторы в быстрые.
