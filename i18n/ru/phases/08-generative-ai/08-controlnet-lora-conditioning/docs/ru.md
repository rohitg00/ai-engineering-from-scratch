# ControlNet, LoRA и кондиционирование

> Текст сам по себе — неуклюжий управляющий сигнал. ControlNet позволяет клонировать предобученную диффузионную модель и управлять ею с помощью карты глубины, скелета позы, наброска или карты границ. LoRA позволяет дообучить модель на 2 млрд параметров, обучив всего 10 миллионов параметров. Вместе они превратили Stable Diffusion из игрушки в конвейер генерации изображений образца 2026 года, который используется в каждом агентстве.

**Тип:** Build
**Языки:** Python
**Предварительные требования:** Фаза 8 · 07 (латентная диффузия), фаза 10 (LLM с нуля — основы LoRA)
**Время:** ~75 минут

## Проблема

Промпт вроде «женщина в красном платье выгуливает собаку на оживлённой улице» не даёт модели никакой информации о том, *где* находится собака, *в какой позе* находится женщина, или *какая перспектива* у улицы. Текст фиксирует лишь около 10% того, что нужно для точного задания изображения. Остальное — визуальная информация, которую невозможно эффективно описать словами.

Обучать новую условную модель с нуля для каждого сигнала (поза, глубина, canny, сегментация) непозволительно дорого. Вместо этого хочется заморозить базовую сеть SDXL с 2,6 млрд параметров, подключить небольшую боковую сеть (side-network), которая читает кондиционирующий сигнал, и позволить ей слегка подталкивать промежуточные признаки базовой сети. Это и есть ControlNet.

Также хочется научить модель новым концепциям (вашему лицу, вашему продукту, вашему стилю), не переобучая модель целиком. Нужна дельта в 100 раз меньше. Это и есть LoRA — низкоранговые адаптеры (low-rank adapters), которые встраиваются в существующие веса внимания.

ControlNet + LoRA + текст = набор инструментов практика образца 2026 года. Большинство продакшен-конвейеров генерации изображений накладывают 2-5 LoRA, 1-3 ControlNet и IP-Adapter поверх базовой модели SDXL / SD3 / Flux.

## Концепция

![ControlNet клонирует энкодер, а LoRA добавляет низкоранговые дельты](../assets/controlnet-lora.svg)

### ControlNet (Zhang et al., 2023)

Возьмите предобученную SD. *Клонируйте* энкодерную половину U-Net. Заморозьте оригинал. Обучите клон принимать дополнительный кондиционирующий вход (границы, глубина, поза). Соедините клон обратно с декодерной половиной оригинала пропускающими соединениями с *нулевой свёрткой* (zero-convolution): свёртками 1×1, инициализированными нулями, которые вначале ничего не меняют, а затем обучаются вносить дельту.

```
SD U-Net decoder:   ... ← orig_enc_features + zero_conv(controlnet_enc(condition))
```

Инициализация zero-conv означает, что ControlNet стартует как тождественное отображение — вреда нет даже до начала обучения. Обучение проводится на 1M троек (промпт, условие, изображение) со стандартной функцией потерь диффузии.

ControlNet для каждой модальности поставляются в виде небольших боковых моделей (~360M для SDXL, ~70M для SD 1.5). Их можно комбинировать при инференсе:

```
features += weight_a * control_a(depth) + weight_b * control_b(pose)
```

### LoRA (Hu et al., 2021)

Для любого линейного слоя `W ∈ R^{d×d}` в модели заморозьте `W` и добавьте низкоранговую дельту:

```
W' = W + ΔW,  ΔW = B @ A,  A ∈ R^{r×d},  B ∈ R^{d×r}
```

где `r << d`. Ранг 4-16 стандартен для внимания, ранг 64-128 — для тяжёлых дообучений. Количество новых параметров: `2 · d · r` вместо `d²`. Для внимания SDXL при `d=640`, `r=16`: 20 тыс. параметров на адаптер вместо 410 тыс. — сокращение в 20 раз. В масштабе всей модели: LoRA обычно занимает 20-200 МБ против 5 ГБ базовой модели.

При инференсе LoRA можно масштабировать: `W' = W + α · B @ A`. Обычное значение — `α = 0.5-1.5`. Несколько LoRA складываются аддитивно (с обычной оговоркой, что их взаимодействие нелинейно).

### IP-Adapter (Ye et al., 2023)

Крошечный адаптер, который принимает *изображение* в качестве кондиционирующего сигнала (наряду с текстом). Использует энкодер изображений CLIP для получения токенов изображения и внедряет их в механизм перекрёстного внимания наряду с текстовыми токенами. ~20 МБ на базовую модель. Позволяет реализовать «сгенерируй изображение в стиле этого референса» без LoRA.

## Матрица совместимости

| Инструмент | Чем управляет | Размер | Когда использовать |
|------|------------------|------|-------------|
| ControlNet | Пространственной структурой (позой, глубиной, границами) | 70-360 МБ | Точная компоновка и композиция |
| LoRA | Стилем, субъектом, концепцией | 20-200 МБ | Персонализация, стиль |
| IP-Adapter | Стилем или субъектом из референсного изображения | 20 МБ | Когда внешний вид невозможно описать текстом |
| Textual Inversion | Единственной концепцией в виде нового токена | 10 КБ | Устаревший подход, в основном вытесненный LoRA |
| DreamBooth | Полным дообучением на субъекте | 2-5 ГБ | Точная идентичность, высокие вычислительные затраты |
| T2I-Adapter | Более лёгкая альтернатива ControlNet | 70 МБ | Периферийные устройства, ограниченный бюджет инференса |

ControlNet ≈ пространственное. LoRA ≈ семантическое. Используйте оба.

## Постройте это

`code/main.py` моделирует оба механизма в одномерном случае:

1. **LoRA.** Предобученный линейный слой `W`. Заморозьте его. Обучите низкоранговый `B @ A` так, чтобы `W + BA` соответствовал целевому линейному слою. Покажите, что `r = 1` достаточно, чтобы точно выучить поправку ранга 1.

2. **ControlNet-lite.** Предиктор с «замороженной базой» (frozen base) и «боковая сеть» (side network), которая читает дополнительный сигнал. Выход боковой сети управляется обучаемым скаляром-«гейтом», инициализированным нулём (наш вариант zero-conv). Обучите и понаблюдайте, как значение гейта нарастает.

### Шаг 1: математика LoRA

```python
def lora(W, A, B, x, alpha=1.0):
    # W is frozen; A, B are the trainable low-rank factors.
    return [W[i][j] * x[j] for i, j in ...] + alpha * (B @ (A @ x))
```

### Шаг 2: боковая сеть с нулевой инициализацией

```python
side_out = control_net(x, condition)
gated = gate * side_out  # gate initialized to 0
h = base(x) + gated
```

На шаге 0 выход идентичен базовому. На ранних этапах обучения `gate` изменяется медленно — без катастрофического дрейфа.

## Подводные камни

- **Чрезмерное масштабирование LoRA.** `α = 2` или `α = 3` — распространённый трюк «сделать сильнее», который приводит к чрезмерно стилизованным или сломанным результатам. Держите `α ≤ 1.5`.
- **Конфликт весов ControlNet.** Использование Pose ControlNet с весом 1.0 и Depth ControlNet с весом 1.0 обычно приводит к перерегулированию. Безопасное значение по умолчанию — сумма весов ≈ 1.0.
- **LoRA на несовместимой базовой модели.** LoRA для SDXL незаметно ничего не меняют в SD 1.5, потому что размерности внимания не совпадают. Начиная с версии 0.30+ Diffusers выдаёт предупреждение.
- **Дрейф Textual Inversion.** Токены, обученные на одной контрольной точке, сильно «уплывают» на другой. LoRA более переносима.
- **Слияние весов LoRA и хранение.** LoRA можно «впечь» в веса базовой модели ради более быстрого инференса (без сложения во время выполнения), но при этом теряется возможность масштабировать `α` во время выполнения. Храните обе версии.

## Упражнения

1. **Лёгкое.** В `code/main.py` варьируйте ранг LoRA `r` от 1 до 4. При каком ранге LoRA точно совпадает с целевой дельтой ранга 2?
2. **Среднее.** Обучите две отдельные LoRA на двух целевых преобразованиях. Загрузите их вместе и покажите их аддитивное взаимодействие. Когда это взаимодействие нарушает линейность?
3. **Сложное.** Используя diffusers, соберите стек: SDXL-base + Canny-ControlNet (вес 0.8) + стилевая LoRA (α 0.8) + IP-Adapter (вес 0.6). Измерьте компромисс FID против соответствия промпту при варьировании весов стека.

## Ключевые термины

| Термин | Как обычно говорят | Что это означает на самом деле |
|------|-----------------|-----------------------|
| ControlNet | «Пространственный контроль» | Клонированный энкодер + zero-conv-соединения; читает кондиционирующее изображение. |
| Нулевая свёртка | «Стартует как тождественное отображение» | Свёртка 1×1, инициализированная нулями; в начальный момент ControlNet ничего не меняет. |
| LoRA | «Низкоранговый адаптер» | `W + B @ A`, `r << d`; в 100 раз меньше параметров, чем при полном дообучении. |
| ранг r | «Регулятор» | Степень сжатия LoRA; типично 4-16, 64+ для глубокой персонализации. |
| α | «Сила LoRA» | Масштабирование дельты LoRA во время выполнения. |
| IP-Adapter | «Референсное изображение» | Небольшой адаптер кондиционирования по изображению через токены изображения CLIP. |
| DreamBooth | «Полное дообучение на субъекте» | Обучение всей модели на ~30 изображениях субъекта. |
| Textual Inversion | «Новый токен» | Обучается только новый эмбеддинг слова; устаревший подход, в основном вытеснен. |

## Заметка о продакшене: смена LoRA на лету, полосы ControlNet, мультитенантное обслуживание

Реальный SaaS для генерации изображений по тексту обслуживает сотни LoRA и десяток ControlNet поверх одной и той же базовой контрольной точки. Задача обслуживания очень похожа на мультитенантность LLM (в литературе о продакшене случай LLM описывается в терминах непрерывного пакетирования (continuous batching) и LoRAX / S-LoRA):

- **Горячая замена LoRA вместо слияния.** Слияние `W' = W + α·B·A` в базовую модель даёт ~3-5% ускорение инференса на шаг, но фиксирует `α` и базу. Держите LoRA «горячими» в VRAM как дельты ранга r; diffusers предоставляет `pipe.load_lora_weights()` + `pipe.set_adapters([...], adapter_weights=[...])` для активации на уровне запроса. Стоимость замены — веса `2 · d · r · num_layers`, то есть масштаб в мегабайтах и меньше секунды.
- **ControlNet как вторая полоса внимания.** Клонированный энкодер работает параллельно с базовой моделью. Два ControlNet с весом 1.0 каждый = два дополнительных прямых прохода на шаг, а не один объединённый проход. Запас по размеру батча падает квадратично. Закладывайте ~1.5× стоимости шага на каждый активный ControlNet.
- **Квантованные LoRA — тоже вариант.** Если вы квантовали базовую модель (см. урок 07, Flux на 8 ГБ), дельта LoRA тоже чисто квантуется до 8 бит или 4 бит. Загрузка в стиле QLoRA позволяет накладывать 5-10 LoRA поверх 4-битной базы Flux, не превышая бюджет памяти.

Специфика Flux: ноутбук Нильса Flux-on-8GB квантует базу до 4 бит; наложение стилевой LoRA (`pipe.load_lora_weights("user/style-lora")`) на эту квантованную базу с `weight_name="pytorch_lora_weights.safetensors"` по-прежнему работает. Это рецепт, который большинство SaaS-агентств используют в продакшене в 2026 году.
