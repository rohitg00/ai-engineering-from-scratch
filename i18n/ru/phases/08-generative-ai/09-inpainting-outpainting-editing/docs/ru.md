# Инпейнтинг, аутпейнтинг и редактирование изображений

> Генерация изображений по тексту создаёт новое. Инпейнтинг чинит старое. В продакшене 70% оплачиваемой работы с изображениями — это редактирование: заменить фон, убрать логотип, расширить холст, перегенерировать руку. Инпейнтинг — то место, где диффузия окупает себя.

**Тип:** Build
**Языки:** Python
**Предварительные требования:** Этап 8 · 07 (Латентная диффузия), Этап 8 · 08 (ControlNet и LoRA)
**Время:** ~75 минут

## Проблема

Клиент присылает идеальное фото товара с отвлекающей вывеской на заднем плане. Вы хотите стереть вывеску и оставить всё остальное попиксельно неизменным. Нельзя запустить генерацию изображения по тексту с нуля — результат получит другой цвет, другое освещение, другой ракурс товара. Вам нужно перегенерировать *только* область под маской, причём так, чтобы регенерация учитывала окружающий контекст.

Это и есть инпейнтинг (inpainting). Варианты:

- **Инпейнтинг.** Перегенерация внутри маски, пиксели снаружи сохраняются.
- **Аутпейнтинг (outpainting).** Перегенерация вне маски (или за пределами холста), внутренняя часть сохраняется.
- **Редактирование изображений.** Перегенерация всего изображения с сохранением семантической или структурной верности оригиналу (SDEdit, InstructPix2Pix).

В 2026 году каждый диффузионный конвейер поставляется с режимом инпейнтинга. Flux.1-Fill, Stable Diffusion Inpaint, SDXL-Inpaint, DALL-E 3 Edit. Все они работают по одному и тому же принципу.

## Концепция

### Наивный подход (и почему он неверен)

Запустите обычную генерацию изображения по тексту с маской. На каждом шаге сэмплирования заменяйте немаскированную область зашумленного латента на зашумленную прямым процессом версию чистого изображения. Это работает... плохо. Артефакты на границе просачиваются насквозь, потому что у модели нет информации о том, что находится в замаскированной области.

### Правильная модель инпейнтинга

Обучите модифицированный U-Net, который принимает 9 входных каналов вместо 4:

```
input = concat([ noisy_latent (4ch), encoded_image (4ch), mask (1ch) ], dim=channel)
```

Дополнительные каналы — это копия исходного изображения, закодированного VAE, плюс одноканальная маска. Во время обучения вы случайным образом маскируете области изображения и обучаете модель убирать шум только в замаскированной области, при этом немаскированная область подаётся как чистый сигнал кондиционирования. При инференсе модель может «видеть», что окружает замаскированную область, и создаёт согласованное продолжение.

SD-Inpaint, SDXL-Inpaint, Flux-Fill — все используют этот 9-канальный (или аналогичный) вход. Diffusers `StableDiffusionInpaintPipeline`, `FluxFillPipeline`.

### SDEdit (Meng et al., 2022) — редактирование без переобучения

Добавьте шум к исходному изображению до некоторого промежуточного `t`, затем запустите обратную цепочку от `t` до 0 с новым промптом. Без переобучения. Выбор стартового `t` — это компромисс между верностью источнику и творческой свободой:

- `t/T = 0.3` → почти идентично источнику, небольшие стилистические изменения
- `t/T = 0.6` → умеренные правки, сохраняется грубая структура
- `t/T = 0.9` → сгенерировано почти из шума, минимальное сохранение источника

### InstructPix2Pix (Brooks et al., 2023)

Дообучите диффузионную модель на тройках `(input_image, instruction, output_image)`. При инференсе кондиционируйте одновременно на входном изображении и текстовой инструкции («сделай закат», «добавь дракона»). Два масштаба CFG: масштаб для изображения и масштаб для текста.

### RePaint (Lugmayr et al., 2022)

Оставьте стандартную безусловную диффузионную модель. На каждом обратном шаге выполняйте ресэмплирование — время от времени отступайте назад к более зашумленному состоянию и перегенерируйте. Это позволяет избежать артефактов на границе. Используется, когда у вас нет обученной модели инпейнтинга.

```figure
inpaint-mask-reinject
```

## Постройте это

`code/main.py` реализует игрушечную одномерную (1-D) схему инпейнтинга на пятимерных данных. Мы обучаем DDPM на 5-мерных данных смеси, где каждый сэмпл — это 5 чисел с плавающей точкой из одного из двух кластеров. При инференсе мы «маскируем» 2 из 5 измерений, на каждом шаге подмешиваем версию трёх немаскированных измерений, зашумленную прямым процессом, и перегенерируем только замаскированные измерения.

### Шаг 1: 5-мерные данные DDPM

```python
def sample_data(rng):
    cluster = rng.choice([0, 1])
    center = [-1.0] * 5 if cluster == 0 else [1.0] * 5
    return [c + rng.gauss(0, 0.2) for c in center], cluster
```

### Шаг 2: обучение шумоподавителя по всем 5 измерениям

Стандартный DDPM. Сеть выдаёт 5-мерное предсказание шума для 5-мерного зашумленного входа.

### Шаг 3: при инференсе — обратный проход с учётом маски

```python
def inpaint_step(x_t, mask, clean_image, alpha_bars, t, rng):
    # replace unmasked dims with a freshly noised version of the clean source
    a_bar = alpha_bars[t]
    for i in range(len(x_t)):
        if not mask[i]:
            x_t[i] = math.sqrt(a_bar) * clean_image[i] + math.sqrt(1 - a_bar) * rng.gauss(0, 1)
    # ...then run the normal reverse step on x_t
```

Это наивный подход, и на игрушечных одномерных данных он работает. Реальный инпейнтинг изображений использует 9-канальный вход, потому что связность текстуры важнее.

### Шаг 4: аутпейнтинг

Аутпейнтинг — это инпейнтинг с инвертированной маской: маскируется новый (ранее не существовавший) холст, остальное заполняется из оригинала. Цель обучения идентична.

## Подводные камни

- **Швы.** Наивный подход оставляет видимые границы, потому что информация о градиенте не проходит через маску. Решение: расширьте маску на 8–16 пикселей или используйте полноценную модель инпейнтинга.
- **Утечка через маску.** Если немаскированная область кондиционирующего изображения низкого качества или зашумлена, это загрязняет генерацию внутри маски. Слегка подавите шум или размойте.
- **CFG взаимодействует с размером маски.** Высокий CFG на маленькой маске = перенасыщенный участок. Снижайте CFG для мелких правок.
- **Обрыв верности у SDEdit.** Переход от `t/T = 0.5` к `t/T = 0.6` может потерять идентичность объекта. Проверяйте на сетке значений и фиксируйте контрольные точки.
- **Несовпадение промпта.** Промпт должен описывать *всё* изображение, а не только новый контент. «Кошка сидит на стуле», а не «кошка».

## Применение

| Задача | Конвейер |
|------|----------|
| Удалить объект, небольшая маска | SD-Inpaint или Flux-Fill, стандартный промпт |
| Заменить небо | SD-Inpaint + «голубое небо на закате» |
| Расширить холст | Режим аутпейнтинга SDXL (растушёвка 8px) или Flux-Fill с маской аутпейнтинга |
| Перегенерировать руку или лицо | SD-Inpaint с промптом, заново описывающим объект, + ControlNet-Openpose |
| Изменить стиль одной области | SDEdit при `t/T=0.5` на замаскированной области |
| «Сделать закат» | InstructPix2Pix или Flux-Kontext |
| Заменить фон | Маска SAM → SD-Inpaint |
| Максимальная верность оригиналу | Flux-Fill или GPT-Image (облачный сервис) для самых сложных случаев |

SAM (Segment Anything от Meta, 2023) + диффузионный инпейнтинг — это конвейер удаления фона 2026 года. SAM 2 (2024) работает с видео.

## Упражнения

1. **Лёгкое.** В `code/main.py` варьируйте долю замаскированных измерений от 0.2 до 0.8. При какой доле качество инпейнтинга (остаток в замаскированных измерениях) сравнивается с безусловной генерацией?
2. **Среднее.** Реализуйте RePaint: на каждом 10-м обратном шаге отступайте на 5 шагов назад (добавляя шум) и заново подавляйте шум. Измерьте, снижает ли это остаточный сигнал на границе маски.
3. **Сложное.** Используя Hugging Face diffusers, сравните: SD 1.5 Inpaint + ControlNet-Openpose против Flux.1-Fill на 20 задачах перегенерации лица. Оцените отдельно соответствие позе и сохранение идентичности.

## Ключевые термины

| Термин | Как обычно говорят | Что это означает на самом деле |
|------|-----------------|-----------------------|
| Инпейнтинг | «Заполнить дыру» | Перегенерация внутри маски; пиксели снаружи сохраняются. |
| Аутпейнтинг | «Расширить холст» | Перегенерация за пределами холста; внутренняя часть сохраняется. |
| 9-канальный U-Net | «Правильная модель инпейнтинга» | U-Net со входом `noisy \| encoded-source \| mask`. |
| SDEdit | «Img2img с уровнем шума» | Зашумление до момента `t`, подавление шума с новым промптом. |
| InstructPix2Pix | «Правки только по тексту» | Диффузионная модель, дообученная на тройках (изображение, инструкция, результат). |
| RePaint | «Без переобучения» | Периодическое повторное зашумление во время обратного прохода для уменьшения швов. |
| SAM | «Segment Anything» | Генератор масок по кликам или рамкам; используется в паре с инпейнтингом. |
| Flux-Kontext | «Правка с учётом контекста» | Вариант Flux, принимающий референсное изображение + инструкцию для правок. |

## Заметка о продакшене: конвейеры редактирования чувствительны к задержке

Пользователи, редактирующие изображение, ожидают отклика меньше чем за 5 секунд. 30-шаговый SDXL-Inpaint при 1024² занимает 3-4 с на L4, плюс генерация маски SAM (~200 мс) и кодирование/декодирование VAE (~500 мс суммарно). В терминах продакшена это скорее ограничено TTFT (временем до первого токена), чем пропускной способностью — батч 1, низкая конкурентность, минимизируйте каждый этап:

- **SAM-H — самый медленный.** SAM-H при 1024² занимает ~200 мс; SAM-ViT-B — ~40 мс с небольшой потерей качества. SAM 2 (видео) добавляет временные накладные расходы; не используйте её для правки одиночных изображений.
- **По возможности пропускайте кодирование.** `pipe.image_processor.preprocess(img)` кодирует в латенты. Если у вас есть латенты из предыдущей генерации (типично для интерфейсов итеративного редактирования), передайте их напрямую через `latents=...`, чтобы пропустить одно кодирование VAE.
- **Расширение маски важно и для пропускной способности.** Маленькая маска означает, что большая часть прямого прохода U-Net тратится впустую (немаскированные пиксели всё равно фиксируются). Библиотека `diffusers` в конвейере `StableDiffusionInpaintPipeline` запускает полный U-Net независимо от размера маски; только полноценные 9-канальные варианты инпейнтинга используют маскированные вычисления.
- **Flux-Kontext — ответ 2025 года.** Единственный прямой проход над `(source_image, instruction)` — без отдельной маски, без перебора уровней шума SDEdit. На H100 правка выполняется примерно за 1.5 с. Архитектурный урок: объедините этапы.
