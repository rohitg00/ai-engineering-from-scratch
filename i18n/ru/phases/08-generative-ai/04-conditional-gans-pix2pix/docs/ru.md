# Условные GAN и Pix2Pix

> Первый большой прорыв 2014–2017 годов — это контроль над тем, что создаёт GAN. Прикрепите метку, или изображение, или предложение. Pix2Pix сделал версию для изображений, и она до сих пор превосходит любую универсальную модель преобразования текста в изображение на узких задачах изображение-в-изображение.

## Проблема

Безусловный GAN сэмплирует произвольные лица. Полезно для демо, бесполезно в продакшене. Вам нужно: *превратить эскиз в фото*, *превратить карту в аэрофотоснимок*, *превратить дневную сцену в ночную*, *раскрасить чёрно-белое изображение*. Во всех этих случаях вам дано входное изображение `x`, и вы должны выдать `y` с некоторым семантическим соответствием. Правдоподобных `y` на один `x` может быть много. Среднеквадратичная ошибка сплющивает их в кашу. Состязательная функция потерь — нет, потому что «выглядит настоящим» — острый критерий.

Условный GAN (Mirza & Osindero, 2014) добавляет условие `c` как вход и для `G`, и для `D`. Pix2Pix (Isola et al., 2017) специализировал этот подход: условие — это целое входное изображение, генератор — это U-Net, дискриминатор — это классификатор на основе *патчей* (PatchGAN), а функция потерь — состязательная + L1. Этот рецепт превосходит модели преобразования текста в изображение, обученные с нуля, на узких доменах изображение-в-изображение даже в 2026 году, потому что он обучается на *парных данных* — у вас есть именно тот сигнал, который нужен.

## Концепция

![Pix2Pix: генератор U-Net, дискриминатор PatchGAN](../assets/pix2pix.svg)

**Условный G.** `G(x, z) → y`. В Pix2Pix `z` — это дропаут внутри G (без входного шума — Isola обнаружил, что явный шум игнорировался).

**Условный D.** `D(x, y) → [0, 1]`. Вход — это *пара* (условие, выход). В этом ключевое отличие: D должен судить, согласуется ли `y` с `x`, а не просто выглядит ли `y` настоящим.

**Генератор U-Net.** Энкодер-декодер с пропускающими связями в обход узкого места. Критичен для задач, где вход и выход разделяют низкоуровневую структуру (края, силуэт). Без пропускающих связей высокочастотные детали исчезают.

**Дискриминатор PatchGAN.** Вместо того чтобы выдавать одну оценку «настоящее/подделка», D выдаёт сетку `N×N`, где каждая ячейка оценивает рецептивное поле ~70×70 пикселей. Оценки усредняются. Это предположение марковского случайного поля: реалистичность локальна. Обучается намного быстрее, содержит меньше параметров и даёт более чёткий результат.

**Функция потерь.**

```
loss_G = -log D(x, G(x)) + λ · ||y - G(x)||_1
loss_D = -log D(x, y) - log (1 - D(x, G(x)))
```

Слагаемое L1 стабилизирует обучение и подталкивает G к известной цели. L1 даёт более чёткие края, чем L2 (медианы, а не средние). `λ = 100` — значение по умолчанию для Pix2Pix.

## CycleGAN — когда нет пар

Pix2Pix нужны парные данные `(x, y)`. CycleGAN (Zhu et al., 2017) снимает это требование ценой дополнительной функции потерь: потери *цикличной согласованности*. Два генератора `G: X → Y` и `F: Y → X`. Обучите их так, чтобы `F(G(x)) ≈ x` и `G(F(y)) ≈ y`. Это позволяет превращать лошадей в зебр, лето в зиму — без парных примеров.

В 2026 году непарный перевод изображение-в-изображение чаще всего выполняется через диффузию (ControlNet, IP-Adapter), а не через CycleGAN, но идея цикличной согласованности выживает почти в каждой статье про непарную адаптацию домена.

## Постройте это

`code/main.py` реализует крошечный условный GAN на одномерных данных. Условие `c` — это метка класса (0 или 1). Задача: произвести пример из условного распределения для заданного класса.

### Шаг 1: добавьте условие ко входам и G, и D

```python
def G(z, c, params):
    return mlp(concat([z, one_hot(c)]), params)

def D(x, c, params):
    return mlp(concat([x, one_hot(c)]), params)
```

Унитарное кодирование — самый простой способ. Более крупные модели используют обучаемые эмбеддинги, FiLM-модуляцию или перекрёстное внимание.

### Шаг 2: условное обучение

```python
for step in range(steps):
    x, c = sample_real_conditional()
    noise = sample_noise()
    update_D(x_real=x, x_fake=G(noise, c), c=c)
    update_G(noise, c)
```

Генератор должен соответствовать настоящему распределению *для заданного условия*, а не маргинальному.

### Шаг 3: проверьте выход по каждому классу

```python
for c in [0, 1]:
    samples = [G(noise, c) for noise in batch]
    mean_c = mean(samples)
    assert_near(mean_c, real_mean_for_class_c)
```

## Ловушки

- **Условие игнорируется.** G учится маргинализировать, D никогда не штрафует, потому что сигнал условия слаб. Решение: обусловливайте D более агрессивно (на раннем слое, а не только на позднем), используйте проекционный дискриминатор (Miyato & Koyama 2018).
- **Вес L1 слишком мал.** G дрейфует к произвольным правдоподобным, но не точным выходам. Начинайте с λ≈100 для задач в стиле Pix2Pix.
- **Вес L1 слишком велик.** G производит размытые выходы, потому что L1 всё равно остаётся нормой L_p. Постепенно уменьшайте, когда обучение стабилизируется.
- **Утечка эталонного ответа в D.** Конкатенируйте `(x, y)` как вход D, а не только `y`. Без этого D не может проверить согласованность.
- **Коллапс мод по классу.** Каждый класс может коллапсировать независимо. Проводите проверки разнообразия, обусловленные классом.

## Применение

Состояние задач изображение-в-изображение в 2026 году:

| Задача | Лучший подход |
|------|---------------|
| Эскиз → фото, тот же домен, парные данные | Pix2Pix / Pix2PixHD (всё ещё быстро, всё ещё чётко) |
| Эскиз → фото, непарные данные | ControlNet с моделью обусловливания по наброску |
| Семантическая сегментация → фото | SPADE / GauGAN2 или SD + ControlNet-Seg |
| Перенос стиля | Диффузия с IP-Adapter или LoRA; методы на GAN устарели |
| Глубина → фото | ControlNet-Depth поверх Stable Diffusion |
| Суперразрешение | Real-ESRGAN (GAN), ESRGAN-Plus, или SD-Upscale (диффузия) |
| Колоризация | ColTran, диффузионные колоризаторы, или Pix2Pix-color |
| День → ночь, сезоны, погода | CycleGAN или подходы на основе ControlNet |

Pix2Pix остаётся правильным инструментом, когда (a) у вас есть тысячи парных примеров, (b) задача узкая и повторяемая, и (c) вам нужен быстрый инференс. На универсальных задачах открытого домена побеждает диффузия.

## Ключевые термины

| Термин | Как обычно говорят | Что это означает на самом деле |
|------|-----------------|-----------------------|
| Условный GAN | «GAN с метками» | G(z, c), D(x, c). Обе сети видят условие. |
| Pix2Pix | «GAN изображение-в-изображение» | Парный cGAN с генератором U-Net и дискриминатором PatchGAN + потери L1. |
| U-Net | «Энкодер-декодер со сквозными соединениями» | Симметричная свёрточная сеть; сквозные соединения сохраняют высокие частоты. |
| PatchGAN | «Классификатор локального реализма» | D выдаёт оценку для каждого патча вместо глобальной оценки. |
| CycleGAN | «Непарный перевод изображений» | Два G + потери цикличной согласованности; без парных данных. |
| SPADE | «GauGAN» | Нормализует промежуточные активации семантической картой; сегментация-в-изображение. |
| FiLM | «Линейная модуляция отдельных признаков» | Поканальное аффинное преобразование от условия; дешёвое обусловливание. |

## Заметка о продакшене: Pix2Pix как база, ограниченная задержкой

Когда у вас есть парные данные и узкая задача (эскиз → рендер, семантическая карта → фото, день → ночь), одношаговый инференс Pix2Pix превосходит диффузию по задержке на порядок. Продакшен-сравнение обычно выглядит так:

| Вариант | Число шагов | Типичная задержка при 512² на одной L4 |
|------|-------|----------------------------------------|
| Pix2Pix (прямой проход U-Net) | 1 | ~30 мс |
| SD-Inpaint или SD-Img2Img | 20 | ~1.2 с |
| SDXL-Turbo Img2Img | 1-4 | ~0.15-0.35 с |
| ControlNet + базовая SDXL | 20-30 | ~3-5 с |

Pix2Pix побеждает по пропускной способности в статичных пакетах (каждый запрос требует одинаковое число FLOPs). Диффузия побеждает по качеству и обобщению. Современный подход часто состоит в том, чтобы выпустить дистиллированную модель в стиле Pix2Pix для узкой задачи и предусмотреть диффузионный резервный вариант для редких входных данных.
