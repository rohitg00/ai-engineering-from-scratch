# Визуальные трансформеры (ViT)

> Изображение — это сетка патчей. Предложение — это сетка токенов. Один и тот же трансформер поглощает и то, и другое.

**Тип:** Build
**Языки:** Python
**Предварительные требования:** Этап 7 · 05 (Полный трансформер), этап 4 · 03 (CNN), этап 4 · 14 (Введение в визуальные трансформеры)
**Время:** ~45 минут

## Проблема

До 2020 года компьютерное зрение означало свёртки. Все лучшие решения для ImageNet, COCO и бенчмарков детекции использовали CNN-бэкбон. Трансформеры предназначались для языка.

Dosovitskiy et al. (2020) — «An Image is Worth 16x16 Words» — показали, что свёртки можно убрать полностью. Разрежьте изображение на патчи фиксированного размера, линейно спроецируйте каждый патч в эмбеддинг и подайте последовательность в обычный энкодер трансформера. При достаточном масштабе (предварительное обучение на ImageNet-21k или более крупном наборе данных) ViT не уступает моделям на базе ResNet или превосходит их.

ViT стал началом более широкого паттерна в 2026 году: одна архитектура, много модальностей. Whisper токенизирует аудио. ViT токенизирует изображения. Токены действий для робототехники. Пиксельные токены для видео. Трансформеру всё равно — подайте ему последовательность, и он научится.

К 2026 году ViT и его потомки (DeiT, Swin, DINOv2, ViT-22B, SAM 3) доминируют в большинстве задач компьютерного зрения. CNN всё ещё выигрывают на периферийных устройствах и в задачах, чувствительных к задержке. Во всех остальных случаях где-то в стеке есть ViT.

## Концепция

![Изображение → патчи → токены → трансформер](../assets/vit.svg)

### Шаг 1 — патчификация

Разделите изображение `H × W × C` на последовательность плоских патчей `N × (P·P·C)`. Типичная настройка: изображение `224 × 224`, патчи `16 × 16` → 196 патчей по 768 значений каждый.

```
image (224, 224, 3) → 14 × 14 grid of 16x16x3 patches → 196 vectors of length 768
```

Размер патча — это рычаг. Меньшие патчи = больше токенов, лучше разрешение, квадратичная стоимость внимания. Большие патчи = грубее, дешевле.

### Шаг 2 — линейный эмбеддинг

Единственная обучаемая матрица проецирует каждый плоский патч в `d_model`. Эквивалентно свёртке с размером ядра `P` и шагом `P`. В PyTorch это буквально `nn.Conv2d(C, d_model, kernel_size=P, stride=P)` — реализация в 2 строки.

### Шаг 3 — добавить токен `[CLS]`, добавить позиционные эмбеддинги

- Добавьте обучаемый токен `[CLS]` в начало. Его итоговое скрытое состояние — это представление изображения, используемое для классификации.
- Добавьте обучаемые позиционные эмбеддинги (оригинальный ViT) или синусоидальные 2D (более поздние варианты).
- С 2024 года RoPE расширили до 2D для позиции, иногда без явных эмбеддингов.

### Шаг 4 — стандартный энкодер трансформера

Составьте L блоков `LayerNorm → Self-Attention → + → LayerNorm → MLP → +`. Идентично BERT. Никаких специфичных для зрения слоёв. В этом и педагогический смысл статьи.

### Шаг 5 — голова

Для классификации: возьмите скрытое состояние `[CLS]` → линейный слой → softmax. Для DINOv2 или SAM отбросьте `[CLS]`, используйте напрямую эмбеддинги патчей.

### Значимые варианты

| Модель | Год | Изменение |
|-------|------|--------|
| ViT | 2020 | Оригинал. Фиксированный размер патча, полное глобальное внимание. |
| DeiT | 2021 | Дистилляция; модель можно обучить, используя только ImageNet-1k. |
| Swin | 2021 | Иерархическая структура со сдвинутыми окнами. Фиксированная субквадратичная стоимость. |
| DINOv2 | 2023 | Самоконтролируемое обучение (без меток). Лучшие универсальные признаки для задач компьютерного зрения. |
| ViT-22B | 2023 | 22 млрд параметров; применимы законы масштабирования. |
| SigLIP | 2023 | ViT + языковая пара, сигмоидная контрастивная функция потерь. |
| SAM 3 | 2025 | Сегментирует что угодно; ViT-Large + промптируемый декодер масок. |

### Почему это заняло время

ViT нужно *очень много* данных, чтобы сравняться с CNN, потому что у него нет индуктивных смещений CNN (инвариантности к сдвигу и локальности). Без >100M размеченных изображений или эффективного самоконтролируемого предварительного обучения CNN всё ещё побеждают при сопоставимых вычислениях. DeiT решил эту проблему в 2021 году с помощью приёмов дистилляции, а DINOv2 — окончательно в 2023 году с помощью самоконтролируемого обучения.

## Создаём

См. `code/main.py`. Патчификация + линейный эмбеддинг на чистом stdlib + проверки на здравый смысл. Без обучения — ViT в любом реалистичном масштабе требует PyTorch и часов работы GPU.

### Шаг 1: искусственное изображение

Изображение RGB 24 × 24 в виде списка строк из кортежей `(R, G, B)`. Используем патчи 6×6 → 16 патчей, вектор эмбеддинга по 108 измерений каждый.

### Шаг 2: патчификация

```python
def patchify(image, P):
    H = len(image)
    W = len(image[0])
    patches = []
    for i in range(0, H, P):
        for j in range(0, W, P):
            patch = []
            for di in range(P):
                for dj in range(P):
                    patch.extend(image[i + di][j + dj])
            patches.append(patch)
    return patches
```

Порядок растра: построчно по сетке. Так делает каждый ViT.

### Шаг 3: линейный эмбеддинг

Умножьте каждый плоский патч на случайную матрицу `(patch_flat_size, d_model)`. Проверьте, что форма вывода — `(N_patches + 1, d_model)` после добавления `[CLS]`.

### Шаг 4: подсчитать параметры для реалистичного ViT

Выведите количество параметров для ViT-Base: 12 слоёв, 12 голов, d=768, patch=16. Сравните с ResNet-50 (~25M). У ViT-Base получается ~86M параметров, у ViT-Large — ~307M, у ViT-Huge — ~632M.

## Применяем

```python
from transformers import ViTImageProcessor, ViTModel
import torch
from PIL import Image

processor = ViTImageProcessor.from_pretrained("google/vit-base-patch16-224-in21k")
model = ViTModel.from_pretrained("google/vit-base-patch16-224-in21k")

img = Image.open("cat.jpg")
inputs = processor(img, return_tensors="pt")
out = model(**inputs).last_hidden_state   # (1, 197, 768): [CLS] + 196 patches
cls_emb = out[:, 0]                       # image representation
```

**Эмбеддинги DINOv2 — вариант по умолчанию для признаков изображений в 2026 году.** Заморозьте бэкбон, обучите крошечную голову. Работает для классификации, поиска, детекции, генерации подписей. Контрольные точки DINOv2 от Meta превосходят CLIP во всех задачах зрения, не связанных с текстом.

**Выбор размера патча.** Маленькие модели используют 16×16 (ViT-B/16). Плотное предсказание (сегментация) использует 8×8 или 14×14 (SAM, DINOv2). Очень крупные модели используют 14×14.

2. **Средне.** Реализуйте 2D-синусоидальные позиционные эмбеддинги — два независимых синусоидальных кода для `row` и `col` каждого патча, объединённые в один вектор. Подайте их в небольшой ViT на PyTorch и сравните точность с обучаемыми позиционными эмбеддингами на CIFAR-10.

## Ключевые термины

| Термин | Как обычно говорят | Что это означает на самом деле |
|------|-----------------|-----------------------|
| Патч | «Токен визуального трансформера» | Плоский вектор значений пикселей области изображения размером `P × P × C`. |
| Патчификация | «Нарезать и сплющить» | Разрезать изображение на неперекрывающиеся патчи и сплющить каждый из них в вектор. |
| Токен `[CLS]` | «Сводка изображения» | Обучаемый токен, добавляемый в начало последовательности; его итоговый эмбеддинг представляет изображение. |
| Индуктивное смещение | «Что модель предполагает заранее» | У ViT меньше априорных предположений, чем у CNN, поэтому для компенсации этого различия требуется больше данных. |
| DINOv2 | «Самоконтролируемый ViT» | Обучен без меток с помощью аугментации изображений и учителя с импульсным обновлением. Даёт лучшие универсальные признаки изображений в 2026 году. |
| SigLIP | «Преемник CLIP» | ViT + текстовый энкодер, обученные с сигмоидной контрастивной функцией потерь; лучше CLIP при сопоставимых вычислениях. |
| Swin | «Оконный ViT» | Иерархический ViT с локальным вниманием и сдвинутыми окнами; стоимость субквадратичная. |
| Токены-регистры | «Приём 2023 года» | Несколько дополнительных обучаемых токенов, поглощающих ловушки внимания; улучшают признаки DINOv2. |
