# Варианты внимания — скользящее окно, разреженное и дифференциальное внимание

> Полное внимание — это круг. Каждый токен видит каждый токен, и за это расплачивается память. Четыре варианта меняют форму круга и позволяют вдвое сократить затраты.

**Тип:** Build
**Языки:** Python
**Предварительные требования:** Фаза 7 · 02 (самовнимание), Фаза 7 · 03 (многоголовое внимание), Фаза 7 · 12 (KV-кеш / Flash Attention)
**Время:** ~60 минут

## Проблема

Полное внимание требует `O(N²)` памяти и `O(N²)` вычислений по длине последовательности. Для Llama 3 70B с контекстом 128K это 16 миллиардов элементов матрицы внимания на слой, умноженные на 80 слоёв. Flash Attention (Урок 12) скрывает затраты памяти `O(N²)` на активации, но не меняет арифметическую стоимость — каждый токен по-прежнему обращает внимание на все остальные токены.

Три класса вариантов меняют саму топологию матрицы внимания:

1. **Внимание со скользящим окном (sliding window attention, SWA).** Каждый токен обращает внимание на фиксированное окно соседей, а не на весь префикс. Память и вычисления сокращаются до `O(N · W)`, где `W` — размер окна. Этот подход применяется в Gemma 2/3, первых слоях Mistral 7B и Phi-3-Long.
2. **Разреженное / блочное внимание (sparse / block attention).** Оценка вычисляется только для выбранных пар `(i, j)`; остальным принудительно присваивается нулевой вес. Примеры: Longformer, BigBird и OpenAI sparse transformer.
3. **Дифференциальное внимание (differential attention).** Вычисляются две карты внимания с отдельными проекциями Q/K, после чего одна вычитается из другой. Это устраняет «сток внимания» (attention sink) — эффект, при котором вес утекает в первые несколько токенов. DIFF Transformer от Microsoft (2024).

Эти подходы сосуществуют. Передовая модель 2026 года часто сочетает их: большинство слоёв работают как SWA-1024, каждый пятый использует глобальное полное внимание, а несколько голов — дифференциальное внимание для повышения качества поиска. Соотношение слоёв SWA и глобального внимания 5:1 в Gemma 3 — сегодняшний стандарт по умолчанию.

## Концепция

### Внимание со скользящим окном (SWA)

Каждый запрос в позиции `i` обращает внимание только на позиции в `[i - W, i]` (каузальный SWA) или `[i - W/2, i + W/2]` (двунаправленный). Токены за пределами окна получают `-inf` в матрице оценок.

```
full causal:           sliding window (W=4):
positions 0-7          positions 0-7, W=4
    0 1 2 3 4 5 6 7        0 1 2 3 4 5 6 7
0 | x                0 |  x
1 | x x              1 |  x x
2 | x x x            2 |  x x x
3 | x x x x          3 |  x x x x
4 | x x x x x        4 |    x x x x
5 | x x x x x x      5 |      x x x x
6 | x x x x x x x    6 |        x x x x
7 | x x x x x x x x  7 |          x x x x
```

Для `N = 8192` и `W = 1024` матрица оценок в среднем содержит 1024 × 8192 ненулевых строк — сокращение в 8 раз.

**KV-кеш сжимается благодаря SWA.** На каждом слое достаточно хранить только последние `W` токенов K и V. Для конфигурации в духе Gemma 3 (окно 1024, контекст 128K) KV-кеш уменьшается в 128 раз.

**Цена качества.** Трансформеры, использующие только SWA, плохо справляются с поиском на большом расстоянии. Решение: чередовать слои SWA со слоями полного внимания. Gemma 3 использует соотношение SWA и глобального внимания 5:1. Mistral 7B использовала стек каузальных слоёв SWA, где информация «течёт вперёд» через перекрывающиеся окна: каждый слой увеличивает эффективное рецептивное поле на `W`, и после `L` слоёв модель может обращаться к токенам на расстоянии до `L × W` позиций назад.

### Разреженное / блочное внимание

Заранее выбирается шаблон разреженности размером `N × N`. Три канонические формы:

- **Локальное + с шагом (OpenAI sparse transformer).** Внимание обращается на последние `W` токенов плюс на каждый `stride`-й токен до них. Этот вариант охватывает и локальный, и дальний контекст при вычислительной стоимости `O(N · sqrt(N))`.
- **Longformer / BigBird.** Локальное окно + небольшой набор глобальных токенов (например, `[CLS]`), которые обращают внимание на всех и на которые обращают внимание все, + случайные разреженные связи. Эмпирически даёт 2-кратное увеличение контекста при сопоставимом качестве.
- **Native Sparse Attention (DeepSeek, 2025).** Модель обучается определять, какие блоки `(Q, K)` важны, и пропускает нулевые блоки на уровне ядра. Совместимо с FlashAttention.

Разреженное внимание — это, по сути, вопрос разработки ядер. Математика проста (замаскировать матрицу оценок); выигрыш достигается за счёт того, что нулевые элементы вообще не загружаются в SRAM. FlashAttention-3 и API FlexAttention 2026 года делают произвольные разреженные шаблоны полноценной частью PyTorch.

### Дифференциальное внимание (DIFF Transformer, 2024)

У обычного внимания есть проблема «стока внимания»: функция softmax заставляет каждую строку суммироваться в 1, поэтому токены, которым нечему уделять особое внимание, сбрасывают вес на первый токен (или первые несколько). Это отбирает ёмкость, которая должна была достаться реальному содержимому.

Дифференциальное внимание решает эту проблему, вычисляя **две** карты внимания и вычитая одну из другой:

```
A1 = softmax(Q1 K1^T / √d)
A2 = softmax(Q2 K2^T / √d)
DiffAttn = (A1 - λ · A2) V
```

где `λ` — обучаемый скаляр (обычно 0.5–0.8). A1 отражает веса реального содержимого, а A2 — сток внимания. Вычитание устраняет этот сток и перераспределяет вес на релевантные токены.

Заявленные результаты (Microsoft, 2024): перплексия ниже на 5–10%, эффективный контекст в 1.5–2 раза длиннее при той же длине обучения, более точный поиск «иглы в стоге сена».

### Сравнение вариантов

| Вариант | Вычисления | KV-кеш | Качество относительно полного внимания | Применение в продакшене |
|---------|---------|----------|-----------------|----------------|
| Полное внимание | O(N²) | O(N) на слой | базовый уровень | стандартный тип слоя во всех моделях |
| SWA (окно 1024) | O(N·W) | O(W) на слой | -0.1 ppl, хорошее при наличии глобальных слоёв | Gemma 2/3, Phi-3-Long |
| Локальное + разреженное с шагом | O(N·√N) | смешанный | сопоставимо с SWA | OpenAI sparse transformer, Longformer |
| BigBird (локальное + глобальное + случайное) | O(N) приблизительно | смешанный | соответствует полному вниманию при вдвое большем контексте | ранние версии BERT с длинным контекстом |
| Native Sparse (DeepSeek-V3.2) | O(N · active fraction) | O(N) | отклонение не более 0.05 по перплексии | DeepSeek-V3.2, 2025 |
| Дифференциальное | O(2·N²) | O(2N) | перплексия ниже на 5–10% | DIFF Transformer, ранние модели 2026 года |

## Постройте это

См. `code/main.py`. Мы реализуем средство сравнения каузальных масок, которое показывает на игрушечной последовательности полное внимание, SWA, локальное внимание с шагом и дифференциальное внимание рядом друг с другом.

### Шаг 1: полная каузальная маска (базовый вариант)

```python
def causal_mask(n):
    return [[0.0 if j <= i else float("-inf") for j in range(n)] for i in range(n)]
```

Базовый вариант из Урока 07. Нижнетреугольная матрица; нулевой вес выше диагонали.

### Шаг 2: каузальная маска со скользящим окном

```python
def swa_mask(n, window):
    M = [[float("-inf")] * n for _ in range(n)]
    for i in range(n):
        lo = max(0, i - window + 1)
        for j in range(lo, i + 1):
            M[i][j] = 0.0
    return M
```

Один параметр — `window`. При `window >= n` получаем полное каузальное внимание. При `window = 1` каждый токен обращает внимание только на самого себя.

### Шаг 3: локальная разреженная маска с шагом

```python
def strided_mask(n, window, stride):
    M = [[float("-inf")] * n for _ in range(n)]
    for i in range(n):
        lo = max(0, i - window + 1)
        for j in range(lo, i + 1):
            M[i][j] = 0.0
        for j in range(0, i + 1, stride):
            M[i][j] = 0.0
    return M
```

Плотное локальное окно плюс каждый `stride`-й токен назад до начала последовательности. Рецептивное поле растёт логарифмическими шагами с добавлением слоёв.

### Шаг 4: дифференциальное внимание

```python
def diff_attention(Q1, K1, Q2, K2, V, lam):
    A1 = softmax_causal(Q1 @ K1.T / sqrt_d)
    A2 = softmax_causal(Q2 @ K2.T / sqrt_d)
    return (A1 - lam * A2) @ V
```

Два прохода внимания и вычитание с обучаемым коэффициентом смешивания. В коде мы сравниваем тепловые карты стока внимания для обычного и дифференциального внимания и наблюдаем, как сток исчезает.

### Шаг 5: размеры KV-кеша

Выведите размер кеша на слой при `N = 131072` для каждого варианта. SWA и разреженные варианты сокращают его в 10–100 раз. Дифференциальное внимание удваивает его. Осознанно оплачивайте свой счёт за память.

## Применение

Паттерны для продакшена в 2026 году:

```python
from transformers import AutoModelForCausalLM
# Gemma 3 mixes SWA (window=1024) and global layers at 5:1.
model = AutoModelForCausalLM.from_pretrained("google/gemma-3-27b-it")
# print(model.config.sliding_window, model.config.layer_types)
```

FlexAttention в PyTorch 2.5+ принимает функцию маски:

```python
from torch.nn.attention.flex_attention import flex_attention, create_block_mask

def swa_pattern(b, h, q_idx, kv_idx):
    return (q_idx - kv_idx < 1024) & (q_idx >= kv_idx)

mask = create_block_mask(swa_pattern, B=batch, H=heads, Q_LEN=n, KV_LEN=n)
out = flex_attention(q, k, v, block_mask=mask)
```

Это компилируется в специализированное ядро Triton. Для типичных шаблонов скорость отличается от FlashAttention-3 не более чем на 10%, а функция маски — это обычный вызываемый объект Python.

**Когда что выбирать:**

- **Только полное внимание** — на каждом слое при контексте до ~16K либо когда качество поиска важнее всего.
- **Сочетание SWA и глобального внимания** — длинный контекст (>32K), когда обучение и инференс ограничены памятью. Стандарт 2026 года для контекста длиннее 32K.
- **Разреженное блочное внимание** — специализированное ядро и собственный шаблон. Используется для специализированных задач (поиск, аудио).
- **Дифференциальное внимание** — любые задачи, где вредит загрязнение от стока внимания (RAG с длинным контекстом, поиск «иглы в стоге сена»).

## Ключевые термины

| Термин | Что говорят | Что это означает на самом деле |
|------|-----------------|-----------------------|
| Внимание со скользящим окном (SWA) | «Локальное внимание» | Каждый запрос обращает внимание только на последние `W` токенов; KV-кеш сжимается до `O(W)`. |
| Эффективное рецептивное поле | «Как далеко назад видит модель» | В стеке SWA из `L` слоёв с окном `W` — до `L × W` токенов. |
| Longformer / BigBird | «Локальное + глобальное + случайное» | Разреженные шаблоны с несколькими глобальными токенами, которые всегда участвуют во внимании; ранний подход к длинному контексту. |
| Native Sparse Attention | «Трюк DeepSeek на уровне ядра» | Обучение разреженности на уровне блоков; пропуск нулевых блоков на уровне ядра без потери качества. |
| Дифференциальное внимание | «Две карты, одна вычитается» | DIFF Transformer: из первой карты внимания вычитается вторая, умноженная на обучаемое `λ`, что устраняет сток внимания. |
| Сток внимания | «Вес утекает в токен 0» | Нормализация функцией softmax заставляет строки суммироваться в 1; неинформативные запросы сбрасывают вес на позицию 0. |
| FlexAttention | «Маска как Python-код» | API PyTorch 2.5+, который компилирует произвольные функции маски в ядра в духе FlashAttention. |
| Смешение типов слоёв | «Соотношение SWA и глобального внимания 5:1» | Чередование разреженных слоёв и слоёв полного внимания в стеке для сохранения качества при меньшем потреблении памяти. |
