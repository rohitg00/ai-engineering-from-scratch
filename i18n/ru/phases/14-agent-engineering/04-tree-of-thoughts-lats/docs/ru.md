# Tree of Thoughts и LATS: осознанный поиск

> Единственная траектория цепочки рассуждений (chain-of-thought) не оставляет места для отката назад. ToT (Yao et al., 2023) превращает рассуждение в дерево с самооценкой на каждом узле. LATS (Zhou et al., 2024) объединяет ToT с ReAct и Reflexion под общей крышей поиска по дереву Монте-Карло (MCTS). Game of 24 поднимается с 4% (CoT) до 74% (ToT); LATS достигает 92.7% pass@1 на HumanEval.

**Тип:** Build
**Языки:** Python (стандартная библиотека)
**Предварительные требования:** Фаза 14 · 01 (цикл агента), фаза 14 · 03 (Reflexion)
**Время:** ~75 минут

## Цели обучения

- Представьте рассуждение как поиск: узлы — это «мысли», рёбра — «расширения», ценность — «насколько многообещающе».
- Реализуйте поиск по дереву в стиле ToT методом BFS на стандартной библиотеке с оценкой через самооценку.
- Расширьте его до упрощённого цикла LATS MCTS с выбором / расширением / симуляцией / обратным распространением.
- Решите, когда поиск оправдывает множитель по токенам (Game of 24, генерация кода), а когда достаточно одной траектории (простые вопросы-ответы).

## Проблема

Цепочка рассуждений (chain-of-thought) — это линейный проход. Если первый шаг неверен, каждый последующий шаг строится на плохой предпосылке. На Game of 24 (получить 24 из четырёх цифр с помощью + − × ÷) GPT-4 с CoT достигает точности 4%. Модель рано выбирает неверное подвыражение и не может восстановиться.

Рассуждению нужна способность предлагать несколько кандидатов, оценивать их, выбирать многообещающие и откатываться назад при попадании в тупик. Это и есть поиск. Tree of Thoughts и LATS — две канонические формулировки этого подхода.

## Концепция

### Tree of Thoughts (Yao et al., NeurIPS 2023)

Каждый узел — это связный промежуточный шаг («мысль»). Каждый узел может расшириться до K дочерних мыслей. LLM самостоятельно оценивает каждый узел с помощью промпта-оценщика. Поиск исследует дерево методами BFS, DFS или лучевого поиска.

```
                     (root: "find 24 from 4 6 4 1")
                    /               |            \
           ("6 - 4 = 2")    ("4 + 1 = 5")    ("4 * 6 = 24")  <- Score: HIGH
              /   \              |                  |
          ...    ...          ...                finish
```

Самооценка — несущий элемент подхода. В статье показаны три варианта: классификация `sure / likely / impossible`, числовая оценка `1..10` и голосование среди кандидатов. Все три существенно превосходят CoT на Game of 24 (4% -> 74% с GPT-4).

### LATS (Zhou et al., ICML 2024)

LATS объединяет ToT, ReAct и Reflexion под MCTS. LLM играет три роли:

- **Политика**: предлагает варианты следующего действия (в стиле ReAct).
- **Функция ценности**: оценивает частичную траекторию (самооценка в стиле ToT).
- **Саморефлектор**: после неудачи формулирует рефлексию на естественном языке (в стиле Reflexion) и использует её для повторной инициализации будущих траекторий моделирования.

Обратная связь от среды (наблюдения) подмешивается в функцию ценности, чтобы поиск опирался на реальные результаты инструментов, а не только на мнения модели. Результаты на момент публикации статьи: HumanEval pass@1 92.7% с GPT-4 (SOTA), средний результат WebShop 75.9 с GPT-3.5 (приближается к дообучению на основе градиентов).

### MCTS вкратце

Четыре фазы на каждой итерации:

1. **Выбор** — проход от корня до листа с помощью UCT (верхней доверительной границы для деревьев).
2. **Расширение** — генерация K дочерних узлов с помощью политики.
3. **Симуляция** — моделирование траектории от дочернего узла с помощью политики и оценка листа функцией ценности (или наградой среды).
4. **Обратное распространение** — обновление счётчиков посещений и оценок ценности вверх по пути.

Формула UCT: `Q(s, a) + c * sqrt(ln N(s) / N(s, a))`. Первое слагаемое — эксплуатация; второе — исследование. Настраивайте `c` под конкретную задачу.

### Реальная цена

Поиск взрывает расход токенов. ToT на Game of 24 использует в 100–1000 раз больше токенов, чем CoT. У LATS похожая картина. Это не бесплатно; оставляйте поиск для:

- Задач, где одной траектории заведомо недостаточно (Game of 24, сложный код).
- Задач, где время выполнения менее важно, чем корректность.
- Задач с дешёвой и надёжной функцией ценности (юнит-тесты для кода, явная цель для математики).

Если у вашей задачи один правильный ответ и зашумлённый оценщик, поиск часто только ухудшает результат — он находит неверный ответ с «хорошей оценкой».

### Положение дел в 2026 году

Большинство промышленных агентов не запускают LATS. Они запускают ReAct с проверкой, опирающейся на инструменты (CRITIC, урок 05). Поиск встречается в специализированных нишах:

- Кодовых агентов, использующих тесты как функцию ценности (в стиле HumanEval).
- Агентов глубокого исследования, изучающих несколько путей запросов.
- Рабочих процессов с интенсивным планированием внутри подграфов LangGraph.

AlphaEvolve (урок 11) — крайний случай 2025 года: эволюционный поиск по коду, машинно проверяемая приспособленность и прорывные результаты (первое улучшение умножения матриц 4x4 за 56 лет).

## Реализация

`code/main.py` реализует:

- Небольшой поиск ToT методом BFS на упрощённой задаче «выбор арифметических операций».
- Упрощённый цикл LATS MCTS на той же задаче (выбор / расширение / симуляция / обратное распространение) с выбором по UCT.
- Функцию ценности, объединяющую символьную оценку и результат самооценки.

Запустите:

```
python3 code/main.py
```

Трассировка показывает, как ToT расширяет каждый узел тремя вариантами методом BFS, а LATS сходится к лучшей траектории моделирования с помощью MCTS. Для обоих методов выводится количество токенов.

## Применение

LangGraph предоставляет исследование в стиле ToT в виде шаблонов подграфов; публикация команды LangChain о LATS (май 2024 года) служит эталонным учебным материалом. LlamaIndex предоставляет агента `TreeOfThoughts`. В большинстве промышленных агентов 2026 года этот шаблон включается по условию `if task_complexity > threshold: use_search()` — см. шаблон «оценщик — оптимизатор» в уроке 05.

## Ключевые термины

| Термин | Как обычно говорят | Что это означает на деле |
|------|----------------|------------------------|
| Tree of Thoughts | «Ветвящаяся CoT» | Подход Yao et al.: дерево узлов рассуждений с самооценкой |
| LATS | «MCTS для LLM» | Подход Zhou et al., объединяющий ToT, ReAct и Reflexion в рамках MCTS |
| UCT | «Верхняя доверительная граница» | Формула выбора, которая уравновешивает эксплуатацию (Q) и исследование (ln N / n) |
| Функция ценности | «Насколько хорошо это состояние» | Оценка LLM по промпту или награда среды; используется при обратном распространении |
| Политика | «Механизм выбора действий» | Генератор в стиле ReAct; выдаёт варианты следующих мыслей или действий |
| Траектория моделирования | «Смоделированная траектория» | Проход от узла до листа с помощью политики с последующей оценкой функцией ценности |
| Обратное распространение | «Обновление предков» | Передача награды листа вверх по пути с обновлением счётчиков посещений и Q |
| Стоимость поиска | «Взрывной расход токенов» | В 100–1000 раз больше, чем у CoT на Game of 24; перед внедрением определите бюджет |
