# Продакшен-рантаймы агентов — быстрое инстанцирование и типизированные рабочие процессы

> Продакшен-рантайм агентов оптимизирует то, что фреймворки для прототипирования оставляют без внимания: стоимость инстанцирования, типизированные интерфейсы рабочих процессов и готовый к обслуживанию запросов бэкенд. Пара 2026 года: Agno (Python) нацелен на инстанцирование агента за микросекунды и бэкенды без состояния на FastAPI. Mastra поставляет агентов, инструменты, рабочие процессы, унифицированную маршрутизацию моделей и композитное хранилище на основе Vercel AI SDK.

**Тип:** Learn
**Языки:** Python, TypeScript
**Предварительные требования:** Этап 14 · 01 (Цикл агента), этап 14 · 13 (LangGraph)
**Время:** ~45 минут

## Цели обучения

- Определить целевые показатели производительности Agno и когда они важны.
- Назвать три примитива Mastra — Agents, Tools, Workflows — и поддерживаемые серверные адаптеры.
- Объяснить, почему бэкенд без состояния с изоляцией по сессиям на FastAPI — рекомендуемый продакшен-путь для Agno.
- Выбрать Agno или Mastra под конкретный стек (ориентированный прежде всего на Python или TypeScript).

## Проблема

LangGraph, AutoGen, CrewAI — тяжеловесные фреймворки. Команды, которым нужен «просто цикл агента, быстро, в моём рантайме», обращаются к Agno (Python) или Mastra (TypeScript). Оба меняют часть примитивов, которыми владеет фреймворк, на голую скорость и более плотное прилегание к окружающему стеку.

## Концепция

### Agno

- Рантайм на Python, ранее назывался Phi-data.
- «Никаких графов, цепочек и запутанных паттернов — только чистый Python».
- Целевые показатели производительности из их документации: ~2 мкс на инстанцирование агента, ~3,75 КиБ памяти на агента, ~23 провайдера моделей.
- Продакшен-путь: бэкенд без состояния с изоляцией по сессиям на FastAPI. Каждый запрос запускает нового агента; состояние сессии хранится в БД.
- Нативная мультимодальность (текст, изображение, аудио, видео, файл) и агентный RAG.

Целевые показатели скорости важны, когда у вас тысячи короткоживущих агентов в секунду (объединение потоков чата, конвейеры оценивания). Они менее важны, когда один агент работает 10 минут.

### Mastra

- TypeScript, построен на Vercel AI SDK.
- Три примитива: **Agents**, **Tools** (типизированные Zod), **Workflows**.
- Unified Model Router — 3300+ моделей у 94 провайдеров (март 2026).
- Композитное хранилище: память, рабочие процессы, наблюдаемость — в разных бэкендах; для наблюдаемости в масштабе рекомендуется ClickHouse.
- Apache 2.0, при этом директории `ee/` распространяются по корпоративной лицензии с доступным исходным кодом.
- Серверные адаптеры для Express, Hono, Fastify, Koa; первоклассная интеграция с Next.js и Astro.
- Поставляет Mastra Studio (localhost:4111) для отладки.
- 22 тыс.+ звёзд на GitHub, 300 тыс.+ еженедельных загрузок npm на версии 1.0 (январь 2026).

### Позиционирование

Ни один из них не пытается быть LangGraph. Они конкурируют по:

- **Соответствию языку.** Agno — для команд, ориентированных на Python; Mastra — для команд, ориентированных на TypeScript.
- **Эргономике рантайма.** Agno = почти нулевые накладные расходы; Mastra = интеграция с экосистемой Vercel.
- **Наблюдаемости.** Оба интегрируются с Langfuse/Phoenix/Opik (Урок 24), но Mastra Studio — собственный продукт Mastra.

### Когда выбирать каждый

- **Agno** — Python-бэкенд, много короткоживущих агентов, строгие требования к производительности, команда использует FastAPI.
- **Mastra** — TypeScript-бэкенд, развёртывание на Next.js / Vercel, унифицированная маршрутизация нескольких провайдеров моделей, типизированные Zod инструменты.
- **LangGraph** (Урок 13) — когда сохраняемое состояние и явное графовое рассуждение важнее голой скорости.
- **OpenAI / Claude Agent SDK** — когда нужен готовый продуктовый интерфейс конкретного провайдера (Уроки 16–17).

### Где этот паттерн даёт сбой

- **Скорость ради скорости.** Выбор Agno, потому что «2 мкс» звучит хорошо, когда нагрузка — это один медленный вызов агента на запрос. Накладные расходы — не узкое место.
- **Привязка к экосистеме.** Интеграция Mastra с Vercel — плюс на Vercel, минус в другом месте.
- **Путаница с корпоративной лицензией.** Исходный код директорий `ee/` у Mastra доступен для чтения, но они распространяются не по лицензии Apache 2.0. Читайте лицензии, если планируете форк.

```figure
wb-runtime-spawn
```

## Реализация

Этот урок в первую очередь сравнительный: один артефакт с кодом не смог бы в полной мере представить оба фреймворка. В `code/main.py` приведён параллельный учебный пример: минимальный процесс «запустить агента, передавать вывод потоком, сохранить сессию», реализованный дважды — в стиле Agno и в стиле Mastra.

Запустите:

```
python3 code/main.py
```

Две структурно разные, но функционально эквивалентные трассировки.

## Применение

- **Agno** — Python-бэкенд, которому нужны скорость и форма FastAPI.
- **Mastra** — TypeScript-бэкенд со множеством провайдеров и примитивами рабочих процессов.
- Оба предоставляют собственные хуки наблюдаемости. Оба интегрируются с Langfuse.

## Поставка

`outputs/skill-runtime-picker.md` выбирает Agno, Mastra, LangGraph или SDK провайдера на основе стека, бюджета задержки и операционной формы.

## Упражнения

1. Прочитайте документацию Agno. Перенесите stdlib-цикл ReAct (Урок 01) на Agno. Что исчезло? Что осталось?
2. Прочитайте документацию Mastra. Перенесите тот же цикл на Mastra. Что изменилось в типизации инструментов (Zod против ничего)?
3. Замерьте: измерьте задержку инстанцирования агента на вашем стеке. Важны ли 2 мкс Agno для вашей нагрузки?
4. Спроектируйте миграцию: если вы запускали CrewAI на Python, что сломается при переходе на Agno?
5. Прочитайте условия лицензии `ee/` у Mastra. Какие ограничения затронут форк с открытым исходным кодом?

## Ключевые термины

| Термин | Как обычно говорят | Что это значит на деле |
|------|----------------|------------------------|
| Agno | «Быстрые агенты на Python» | Рантайм агентов без состояния с изоляцией по сессиям |
| Mastra | «Агенты на TypeScript поверх Vercel AI SDK» | Агенты + инструменты + рабочие процессы + маршрутизатор моделей |
| Unified Model Router | «Доступ к нескольким провайдерам» | Единый клиент для 3300+ моделей у 94 провайдеров |
| Композитное хранилище | «Несколько бэкендов» | Память, рабочие процессы и наблюдаемость используют разные хранилища |
| Mastra Studio | «Локальный отладчик» | Интерфейс на localhost:4111 для исследования работы агентов |
| Доступный исходный код | «Не открытое ПО» | Лицензия разрешает читать исходный код, но ограничивает коммерческое использование |
