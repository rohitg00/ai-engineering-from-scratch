# Харнесс как библиотека — субагенты и хранилище сессий

> Харнесс, который можно импортировать: встроенные инструменты, субагенты для изоляции контекста, хуки, распространение W3C-трассировки, персистентность сессий. Claude Agent SDK — эталонный пример, библиотечная форма харнесса Claude Code, а Claude Managed Agents — хостинговая альтернатива для долгоживущей асинхронной работы.

**Тип:** Learn + Build
**Языки:** Python (stdlib)
**Предварительные требования:** Этап 14 · 01 (Цикл агента), этап 14 · 10 (Библиотеки навыков)
**Время:** ~75 минут

## Цели обучения

- Объяснить разницу между Anthropic Client SDK (сырой API) и Claude Agent SDK (форма харнесса).
- Описать субагенты — параллелизацию и изоляцию контекста — и когда к ним стоит прибегать.
- Назвать поверхность хранилища сессий Python SDK (`append`, `load`, `list_sessions`, `delete`, `list_subkeys`) и роль `--session-mirror`.
- Реализовать stdlib-харнесс со встроенными инструментами, порождением субагентов с изолированным контекстом, хуками жизненного цикла и хранилищем сессий.

## Проблема

Сырой LLM API даёт вам один цикл запрос-ответ. Продакшен-агенту нужны выполнение инструментов, MCP-серверы, хуки жизненного цикла, порождение субагентов, персистентность сессий, распространение трассировки. Claude Agent SDK поставляет эту форму как библиотеку — тот же харнесс, что использует Claude Code, доступный для кастомных агентов.

## Концепция

### Client SDK против Agent SDK

- **Client SDK (`anthropic`).** Сырой Messages API. Вы сами владеете циклом, инструментами, состоянием.
- **Agent SDK (`claude-agent-sdk`).** Встроенное выполнение инструментов, MCP-подключения, хуки, порождение субагентов, хранилище сессий. Цикл Claude Code в виде библиотеки.

### Встроенные инструменты

SDK поставляет 10+ инструментов из коробки: чтение/запись файлов, shell, grep, glob, веб-запросы и другие. Кастомные инструменты регистрируются через стандартный интерфейс схемы инструментов.

### Субагенты

Anthropic документирует две цели:

1. **Параллелизация.** Выполнение независимой работы параллельно. «Найти тестовый файл для каждого из этих 20 модулей» — это 20 параллельных задач субагентов.
2. **Изоляция контекста.** Субагенты используют собственное контекстное окно; в оркестратор возвращаются только результаты. Бюджет оркестратора сохраняется.

Недавние дополнения Python SDK: `list_subagents()`, `get_subagent_messages()` для чтения транскриптов субагентов.

### Хранилище сессий

Паритет протокола с TypeScript:

- `append(session_id, message)` — добавить ход.
- `load(session_id)` — восстановить разговор.
- `list_sessions()` — перечислить.
- `delete(session_id)` — с каскадным удалением сессий субагентов.
- `list_subkeys(session_id)` — перечислить ключи субагентов.

`--session-mirror` (флаг CLI) зеркалирует транскрипт во внешний файл по мере его потоковой передачи — для отладки.

### Хуки

Хуки жизненного цикла, которые можно зарегистрировать:

- `PreToolUse`, `PostToolUse` — контроль или аудит вызовов инструментов.
- `SessionStart`, `SessionEnd` — настройка и завершение.
- `UserPromptSubmit` — действие над вводом пользователя до того, как его увидит модель.
- `PreCompact` — выполняется перед сжатием контекста.
- `Stop` — очистка при выходе агента.
- `Notification` — оповещения по побочному каналу.

Хуки — это способ, которым pro-workflow (справочный материал программы этапа 14) и подобные системы добавляют сквозное поведение.

### Контекст трассировки W3C

Активные на стороне вызывающего спаны OTel распространяются в подпроцесс CLI через заголовки контекста трассировки W3C. Вся многопроцессная трассировка отображается как одна трассировка в вашем бэкенде.

### Claude Managed Agents

Хостинговая альтернатива (бета-заголовок `managed-agents-2026-04-01`). Долгоживущая асинхронная работа, встроенное кеширование промптов, встроенное сжатие. Обмен контроля на управляемую инфраструктуру.

### Где этот паттерн даёт сбой

- **Избыточное порождение субагентов.** Порождение 100 субагентов для 100 крошечных задач. Накладные расходы доминируют. Группируйте задачи вместо этого.
- **Разрастание хуков.** Каждая команда добавляет хуки; время запуска раздувается. Пересматривайте хуки ежеквартально.
- **Разрастание сессий.** Сессии накапливаются; их размер растёт. Используйте `list_sessions` + политику истечения срока.

## Реализация

`code/main.py` реализует форму SDK на stdlib:

- `Tool`, `ToolRegistry` со встроенными `read_file`, `write_file`, `list_dir`.
- `Subagent` — приватный контекст, изолированный запуск, возврат результатов.
- `SessionStore` — append, load, list, delete, list_subkeys.
- `Hooks` — `pre_tool_use`, `post_tool_use`, `session_start`, `session_end`.
- Демонстрация: основной агент порождает 3 субагента параллельно (каждый изолирован), агрегирует результаты, сохраняет сессию.

Запустите:

```
python3 code/main.py
```

Трассировка показывает изоляцию контекста субагентов (размер контекста оркестратора остаётся ограниченным), выполнение хуков и персистентность сессии.

## Применение

- **Claude Agent SDK** для продуктов, ориентированных на Claude, которые хотят форму харнесса Claude Code.
- **Claude Managed Agents** для хостинговой долгоживущей асинхронной работы.
- **OpenAI Agents SDK** (Урок 16) для аналогов, ориентированных на OpenAI.
- **LangGraph + кастомные инструменты**, если вам нужна машина состояний в форме графа.

## Упражнения

1. Добавьте спаунер субагентов, который группирует 20 задач в группы по 5 параллельных субагентов. Измерьте размер контекста оркестратора против варианта «один субагент на задачу».
2. Реализуйте хук `PreToolUse`, который ограничивает частоту вызовов `write_file` (5 в минуту на сессию). Проследите поведение в трассировке.
3. Подключите `list_subkeys` для отрисовки дерева субагентов. Как выглядит глубокая вложенность?
4. Перенесите игрушку на настоящий пакет `claude-agent-sdk` для Python. Что меняется в регистрации инструментов?
5. Прочитайте документацию Claude Managed Agents. Когда стоит перейти с самостоятельного хостинга на управляемый?

## Ключевые термины

| Термин | Как обычно говорят | Что это означает на самом деле |
|------|----------------|------------------------|
| Agent SDK | «Claude Code как библиотека» | Форма харнесса: инструменты, MCP, хуки, субагенты, хранилище сессий |
| Субагент | «Дочерний агент» | Отдельный контекст и собственный бюджет; результаты передаются наверх |
| Хранилище сессий | «База данных разговоров» | Сохраняет, загружает, перечисляет и удаляет ходы с каскадной обработкой субагентов |
| Хук | «Обратный вызов жизненного цикла» | Действия до и после использования инструмента, а также при работе с сессией, отправке промпта, сжатии и остановке |
| Контекст трассировки W3C | «Межпроцессная трассировка» | Родительский спан распространяется в подпроцесс CLI |
| Managed Agents | «Хостинговый харнесс» | Хостинговая инфраструктура Anthropic для долгоживущей асинхронной работы |
| `--session-mirror` | «Зеркало транскрипта» | Записывает ходы сессии во внешний файл по мере их потоковой передачи |
| MCP-сервер | «Интерфейс инструментов» | Внешний источник инструментов и ресурсов, подключённый к агенту |
