# Инструментарий для red-team-тестирования — Garak, Llama Guard, PyRIT

> Три производственных инструмента формируют red-team-стек 2026 года. Llama Guard (Meta) — классификатор на базе Llama-3.1-8B, дообученный на 14 категориях опасности MLCommons; Llama Guard 4 (2025) — нативно мультимодальный классификатор на 12B параметров, полученный прунингом из Llama 4 Scout. Garak (NVIDIA) — сканер уязвимостей LLM с открытым исходным кодом, использующий статические, динамические и адаптивные пробы для галлюцинаций, утечки данных, инъекций промпта, токсичности и джейлбрейков. PyRIT (Microsoft) — многоходовые red-team-кампании с Crescendo, TAP и настраиваемыми цепочками конвертеров для глубокой эксплуатации. Llama Guard 3 описан в статье Meta «Llama 3 Herd of Models» (arXiv:2407.21783); Llama Guard 3-1B-INT4 — в arXiv:2411.17713; архитектура проб Garak — в github.com/NVIDIA/garak. Эти инструменты — производственный интерфейс 2026 года между red-team-исследованиями (уроки 12-15) и развёртыванием (урок 17+).

Уроки 12-15 представляют поверхность атаки. Производственным развёртываниям нужна воспроизводимая, масштабируемая оценка. В 2026 году доминируют три инструмента: Llama Guard (классификатор защиты), Garak (сканер), PyRIT (оркестратор кампаний). Каждый нацелен на свой слой жизненного цикла red-team-тестирования.

## Концепция

### Llama Guard (Meta)

Llama Guard 3 — это модель Llama-3.1-8B, дообученная для классификации входа/выхода по 14 категориям MLCommons AILuminate:
- Насильственные преступления, ненасильственные преступления, контент сексуального характера, CSAM, диффамация
- Специализированные советы, конфиденциальность, интеллектуальная собственность, оружие массового поражения, разжигание ненависти
- Суицид/самоповреждение, сексуальный контент, выборы, злоупотребление интерпретатором кода

Поддерживает 8 языков. Использование: перед LLM (модерация входа), после LLM (модерация выхода) или в обоих местах. Эти два варианта использования порождают разные распределения обучающих данных — Llama Guard 3 поставляется как единая модель, обрабатывающая оба случая.

Llama Guard 3-1B-INT4 (arXiv:2411.17713, 440 МБ, ~30 токенов/с на мобильном CPU) — квантованный вариант для периферийных устройств.

Llama Guard 4 (апрель 2025) — модель на 12B параметров, нативно мультимодальная, полученная прунингом из Llama 4 Scout. Она заменяет и текстового предшественника на 8B, и визуального предшественника на 11B единым классификатором, принимающим текст и изображения.

### Garak (NVIDIA)

Сканер уязвимостей с открытым исходным кодом. Архитектура:
- **Пробы (probes).** Генераторы атак для галлюцинаций, утечки данных, инъекций промпта, токсичности, джейлбрейков. Статические (фиксированные промпты), динамические (генерируемые промпты), адаптивные (реагирующие на вывод цели).
- **Детекторы (detectors).** Оценивают выходы на предмет ожидаемых режимов отказа — токсичность, утечка, взлом (jailbroken).
- **Harness'ы.** Управляют парами проба-детектор, запускают кампании, генерируют отчёты.

TrustyAI интегрирует Garak со щитами (shields) Llama-Stack (Prompt-Guard-86M — классификатор входа, Llama-Guard-3-8B — классификатор выхода) для комплексной оценки защищённой цели (shielded-target evaluation). Оценка по уровням (TBSA) заменяет бинарное прошёл/не прошёл — модель может пройти на уровне серьёзности 3 и не пройти на уровне серьёзности 5 в рамках одной и той же пробы.

### PyRIT (Microsoft)

Python Risk Identification Toolkit. Многоходовые red-team-кампании. Построен вокруг:
- **Конвертеров (converters).** Преобразуют исходный промпт — перефразирование, кодирование, перевод, ролевая игра.
- **Оркестраторов (orchestrators).** Управляют кампанией: Crescendo (эскалация), TAP (ветвление), RedTeaming (настраиваемый цикл).
- **Оценки (scoring).** LLM-судья или классификатор-судья.

PyRIT — более тяжеловесный собрат Garak. Garak запускает тысячи одноходовых проб; PyRIT проводит глубокие многоходовые кампании, нацеленные на конкретные режимы отказа.

### Стек

Разместите Llama Guard по обе стороны от модели. Запускайте Garak каждую ночь для регрессионного тестирования. Запускайте PyRIT для кампаний перед релизом. Это стандартная конфигурация 2026 года для большинства производственных развёртываний.

### Подводные камни оценки

- **Личность судьи.** Все три инструмента могут использовать LLM-судью; калибровка судьи определяет заявленные ASR (урок 12). Указывайте судью вместе с инструментом.
- **Устаревание проб.** Пробы Garak устаревают по мере того, как модели патчатся против них. Адаптивные пробы (в духе PAIR) устаревают медленнее статических.
- **FPR Llama Guard на безобидном контенте.** Ранние версии Llama Guard чрезмерно помечали политический и ЛГБТК+-контент; калибровки Llama Guard 3/4 улучшены, но не откалиброваны под конкретное развёртывание.

## Упражнения

1. Запустите `code/main.py`. Сравните частоту обнаружения классификатором в стиле Llama Guard для одноходовых и многоходовых атак.

2. Реализуйте новую пробу Garak: вредоносный запрос, закодированный в base64. Измерьте её обнаружение классификатором в стиле Llama Guard.

3. Расширьте цепочку конвертеров в стиле PyRIT конвертером «перевести на французский, затем перефразировать». Повторно измерьте успешность атаки.

4. Изучите список категорий опасности Llama Guard 3. Определите две категории, для которых обучающие данные реалистично могут давать высокую долю ложноположительных срабатываний на легитимном контенте разработчиков.

5. Сравните принципы проектирования Garak и PyRIT. Обоснуйте развёртывание, в котором правильным инструментом является каждый из них.

## Ключевые термины

| Термин | Что говорят | Что это значит на самом деле |
|------|-----------------|------------------------|
| Llama Guard | «классификатор» | Дообученный классификатор безопасности Llama-3.1-8B/4-12B с 14 категориями опасности |
| Garak | «сканер» | Сканер уязвимостей NVIDIA с открытым исходным кодом; пробы, детекторы, harness'ы |
| PyRIT | «инструмент для кампаний» | Оркестратор многоходовых red-team-кампаний от Microsoft; конвертеры, оркестраторы, оценка |
| Prompt-Guard | «маленький классификатор» | Классификатор инъекций промпта от Meta на 86M параметров, используется в паре с Llama Guard |
| TBSA | «оценка по уровням» | Оценка Garak по уровням, заменяющая бинарный результат прошёл/не прошёл |
| Converter chain | «перефразирование + кодирование + ...» | Примитив композиции PyRIT для построения многошаговых атак |
| MLCommons hazard categories | «14 таксономий» | Отраслевая стандартная таксономия, на которую нацелен Llama Guard |
