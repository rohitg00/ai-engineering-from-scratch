# Семейство алгоритмов прямой оптимизации предпочтений (Direct Preference Optimization)

> Рафаилов и соавторы (2023) показали, что оптимум RLHF имеет замкнутую форму относительно данных о предпочтениях, поэтому можно обойтись без явной модели вознаграждения и оптимизировать политику напрямую. Эта идея породила целое семейство методов — IPO, KTO, SimPO, ORPO, BPO — каждый из которых устраняет свой режим отказа DPO. В 2026 году алгоритмы прямого согласования (direct alignment algorithms, DAA) обеспечивают больше циклов постобучения передовых моделей, чем PPO. Но кривая избыточной оптимизации из Урока 2 по-прежнему актуальна: DAA не избегают закона Гудхарта (Goodhart's law) — они лишь смещают то место, где он проявляется.

**Тип:** Learn
**Языки:** Python (стандартная библиотека, компаратор шести вариантов функции потерь предпочтений)
**Предварительные требования:** Этап 18 · 01 (InstructGPT), этап 18 · 02 (взлом вознаграждения), этап 10 · 08 (основы DPO)
**Время:** ~75 минут

## Цели обучения

- Вывести замкнутую форму DPO из оптимума RLHF с KL-регуляризацией.
- Сформулировать, какой режим отказа DPO устраняет каждый из IPO, KTO, SimPO, ORPO, BPO.
- Различать «неявный разрыв вознаграждения» (implicit reward gap) и «силу предпочтения» (preference strength), а также объяснить, почему важно тождественное отображение в IPO.
- Объяснить, почему Рафаилов и соавторы (NeurIPS 2024) доказывают, что DAA переоптимизируются, несмотря на отсутствие явной модели вознаграждения (RM).

## Проблема

Целевая функция RLHF (Урок 1):

```
max_pi E_{x,y~pi} [ r(x, y) ] - beta * KL(pi || pi_ref)
```

имеет известный оптимум:

```
pi*(y|x) = (1/Z(x)) * pi_ref(y|x) * exp(r(x, y) / beta)
```

Таким образом, вознаграждение неявно определяется отношением оптимальной политики к референсной:

```
r(x, y) = beta * log(pi*(y|x) / pi_ref(y|x)) + beta * log Z(x)
```

Подставьте это в функцию правдоподобия предпочтений Брэдли — Терри, и статистическая сумма (partition function) `Z(x)` сокращается, поскольку зависит только от `x`. Остаётся функция потерь только от параметров политики — модель вознаграждения не нужна. Это и есть DPO.

Загвоздка в том, что вывод предполагает достижимость оптимума, соответствие данных о предпочтениях распределению обучения (in-distribution) и то, что референсная политика — истинный якорь моды. Ни одно из этих условий не выполняется точно. Каждый представитель семейства устраняет нарушение своего предположения.

## Концепция

### DPO (Рафаилов и соавт., 2023)

```
L_DPO = -log sigmoid(
  beta * log(pi(y_w | x) / pi_ref(y_w | x))
  - beta * log(pi(y_l | x) / pi_ref(y_l | x))
)
```

Что может пойти не так:

- Неявный разрыв вознаграждения (implicit reward gap) `beta * (log(pi/pi_ref)_w - log(pi/pi_ref)_l)` не ограничен. Незначительное предпочтение может привести к сколь угодно большому разрыву.
- Функция потерь толкает логарифмические вероятности выбранного и отклонённого ответов в противоположных направлениях. Она может снижать абсолютную логарифмическую вероятность выбранного ответа, пока вероятность отклонённого падает быстрее. Это явление называется деградацией выбранного ответа (Degraded Chosen Response).
- Предпочтения вне распределения (out-of-distribution; редкая-редкая пара против редкой-редкой пары) порождают произвольные неявные вознаграждения.

### IPO (Азар и соавт., 2024)

Identity Preference Optimization заменяет log-sigmoid тождественным отображением (identity mapping) вероятности предпочтения. Функция потерь превращается в квадратичную ошибку относительно ограниченной цели:

```
L_IPO = (log(pi(y_w | x) / pi_ref(y_w | x)) - log(pi(y_l | x) / pi_ref(y_l | x)) - 1/(2 beta))^2
```

Отступ (margin) ограничен `1/(2 beta)`. Сила предпочтения и разрыв неявного вознаграждения пропорциональны друг другу. Взрывного роста не происходит.

### KTO (Этьярадж и соавт., 2024)

Kahneman-Tversky Optimization полностью отказывается от парной структуры. Имея один размеченный ответ и бинарный сигнал «желательно» (desirable) или «нежелательно» (undesirable), метод отображает его в полезность в духе теории перспектив (prospect theory):

```
v(x, y) = sigma(beta * log(pi(y|x) / pi_ref(y|x)) - z_ref)
```

с разными весами для выигрышей и потерь (неприятие потерь, loss aversion). Преимущество: можно использовать непарные данные, которых значительно больше.

### SimPO (Мэн и соавт., 2024)

Simple Preference Optimization согласует обучающий сигнал с генерацией. Референсная политика убирается полностью, а логарифмическое правдоподобие нормируется по длине:

```
L_SimPO = -log sigmoid(
  (beta / |y_w|) * log pi(y_w | x)
  - (beta / |y_l|) * log pi(y_l | x)
  - gamma
)
```

с отступом `gamma` для стабилизации. Нормировка по длине устраняет стимул эксплуатировать смещение по длине (length bias) — режим отказа DPO, при котором более длинный `y_w` по построению даёт больший разрыв логарифмических вероятностей.

### ORPO (Хон и соавт., 2024)

Odds-Ratio Preference Optimization добавляет слагаемое предпочтения к стандартному отрицательному логарифмическому правдоподобию SFT:

```
L_ORPO = L_NLL(y_w) + lambda * L_OR
L_OR = -log sigmoid(log(odds(y_w) / odds(y_l)))
```

Референсной политики нет — регуляризатором служит слагаемое SFT. Обучение проходит в один этап: от базовой модели сразу к согласованной. Отдельная контрольная точка SFT не нужна.

### BPO (материал, поданный на ICLR 2026, OpenReview id=b97EwMUWu7)

Выявляет проблему деградации выбранных ответов (Degraded Chosen Responses): DPO сохраняет ранжирование `y_w > y_l`, но абсолютная логарифмическая вероятность `y_w` может снижаться. BPO добавляет однострочную поправку, штрафующую снижение вероятности выбранного ответа. Заявлен прирост точности на +10.1% на Llama-3.1-8B-Instruct в задачах математического рассуждения по сравнению с DPO.

### Универсальный результат: DAA всё равно переоптимизируются

Рафаилов и соавторы в статье «Scaling Laws for Reward Model Overoptimization in Direct Alignment Algorithms» (NeurIPS 2024) обучали политики с DPO, IPO, SLiC на нескольких наборах данных при разных KL-бюджетах. Кривые «золотое вознаграждение — KL» имеют ту же форму «пик и обвал», что и у Гао и соавторов. Неявное вознаграждение в ходе обучения обращается к выборкам вне распределения; KL-регуляризация этого не стабилизирует.

DAA не избегают закона Гудхарта. Они лишь смещают поверхность, на которой он проявляется: с «переоптимизации модели вознаграждения» на «переоптимизации отношения к референсной политике». Универсальное решение — более качественные данные, ансамбли, ранняя остановка — применимо к обоим случаям.

### Выбор между ними (2026)

- Если у вас много парных данных о предпочтениях: DPO с консервативным beta, SimPO — если заметно смещение по длине.
- Если у вас непарная бинарная обратная связь: KTO.
- Если нужен одноэтапный пайплайн от базовой модели: ORPO.
- Если в логах DPO видна деградация логарифмических вероятностей выбранных ответов: BPO.
- Если сила предпочтений сильно варьируется и DPO выходит на насыщение: IPO.

Каждая лаборатория прогоняет все пять методов на батарее тестов и выбирает победителя под конкретную задачу. Нет причин полагать, что оптимум одинаков для математического рассуждения и для безопасности.

## Применение

`code/main.py` сравнивает шесть функций потерь (DPO, IPO, KTO, SimPO, ORPO, BPO) на игрушечном наборе данных о предпочтениях, где истинная сила предпочтения варьируется от пары к паре. Каждая функция потерь оптимизируется на одной и той же выборке из 500 пар с небольшой softmax-политикой. Строятся графики итоговой доли побед (win rate), дрейфа логарифмической вероятности выбранного ответа и разброса неявного вознаграждения для каждого метода.

## Поставка

В результате этого урока создаётся `outputs/skill-preference-loss-selector.md`. По статистике набора данных (парные или непарные данные, переменная или равномерная сила предпочтения, распределение длин) и целевому сценарию (одноэтапный или SFT-затем-предпочтения) рекомендуйте функцию потерь предпочтений и укажите режим отказа, от которого она защищает.

## Упражнения

1. Запустите `code/main.py`. Сообщите итоговое падение логарифмической вероятности выбранного ответа для DPO и BPO. BPO должен сохранять более высокую абсолютную вероятность выбранного ответа — проверьте это.

2. Измените данные о предпочтениях так, чтобы все пары имели одинаковую силу. Какой из шести методов наиболее устойчив? Какой деградирует? Объясните преимущество IPO в этом случае.

3. Сделайте отклонённые ответы в среднем в 2 раза длиннее выбранных. Не меняя ничего другого, численно покажите эксплуатацию длины в DPO и то, как это исправляет SimPO.

4. Рафаилов и соавторы (NeurIPS 2024) утверждают, что DAA переоптимизируются. Воспроизведите одноточечную версию: постройте график KL-дивергенции «выбранный минус отклонённый» и понаблюдайте переоптимизацию в DPO при больших значениях beta.

5. Прочитайте аннотацию статьи BPO (OpenReview b97EwMUWu7). Запишите однострочную поправку, которую BPO добавляет к DPO. Сверьте её с реализацией в `code/main.py`.

## Ключевые термины

| Термин | Как его обычно описывают | Что он означает на самом деле |
|------|-----------------|------------------------|
| DPO | «RLHF без модели вознаграждения» | Функция потерь, выведенная из оптимума RLHF в замкнутой форме; зависит только от параметров политики |
| Неявное вознаграждение | «логарифм отношения» | `beta * log(pi(y\|x) / pi_ref(y\|x))` — вознаграждение, неявно задаваемое DPO |
| IPO | «ограниченная DPO» | Заменяет log-sigmoid тождественным отображением; разрыв неявного вознаграждения ограничен значением `1/(2 beta)` |
| KTO | «DPO для непарных данных» | Полезность в духе теории перспектив для отдельных меток с учётом неприятия потерь |
| SimPO | «DPO без референсной политики» | Нормированное по длине логарифмическое правдоподобие с отступом; референсная политика не нужна |
| ORPO | «одноэтапная DPO» | NLL и слагаемое предпочтения на основе отношения шансов; обучение базовой модели выполняется за один проход |
| BPO | «DPO с сохранением выбранного ответа» | DPO со штрафом за снижение абсолютной логарифмической вероятности выбранного ответа |
| Деградация выбранного ответа | «вероятность выбранного ответа снижается» | DPO снижает логарифмическую вероятность выбранного ответа, пока вероятность отклонённого падает быстрее |
| DAA | «алгоритм прямого согласования» | Любой метод с функцией потерь предпочтений, не использующий явную модель вознаграждения |
