# Дифференциальная приватность для LLM

> DP-SGD остаётся стандартом — обновления градиентов с внесением шума дают формальные гарантии (epsilon, delta). Накладные расходы по вычислениям, памяти и полезности существенны; экономная по параметрам DP-дообучение (LoRA + DP-SGD) — распространённая конфигурация 2025 года (ACM 2025). Два массива доказательств находятся в противоречии: атака вывода членства на основе канареек (canary-based membership inference) (Duan et al., 2024) сообщает об ограниченном успехе против языковых моделей; извлечение обучающих данных (training-data extraction) (Carlini et al., 2021; Nasr et al., 2025) восстанавливает существенный объём дословного запоминания. Разрешение (arXiv:2503.06808, март 2025 года): разрыв — в том, что именно измеряется — вставленные канарейки против «наиболее извлекаемых» данных. Новые конструкции канареек позволяют проводить MIA на основе функции потерь без теневых моделей и дают первый нетривиальный DP-аудит LLM, обученной на реальных данных, с реалистичными гарантиями DP. Альтернативы: PMixED (arXiv:2403.15638) — приватное предсказание во время инференса через смесь экспертов на распределениях следующего токена; генерация синтетических данных с DP (Google Research 2024). Формирующаяся атака: Differential Privacy Reversal via LLM Feedback — утечка через оценки уверенности.

## Проблема

LLM запоминают. Carlini и соавторы (2021) показали, что продакшен-модели языка воспроизводят дословный обучающий текст по запросу. DP — формальная защита: обучение проводится так, чтобы выход был доказуемо нечувствителен к любому отдельному обучающему примеру. Данные 2024–2025 годов показывают, что DP-SGD необходим, но развёрнутые значения ε могут не соответствовать модели угроз.

## Концепция

### (ε, δ)-дифференциальная приватность

Рандомизированный алгоритм M является (ε, δ)-DP, если для любых двух наборов данных, отличающихся на один пример, и любого события S:
P(M(D) in S) <= e^ε * P(M(D') in S) + δ.

Интерпретация: распределение выхода достаточно близко (параметризовано ε), что вклад любого отдельного индивида нельзя надёжно установить, за исключением вероятности δ.

### DP-SGD

Abadi и соавторы (2016). Стандартный рецепт:
1. Сэмплируйте мини-пакет.
2. Вычислите градиенты для каждого примера.
3. Отсеките каждый градиент по отдельному примеру до порога C.
4. Просуммируйте отсечённые градиенты и добавьте гауссовский шум со стандартным отклонением σ * C.
5. Используйте зашумлённую сумму для обновления параметров.

Стоимость приватности отслеживается учётчиком (accountant) (Moments Accountant, учётчик Rényi DP). Значения ε, публикуемые в литературе по LLM, сильно варьируются в зависимости от модели угроз, чувствительности данных и целевой полезности; универсального «безопасного» значения ε по умолчанию не существует. Опубликованные примеры охватывают примерно ε ≈ 1–10 в некоторых сценариях обучения LLM, но это иллюстративные значения, а не рекомендуемые настройки по умолчанию. Более низкое ε, как правило, требует больше шума и может увеличивать потерю полезности.

### LoRA + DP-SGD

Полный DP-SGD передовой модели непозволительно дорог. LoRA (Hu и соавторы, 2022) ограничивает обновления градиента небольшим адаптером, снижая объём хранения градиентов по каждому примеру. LoRA + DP-SGD — распространённая конфигурация 2025 года. Гарантии DP применяются к адаптеру; базовая модель остаётся зафиксированной.

### Противоречие 2024–2025 годов

Два направления доказательств:

- **MIA на канарейках (Duan и соавторы, 2024).** Вставляются уникальные канарейки в обучающие данные, измеряется, может ли атакующий с выводом членства их идентифицировать. Сообщается об ограниченном успехе на языковых моделях. Предполагает, что MIA сложна.
- **Извлечение обучающих данных (Carlini, 2021; Nasr и соавторы, 2025).** Модели подаётся префикс; измеряется, восстанавливает ли она дословный текст из обучения. Сообщается о существенном запоминании. Предполагает, что MIA легка в соответствующем смысле.

Разрешение марта 2025 года (arXiv:2503.06808): эти два подхода измеряют разные вещи. MIA спрашивает «есть ли пример e в D?» на вставленных канарейках. Извлечение спрашивает «что я могу восстановить из D?». Для приватности имеет значение «наиболее извлекаемый» пример; канарейки занижают эту оценку, поскольку не оптимизированы под извлекаемость.

Новые конструкции канареек. MIA на основе функции потерь без теневых моделей. Первый нетривиальный DP-аудит LLM на реальных данных с реалистичными гарантиями DP.

### Альтернативы DP-обучению

- **PMixED (arXiv:2403.15638).** Приватное предсказание во время инференса. Смесь экспертов на распределениях следующего токена; каждый эксперт видит один шард обучающих данных; агрегация добавляет шум для DP. Полностью избегает DP-обучения.
- **Генерация синтетических данных с DP (Google Research 2024).** LoRA-дообучение с DP-SGD, сэмплирование синтетических данных, обучение последующего классификатора на синтетических данных.

Оба подхода обходят издержки полезности полного DP-обучения ценой другой модели угроз.

### Реверсирование дифференциальной приватности через обратную связь LLM

Формирующаяся атака 2025 года (Differential Privacy Reversal via LLM Feedback). Использует оценки уверенности DP-обученной модели как оракул для повторной идентификации индивидов. Даже если выходы не дают утечки, распределения уверенности могут её дать.

Защита: не раскрывать значения уверенности либо усекать/квантовать их перед раскрытием. Это дополнительное требование сверх (ε, δ)-DP-обучения.

## Применение

`code/main.py` симулирует DP-SGD на игрушечном наборе данных бинарной классификации. Можно перебирать множитель шума σ и норму отсечения C, отслеживая бюджет (ε, δ) и потерю точности. «Атака канарейкой» вставляет уникальный обучающий пример и измеряет, может ли тест на основе функции потерь обнаружить его до и после применения DP.

## Поставка

Этот урок производит `outputs/skill-dp-audit.md`. Получив заявление о DP для развёртывания языковой модели, он проводит аудит: значений (ε, δ), используемого учётчика, протокола оценки MIA и того, были ли оценены векторы раскрытия уверенности.

## Ключевые термины

| Термин | Как обычно говорят | Что это означает на самом деле |
|------|-----------------|------------------------|
| DP | «(ε, δ)-дифференциальная приватность» | Формальная приватность: распределение выходов почти не меняется при замене одного элемента в соседних наборах данных |
| DP-SGD | «SGD с внесением шума» | Отсечение градиентов и добавление гауссовского шума; стандартное DP-обучение |
| LoRA + DP-SGD | «эффективное приватное дообучение» | DP-SGD на низкоранговых адаптерах; стандартная конфигурация 2025 года |
| MIA | «вывод о членстве» | Атака, определяющая, входил ли пример в обучающие данные |
| Канарейка | «вставленный пример с водяным знаком» | Уникальный обучающий пример, используемый для измерения утечки при DP |
| PMixED | «приватная смесь для инференса» | DP во время инференса через смесь экспертов на распределениях следующего токена |
| DP Reversal | «атака через утечку уверенности» | Атака, использующая уверенность модели как оракул для повторной идентификации |
