# Агентные экономики, токенные стимулы, репутация

> Долгоживущим автономным агентам (кривая работоспособности METR — от 1 до 8 часов) нужна экономическая субъектность. Формирующийся **5-уровневый стек**: **DePIN** (физические вычисления) → **Идентичность** (W3C DID + репутационный капитал) → **Когниция** (RAG + MCP) → **Расчёты** (абстракция аккаунта) → **Управление** (агентные DAO). Продакшен-сети агентных стимулов включают **Bittensor** (сабнеты TAO вознаграждают модели, специализированные под конкретную задачу), **Fetch.ai / ASI Alliance** (LLM ASI-1 Mini + токен FET) и **Gonka** (proof-of-work на основе трансформера, перераспределяющий вычисления на продуктивные задачи ИИ). Академическая работа: децентрализованная LaMAS с AAMAS 2025 использует **распределение вклада на основе значения Шепли** для справедливого вознаграждения вносящих вклад агентов; статья Google Research «Mechanism design for large language models» предлагает **токенные аукционы** с оплатой по цене второго предложения при монотонной агрегации. В этом уроке строится минимальный агентный маркетплейс, применяется распределение вклада на основе значения Шепли к мультиагентному конвейеру и запускается аукцион второй цены с токенами, чтобы аппарат теории игр обрёл конкретное воплощение.

**Тип:** Learn**Языки:** Python (stdlib)**Предварительные требования:** Фаза 16 · 16 (Negotiation and Bargaining), Фаза 16 · 09 (Parallel Swarm Networks)**Время:** ~75 минут
## Проблема

Мультиагентные системы усложняются, когда агенты создают ценность совместно, но должны вознаграждаться индивидуально. Классические механизмы — равное разделение, «победитель забирает всё» для последнего внёсшего вклад — либо несправедливы, либо уязвимы для манипуляций. Коалиционное вознаграждение через значения Шепли справедливо по построению, но дорого вычислительно. Литература 2025–2026 годов продвигает полезные приближения: сэмплирование значений Шепли, аукционы с монотонной агрегацией и ончейн-репутацию, накапливающуюся из подтверждённых вкладов.

Помимо распределения вклада, отрасль обратилась к реальным экономическим агентам: TAO Bittensor вознаграждает майнинг-вычисления за дообучение моделей, специализированных под сабнет, Fetch.ai/ASI вознаграждает использование LLM ASI-1 Mini токенами FET, Gonka перераспределяет proof-of-work трансформера на продуктивные задачи ИИ. Агенты, автономно совершающие транзакции, существуют уже сегодня; вопрос в том, как согласовать стимулы.

Этот урок рассматривает агентные экономики как отдельное семейство задач — распределение вклада, проектирование механизмов и репутация — и строит каждую из них с минимальной математикой, чтобы идеи закрепились.

## Концепция

### 5-уровневый стек агентной экономики

1. **DePIN (физические вычисления).** Децентрализованная инфраструктура, сдающая в аренду GPU, хранилище, пропускную способность. Сабнеты Bittensor, Render Network, Akash. Не специфична для агентов; агенты её используют.
2. **Идентичность.** W3C-децентрализованные идентификаторы (DID) дают каждому агенту устойчивый ID, независимый от любой платформы. Репутация накапливается на DID. Agent Network Protocol (ANP) использует DID как уровень обнаружения.
3. **Когниция.** Цикл рассуждений агента: LLM + RAG + MCP. Это то, что строят остальные фазы.
4. **Расчёты.** Абстракция аккаунта (ERC-4337) позволяет агентам платить за газ со своих собственных балансов, не имея ETH. Агенты могут платить за услуги, друг другу или за вычисления.
5. **Управление.** Агентные DAO: структуры управления, где люди *и* агенты голосуют по изменениям протокола, а сила голоса привязана к репутации.

Не каждая продакшен-система использует все пять уровней. Bittensor использует 1, 2, частично 3, частично 4, и не использует 5. Агенты OpenAI не используют ничего, кроме 3. Стек — это справочная карта, а не требование.

### Bittensor, Fetch.ai, Gonka — что работает на практике

**Bittensor (TAO).** Сабнеты — это специализированные задачи (языковое моделирование, генерация изображений, прогнозирование). Майнеры отправляют выходные данные моделей. Валидаторы их ранжируют; оценка, взвешенная по стейку, распределяет вознаграждения TAO. У каждого сабнета своя собственная система оценивания. Экономический вывод: платите за качество результата под конкретную задачу, а не за использованные вычисления.

**Fetch.ai / ASI Alliance.** LLM ASI-1 Mini работает в сети Fetch.ai; пользователи платят токенами FET за инференс. Нарратив «агенты как равноправные участники» здесь сильнее: агент в Fetch может вызвать другого агента для выполнения задачи и заплатить в FET.

**Gonka.** Proof-of-work трансформера: «работа» — это прямые проходы трансформера. Майнеры зарабатывают, выполняя задачи инференса с известными правильными ответами (из обучающих данных). Ресурсно-продуктивный PoW вместо PoW на основе хеширования.

Все три работают в продакшене по состоянию на апрель 2026 года. Распределение выплат отличается. Bittensor вознаграждает качество относительно валидаторов сабнета; Fetch вознаграждает полезность, измеряемую платящими пользователями; Gonka вознаграждает верифицируемую работу инференса.

### Распределение вклада на основе значения Шепли

Три агента совместно работают над задачей. Результат оценивается в 0,8. Кто какой вклад внёс?

Значение Шепли: единственное распределение вклада, удовлетворяющее четырём аксиомам (эффективность, симметрия, линейность, нулевой игрок). Для агента `i`:

```
shapley(i) = (1/N!) * sum over all orderings O of (v(S_i_O ∪ {i}) - v(S_i_O))
```

где `S_i_O` — множество агентов, предшествующих `i` в упорядочении `O`. На практике: перебираются все перестановки, для каждой перестановки фиксируется предельный вклад каждого агента, затем берётся среднее.

Для N=3 агентов существует 6 перестановок. Для N=10 — 3,6 млн, поэтому на практике упорядочения сэмплируются, а не перебираются.

### Аукцион второй цены для агрегации

Google Research («Mechanism design for large language models») предлагает токенные аукционы второй цены для агрегации выходов LLM. Постановка: N агентов, каждый предлагает вариант завершения; у каждого есть приватная оценка ценности быть выбранным. Аукционер выбирает предложение с наивысшей ценностью и платит по *второй по величине* ценности. При монотонной агрегации (ценность зависит от того, какое предложение выбрано, а не от того, сколько было ставок), это правдивый механизм — агенты делают ставки по своей истинной ценности.

Почему это важно для LLM-систем: задачи завершения можно передать на аутсорс нескольким агентам с разным ценообразованием; аукцион выбирает лучший вариант и справедливо платит, а у агентов нет стимула искажать информацию.

### Репутационный капитал

Привязанная к DID оценка репутации накапливается из подтверждённых вкладов. Простое правило обновления:

```
rep(i, t+1) = alpha * rep(i, t) + (1 - alpha) * contribution_quality(i, t)
```

С коэффициентом затухания `alpha`, близким к 1. Репутация:

- Дёшева для чтения при принятии решений о маршрутизации («отправлять сложные задачи агентам с высокой репутацией»).
- Дорога для подделки (накапливается со временем, привязана к DID).
- Может быть урезана: вклады, не прошедшие верификацию, вычитаются.

### Децентрализованная LaMAS с AAMAS 2025

Предложение LaMAS (AAMAS 2025) объединяет: идентичность на DID, распределение вклада на основе значения Шепли и простой механизм аукциона. Ключевое утверждение: децентрализация этапа распределения вклада делает систему проверяемой и устойчивой к манипуляции из единой точки.

### Где экономика ломается

- **Манипуляция ценовым оракулом.** Если функцию распределения вклада можно обыграть, агенты её обыграют. Каждому механизму нужен состязательный тест.
- **Сивилл-атаки.** Один оператор запускает N поддельных агентов, чтобы завысить собственный вклад. DID замедляют, но не останавливают это; сдерживающий фактор — высокая стоимость подделки репутации.
- **Стоимость верификации.** Распределение вклада справедливо ровно настолько, насколько справедлив верификатор. Если верификация дешёвая (маленькая LLM), её можно обыграть; если дорогая (панель людей-экспертов), система не масштабируется.
- **Регуляторный навес.** Агентные экономики пересекаются с финансовым регулированием. Bittensor, Fetch и Gonka по состоянию на 2026 год работают в юридической серой зоне в некоторых юрисдикциях.

### Когда агентные экономики имеют смысл

- **Открытые сети с гетерогенными операторами.** Ни одна команда не контролирует всех агентов.
- **Верифицируемые результаты.** Без верификации распределение вклада — это догадка.
- **Долгоживущие рабочие процессы.** Одноразовые задачи не выигрывают от накопления репутации.
- **Токенизированные платежи юридически допустимы** в вашей юрисдикции.

В закрытых корпоративных системах экономика уступает место более простому распределению (менеджеры назначают работу, метрики внутренние). Экономическая литература применима в основном к открытым сетям.

```figure
swarm-auction
```

## Реализация

`code/main.py` реализует:

- `shapley(value_fn, agents)` — точное вычисление значения Шепли путём перебора для небольших N.
- `second_price_auction(bids)` — правдивый механизм; победитель платит вторую по величине цену.
- `Reputation` — привязанная к DID репутация с экспоненциальным затуханием и урезанием.
- Демо 1: три агента совместно работают над задачей, точное значение Шепли распределяет вклад.
- Демо 2: пять агентов делают ставки за слот задачи; аукцион второй цены выбирает победителя и оплату.
- Демо 3: 100 раундов назначения задач агентам с гетерогенной репутацией; маршрутизация с учётом репутации превосходит случайную.

Запуск:

```
python3 code/main.py
```

Ожидаемый результат: значения Шепли для каждого агента; результат аукциона, показывающий равновесие правдивых ставок; маршрутизация с учётом репутации, показывающая прирост качества на 10-20% по сравнению со случайной после разогрева.

## Поставка

Запуск агентной экономики в 2026 году:

- **Начинайте с репутации, а не с токенов.** Репутацию дёшево реализовать, и сама по себе она ценна; токены добавляют юридическую и экономическую сложность.
- **Верифицируйте перед тем, как вознаграждать.** Никогда не распределяйте вклад без независимого этапа верификации. Самостоятельно заявленное качество провоцирует сивилл-игры.
- **Сэмплируйте значение Шепли, а не вычисляйте точно.** Сэмплируйте 100-1000 упорядочений; точный перебор не масштабируется.
- **Ограничивайте коэффициент затухания сверху и репутацию снизу.** Неограниченное затухание стирает легитимных участников; слишком медленное затухание вознаграждает агентов с устаревшей высокой репутацией.
- **Проверяйте механизмы состязательно.** Запускайте red-team-сценарии перед открытием сети. У каждого механизма есть своя теория игр; вы хотите найти дыры сами, а не дождаться атакующих.

## Ключевые термины

| Термин | Что говорят люди | Что это на самом деле означает |
|------|----------------|------------------------|
| DePIN | «Децентрализованная физическая инфраструктура» | Вычисления/хранилище/пропускная способность с токенными стимулами. Bittensor, Akash, Render. |
| DID | «Децентрализованный идентификатор» | Спецификация W3C для переносимых ID. Репутация агента привязывается к DID, а не к платформе. |
| ERC-4337 | «Абстракция аккаунта» | Контрактные аккаунты, способные спонсировать газ, что позволяет агентам совершать платежи. |
| Значение Шепли (Shapley value) | «Справедливое распределение вклада» | Единственное распределение, удовлетворяющее эффективности, симметрии, линейности, нулевому игроку. |
| Аукцион второй цены (Second-price auction) | «Аукцион Викри (Vickrey auction)» | Правдивый механизм: победитель платит вторую по величине ставку. Совместим с монотонной агрегацией. |
| Репутационный капитал | «Накопленная оценка качества» | Привязанная к DID оценка из подтверждённых вкладов; со временем затухает. |
| Агентный DAO | «Агенты + люди управляют» | DAO, где агенты-избиратели — полноправные участники, сила голоса привязана к репутации. |
| TAO / FET / GPU credits | «Токенные деноминации» | TAO Bittensor, FET Fetch.ai, различные токены DePIN. |
