# CLIP и контрастивное предварительное визуально-языковое обучение

> CLIP от OpenAI (2021) доказал одну идею, оказавшуюся достаточно масштабной, чтобы задать вектор следующих пяти лет: выровнять энкодер изображений и текстовый энкодер в едином векторном пространстве, используя только зашумлённые веб-пары изображение-подпись и контрастивную функцию потерь. Ноль размеченных меток. 400M пар. Получившееся пространство, в котором каждому изображению или тексту соответствует векторное представление (эмбеддинг), позволяет выполнять классификацию без примеров, поиск по изображениям и тексту и служит визуальным энкодером в каждой VLM 2026 года. SigLIP 2 (2025) заменил функцию softmax на сигмоиду и превзошёл CLIP по масштабу при меньшей стоимости. Этот урок проводит вас через математические основы от InfoNCE до попарной сигмоидной функции потерь и реализует шаг обучения на чистом Python со стандартной библиотекой.

**Тип:** Build
**Языки:** Python (стандартная библиотека, реализации InfoNCE и сигмоидной функции потерь)
**Предварительные требования:** Этап 12 · 01 (патчи ViT), этап 7 (трансформеры)
**Время:** ~180 минут

## Цели обучения

- Вывести функцию потерь InfoNCE из взаимной информации и реализовать численно устойчивую векторизованную версию.
- Объяснить, почему попарная сигмоидная функция потерь (SigLIP) масштабируется до пакета размером 32768+ без накладных расходов all-gather, которых требует softmax.
- Провести классификацию ImageNet без примеров, конструируя текстовые шаблоны (`a photo of a {class}`) и выбирая argmax по косинусному сходству.
- Назвать четыре рычага, которые даёт предварительное обучение CLIP / SigLIP: размер пакета, температуру, шаблон промпта, качество данных.

## Проблема

Зрение до CLIP было с учителем. Собрать размеченные наборы данных (ImageNet: 1.2M изображений, 1000 классов), обучить CNN, выпустить в продакшен. Метки дороги, метки смещены в сторону того, о чём разметчики могут договориться, и метки не переносятся на новые задачи без дообучения.

Веб с изображениями и подписями содержит более миллиарда слабо размеченных пар бесплатно. Фотография золотистого ретривера с alt-текстом «моя собака Макс в парке» несёт обучающий сигнал — текст описывает изображение. Вопрос: можно ли превратить это в полезное обучение?

Ответ CLIP: рассматривать пары изображение-подпись как задачу сопоставления. Дан пакет из N изображений и N подписей — научиться сопоставлять каждое изображение с его собственной подписью среди N-1 отвлекающих вариантов. Обучающий сигнал: «эти две вещи принадлежат друг другу; эти N-1 — нет». Никаких меток классов. Никакой человеческой разметки. Просто контрастивная функция потерь.

Получившееся пространство эмбеддингов позволяет решать больше задач, чем те, для которых обучался CLIP. Классификация ImageNet без примеров работает, потому что «фотография кошки» получает эмбеддинг, близкий к изображениям кошек, которые никогда явно не были помечены как кошки. Именно эта ставка породила каждую VLM 2026 года.

## Концепция

### Двойной энкодер

У CLIP две башни:

- Энкодер изображений `f`: ViT или ResNet, выдаёт D-мерный вектор на изображение.
- Текстовый энкодер `g`: небольшой трансформер, выдаёт D-мерный вектор на подпись.

Обе башни нормализуют свои выходы до единичной длины. Сходство: `cos(f(x), g(y)) = f(x)^T g(y)`, поскольку оба вектора единичной нормы.

Для пакета из N пар (изображение, подпись) строится матрица сходства `S` формы `(N, N)`:

```
S[i, j] = cos(f(x_i), g(y_j)) / tau
```

где `tau` — обучаемая температура (CLIP инициализирует значением 0.07; обучается в логарифмическом пространстве).

### Функция потерь InfoNCE

CLIP использует симметричную кросс-энтропию по строкам и столбцам:

```
loss_i2t = CE(S, labels=identity)     # each image's positive is its own caption
loss_t2i = CE(S^T, labels=identity)   # each caption's positive is its own image
loss = (loss_i2t + loss_t2i) / 2
```

Это и есть InfoNCE. Softmax внутри CE заставляет каждое изображение соответствовать своей подписи сильнее, чем любой другой подписи в пакете. «Негативы» — это все остальные элементы пакета. Чем больше пакет, тем больше негативов и тем сильнее сигнал. CLIP обучался с пакетами размером 32k; масштаб имеет значение.

### Температура

`tau` управляет резкостью распределения softmax. Низкая tau → резкое распределение и эффект отбора сложных негативных примеров. Высокая tau → мягкое распределение, в которое вносят вклад все примеры. CLIP обучает log(1/tau), ограничивая значение, чтобы предотвратить коллапс. SigLIP 2 фиксирует начальную tau и вместо этого использует обучаемое смещение.

### Почему сигмоида масштабируется лучше (SigLIP)

Softmax требует всю матрицу сходства синхронно. В распределённом обучении нужно собрать (all-gather) каждый эмбеддинг на каждую реплику, а затем выполнить softmax. Это квадратичная зависимость от размера мира по коммуникации.

SigLIP заменяет softmax поэлементной сигмоидой: для каждой пары `(i, j)` функция потерь — это бинарная классификация «являются ли они совпадающей парой?»; положительный класс — диагональ, всё остальное — негативный. Функция потерь:

```
L = -1/N sum over (i, j) [ y_ij log sigmoid(S[i,j]) + (1-y_ij) log sigmoid(-S[i,j]) ]
```

`y_ij = 1`, если `i == j`, иначе 0. Потеря каждой пары независима. All-gather не нужен. Каждый GPU вычисляет свой локальный блок и суммирует. SigLIP 2 дёшево масштабируется до пакетов размером 32k-512k там, где CLIP потребовал бы пропорционально больше коммуникации.

### Классификация без примеров

Дано N имён классов; для каждого класса строится текстовый шаблон:

```
"a photo of a {class}"
```

Закодируйте каждый шаблон текстовым энкодером, а изображение — энкодером изображений. Класс с максимальным косинусным сходством — предсказанный класс. Обучение на целевых классах не требуется.

Шаблоны промптов имеют значение. Оригинальная статья CLIP использовала 80 шаблонов на класс (обычный, художественный, фото, картина и т.д.) и усредняла эмбеддинги. +3 балла на ImageNet. Современное использование обычно берёт один-два шаблона.

### Линейные пробы и дообучение

Классификация без примеров — это базовый уровень. Линейная проба (обучение одного линейного слоя поверх замороженных признаков CLIP для целевых классов) превосходит её на задачах из целевого домена. Полное дообучение превосходит линейную пробу в этом домене, но может ухудшить перенос классификации без примеров. Три режима с тремя компромиссами.

### SigLIP 2: NaFlex и плотные признаки

SigLIP 2 (2025) добавляет:
- NaFlex: единая модель обрабатывает переменные соотношения сторон и разрешения.
- Более качественные плотные признаки для сегментации и оценки глубины, нацеленные на использование в роли замороженного бэкбона в VLM.
- Многоязычность: обучен на 100+ языках, тогда как CLIP был только англоязычным.
- Масштаб 1B параметров, где CLIP останавливался на 400M.

В открытых VLM 2026 года SigLIP 2 SO400m/14 — визуальная башня по умолчанию. CLIP остаётся выбором по умолчанию для чистого поиска изображение-текст там, где конкретное распределение обучающих данных LAION-2B соответствует паттерну запросов.

### ALIGN, BASIC, OpenCLIP, EVA-CLIP

ALIGN (Google, 2021): та же идея, что и CLIP, масштаб 1.8B пар, на 90% зашумлённых. Доказал, что зашумлённые данные масштабируются. OpenCLIP (LAION): открытое воспроизведение CLIP на LAION-400M / 2B, несколько масштабов, основная открытая контрольная точка. EVA-CLIP: инициализируется посредством моделирования маскированных изображений; сильный бэкбон для VLM. BASIC: гибрид CLIP+ALIGN от Google. Всё одно семейство, разные данные и настройка.

### Потолок классификации без примеров

Модели класса CLIP упираются в потолок около 76% точности на ImageNet при классификации без примеров (CLIP-G, OpenCLIP-G). Для дальнейшего роста требуются либо намного больше данных (SigLIP 2 достигает 80%+), либо изменения архитектуры (обученные с учителем головы, больше параметров). Бенчмарк насыщается; реальная ценность — пространство эмбеддингов, которое используют последующие VLM.

## Ключевые термины

| Термин | Как обычно говорят | Что это означает на практике |
|--------|--------------------|------------------------------|
| InfoNCE | «Контрастивная функция потерь» | Кросс-энтропия по матрице сходства пакета: позитивом для каждого элемента служит соответствующий ему парный элемент, а все остальные считаются негативами |
| Сигмоидная функция потерь | «Функция потерь SigLIP» | Попарная бинарная кросс-энтропия; без softmax и all-gather, поэтому недорого масштабируется при распределённом обучении |
| Температура | «tau» | Скаляр, масштабирующий логиты перед softmax или сигмоидой; управляет резкостью распределения |
| Классификация без примеров | «Классификация без дообучения» | Текстовые промпты используются для построения эмбеддингов классов, после чего классификация выполняется по косинусному сходству; обучение на целевых классах не требуется |
| Шаблон промпта | «Фотография...» | Текстовая конструкция вокруг имени класса; влияет на точность классификации без примеров на 1–5 пунктов |
| Двойной энкодер | «Две башни» | Один энкодер изображений и один текстовый энкодер, выдающие представления в общем D-мерном пространстве |
| Сложный негативный пример | «Трудный отвлекающий вариант» | Негативный пример, настолько похожий на позитивный, что модели приходится учиться различать их |
| Линейная проба | «Замороженные признаки и один слой» | Обучается только линейный классификатор поверх замороженных признаков; так измеряется качество признаков |
| NaFlex | «Нативное гибкое разрешение» | Возможность SigLIP 2 принимать без изменения размера изображения с любым соотношением сторон и разрешением |
| Масштабирование температуры | «Логарифмически параметризованная tau» | CLIP параметризует `log(1/tau)`, чтобы обеспечить корректное поведение градиентов, и ограничивает значение во избежание коллапса tau почти до нуля |
