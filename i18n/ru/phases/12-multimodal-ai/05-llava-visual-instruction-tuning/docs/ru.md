# LLaVA и обучение на визуальных инструкциях

> LLaVA (апрель 2023) — самая копируемая мультимодальная архитектура на планете. Она заменила Q-Former из BLIP-2 2-слойным MLP, заменила механизм перекрёстного внимания с гейтированием (gated cross-attention) из Flamingo наивной конкатенацией токенов и обучалась на 158k визуально-инструктивных ходах, сгенерированных GPT-4 из чисто текстовых подписей. Любой практик, строивший VLM между 2023 и 2026 годом, строил ту или иную вариацию LLaVA. LLaVA-1.5 добавила AnyRes. LLaVA-NeXT подняла разрешение. LLaVA-OneVision объединила изображение, несколько изображений и видео в одном рецепте. Этот урок разбирает рецепт, реализует проектор и объясняет, почему «победила простота».

**Тип:** Build
**Языки:** Python (стандартная библиотека, проектор + конструктор шаблонов инструкций)
**Предварительные требования:** Этап 12 · 02 (CLIP), этап 11 (инженерия LLM — обучение на инструкциях)
**Время:** ~180 минут

## Цели обучения

- Построить 2-слойный MLP-проектор, отображающий эмбеддинги патчей ViT (размерность 1024) в размерность эмбеддингов LLM (размерность 4096).
- Пройти двухэтапный рецепт LLaVA: (1) выравнивание проектора на 558k парах подписей, (2) обучение на визуальных инструкциях на 158k ходах, сгенерированных GPT-4.
- Построить промпт в формате LLaVA с токеном-заполнителем изображения, системным промптом и ходами пользователь/ассистент.
- Объяснить, почему сообщество перешло от Q-Former к MLP, несмотря на выигрыш Q-Former в бюджете токенов.

## Проблема

Q-Former из BLIP-2 (Урок 12.03) сжимает изображение до 32 токенов. Чисто, эффективно, хорошо для бенчмарков. Но у него две проблемы.

Во-первых, Q-Former обучаем, но его функция потерь — не финальная задача. Этап 1 обучает ITC+ITM+ITG. Этап 2 использует функцию потерь языкового моделирования. Запросы выучивают некое промежуточное представление, которое затем должна декодировать LLM. Информация теряется в узком месте.

Во-вторых, Q-Former занимает 188M параметров, и на масштабе LLaVA 2023 года его приходилось совместно проектировать с целевой LLM. Смените LLM — переобучите Q-Former. Смените визуальный энкодер — переобучите. Каждая комбинация была отдельным R&D-проектом.

Ответ LLaVA был неловко прост: взять 576 патч-токенов ViT, пропустить каждый через 2-слойный MLP (`1024 → 4096 → 4096`) и вбросить все 576 во входную последовательность LLM. Без узкого места. Без предобучения этапа 1 на странных целях. Просто обучить MLP непосредственно с функцией потерь языкового моделирования.

Откуда данные? Второе прозрение LLaVA: использовать GPT-4 (только текст) для генерации инструктивных данных. Скормить GPT-4 подписи COCO и данные об ограничивающих рамках изображения, попросить создать диалоги, описания и вопросы, требующие сложных рассуждений. 158k инструктивно-ответных ходов бесплатно. Без человеческой разметки.

Результат: VLM, которая работала на 8 A100 один день, обошла Flamingo на MMMU и выпустила открытую контрольную точку, которую сообщество могло расширять. К концу 2023 года она породила 50+ форков.

## Концепция

### Архитектура

LLaVA-1.5 на 13B:
- Визуальный энкодер: CLIP ViT-L/14 @ 336 (заморожен на этапе 1, опционально разморожен на этапе 2).
- Проектор: 2-слойный MLP с активацией GELU, `1024 → 4096 → 4096`.
- LLM: Vicuna-13B (позже Llama-3.1-8B).

Прямой проход на изображении + текстовом промпте:

```
img -> ViT -> 576 patches of dim 1024
patches -> MLP -> 576 tokens of dim 4096
prompt: system + "<image>" placeholder + user question
replace <image> token with the 576 projected tokens
feed the full sequence to the LLM
decode response
```

Изображение занимает 576 токенов контекста LLM. При контексте 2048 это оставляет 1472 токена на текст. При контексте 32k это уже статистическая погрешность.

### Этап 1: выравнивание проектора

Заморозить ViT. Заморозить LLM. Обучать только 2-слойный MLP. Набор данных: 558k пар изображение-подпись (LAION-CC-SBU). Функция потерь: языковое моделирование на подписи, обусловленное спроецированными токенами изображения.

За одну эпоху при пакете 128 это занимает несколько часов. Проектор выучивает отображение из пространства ViT в пространство LLM. Без обучения, специфичного для задачи.

### Этап 2: обучение на визуальных инструкциях

Разморозить проектор (по-прежнему обучаемый). Разморозить LLM (обычно полностью, иногда LoRA). Обучать на 158k ходах визуальных инструкций.

Инструктивные данные — это и есть трюк. Liu et al. сгенерировали их так:
1. Взять изображение COCO.
2. Извлечь текстовое описание (5 человеческих подписей + список ограничивающих рамок).
3. Отправить в GPT-4 с тремя шаблонами промптов:
   - Диалог: «Сгенерируй диалог между пользователем и ассистентом об этом изображении».
   - Подробное описание: «Дай насыщенное, подробное описание изображения».
   - Сложное рассуждение: «Задай вопрос, требующий рассуждения об изображении, затем ответь на него».
4. Разобрать вывод GPT-4 в пары (инструкция, ответ).

Ничто из этого не касается изображения напрямую — только текстового описания. GPT-4 галлюцинирует правдоподобное содержание изображения. Есть шум, но сработало: 158k ходов хватило, чтобы разблокировать диалог.

### Почему сообщество это скопировало

- Нет специфичных для этапа 1 функций потерь, которые нужно настраивать. На всём протяжении используется функция потерь языкового моделирования.
- Проектор обучается за часы, а не дни.
- LLM можно заменить (LLaVA-Llama2, LLaVA-Mistral, LLaVA-Llama3), переобучив только проектор.
- Конвейер данных визуальных инструкций использует GPT-4 и дёшев в перегенерации для нового домена.

### LLaVA-1.5 и LLaVA-NeXT

LLaVA-1.5 (октябрь 2023) добавила:
- Академические данные задач (VQA, OKVQA, RefCOCO), подмешанные в обучение на инструкциях.
- Улучшенный системный промпт.
- Контекст 2048 → 32k.

LLaVA-NeXT (январь 2024) добавила:
- AnyRes: разбить изображение высокого разрешения на сетку 2x2 или 1x3 из кропов 336x336, плюс одну глобальную миниатюру низкого разрешения. Каждый кроп становится 576 токенами; всего около 2880 визуальных токенов на изображение. Задачи OCR и работы с диаграммами резко улучшились.
- Улучшенная смесь инструктивных данных с ShareGPT4V (подписи высокого качества от GPT-4V).
- Более сильные базовые LLM (Mistral-7B, Yi-34B).

### LLaVA-OneVision

Урок 12.08 подробно разбирает OneVision. Коротко: тот же проектор, но обучен по учебному плану, охватывающему одно изображение, несколько изображений и видео в одной модели с общим бюджетом визуальных токенов.

### Сравнение с Q-Former

| | Q-Former (BLIP-2) | MLP (LLaVA) |
|---|---|---|
| Визуальных токенов на изображение | 32 | 576 (базовый вариант) или 2880 (AnyRes) |
| Обучаемые параметры | 188M + LM | 40M + LM |
| Функция потерь на этапе 1 | ITC+ITM+ITG | Только LM |
| Замена LLM | Требует переобучения | Замена с минимальным переобучением |
| Несколько изображений | Неудобно | Естественно (конкатенация) |
| Видео | Неудобно | Естественно (конкатенация по кадрам) |
| Бюджет токенов | Малый | Большой |

MLP побеждает по простоте и гибкости токенов. Q-Former побеждает по бюджету токенов. К концу 2023 года бюджет токенов перестал быть связывающим ограничением (контексты LLM выросли до 32k-128k+), и простота возобладала.

### Формат промпта

```
A chat between a curious human and an artificial intelligence assistant. The assistant gives helpful, detailed, and polite answers to the human's questions. USER: <image> Describe this image in detail. ASSISTANT: The image shows ...
```

`<image>` — это токен-заполнитель. До токенизации он заменяется на 576 визуальных токенов (или 2880 с AnyRes). Токенизатор видит последовательность чуть длиннее той, на которой он обучался, но LLM справляется с новым входом, потому что этап 1 её этому научил.

### Экономика параметров

Разбивка LLaVA-1.5-7B:
- CLIP ViT-L/14 @ 336: 303M (заморожен на этапе 1, часто разморожен на этапе 2).
- Проектор (2x линейный): ~22M обучаемых.
- Llama-7B: 7B.
- Всего: 7.3B параметров. Обучается на этапе 2: полные 7B + 22M проектора.

Стоимость обучения для этапа 2: ~20 часов на 8xA100. Это ключевая цифра — один день, один узел, воспроизводимо. Вот почему LLaVA распространилась.

## Применение

`code/main.py` реализует:

1. 2-слойный MLP-проектор (размерность 16 → 32 → 32 для игрушечного масштаба) на чистом Python.
2. Конвейер построения промпта: системный промпт + `<image>` заменён на N спроецированных токенов + ход пользователя + заполнитель для генерации ответа ассистента.
3. Визуализатор того, как выглядит 576-токенный визуальный блок в контексте LLM (процент занятого контекста 2k / 32k / 128k).

## Итоговое задание

Этот урок производит `outputs/skill-llava-vibes-eval.md`. Дана контрольная точка семейства LLaVA — навык прогоняет набор из 10 промптов «vibes-eval» (3 подписи, 3 VQA, 2 рассуждения, 2 отказа) и выдаёт удобочитаемую оценочную карточку. Не бенчмарк, а дымовой тест, подтверждающий, что проектор и LLM хорошо соединены.

## Упражнения

1. Вычислите число обучаемых параметров 2-слойного MLP-проектора `1024 → 4096 → 4096`. С GELU и смещением, какую долю LLaVA-13B он представляет?

2. Постройте промпт LLaVA для случая «отказа» — изображение содержит частное лицо. Напишите ожидаемый ответ ассистента. Почему LLaVA должна отказать в этом режиме без примеров (zero-shot), и какие обучающие данные нужны, чтобы закрепить отказ?

3. Прочитайте раздел AnyRes блога LLaVA-NeXT. Вычислите число визуальных токенов для изображения 1344x672 при AnyRes. Сравните с базовыми 576 токенами при 336x336.

4. Проектор этапа 1 LLaVA обучается на подписях с функцией потерь языкового моделирования. Что произойдёт, если пропустить этап 1 и сразу перейти к этапу 2 (обучению на визуальных инструкциях)? Подтвердите ответ ссылкой на абляционное исследование Prismatic VLMs (arXiv:2402.07865).

5. LLaVA-Instruct-150k использует GPT-4 с подписями COCO для генерации инструкций. Для нового домена (рентгеновские снимки, спутниковые изображения) опишите четырёхшаговый конвейер данных для генерации доменных инструкций. Что может пойти не так на каждом шаге?

## Ключевые термины

| Термин | Как его называют | Что он означает на самом деле |
|------|----------------|------------------------|
| Проектор | «MLP-мост» | 2-слойный MLP с GELU, отображающий размерность ViT в размерность LLM |
| Токен изображения | «Заполнитель <image>» | Маркер в промпте, который перед инференсом заменяется на N спроецированных визуальных токенов |
| Обучение на визуальных инструкциях | «Этап 2 LLaVA» | Обучение на сгенерированных GPT-4 тройках (изображение, инструкция, ответ) |
| Выравнивание на этапе 1 | «Предварительное обучение проектора» | ViT и LLM замораживают, а проектор обучают на подписях с функцией потерь языкового моделирования |
| AnyRes | «Мозаика из нескольких кропов» | Изображение высокого разрешения разбивают на сетку фрагментов и конкатенируют визуальные токены каждого фрагмента |
| LLaVA-Instruct | «Сгенерировано GPT-4» | 158k пар «инструкция — ответ», синтезированных из подписей COCO с помощью GPT-4 |
| Заморозка визуального энкодера | «Базовая сеть заблокирована» | Веса CLIP не обновляются на этапе 1, а иногда и на этапе 2 |
| ShareGPT4V | «Улучшенные подписи» | 1M подробных подписей, сгенерированных GPT-4V и используемых для более качественного выравнивания |
| VQA | «Визуальные вопросы и ответы» | Задача, в которой нужно ответить на вопрос об изображении в свободной форме |
| Prismatic VLMs | «Статья о пространстве вариантов архитектуры» | Абляционное исследование Karamcheti 2024 года, систематически проверяющее варианты проектора и данных |
