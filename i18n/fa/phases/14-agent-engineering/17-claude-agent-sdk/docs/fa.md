# "هرنس" به عنوان کتابخانه  زیرنویس و فروشگاه جلسات

> یک هرنس که می توانید وارد کنید: ابزار داخلی، زیرنویس برای تعزیر زمینه، هوک، گسترش ردیابی W3C، دوام جلسه. SDK عامل کلاود نمونه مرجع است  فرم کتابخانه هرنس کد کلاود  و Claude Managed Agents جایگزین میزبان برای کار async طولانی مدت است.

**Type:** Learn + Build
**Languages:** Python (stdlib), TypeScript
**Prerequisites:** Phase 14 · 01 (Agent Loop), Phase 14 · 10 (Skill Libraries)
**Time:** ~75 minutes

## اهداف یادگیری

- تفاوت بین SDK مشتری انتروپک (API خام) و SDK عامل کلاود (شکل زره) را توضیح دهید.
- زیرنویس های  موازی و تعزیر زمینه  و زمانی که برای آنها برسید را توصیف کنید.
- نام سطح ذخیره سازی جلسه SDK پایتون (`append`،`load`،`list_sessions`،`delete`،`list_subkeys`) و نقش `--session-mirror`. .
- استفاده از یک آرم استدلیب با ابزار های داخلی، زایمان زیربند با زمینه ای جداگانه، هک چرخه زندگی و یک فروشگاه جلسه.

## مشکل

یک API LLM خام به شما یک سفر برگشت می دهد. یک عامل تولید نیاز به اجرای ابزار، سرورهای MCP، هوک چرخه حیات، زایمان زیربند، دوام جلسه، گسترش ردیابی دارد. Claude Agent SDK این شکل را به عنوان یک کتابخانه ارسال می کند  همان هارم Claude Code استفاده می کند، برای عوامل سفارشی در معرض قرار می گیرد.

## مفهوم

### SDK مشتری در مقابل SDK عامل

- **Client SDK (`anthropic`).**تو مال حلق، ابزار، دولت هستي
- **Agent SDK (`claude-agent-sdk`).**اجرا ابزار ساخته شده، اتصال MCP، هک ها، زایمان زیرکود، فروشگاه جلسه، حلقه کلوید کد به عنوان یک کتابخانه

### ابزار های داخلی

SDK 10+ ابزار را از جعبه خارج می کند: فایل خواندن / نوشتن، shell، grep، glob، web fetch، بیشتر. ابزار سفارشی از طریق رابط استاندارد ابزار-نماینه ثبت می شود.

### فرش های زیر

دو هدف توسط Anthropic مستند شده:

1. **Parallelization.**کار مستقل را همزمان اجرا کنید. "فایل تست را برای هر یک از این 20 ماژول پیدا کنید" 20 کار متوازی زیر است.
2. **Context isolation.**زیرنویس ها از پنجره های زمینه خود استفاده می کنند؛ تنها نتایج به آرژانتور باز می گردند. بودجه آرژانتور حفظ می شود.

افزونه های اخیر SDK پایتون: `list_subagents()`،`get_subagent_messages()`برای خواندن نقل نامه های زیر

### فروشگاه جلسات

برتری پروتکل با TypeScript:

- `append(session_id, message)` یک نوبت اضافه کنید.
- `load(session_id)` بازسازي مکالمه
- `list_sessions()` شمارش
- `delete(session_id)` با جلسات زیربنایی
- `list_subkeys(session_id)` کلید های زیرنویس را لیست کنید.

`--session-mirror`(بندر CLI) نقل را به یک فایل خارجی در حالی که جریان می یابد، برای تنظیم خطا بازتاب می کند.

### هک ها

هک های چرخه عمر شما می توانید ثبت نام کنید:

- `PreToolUse`،`PostToolUse` تماس با دروازه یا ابزار حسابرسی
- `SessionStart`،`SessionEnd` راه اندازی و تخریب
- `UserPromptSubmit` قبل از اینکه مدل آن را ببیند، بر روی ورودی کاربر عمل کند.
- `PreCompact` قبل از فشرده سازی زمینه اجرا کنید.
- `Stop` تمیز کردن در خروج مامور
- `Notification` هشدار های کانال جانبی

این ها نحوه ی افزایشی عمل و کار (مرجع برنامه درسی مرحله 14) و سیستم های مشابه هستند.

### زمینه ردیابی W3C

دامنه های OTel فعال در تماس گیرنده از طریق عنوان های زمینه W3C CLI گسترش می یابد. کل ردیابی چند فرآیند به عنوان یک ردیابی در پس زمینه شما ظاهر می شود.

### کلاود ماموران را مدیریت کرد

گزینه میزبانی شده (بهترین`managed-agents-2026-04-01`) کار طولانی مدت از همبستگی، ذخیره سازی سریع داخلی، فشرده سازی داخلی. کنترل تجارت برای زیرساخت های مدیریت شده.

## آن را بسازید

`code/main.py`شکل SDK را در stdlib پیاده سازی می کند:

- `Tool`،`ToolRegistry`با ساخت`read_file`،`write_file`،`list_dir`. .
- `Subagent` زمینه خصوصی، اجرا جداگانه، نتایج بازگردانده شده.
- `SessionStore` اضافه کردن، بارگذاری، لیست، حذف، list_subkeys.
- `Hooks` `pre_tool_use`،`post_tool_use`،`session_start`،`session_end`. .
- یک نمایش: عامل اصلی 3 زیرنویس را در موازی (هر یک جداگانه) تولید می کند، نتایج را جمع می کند، جلسه ادامه دارد.

اجرا کن

```
python3 code/main.py
npx tsx code/main.ts
```

ردیابی از تعزیر زمینه زیر (حجم زمینه آرکیستراتور محدود می ماند) ، اجرای هوک و دوام جلسه را نشان می دهد.

## تمرینات

1. یک اسپونر زیربنج را اضافه کنید که 20 کار را به گروه های 5 زیربنج متوازی تقسیم می کند. اندازه گیری اندازه زمینه آرکیستراتور در مقابل یک در هر کار.
2. اجرای یک`PreToolUse`اين حد نرخ رو هم بگير`write_file`تماس ها (5 دقیقه در هر جلسه) رفتار را ردیابی کنید.
3. سیم`list_subkeys`. تا یک درخت زیرکاره بسازیم . گره گیره شدن به چه شکلی است ؟
4. اسباب بازي رو به حقيقت بگير`claude-agent-sdk`بسته پایتون. چه تغییری در ثبت ابزار وجود دارد؟
5. تو دوکلوگ هاي "کلود" اداره شده رو بخوني، چه وقت از خود میزبانی به اداره شده ميري؟

## اصطلاحات کلیدی

| Term | What people say | What it actually means |
|------|----------------|------------------------|
| Agent SDK | "Claude Code as a library" | Harness shape: tools, MCP, hooks, subagents, session store |
| Subagent | "Child agent" | Separate context, own budget; results bubble up |
| Session store | "Conversation DB" | Persist, load, list, delete turns with subagent cascade |
| Hook | "Lifecycle callback" | Pre/post tool, session, prompt submit, compact, stop |
| W3C trace context | "Cross-process trace" | Parent span propagates into CLI subprocess |
| Managed Agents | "Hosted harness" | Anthropic-hosted long-running async work |
| `--session-mirror` | "Transcript mirror" | Writes session turns to an external file as they stream |
| MCP server | "Tool surface" | External tool/resource source attached to the agent |
