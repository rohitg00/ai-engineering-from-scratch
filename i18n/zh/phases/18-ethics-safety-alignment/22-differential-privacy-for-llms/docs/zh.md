# 面向大语言模型的差分隐私

> DP-SGD 仍是标准做法——注入噪声的梯度更新提供形式化的 (epsilon, delta) 保证。计算、内存和效用方面的开销相当可观；参数高效的 DP 微调(LoRA + DP-SGD)是 2025 年的常见配置(ACM 2025)。两方面的证据相互矛盾:基于金丝雀样本的成员推断攻击(Duan et al., 2024)报告对语言模型的攻击成功率有限;训练数据提取攻击(Carlini et al., 2021; Nasr et al., 2025)则能恢复大量逐字记忆的内容。调和结论(arXiv:2503.06808,2025 年 3 月):差异在于测量对象不同——插入的金丝雀样本 vs "最易提取"的数据。新的金丝雀设计使基于损失的 MIA 无需影子模型,并实现了首次在真实数据、真实 DP 保证下训练的 LLM 的非平凡 DP 审计。替代方案:PMixED(arXiv:2403.15638)——在推理时通过对下一个词元分布的专家混合实现私有预测;DP 合成数据生成(Google Research 2024)。新兴攻击:通过 LLM 反馈的差分隐私逆转——置信度分数泄露。

## 问题所在

LLM 会记忆。Carlini et al. 2021 表明,生产级语言模型可以按需逐字复现训练文本。DP 是形式化的防御:使训练后的输出对任意单个训练样本可证明地不敏感。2024–2025 年的证据表明 DP-SGD 是必要的,但部署中采用的 ε 值可能与威胁模型不匹配。

## 核心概念

### (ε, δ)-差分隐私

若对于任意两个仅相差一个样本的数据集以及任意事件 S,随机化算法 M 满足:
P(M(D) in S) <= e^ε * P(M(D') in S) + δ,
则称 M 是 (ε, δ)-DP 的。

解释:输出分布足够接近(由 ε 参数化),以至于任何单个个体的贡献都无法被可靠地推断出来,除非以概率 δ 发生例外。

### DP-SGD

Abadi et al. 2016。标准配方:
1. 采样一个小批量(mini-batch)。
2. 计算逐样本梯度。
3. 将每个逐样本梯度裁剪到阈值 C。
4. 对裁剪后的梯度求和,并加入标准差为 σ * C 的高斯噪声。
5. 用带噪的和更新参数。

隐私代价由会计器跟踪(Moments Accountant、Rényi DP 会计器)。LLM 文献中报告的 ε 值因威胁模型、数据敏感性和效用目标而有很大差异;并不存在普适的"安全"默认 ε。已发表的示例在某些 LLM 训练场景中大致涵盖 ε ≈ 1–10,但这些仅是说明性的——并非推荐默认值。较低的 ε 通常需要更多噪声,并可能增加效用损失。

### LoRA + DP-SGD

对前沿模型进行完整的 DP-SGD 训练代价高昂。LoRA(Hu et al. 2022)将梯度更新限制在小型适配器上,从而减少逐样本梯度的存储。LoRA + DP-SGD 是 2025 年的常见配置。DP 保证仅适用于适配器;基础模型保持固定。

### 2024–2025 年的矛盾

两条证据线:

- **金丝雀 MIA(Duan et al. 2024)。** 在训练数据中插入唯一的金丝雀样本,测量成员推断攻击者能否识别它们。报告对语言模型的攻击成功率有限。暗示 MIA 很难。
- **训练数据提取(Carlini 2021、Nasr et al. 2025)。** 用前缀提示模型;测量它能否逐字恢复训练文本。报告存在大量记忆。暗示在相关意义上 MIA 很容易。

2025 年 3 月的调和(arXiv:2503.06808):两者测量的是不同的东西。MIA 在插入的金丝雀上问"样本 e 是否在 D 中?"。提取问的是"我能从 D 中恢复什么?"。对隐私而言,"最易提取"的样本才是关键;金丝雀会低估这一点,因为它们并未针对可提取性进行优化。

新的金丝雀设计。无需影子模型的基于损失的 MIA。首次对在真实数据、真实 DP 保证下训练的 LLM 进行非平凡 DP 审计。

### DP 训练的替代方案

- **PMixED(arXiv:2403.15638)。** 推理时的私有预测。对下一个词元分布使用专家混合;每个专家只见一份数据分片;聚合时加噪以实现 DP。完全避免 DP 训练。
- **DP 合成数据生成(Google Research 2024)。** 用 DP-SGD 做 LoRA 微调,采样合成数据,再在合成数据上训练下游分类器。

两者都规避了完整 DP 训练的效用代价,代价是采用不同的威胁模型。

### 通过 LLM 反馈的差分隐私逆转

2025 年的新兴攻击。利用经 DP 训练的模型的置信度分数作为预言机来重新识别个体。即使输出本身不泄露,置信度分布也可能泄露。

防御:不暴露置信度,或在暴露前对其进行截断/量化。这是 (ε, δ)-DP 训练之外的额外要求。

## 动手实践

`code/main.py` 在一个玩具二分类数据集上模拟 DP-SGD。你可以扫描噪声乘子 σ 和裁剪范数 C,并跟踪 (ε, δ) 预算与精度代价。"金丝雀攻击"会插入一个唯一的训练样本,并测量基于对数损失的检验在 DP 前后能否检测到它。

## 交付成果

本课产出 `outputs/skill-dp-audit.md`。给定某个语言模型部署的 DP 声明,它审计:(ε, δ) 值、所用的会计器、MIA 评估协议,以及置信度暴露向量是否经过评估。

## 练习

1. 运行 `code/main.py`。在 {0.5, 1.0, 2.0} 中扫描 σ,报告 (ε, δ) 与精度的权衡。找出效用崩溃的临界点。

2. 实现金丝雀插入和基于对数损失的检验。在 σ = 1.0 下测量 DP-SGD 前后的检测率。

3. 阅读 Nasr et al. 2025 关于训练数据提取的论文。为什么在中等 ε 下提取攻击的成功率不会崩溃?这对"MIA 作为评估手段"意味着什么?

4. 设计一个完全在推理时运行的 PMixED(arXiv:2403.15638)部署方案。PMixED 应对了哪些 DP-SGD 未覆盖的威胁模型?

5. 概述 DP Reversal via LLM Feedback 攻击。设计一种限制置信度分数泄露的对策,并估计其部署成本。

## 关键术语

| 术语 | 人们的说法 | 实际含义 |
|------|-----------------|------------------------|
| DP | "(ε, δ)-差分隐私" | 形式化隐私:输出分布在相邻数据集变化下保持接近 |
| DP-SGD | "注入噪声的 SGD" | 梯度裁剪 + 高斯噪声添加;标准 DP 训练方法 |
| LoRA + DP-SGD | "高效的私有微调" | 在低秩适配器上执行 DP-SGD;2025 年的标准配置 |
| MIA | "成员推断攻击" | 判断某样本是否在训练数据中的攻击 |
| Canary | "插入的水印样本" | 用于测量 DP 泄露的唯一训练样本 |
| PMixED | "私有推理混合" | 通过对下一个词元分布的专家混合实现的推理时 DP |
| DP Reversal | "置信度泄露攻击" | 利用模型置信度作为预言机进行重识别的攻击 |
