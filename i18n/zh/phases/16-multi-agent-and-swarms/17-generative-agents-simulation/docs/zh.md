# 生成式智能体与涌现式模拟

> Park 等人 2023（UIST '23，arXiv:2304.03442）构建了 **Smallville**，一个由 25 个智能体组成的沙盒，采用三部分架构：**记忆流**（memory stream，自然语言日志）、**反思**（reflection，智能体对自身记忆流生成的高层次综合）和**计划**（plan，先有日级行为，再分解为子计划）。标志性成果是情人节派对的涌现：一个被植入“想举办情人节派对”目标的智能体，在没有任何进一步脚本编写的情况下，产生了在群体中传播的邀请、协调好的赴约，派对真的发生了——而其余 24 个智能体最初对此一无所知。消融实验表明，三个组件缺一不可。文档记录的失败案例是空间规范错误（走进已打烊的商店、共用单人浴室）。这就是 2026 年智能体模拟与多智能体社会评估的参考架构。

**Type:** Learn + Build
**Languages:** Python (stdlib)
**Prerequisites:** Phase 16 · 04 (Primitive Model), Phase 16 · 13 (Shared Memory)

## 问题

大多数多智能体系统是 tightly-scripted 的团队：规划者规划、编码者编码、评审者评审。这对定义明确的任务有效。但它无法捕捉当智能体拥有记忆、优先级和开放世界时所产生的涌现式、非脚本化行为。研究、社会模拟，以及越来越多的游戏 AI，都需要这第二种类型。

Smallville 架构是这方面的基准。在 Park 2023 之前，最好的智能体模拟只是浅层的脚本跟随者；在此之后，该模式成为开放世界中生成式智能体的默认选择。如果你在 2026 年构建智能体模拟，你要么使用 Smallville 的三个组件，要么明确论证为什么不用。

## 概念

### 三个组件

**记忆流。** 一个只追加的日志，记录观察、行动、反思和计划。每条记录包含时间戳、类型、描述（自然语言）以及派生的元数据：**时近性**（recency）、**重要性**（importance，由智能体自评 1-10 分）和**相关性**（relevance，与当前查询的余弦相似度）。

```
[2026-02-14 09:12:03] observation: Isabella Rodriguez asked me if I like jazz
[2026-02-14 09:14:22] reflection:   I enjoy long conversations about music
[2026-02-14 10:05:00] plan:         Attend Isabella's Valentine's Day party tonight
```

记忆检索综合三个分数：`score = w_recency * e^(-decay * age) + w_importance * importance + w_relevance * cos_sim`。得分最高的 top-k 条目进入当前提示。

**反思。** 周期性地（每 N 条记忆或在重要事件发生时），智能体从近期记忆中生成高阶综合。反思条目会重新写入记忆流，并像其他记忆一样可被检索。这就是智能体构建“理解”的方式——该架构对长期信念的等价物。

**计划。** 自顶向下的分解。首先是大致的日级计划（“去上班，和 Klaus 吃晚餐”）。然后是小时级计划。再是行动级计划。计划是可修订的：当观察与计划相矛盾时，智能体重新规划受影响的部分。

### 为什么三者缺一不可（消融实验）

Park 等人分别去除了观察、反思和计划进行消融实验。每次消融都损害了可信度：

- 没有**观察**，智能体会遗漏上下文，基于过时的信念行动。
- 没有**反思**，智能体无法形成高阶信念；交互停留在浅层。
- 没有**计划**，行为变成反应式的噪声；目标随之消散。

人类评分者给出的可信度分数在三者齐备时最高；去掉任何一个都会产生可测量的退化。

### 情人节涌现

一个智能体，Isabella Rodriguez，被植入目标“想在 2 月 14 日下午 5 点在 Hobbs Cafe 举办情人节派对”。其他 24 个智能体没有收到任何此类植入。在模拟的数天中：

1. Isabella 的计划包含邀请他人。
2. 每个邀请成为邻居记忆流中的一条观察。
3. 该邻居的反思产生信念：“Isabella 要举办派对。”
4. 邻居的计划纳入“2 月 14 日参加派对”。
5. 邻居告诉其他邻居。邀请在没有中央协调的情况下传播。
6. 2 月 14 日下午 5 点，多个智能体聚集在 Hobbs Cafe。

这就是技术意义上的涌现：系统级行为（一场派对）从局部交互（双向邀请 + 个体规划）中产生，而没有中央编排者。

### 文档记录的失败模式

Park 等人明确记录了：

- **空间规范错误。** 智能体走进已打烊的商店。智能体试图使用同一间单人浴室。智能体在非用餐的房间里吃饭。模型无法仅从环境中推断社会-物理规范。
- **记忆溢出。** 深度模拟运行导致记忆检索成本增长。实用的补救措施：周期性记忆压缩（总结并修剪）以及对低重要性条目施加衰减。
- **反思幻觉。** 反思可能编造记忆流中不存在的关系。缓解措施：在反思提示中包含源记忆 id，并在检索时进行验证。

这些是与生产相关的失败模式：任何 2026 年的智能体模拟都会继承它们。

### 三组件实现规则

1. **记忆是只追加的。** 永远不要修改记忆条目。更正以新条目形式写入。
2. **重要性评分很廉价。** 在写入时调用 LLM 评 1-10 分的重要性。缓存该分数。
3. **检索是排序的，而非过滤的。** 按综合分数取 top-k；不要使用硬过滤（会丢失上下文）。
4. **反思周期性运行。** 当未处理记忆的重要性总和超过阈值（例如 150）时触发。
5. **计划可修订。** 当新观察与计划相矛盾时，只重新生成受影响的部分，而不是整个计划。

### Smallville 之外的生成式智能体

2024-2026 年的后续文献扩展了该架构：

- **面向政策 / 市场研究的多智能体社会模拟。** 类 Smallville 的群体模拟用户对功能特性的响应行为。比 A/B 测试更快；准确性尚有争议。
- **游戏 NPC AI。** 采用 Smallville 智能体的 RPG 产生涌现式故事线，而非脚本化任务。
- **生成式智能体评估基准。** 衡量指标不再是任务准确率，而是长时间运行中行为的可信度 + 连贯性。

该架构是参考标准。扩展方案替换组件（用向量库做记忆、检索增强的反思、神经符号计划），但保留三部分结构。

### 为什么这对多智能体工程很重要

Smallville 证明了概念可行性：只要组件正确，多智能体涌现是廉价的。该架构如今已在开源模型上得到复现（更小的 LLM 会平缓地而非急剧地损失可信度）。任何需要**涌现式社会行为**的生产系统都采用这种形态。任何需要**紧密任务执行**的系统则使用本阶段早先介绍的 supervisor / roles / primitives 模式。

## 动手构建

`code/main.py` 用 stdlib Python 以及脚本化的智能体策略（不使用真实 LLM）实现三个组件。演示以微型规模复现情人节派对涌现：

- `MemoryStream` — 只追加日志，支持时近性/重要性/相关性检索。
- `reflect(stream)` — 对近期高重要性记忆进行脚本化反思。
- `plan(agent_state)` — 基于当前信念的日级与小时级计划。
- 场景：5 个智能体。智能体 1 以“下午 5 点举办派对”开始。在模拟 tick 中，邀请传播，智能体聚集。

运行：

```
python3 code/main.py
```

预期输出：逐 tick 的追踪。到最后一个 tick，5 个智能体中至少有 3 个在其计划中包含派对，并且聚集在派对地点。单一种子在没有编排者的情况下产生了协调一致的到达。

## 应用它

`outputs/skill-simulation-designer.md` 设计一个生成式智能体模拟：智能体数量、记忆模式、反思频率、计划时间跨度以及评估指标。

## 交付上线

生产级模拟的规则：

- **记忆就是数据库。** 在规模化时选择真正的存储（向量数据库、Postgres）。内存中的 stdlib 仅用于原型。
- **记录检索轨迹。** 对每个动作，记录驱动它的 top-k 记忆。这是你的调试能力。
- **为每个智能体预算 token。** 每个 tick 中每个智能体的检索 + 反思 + 计划是 O(k) 次 LLM 调用。N 个智能体 × T 个 tick × 每 tick 调用次数可能会吞噬你的预算。
- **周期性压缩记忆。** 总结并修剪低重要性条目。保留策略是设计决策，而非细节。
- **显式检测空间 / 社会规范违规。** 该架构本身不会学到这些。

## 练习

1. 运行 `code/main.py`。确认 3 个以上智能体聚集在派对。将智能体增加到 10 个——涌现仍然发生吗？
2. 移除反思步骤。行为变成什么样？与 Park 2023 的消融发现对照。
3. 引入一个相互竞争的植入目标（“Klaus 想在下午 5 点做一个研究报告”）。智能体会分裂吗，还是一个目标占主导？什么决定结果？
4. 添加空间约束：Hobbs Cafe 最多容纳 4 个智能体。模拟能否优雅地处理溢出，还是会落入“单人浴室”式的失败模式？
5. 阅读 Park 等人（arXiv:2304.03442）第 6 节（涌现行为实验）。找出一个无法在你的微型版本中复现的行为。你需要增强架构的哪个组件？

## 关键术语

| 术语 | 人们怎么说 | 它实际意味着什么 |
|------|------------------------|
| 记忆流 | “智能体的日记” | 观察行动反思计划的只追加日志。 |
| 时近性 | “记忆有多新” | 按时间年龄的指数衰减分数。 |
| 重要性 | “智能体有多在意” | 写入时自评 1-10 分。已缓存。 |
| 相关性 | “与当前查询有多相关” | 余弦相似度（基于 embedding）。 |
| 反思 | “高阶信念” | 从近期记忆生成的综合，作为新记忆重新写入。 |
| 计划 | “日/小时/行动分解” | 自顶向下的计划树。观察相矛盾时可修订。 |
| Smallville | “Park 2023 的沙盒” | 产生了情人节涌现的 25 智能体模拟。 |
| 可信度 | “质量指标” | 人类评分者对行为是否像一个可信智能体的打分。 |
