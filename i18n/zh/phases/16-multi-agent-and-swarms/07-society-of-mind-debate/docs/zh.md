# 心智社会与多智能体辩论

> Minsky 在 1986 年提出的前提——智能是一个由专家组成的社会——每隔十年就会被重新发现一次。2023 年，Du 等人将其转化为一个具体的算法：多个 LLM 实例提出答案、阅读彼此的答案、进行批评并更新。经过 N 轮迭代，它们收敛到一个共识，在六项推理与事实性任务上超越了 zero-shot CoT 和自我反思。有两个发现很重要：**多个智能体**和**多轮交互**各自独立地做出贡献。多智能体社会优于单智能体的独白；多轮交互优于一次性投票。

**Type:** Learn + Build
**Languages:** Python (stdlib)
**Prerequisites:** Phase 16 · 04 (Primitive Model)
**Time:** 约 60 分钟

## 问题

Self-consistency——对同一个模型采样多次并取多数答案——是你可以附加的最廉价的推理改进手段。它有效，但很快就会饱和。你即使把采样数量翻倍，也看不到另一次有意义的提升。

辩论打破了这种饱和。不同于从一个模型获取 N 个独立样本，N 个智能体会阅读彼此的推理并修订。样本之间的相关性下降（它们不再是 i.i.d. 的），并且收敛点常常是正确的，而 i.i.d. 投票却自信地给出了错误答案。

## 概念

### Du 等人 2023 年的算法

来自 arXiv:2305.14325（ICML 2024）：

1. N 个智能体各自对该问题产出一个初始答案。
2. 对于第 r = 2..R 轮：向每个智能体展示其他智能体第 r-1 轮的答案，并要求“考虑到这些，给出你的更新答案。”
3. R 轮之后，对最终答案进行多数投票。

该论文在 MMLU、GSM8K、传记、MATH 和事实性基准上进行了测试。辩论始终优于 CoT 和 Self-Reflection。

### 两个独立的旋钮

同一篇论文的消融实验：

- **仅增加智能体数量**（1 轮，N 个答案的多数投票）在大多数任务上优于单智能体，但会趋于平缓。
- **仅增加轮数**（1 个智能体查看自己先前的推理）几乎没有帮助——这是反思的已知弱点。
- **两者结合**才产生大幅提升。多智能体之间的多轮交互是收益的来源。

### 为什么有效

两个机制：

1. **接触到分歧。** 当一个智能体看到另一个智能体得出不同结论的推理链时，它必须要么为其辩护，要么进行更新。无论哪种方式，第 r+1 轮的上下文都比第 r 轮更丰富。
2. **相关误差的减少。** 在 self-consistency 中，所有样本都来自同一个模型，因此误差是相关的——你平均后得到一个自信但错误的答案。不同的模型或不同的种子可以去除相关性。不同的*经过辩论的观点*能进一步去除相关性。

### 异构辩论

A-HMAD 及相关后续工作为不同智能体使用*不同的基础模型*。Llama + Claude + GPT 的辩论减少了单一文化崩溃（第 26 课），因为一个模型家族的相关误差不会被其他家族共享。

缺点：一个弱模型参与辩论可能把共识拖向它的错误答案（参见 "Should we be going MAD?"，arXiv:2311.17371）。

### NLSOM——129 个智能体的扩展

Zhuge 等人（"Mindstorms in Natural Language-Based Societies of Mind," arXiv:2305.17066）将这一想法扩展到 129 个成员的社会。结果是：专业化和自组织随规模而涌现，并且该系统在视觉问答等任务上超越了单智能体。

### 失败模式

- **谄媚级联。** 所有智能体都服从听起来最自信的那个智能体。辩论坍缩为最响亮的声音。通过提示设定对抗性角色（“一个智能体必须为相反立场辩护”）会有所帮助。
- **话题漂移。** 多轮辩论会偏离原始问题。缓解方法：每轮都重新注入问题。
- **计算量爆炸。** N 个智能体 × R 轮 = N·R 次 LLM 调用，每次调用的上下文都在增长。一场 5 个智能体、5 轮的辩论是 25 次上下文不断增长的调用。每个问题的成本可能超过单次 CoT 调用的 10 倍。

## 动手构建

`code/main.py` 在一道数学题上运行一场 3 个智能体 × 3 轮的辩论，其中每个智能体从一个不同的（可能是错误的）答案开始。智能体是脚本化的——每个智能体通过按脚本化的置信度对邻居的答案加权求平均来进行“更新”。逐轮日志中可以观察到收敛。

该演示展示了两个关键效应：

- 一轮交互就能使智能体更接近正确答案。
- 第 2 轮之后的额外轮次显示出边际收益递减（与 Du 等人的平台期一致）。

运行：

```
python3 code/main.py
```

## 使用它

`outputs/skill-debate-configurator.md` 为新任务配置一场辩论：智能体数量、轮数、异构性（相同模型 vs 混合模型）、角色分配（对称 vs 一个对抗者）。它还会在运行前估算 token 成本。

## 上线部署

如果你要部署辩论：

- **轮数上限设为 3。** Du 等人表明 3 轮即可捕获大部分收益。更多只是成本，不是质量。
- **智能体数量上限设为 5。** 超过 5 个后，上下文膨胀和成本将占据主导。
- **默认使用异构。** 池中至少包含两个不同的基础模型。
- **设置对抗位。** 一个智能体被提示无条件持不同意见。可打破谄媚。
- **记录每一轮。** 隐藏中间轮次的辩论系统无法调试或审计。

## 练习

1. 运行 `code/main.py`，然后将轮数设为 5 并观察边际收益递减。到第几轮时额外的收敛停止了？
2. 添加第四个具有对抗角色的智能体：总是与当前多数意见不一致。这会破坏还是改善收敛？
3. 绘制（打印）每轮的一致性得分（多数答案上的智能体比例）。它何时达到 1.0，这是否等同于“正确”？
4. 阅读 Du 等人第 4 节的消融实验。用这段代码复现“仅智能体” vs “仅轮数” vs “两者结合”的结果。
5. 阅读 "Should we be going MAD?"（arXiv:2311.17371），列出两种轮转之外的辩论变体——例如裁判主导、辩论链、对抗式。

## 关键术语

| 术语 | 人们怎么说 | 实际含义 |
|------|----------------|------------------------|
| Society of Mind | "Minsky 的想法" | 智能是相互作用的专家；1986 年的框架如今通过 LLM 辩论得以实现。 |
| 多智能体辩论 | "智能体们争论" | N 个智能体提出观点、相互批评、经过 R 轮修订，最后多数投票。 |
| 共识 | "他们达成一致" | 并非认知上的真理——只是多数答案上的比例。可能自信地出错。 |
| 轮次 | "交互步骤" | 一轮 = 每个智能体阅读其他智能体并更新一次。 |
| 异构辩论 | "混合模型家族" | 使用不同的基础模型以去除误差相关性。 |
| 谄媚级联 | "每个人都同意最响亮的那个人" | 一种辩论失败模式：智能体无论对错都服从最自信的智能体。 |
| NLSOM | "129 个智能体的社会" | 基于自然语言的心智社会；Zhuge 等人的扩展版本。 |
| 相关误差 | "同一个模型，同样的 bug" | 为什么 self-consistency 会饱和；跨不同观点的辩论可去除相关性。 |
