# 機器學習統計學

> 統計學能幫你判斷模型是否真的有效，還是只是運氣好。

**Type:** Build
**Language:** Python
**Prerequisites:** Phase 1, Lessons 06 (Probability and Distributions), 07 (Bayes' Theorem)
**Time:** ~120 minutes

## Learning Objectives｜學習目標

- 從頭計算描述統計量、Pearson／Spearman 相關係數與共變異數矩陣
- 執行假設檢定（t 檢定、卡方檢定），並正確解讀 p 值與信賴區間
- 使用自助法重抽樣，在不假設分布型態的情況下，為任何指標建立信賴區間
- 使用效果量區分統計顯著性與實際重要性

## The Problem｜問題

你訓練了兩個模型。模型 A 在測試集上的分數是 0.87，模型 B 是 0.89。你部署了模型 B。三週後，正式環境的指標卻比之前更差。發生了什麼事？

模型 B 實際上並沒有勝過模型 A。0.02 的差異只是雜訊。你的測試集太小、變異太大，或兩者皆是。你把隨機波動包裝成進步，然後上線了。

這種情況不斷發生：Kaggle 排行榜洗牌、無法重現的論文，以及只靠幾百筆樣本就宣布勝出的 A/B 測試。根本原因總是相同：有人略過了統計分析。

統計學提供區分訊號與雜訊的工具。它能告訴你差異是否真實、應該有多大把握，以及需要多少資料才能相信結果。每條機器學習管線、每次模型比較與每個實驗都需要統計分析。沒有它，你只是在猜。

## The Concept｜核心概念

### 描述統計：摘要呈現資料

在建立模型之前，你需要先了解資料的樣貌。描述統計會將資料集濃縮成少數幾個數值，呈現資料的形狀。

**集中趨勢的測量值**回答「中間在哪裡？」

```text
平均數：所有數值加總後除以個數
        mu = (1/n) * sum(x_i)

中位數：排序後位於中間的數值
        對離群值較穩健。例如 [1, 2, 3, 4, 1000] 的平均數是 202
        但中位數是 3。

眾數：出現次數最多的數值
        適用於類別資料；對連續資料通常資訊有限。
```

平均數是平衡點，中位數則是正中間。兩者差距大時，表示分布偏斜。收入分布的平均數遠大於中位數（少數億萬富翁使分布右偏）；訓練期間的損失分布則常見平均數遠小於中位數（容易的樣本使分布左偏）。

**離散程度的測量值**回答「資料分散得多開？」

```text
變異數：各數值與平均數之差平方的平均
            sigma^2 = (1/n) * sum((x_i - mu)^2)

標準差：變異數的平方根
                     sigma = sqrt(sigma^2)
                     單位與資料相同，因此較容易解讀。

全距：      最大值 - 最小值
            容易受離群值影響，幾乎不應單獨使用。

IQR：       Q3 - Q1（四分位距）
            中間 50% 資料的範圍。
            對離群值較穩健，用於盒鬚圖與離群值偵測。
```

**百分位數**會將排序後的資料分成 100 個等份。第 25 百分位數（Q1）表示 25% 的數值低於這個位置；第 50 百分位數就是中位數；第 75 百分位數是 Q3。

```text
延遲監控範例：
  P50 = 延遲中位數          （典型使用者體驗）
  P95 = 第 95 百分位數      （偏差，但非最糟情況）
  P99 = 第 99 百分位數      （尾端延遲，常是中位數的 10 倍）
```

在機器學習中，你會用百分位數觀察推論延遲、預測信心分布與誤差分布。平均誤差低，但 P99 誤差很差的模型，可能不適合安全關鍵應用。

**樣本統計量與母體統計量。** 從樣本計算變異數時，分母要用 (n-1)，而不是 n。這稱為 Bessel 修正，可補償樣本平均數不等於母體平均數的情況。分母使用 n 會持續低估母體真實變異數；使用 (n-1) 則能得到無偏估計。

```text
母體變異數：sigma^2 = (1/N) * sum((x_i - mu)^2)
樣本變異數：s^2     = (1/(n-1)) * sum((x_i - x_bar)^2)
```

實務上，如果 n 很大（數千筆樣本），差異可以忽略；如果 n 很小（幾十筆樣本），差異就很重要。

### 相關性：變數如何一起變動

相關性衡量兩個變數之間線性關係的強度與方向。

**Pearson 相關係數**衡量線性關聯：

```text
r = sum((x_i - x_bar)(y_i - y_bar)) / (n * s_x * s_y)

r = +1：完全正向線性關係
r = -1：完全負向線性關係
r =  0：沒有線性關係（但可能存在非線性關係！）

範圍：[-1, 1]
```

Pearson 假設兩個變數之間的關係是線性的，而且兩個變數大致符合常態分布。它容易受離群值影響；單一極端資料點就可能讓 r 從 0.1 變成 0.9。

**Spearman 等級相關係數**衡量單調關聯：

```text
1. 將每個數值替換成排名（1、2、3、...）
2. 對排名計算 Pearson 相關係數

Spearman 能捕捉所有單調關係，不只線性關係。
若 y = x^3，Pearson 得到 r < 1，但 Spearman 得到 rho = 1。
```

**何時使用哪一種：**

```text
Pearson：  兩個變數皆為連續型且大致符合常態分布。
          你特別關心線性關係。
          沒有極端離群值。

Spearman： 順序資料（排名、評分）。
          資料不符合常態分布。
          懷疑存在單調但非線性的關係。
          有離群值。
```

**重要原則：**相關不代表因果。冰淇淋銷售量與溺水死亡數有相關性，是因為兩者都會在夏天增加。模型準確率和參數數量也可能相關，但增加參數不會自動提升準確率（參見過度擬合）。

### 共變異數矩陣

兩個變數的共變異數衡量它們如何一起變動：

```text
Cov(X, Y) = (1/n) * sum((x_i - x_bar)(y_i - y_bar))

Cov(X, Y) > 0：X 與 Y 通常會一起增加
Cov(X, Y) < 0：X 增加時，Y 通常會減少
Cov(X, Y) = 0：沒有線性共同變動
```

若有 d 個特徵，共變異數矩陣 C 就是 d x d 矩陣，其中 C[i][j] = Cov(feature_i, feature_j)。對角線元素 C[i][i] 是各特徵的變異數。

```text
C = | Var(x1)      Cov(x1,x2)  Cov(x1,x3) |
    | Cov(x2,x1)  Var(x2)      Cov(x2,x3) |
    | Cov(x3,x1)  Cov(x3,x2)  Var(x3)     |

性質：
  - 對稱：C[i][j] = C[j][i]
  - 正半定：所有特徵值 >= 0
  - 對角線 = 變異數
  - 非對角線 = 共變異數
```

**與 PCA 的關聯。** PCA 會對共變異數矩陣進行特徵分解。特徵向量是主成分（變異數最大的方向）；特徵值則代表每個成分涵蓋多少變異數。這正是第 10 課介紹的內容，而現在你也能理解為什麼要分解共變異數矩陣：它編碼了資料中所有成對的線性關係。

**與相關性的關聯。** 相關矩陣是標準化變數（各自除以標準差）所形成的共變異數矩陣。相關係數會將共變異數正規化，因此所有數值都落在 [-1, 1]。

### 假設檢定

假設檢定是一套在不確定性下做決策的方法。你先提出主張，再收集資料，並判斷資料是否與這項主張一致。

**檢定設定：**

```text
虛無假設（H0）：        預設假設，通常表示「沒有影響」
對立假設（H1）：        你想要證明的主張

範例：
  H0：模型 A 與模型 B 的準確率相同
  H1：模型 B 的準確率高於模型 A
```

**p 值**是在 H0 為真的前提下，觀察到目前這麼極端或更極端資料的機率。它不是 H0 為真的機率。這是統計學中最常見的誤解。

```text
p 值 = P（在 H0 為真時，觀察到這麼極端的資料）

若 p 值 < alpha（通常為 0.05）：
    拒絕 H0，結果達到「統計顯著」。
若 p 值 >= alpha：
    無法拒絕 H0，證據不足。
    這不代表 H0 為真。
```

**信賴區間**會提供某個參數的合理取值範圍：

```text
平均數的 95% 信賴區間：
    x_bar +/- z * (s / sqrt(n))

z = 95% 信賴水準時為 1.96

解讀：如果你重複這項實驗許多次，計算出的區間中有 95%
會包含母體真實平均數。這不代表真實平均數有 95% 機率
落在這個特定區間中。
```

信賴區間的寬度反映估計精確度。區間寬表示不確定性高；區間窄表示估計精確（但若資料有偏誤，仍不代表準確）。

### t 檢定

t 檢定用來比較平均數，分成幾種形式。

**單樣本 t 檢定：**母體平均數是否不同於假設值？

```text
t = (x_bar - mu_0) / (s / sqrt(n))

自由度 = n - 1
```

**雙樣本 t 檢定（獨立樣本）：**兩組的平均數是否不同？

```text
t = (x_bar_1 - x_bar_2) / sqrt(s1^2/n1 + s2^2/n2)

這是 Welch t 檢定，不假設變異數相等。
除非有明確理由假設變異數相等，否則一律使用 Welch t 檢定。
```

**成對 t 檢定：**測量值成對出現時使用（例如用相同資料切分評估同一組模型）：

```text
每一對都計算 d_i = x_i - y_i
接著以 mu_0 = 0 為基準，對 d_i 值執行單樣本 t 檢定
```

在機器學習中，成對 t 檢定很常見：你讓兩個模型分別使用相同的 10 個交叉驗證切分，再逐對比較分數。

### 卡方檢定

卡方檢定用來檢查觀察到的次數是否符合預期次數，適合類別資料。

```text
chi^2 = sum((observed - expected)^2 / expected)

範例：語言模型的輸出分布是否符合
各類別的訓練分布？

類別       觀察次數   預期次數
正向          120        100
負向           80        100
chi^2 = (120-100)^2/100 + (80-100)^2/100 = 4 + 4 = 8

自由度為 1 時，chi^2 = 8 對應 p < 0.005。
差異達到統計顯著。
```

### 機器學習模型的 A/B 測試

機器學習中的 A/B 測試和網頁 A/B 測試並不相同。比較模型時有幾項特別需要注意的地方：

```text
1. 相同測試集：兩個模型都必須使用相同資料評估。
                 使用不同測試集就無法公平比較。

2. 多個指標：僅看準確率不夠，還需要精確率、
                 召回率、F1、延遲與公平性指標。

3. 變異：      使用交叉驗證或自助法估計
                 各項指標的變異，而非只看單一估計值。

4. 資料洩漏：  若測試集曾用於模型選擇，
                 比較結果就會有偏誤。請保留最終測試集。
```

**執行步驟：**

```text
1. 定義指標與顯著水準（alpha = 0.05）
2. 讓兩個模型使用相同的 k 折交叉驗證切分
3. 收集成對分數：[(a1, b1), (a2, b2), ..., (ak, bk)]
4. 計算差值：d_i = b_i - a_i
5. 對差值執行成對 t 檢定
6. 檢查平均差異是否顯著異於 0
7. 計算平均差異的信賴區間
8. 計算效果量（Cohen’s d），判斷實際重要性
```

### 統計顯著性與實際重要性

結果可能達到統計顯著，實際上卻毫無意義。資料量夠大時，即使極小的差異也會達到統計顯著。

```text
範例：
  模型 A 準確率：0.9234
  模型 B 準確率：0.9237
  n = 1,000,000 筆測試樣本
  p 值 = 0.001

統計上顯著嗎？是。
實際上重要嗎？提升 0.03% 不值得付出
部署新模型的工程成本。
```

**效果量**衡量差異有多大，不受樣本數影響：

```text
Cohen’s d = (mean_1 - mean_2) / pooled_std

d = 0.2：小效果量
d = 0.5：中效果量
d = 0.8：大效果量
```

務必同時報告 p 值與效果量。p 值告訴你差異是否真實；效果量則告訴你差異是否重要。

### 多重比較問題

同時檢驗許多假設時，有些結果可能只是碰巧「顯著」。若以 alpha = 0.05 檢驗 20 項，即使沒有任何真實效果，預期也會出現 1 個偽陽性。

```text
P（至少出現一個偽陽性）= 1 - (1 - alpha)^m

m = 20 次檢定，alpha = 0.05：
P（偽陽性）= 1 - 0.95^20 = 0.64

至少出現一個偽陽性的機率是 64%。
```

**Bonferroni 修正：**將 alpha 除以檢定次數。

```text
修正後的 alpha = alpha / m = 0.05 / 20 = 0.0025

只有 p 值 < 0.0025 時才拒絕 H0。
保守但簡單；適用於檢定彼此獨立的情況。
```

在機器學習中，比較模型的多個指標、測試許多超參數組合，或在多個資料集上評估時，都要注意這個問題。

### 自助法

自助法會透過有放回的重抽樣，估計統計量的抽樣分布。它不需要對資料的底層分布做任何假設。

**演算法：**

```text
1. 你有 n 筆資料
2. 有放回抽取 n 筆樣本（有些資料會重複出現，
   有些資料則不會被抽到）
3. 在這份自助樣本上計算統計量
4. 重複 B 次（通常 B = 1000 到 10000）
5. 自助統計量的分布可近似
   統計量的抽樣分布
```

**自助法信賴區間（百分位數法）：**

```text
將 B 個自助統計量排序
95% CI = [第 2.5 百分位數，第 97.5 百分位數]
```

**自助法對機器學習的重要性：**

```text
- 測試集準確率是點估計；自助法能提供
  信賴區間。
- 不能假設指標分布符合常態（尤其是
  AUC、F1、Precision@k）。
- 自助法適用於任何統計量：中位數、兩個平均數的比值，
  或兩個模型之間 AUC 的差異。
- 不需要封閉形式的公式。
```

**使用自助法比較模型：**

```text
1. 你有模型 A 與模型 B 在相同測試集上的預測結果
2. 每次自助重抽樣時：
   a. 有放回地重新抽取測試索引
   b. 在重抽樣資料上計算 metric_A 與 metric_B
   c. 儲存 diff = metric_B - metric_A
3. 差異的 95% CI：
   [差異的第 2.5 百分位數，第 97.5 百分位數]
4. 若區間不包含 0，差異就達到統計顯著
```

相較於成對 t 檢定，自助法更穩健，因為它不需要對分布做任何假設。

### 參數與無母數檢定

**參數檢定**假設資料符合特定分布（通常是常態分布）：

```text
t 檢定：        假設資料符合常態分布（或 n 大時依 CLT）
ANOVA：         假設常態分布且變異數相等
Pearson r：     假設雙變量常態分布
```

**無母數檢定**不對分布型態做假設：

```text
Mann-Whitney U：    比較兩組資料（取代獨立樣本 t 檢定）
Wilcoxon 符號等級：比較成對資料（取代成對 t 檢定）
Spearman rho：      依排名計算相關性（取代 Pearson）
Kruskal-Wallis：    比較多組資料（取代 ANOVA）
```

**適合使用無母數檢定的情況：**

```text
- 樣本數小（n < 30），而且資料明顯不符合常態分布
- 順序資料（評分、排名）
- 無法移除的大型離群值
- 偏斜分布
```

**適合使用參數檢定的情況：**

```text
- 樣本數大（CLT 會讓檢定統計量近似常態分布）
- 資料大致對稱，沒有極端離群值
- 需要較高檢定力（更容易偵測真實差異）
```

在機器學習實驗中，n 通常很小（只有 5 或 10 個交叉驗證切分），因此 Wilcoxon 符號等級檢定等無母數方法，往往比 t 檢定更合適。

### 中央極限定理的實務意涵

中央極限定理（CLT）指出，隨著 n 增加，樣本平均數的分布會趨近常態分布，與母體原本的分布無關。

```text
若 X_1、X_2、...、X_n 為 iid，平均數為 mu、變異數為 sigma^2：

    X_bar ~ Normal(mu, sigma^2 / n)    當 n -> infinity

多數情況下 n >= 30 即可。
若分布高度偏斜，可能需要 n >= 100。
```

**這對機器學習的重要性：**

```text
1. 可用於合理化彙總指標的信賴區間與 t 檢定
2. 說明為什麼對交叉驗證各折結果取平均能得到穩定估計，
   即使每一折的數值差異很大
3. 小批次梯度下降有效，是因為批次平均梯度
   近似真實梯度（CLT 的實際應用）
4. 集成方法：平均多個模型的預測，
   比單一模型的輸出更穩定
```

**CLT 不會做到的事：**

```text
- 它不會讓資料本身變成常態分布；變成常態的是樣本平均數。
- 不適用於變異數無限大的重尾分布
  （例如 Cauchy 分布）。
- 不適用於彼此相依的資料（未經修正的時間序列）。
```

### 機器學習論文常見的統計錯誤

1. **使用訓練集測試。** 這會導致過度擬合。務必保留模型訓練期間從未看過的資料。

2. **沒有信賴區間。** 只報告單一準確率、沒有呈現不確定性，會讓結果無法重現或驗證。

3. **忽略多重比較。** 測試 50 種設定後，不做修正就只報告最佳結果，會提高偽陽性率。

4. **混淆統計顯著性與實際重要性。** 準確率只提升 0.01% 時，即使 p 值是 0.001，也沒有實際意義。

5. **對不平衡資料使用準確率。** 若資料集有 99% 是負類，即使模型什麼也沒學到，準確率仍可達 99%。請改用精確率、召回率、F1 或 AUC。

6. **挑選有利指標。** 只報告模型表現勝出的指標。誠實的評估應呈現所有相關指標。

7. **訓練／測試切分之間資訊洩漏。** 例如切分前就先做正規化，或用未來資料預測過去。

8. **測試集太小，且沒有變異估計。** 只用 100 筆樣本評估，就宣稱提升 2%，那是雜訊而非訊號。

9. **資料不獨立，卻假設彼此獨立。** 例如同一位病患的多張醫學影像，或同一份文件中的多個句子。同一群組內的觀測值彼此相關。

10. **P-hacking（操弄 p 值）。** 不斷嘗試不同檢定、子集或排除條件，直到得到 p < 0.05。這種結果只是反覆搜尋後產生的假象。

## Key Terms｜關鍵術語

| 術語 | 定義 |
|---|---|
| Mean（平均數） | 數值總和除以個數，容易受離群值影響。 |
| Median（中位數） | 排序後位於中間的數值，對離群值較穩健。 |
| Standard deviation（標準差） | 變異數的平方根，以原始資料的單位衡量離散程度。 |
| Percentile（百分位數） | 資料中有指定百分比低於此值的數值。 |
| IQR（四分位距） | Q3 減去 Q1，衡量中間 50% 資料的離散程度。 |
| Pearson correlation（Pearson 相關係數） | 衡量兩個變數的線性關聯，範圍為 [-1, 1]。 |
| Spearman correlation（Spearman 相關係數） | 使用排名衡量單調關聯。 |
| Covariance matrix（共變異數矩陣） | 包含所有特徵兩兩共變異數的矩陣。 |
| Null hypothesis（虛無假設） | 預設沒有作用或沒有差異的假設。 |
| p-value（p 值） | 在虛無假設為真的前提下，觀察到目前這麼極端資料的機率。 |
| Confidence interval（信賴區間） | 在指定信賴水準下，某個參數可能值的範圍。 |
| t-test（t 檢定） | 使用 t 分布檢驗平均數之間是否有顯著差異。 |
| Chi-squared test（卡方檢定） | 檢驗觀察次數與預期次數是否有差異。 |
| Effect size（效果量） | 不受樣本數影響的差異大小，常用 Cohen’s d 衡量。 |
| Bonferroni correction（Bonferroni 修正） | 以檢定次數除顯著性門檻，控制偽陽性。 |
| Bootstrap（自助法） | 以有放回重抽樣估計抽樣分布。 |
| Type I error（第一類錯誤） | 偽陽性：H0 為真卻拒絕 H0。 |
| Type II error（第二類錯誤） | 偽陰性：H0 為假卻未能拒絕 H0。 |
| Statistical power（統計檢定力） | 正確拒絕錯誤 H0 的機率，等於 1 減去第二類錯誤率。 |
| Central limit theorem（中央極限定理） | 樣本數增加時，樣本平均數會趨近常態分布。 |
| Parametric test（參數檢定） | 假設資料符合特定分布（通常是常態分布）的檢定。 |
| Non-parametric test（無母數檢定） | 不假設特定分布，使用排名或符號進行檢定。 |
