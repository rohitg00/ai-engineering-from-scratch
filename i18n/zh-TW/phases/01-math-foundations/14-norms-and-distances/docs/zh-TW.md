# 範數與距離

> 距離函數定義了「相似」的意義。選錯指標，後續所有結果都可能出問題。

**Type:** Build
**Language:** Python
**Prerequisites:** Phase 1, Lessons 01 (Linear Algebra Intuition), 02 (Vectors, Matrices & Operations)
**Time:** ~90 minutes

## Learning Objectives｜學習目標

- 從頭實作 L1、L2、餘弦、Mahalanobis、Jaccard 與編輯距離函數
- 為指定的機器學習任務挑選適合的距離指標，並說明其他選項為何不適用
- 說明 L1 與 L2 範數如何連結 LASSO、Ridge 正則化及其幾何限制區域
- 示範同一份資料使用不同指標時，最近鄰也會不同

## The Problem｜問題

你有兩個向量。它們可能是詞嵌入、使用者個人檔案，也可能是像素陣列。你想知道：它們有多接近？

答案完全取決於你選擇哪個距離函數。同兩個資料點在一種指標下可能互為最近鄰，在另一種指標下卻相距甚遠。KNN 分類器、推薦引擎、向量資料庫、分群演算法與損失函式，全都仰賴這項選擇。選錯了，模型最佳化的目標也會跟著錯。

沒有一種距離適用所有情況。L2 適合空間資料；NLP 常用餘弦相似度；Jaccard 適合集合；編輯距離適合字串；Mahalanobis 距離會納入相關性；Wasserstein 距離則衡量機率質量的搬移。每種指標都代表對「相似」的不同假設。

本課程會從頭建構各種主要距離函數，說明每種函數適用的情境，並示範同一份資料如何因距離指標不同而產生完全不同的最近鄰。

## The Concept｜核心概念

### 範數：衡量向量大小

範數用來衡量向量的「大小」。任兩個向量的距離函數，都能寫成兩者差值的範數：d(a, b) = ||a - b||。因此，理解範數也就是理解距離。

### L1 範數（曼哈頓距離）

L1 範數會加總所有分量的絕對值。

```text
||x||_1 = |x_1| + |x_2| + ... + |x_n|
```

它又稱曼哈頓距離，因為它描述的是在城市街廓中沿著座標軸行走的距離；不能走對角線。

```text
點 A = (1, 1)
點 B = (4, 5)

L1 距離 = |4-1| + |5-1| = 3 + 4 = 7

在格線上，你要向東走 3 個街廓，再向北走 4 個街廓。
```

L1 的適用情境：
- 高維稀疏資料（文字特徵、one-hot 編碼）
- 希望降低離群值影響時（單一巨大差異不會主導結果）
- 特徵選取問題（L1 正則化會促進稀疏性）

L1 正則化（Lasso）的連結：在損失函式加入 ||w||_1，會懲罰權重絕對值的總和，讓較小的權重變成精確的零，藉此自動選取特徵。L1 懲罰在權重空間形成菱形限制區，其角落落在座標軸上，因此部分權重會是零。

損失函式的連結：平均絕對誤差（MAE）是預測值與目標值之間 L1 距離的平均。它對所有誤差採線性懲罰，因此比 MSE 更能抵抗離群值。

### L2 範數（歐幾里得距離）

L2 範數是直線距離，也就是各分量平方和的平方根。

```text
||x||_2 = sqrt(x_1^2 + x_2^2 + ... + x_n^2)
```

這是你在幾何課學過的距離公式，也就是將畢氏定理推廣到 n 維空間。

```text
點 A = (1, 1)
點 B = (4, 5)

L2 距離 = sqrt((4-1)^2 + (5-1)^2) = sqrt(9 + 16) = sqrt(25) = 5.0

沿著格線斜向切過去的直線距離。
```

L2 的適用情境：
- 低到中維的連續資料
- 特徵尺度相近時
- 實體距離（空間資料、感測器讀值）
- 像素層級的影像相似度

L2 正則化（Ridge）的連結：在損失函式加入 ||w||_2^2，會懲罰過大的權重。不同於 L1，它不會把權重推到零，而是依比例將所有權重縮小。L2 懲罰形成圓形限制區，座標軸上沒有尖角，因此權重通常會變小，但很少恰好為零。

損失函式的連結：均方誤差（MSE）是 L2 距離平方的平均。平方會讓大誤差受到比小誤差更重的懲罰。

```text
MAE（L1 損失）：|y - y_hat|         線性懲罰，對離群值較穩健。
MSE（L2 損失）：(y - y_hat)^2       二次懲罰，容易受離群值影響。
```

### Lp 範數：一般化的範數族

L1 與 L2 是 Lp 範數的特例：

```text
||x||_p = (|x_1|^p + |x_2|^p + ... + |x_n|^p)^(1/p)
```

p 值不同，會形成形狀不同的「單位球」（也就是距離原點為 1 的所有點所構成的集合）：

```text
p=1：    菱形       （角落落在座標軸上）
p=2：    圓形／球體 （一般的圓球）
p=3：    超橢圓     （圓角方形）
p=inf：  正方形／超立方體（平面沿著座標軸）
```

### L 無窮範數（切比雪夫距離）

當 p 趨近無窮大時，Lp 範數會收斂至各分量絕對值中的最大值。

```text
||x||_inf = max(|x_1|, |x_2|, ..., |x_n|)
```

兩點之間的距離由差異最大的那個維度決定，其他維度都不納入考量。

```text
點 A = (1, 1)
點 B = (4, 5)

L-inf 距離 = max(|4-1|, |5-1|) = max(3, 4) = 4
```

L 無窮範數的適用情境：
- 任何單一維度的最壞情況偏差都很重要時
- 棋盤遊戲（國王每次可沿任意方向走一步，依 L 無窮範數計算一步距離為 1）
- 製造公差（每個維度都必須符合規格）

### 餘弦相似度與餘弦距離

餘弦相似度衡量兩個向量之間的夾角，不考慮向量大小。

```text
cos_sim(a, b) = (a . b) / (||a||_2 * ||b||_2)
```

取值範圍為 -1（方向相反）到 +1（方向相同）。互相垂直的向量，其餘弦相似度為 0。

餘弦距離會將相似度轉換成距離：cosine_distance = 1 - cosine_similarity。取值範圍為 0（方向相同）到 2（方向相反）。

```text
a = (1, 0)    b = (1, 1)

cos_sim = (1*1 + 0*1) / (1 * sqrt(2)) = 1/sqrt(2) = 0.707
cos_dist = 1 - 0.707 = 0.293
```

為什麼 NLP 與嵌入常以餘弦相似度為主：在文字任務中，文件長度不應影響相似度。一篇談貓的文件即使是另一篇的兩倍長，也應該仍然「相似」。餘弦相似度忽略向量大小（長度），只看方向。兩篇詞彙分布相同但長度不同的文件方向相同，因此餘弦相似度為 1.0。

餘弦相似度的適用情境：
- 文字相似度（TF-IDF 向量、詞嵌入、句子嵌入）
- 大小是雜訊、方向才代表訊號的領域
- 推薦系統（使用者偏好向量）
- 嵌入搜尋（向量資料庫幾乎都使用餘弦相似度或點積）

### 點積相似度與餘弦相似度

兩個向量的點積為：

```text
a . b = a_1*b_1 + a_2*b_2 + ... + a_n*b_n
      = ||a|| * ||b|| * cos(angle)
```

餘弦相似度是將點積除以兩個向量的大小。若兩個向量都已正規化為單位向量（大小為 1），點積和餘弦相似度就相同。

```text
若 ||a|| = 1 且 ||b|| = 1：
    a . b = cos(a 與 b 的夾角)
```

兩者不同之處在於：點積也包含大小資訊。大小較大的向量會得到較高的點積分數。在某些檢索系統中，如果你希望「熱門」項目排名較高，這就很重要；向量大小會隱含代表品質或重要性。

```text
a = (3, 0)    b = (1, 0)    c = (0, 1)

dot(a, b) = 3     dot(a, c) = 0
cos(a, b) = 1.0   cos(a, c) = 0.0

兩種方法都能比較方向，但點積也會反映向量大小。
```

實務上：
- 想比較純粹的方向相似度時，使用餘弦相似度
- 向量大小含有意義時，使用點積
- 許多向量資料庫（Pinecone、Weaviate、Qdrant）都讓你選擇其中一種
- 如果嵌入已用 L2 正規化，兩者選擇沒有差別

### Mahalanobis 距離

歐幾里得距離將所有維度一視同仁。但如果特徵彼此相關或尺度不同，L2 會產生誤導結果。

Mahalanobis 距離會考量資料的共變異數結構。

```text
d_M(x, y) = sqrt((x - y)^T * S^(-1) * (x - y))
```

其中 S 是資料的共變異數矩陣。

直觀來說，Mahalanobis 距離會先將資料去相關並正規化（白化），再於轉換後的空間計算 L2 距離。如果 S 是單位矩陣（特徵彼此不相關且變異數為 1），Mahalanobis 距離就會退化為歐幾里得距離。

```text
範例：身高與體重相關。
身高 6'2"、體重 180 磅的人並不罕見。
身高 5'0"、體重 180 磅的人就很少見。

歐幾里得距離可能會認為兩人離平均值一樣遠。
Mahalanobis 距離則會正確將第二人辨識為離群值，
因為它考量了身高與體重之間的相關性。
```

Mahalanobis 距離的適用情境：
- 離群值偵測（與平均值的 Mahalanobis 距離很大的點就是離群值）
- 特徵尺度不同且彼此相關的分類問題
- 資料量足以估計可靠共變異數矩陣時
- 製造業的品質管制（多變量製程監控）

### Jaccard 相似度（適用於集合）

Jaccard 相似度衡量兩個集合的重疊程度。

```text
J(A, B) = |A intersect B| / |A union B|
```

取值範圍為 0（完全沒有重疊）到 1（集合完全相同）。Jaccard 距離 = 1 - Jaccard 相似度。

```text
A = {cat, dog, fish}
B = {cat, bird, fish, snake}

交集 = {cat, fish}              大小 = 2
聯集 = {cat, dog, fish, bird, snake}  大小 = 5

Jaccard 相似度 = 2/5 = 0.4
Jaccard 距離 = 0.6
```

Jaccard 的適用情境：
- 比較標籤、類別或特徵集合
- 依據詞語是否出現（而非出現頻率）比較文件
- 偵測近似重複資料（以 MinHash 近似 Jaccard 相似度）
- 比較二元特徵向量（是否出現的資料）
- 評估分割模型（Intersection over Union，即 Jaccard 相似度）

### 編輯距離（Levenshtein 距離）

編輯距離是將一個字串轉換成另一個字串所需的最少單字元操作數。操作包括插入、刪除或取代。

```text
「kitten」 -> 「sitting」

kitten -> sitten  （將 k 取代為 s）
sitten -> sittin  （將 e 取代為 i）
sittin -> sitting （插入 g）

編輯距離 = 3
```

使用動態規劃計算：填入一個矩陣，其中第 (i, j) 個元素表示字串 A 的前 i 個字元與字串 B 的前 j 個字元之間的編輯距離。

```text
        ""  s  i  t  t  i  n  g
    ""   0  1  2  3  4  5  6  7
    k    1  1  2  3  4  5  6  7
    i    2  2  1  2  3  4  5  6
    t    3  3  2  1  2  3  4  5
    t    4  4  3  2  1  2  3  4
    e    5  5  4  3  2  2  3  4
    n    6  6  5  4  3  3  2  3
```

編輯距離的適用情境：
- 拼字檢查與校正
- DNA 序列比對（可為不同操作設定不同權重）
- 模糊字串比對
- 清理雜亂文字資料時去除重複項目

### KL 散度（不是距離，但常以距離的方式使用）

KL 散度衡量兩個機率分布之間的差異。本課程第 09 課會介紹它；這裡也會討論，因為人們常把它當作「距離」，儘管它並不符合距離的定義。

```text
D_KL(P || Q) = sum(p(x) * log(p(x) / q(x)))
```

重要性質：KL 散度不具對稱性。

```text
D_KL(P || Q) != D_KL(Q || P)
```

這表示它不符合距離指標的基本條件，也不符合三角不等式。它是散度，不是距離。

正向 KL（D_KL(P || Q)）會「尋找平均」：Q 會嘗試涵蓋 P 的所有眾數。
反向 KL（D_KL(Q || P)）會「尋找眾數」：Q 會聚焦在 P 的單一眾數。

KL 散度的常見用途：
- VAE（ELBO 中的 KL 項會讓潛在分布靠近先驗分布）
- 知識蒸餾（學生模型嘗試貼近教師模型的分布）
- RLHF（KL 懲罰讓微調後的模型維持接近基礎模型）
- 策略梯度方法（限制策略更新幅度）

### Wasserstein 距離（推土機距離）

Wasserstein 距離衡量將一個機率分布轉換成另一個分布所需的最少「工作量」。可以想像：如果一個分布是一堆土，另一個分布是一個坑，要搬多少土、搬多遠才能填滿？

```text
W(P, Q) = 在所有傳輸計畫 gamma 中，取 E[d(x, y)] 的下確界
```

對一維分布而言，它可簡化為累積分布函數之差的絕對值積分：

```text
W_1(P, Q) = 累積分布函數 CDF_P(x) 與 CDF_Q(x) 之差的絕對值積分
```

Wasserstein 距離的重要性：
- 它是真正的度量（具對稱性並符合三角不等式）
- 即使兩個分布沒有重疊，它仍能提供梯度（KL 散度此時會趨近無限大）
- 這項性質讓它成為 Wasserstein GAN（WGAN）的核心，解決了原始 GAN 訓練不穩定的問題

```text
分布完全沒有重疊：

P: [1, 0, 0, 0, 0]    Q: [0, 0, 0, 0, 1]

KL 散度：無限大（log(0)）
Wasserstein：4（將所有質量搬移 4 格）

Wasserstein 能提供有意義的梯度，KL 則不行。
```

Wasserstein 距離的適用情境：
- GAN 訓練（WGAN、WGAN-GP）
- 比較可能完全不重疊的分布
- 最佳化傳輸問題
- 影像檢索（比較色彩直方圖）

### 不同任務需要不同距離

| 任務 | 適用距離 | 原因 |
|------|----------|------|
| 文字相似度 | 餘弦相似度 | 大小是雜訊，方向代表語意 |
| 影像像素比較 | L2 | 空間關係重要，特徵尺度相近 |
| 高維稀疏特徵 | L1 | 穩健，不會放大少見的大差異 |
| 集合重疊（標籤、類別） | Jaccard | 資料天生是集合，不是向量 |
| 字串比對 | 編輯距離 | 操作方式符合人類編輯文字的直覺 |
| 離群值偵測 | Mahalanobis | 會考量特徵間的相關性與尺度 |
| 比較分布 | KL 散度 | 衡量使用 Q 取代 P 時遺失的資訊 |
| GAN 訓練 | Wasserstein | 即使分布不重疊，也能提供梯度 |
| 嵌入（向量資料庫） | 餘弦相似度或點積 | 嵌入訓練時會將語意編碼在方向中 |
| 推薦 | 點積 | 大小可代表熱門程度或信心 |
| DNA 序列 | 加權編輯距離 | 不同核苷酸配對的取代成本不同 |
| 製造業品質管制 | L 無窮範數 | 任一維度的最壞偏差都很重要 |

### 與損失函式的關聯

損失函式就是將距離函數用於預測值與目標值之間。

```text
損失函式       使用的距離       行為
MSE            L2 平方           對大誤差施加較重懲罰
MAE            L1                對所有誤差施加相同懲罰
Huber 損失     大誤差用 L1，     兼具穩健性與平滑梯度，
               小誤差用 L2       在零附近的梯度平滑
交叉熵         KL 散度           衡量分布差異
Hinge 損失     max(0, margin - d) 僅懲罰低於邊界的樣本
Triplet 損失   通常用 L2         拉近正樣本、推遠
                                  負樣本
Contrastive 損失 L2              拉近相似配對，讓不相似配對
                                  超過邊界
```

### 與正則化的關聯

正則化會在損失函式中加入權重範數懲罰。

```text
L1 正則化（Lasso）：   loss + lambda * ||w||_1
  -> 權重稀疏，部分權重會精確地變成零。
  -> 自動選取特徵。
  -> 解具有尖角（在零點不可微）。

L2 正則化（Ridge）：   loss + lambda * ||w||_2^2
  -> 權重較小，所有權重都會往零縮減。
  -> 不會選取特徵（沒有任何權重會恰好變成零）。
  -> 解處處平滑。

Elastic Net：             loss + lambda_1 * ||w||_1 + lambda_2 * ||w||_2^2
  -> 結合 L1 的稀疏性與 L2 的穩定性。
  -> 相關特徵會成組保留或剔除。
```

為什麼 L1 會產生稀疏性而 L2 不會：想像二維權重空間中的限制區域。L1 是菱形，L2 是圓形。損失函式的等高線（橢圓）最容易在菱形角落相切，此時某個權重為零；等高線則會在圓形的平滑處相切，兩個權重都不為零。

### 最近鄰搜尋

每種距離函數都對應一種最近鄰搜尋問題：給定查詢點，找出資料集內距離最近的點。

對包含 n 個資料點、每點有 d 個維度的資料集而言，每次查詢的精確最近鄰搜尋成本為 O(n * d)。資料集很大時，這會太慢。

近似最近鄰（ANN）演算法會犧牲少量準確度，換取大幅提升的速度：

```text
演算法           方法                         使用情境
KD-tree          沿座標軸切分空間             scikit-learn（低維）
Ball tree        巢狀超球面                   scikit-learn（中維）
LSH              隨機雜湊投影                 近似重複偵測
HNSW             階層式可導覽                  FAISS、Qdrant、Weaviate
                 小世界圖
IVF               倒排檔案索引搭配              FAISS（十億級資料）
                  群集搜尋
Product quant.   壓縮向量，並在                 FAISS（記憶體受限）
                  壓縮空間中搜尋
```

HNSW（Hierarchical Navigable Small World）是現代向量資料庫中最主要的演算法。它會建立多層圖，每個節點都連接到近似最近鄰。搜尋從頂層開始（節點稀疏、可跨越較遠距離），再逐層往下（節點密集、步幅較短）。

## Use It

最常見的實務用途，是在向量資料庫中尋找相似項目。

```python
import numpy as np

def cosine_similarity_matrix(X):
    norms = np.linalg.norm(X, axis=1, keepdims=True)
    norms = np.where(norms == 0, 1, norms)
    X_normalized = X / norms
    return X_normalized @ X_normalized.T

embeddings = np.random.randn(1000, 768)

sim_matrix = cosine_similarity_matrix(embeddings)

query_idx = 0
similarities = sim_matrix[query_idx]
top_k = np.argsort(similarities)[::-1][1:6]
print(f"Top 5 most similar to item 0: {top_k}")
print(f"Similarities: {similarities[top_k]}")
```

你呼叫 `model.encode(text)` 後搜尋向量資料庫時，底層會進行這些運算。嵌入模型先將文字轉成向量，再由向量資料庫計算查詢向量與每個儲存向量之間的餘弦相似度（或點積），並使用 ANN 演算法避免逐一檢查所有向量。

## Key Terms｜關鍵術語

| 術語 | 常見說法 | 實際意義 |
|------|----------|----------|
| Norm（範數） |「向量的大小」| 將向量映射為非負純量的函數，符合三角不等式、絕對齊次性，且只有零向量的範數為零 |
| L1 norm（L1 範數） |「曼哈頓距離」| 將各分量的絕對值加總。可在最佳化中產生稀疏性，並降低離群值影響 |
| L2 norm（L2 範數） |「歐幾里得距離」| 各分量平方和的平方根，是歐幾里得空間中的直線距離 |
| Lp norm（Lp 範數） |「一般化範數」| 各分量絕對值的 p 次方和，再取 p 次方根。L1 與 L2 都是特例 |
| L-infinity norm（L 無窮範數） |「最大範數」或「切比雪夫距離」| 各分量絕對值的最大值，也是 p 趨近無窮大時 Lp 的極限 |
| Cosine similarity（餘弦相似度） |「向量間的夾角」| 將點積除以兩個向量大小，取值介於 -1 到 +1，且不考慮向量長度 |
| Cosine distance（餘弦距離） |「1 減去餘弦相似度」| 將餘弦相似度轉成距離，取值介於 0 到 2 |
| Dot product（點積） |「未正規化的餘弦相似度」| 將各分量相乘後加總，等於餘弦相似度乘上兩個向量的大小 |
| Mahalanobis distance（Mahalanobis 距離） |「考量相關性的距離」| 使用資料共變異數矩陣進行白化（去相關與正規化）後，在轉換空間計算的 L2 距離 |
| Jaccard similarity（Jaccard 相似度） |「集合重疊程度」| 交集大小除以聯集大小，適用於集合而非向量 |
| Edit distance（編輯距離） |「Levenshtein 距離」| 將一個字串轉換為另一字串所需的最少插入、刪除與取代次數 |
| KL divergence（KL 散度） |「分布間的距離」| 並非真正的距離（不具對稱性），衡量使用 Q 編碼 P 時增加的位元數 |
| Wasserstein distance（Wasserstein 距離） |「推土機距離」| 將機率質量從一個分布搬到另一個分布所需的最少工作量；是真正的度量 |
| Approximate nearest neighbor（近似最近鄰） |「ANN 搜尋」| 使用 HNSW、LSH、IVF 等演算法，以遠快於精確搜尋的速度尋找近似最近點 |
| HNSW |「向量資料庫演算法」| Hierarchical Navigable Small World，多層圖結構，可快速執行近似最近鄰搜尋 |
| L1 regularization（L1 正則化） |「Lasso」| 在損失函式加入權重的 L1 範數，促使部分權重變成零，形成稀疏性 |
| L2 regularization（L2 正則化） |「Ridge」或「權重衰減」| 在損失函式加入權重的 L2 範數平方，讓權重縮小，但不會形成稀疏性 |
| Elastic Net（彈性網路） |「L1 + L2」| 結合 L1 與 L2 正則化；對相關特徵群組的處理優於單獨使用其中一種 |
