# 大型語言模型的差分隱私技術（Differential Privacy for LLMs）

> 差分隱私隨機梯度下降（DP-SGD）依然是標準——透過向梯度更新注入高斯雜訊，提供嚴密的 (ε, δ) 形式化隱私保證。然而其在算力、記憶體與模型實用性上的開銷相當可觀；參數高效的差分隱私 fine-tuning（LoRA + DP-SGD）是 2025 年常見的設定（ACM 2025）。兩類實證結果呈現張力：基於金絲雀樣本的成員推論攻擊（MIA，Duan 等人，2024）回報在語言模型上的成功有限；訓練資料提取攻擊（Carlini 等人，2021；Nasr 等人，2025）則顯示模型有相當程度的逐字記憶。2025 年 3 月的最新論文（arXiv:2503.06808）說明了這項差異：兩者衡量的對象不同——前者測試的是人為插入的金絲雀，而後者探查的是整個資料集中「最易被提取」的資料。新型金絲雀設計使無需影子模型的損失型 MIA 成為可能，並在真實資料上完成了首個具備合理 DP 保證的非平凡大型語言模型差分隱私審計。替代架構：PMixED（arXiv:2403.15638）——在推論執行時期透過混合專家（MoE）對 Next-token 預測機率分佈實施隱私保護；差分隱私合成資料生成（Google Research，2024）。新興攻擊向量：基於 LLM 反饋的差分隱私重新識別攻擊（DP Reversal）——利用模型暴露的信心分數重新識別個體。

## The Problem｜問題

大型語言模型會記憶訓練資料。Carlini 等人 2021 年指出，正式環境中的語言模型可依要求逐字重現訓練文字。差分隱私（Differential Privacy, DP）是一種形式化防護方式：透過對訓練過程實施可證明的隨機擾動，確保模型的最終輸出分佈對任何單一訓練樣本的存在與否皆在統計上不敏感。然而 2024 至 2025 年的實證表明，DP-SGD 是必要防護，但實際部署的 ε 數值可能與威脅模型不相符。

## The Concept｜核心概念

### (ε, δ)-差分隱私數學定義

一個隨機化演算法 M 滿足 (ε, δ)-差分隱私，若且唯若對於任意兩個僅相差一個樣本的相鄰資料集 D 與 D'，以及任意輸出事件子集 S：
P(M(D) in S) <= e^ε * P(M(D') in S) + δ。

直觀而言，對只差一個樣本的相鄰資料集，任意輸出事件 S 在一個資料集下發生的機率，至多為另一個資料集下該事件機率的 e^ε 倍再加上 δ（反向亦然）。這限制了單一個體對輸出分布的影響。

### DP-SGD 標準架構流水線

Abadi 等人於 2016 年確立的黃金配方：
1. 從全量資料中抽樣一個小批次（mini-batch）。
2. 計算每一個樣本各自的獨立梯度向量（Per-example gradients）。
3. 將每個樣本的梯度依照範數上限 C 進行裁剪（Clipping）。
4. 將裁剪後的各樣本梯度求和，並注入標準差為 σ * C 的高斯雜訊向量。
5. 使用受雜訊擾動的梯度總和更新模型參數。

全流程消耗的隱私預算由隱私會計器（如 Moments Accountant 或 Rényi DP Accountant）累計。大型語言模型文獻中回報的 ε 數值因威脅建模、資料敏感度與實用性目標不同而存在極大差異；業界絕無放之四海皆準的「絕對安全預設 ε」。部分文獻中的典型數值大致落在 ε ≈ 1–10 區間，但這些僅屬示範性參考——絕非開箱即用的安全承諾。較低的 ε 通常需要更多雜訊，也可能增加模型的效用損失。

### LoRA + DP-SGD 參數高效 fine-tuning

對前沿模型執行完整 DP-SGD 的開銷難以承受。LoRA（Hu 等人，2022）將梯度更新限制在小型 adapter 中，降低每樣本梯度的儲存空間。LoRA + DP-SGD 是 2025 年常見的配置。此時嚴密的差分隱私數學保證僅作用於該 LoRA 適配器；而龐大的 Base 模型權重全程凍結保持不變。

### 2024 至 2025 年的隱私學術大爭論

兩大看似針鋒相對的實驗實證：

- **金絲雀成員推論攻擊（Canary MIA，Duan 等人，2024）**：在訓練集裡插入獨特的金絲雀樣本，再測試攻擊者能否透過模型輸出判斷該金絲雀是否存在。研究回報，這類攻擊在語言模型上的成功有限，顯示 MIA 並不容易。
- **訓練資料逐字提取攻擊（Carlini 2021，Nasr 等人 2025）**：向模型提供一段前綴，測試其能否逐字還原訓練資料中的文字。研究回報有相當程度的記憶現象，顯示在相關意義上，MIA 並不難。

2025 年 3 月的論文（arXiv:2503.06808）指出，兩者測量的對象不同。MIA 使用插入的金絲雀，詢問「樣本 e 是否在資料集 D 中？」；提取攻擊則詢問「我能從 D 中取回什麼？」對隱私而言，最容易被提取的樣本才是關鍵；金絲雀並非針對可提取性最佳化，因此會低估這項風險。

新一代金絲雀設計讓不需影子模型（Shadow models）的損失型 MIA 成為可能，並促成首個以真實資料訓練、具備合理 DP 保證的大型語言模型非平凡差分隱私審計。

### 替代 DP 訓練的新興架構

- **PMixED（arXiv:2403.15638）**：在推論時提供私有預測。將訓練資料分片為多個獨立子集並指派給不同的專家模型；在推論時以混合專家處理 Next-token 預測機率分布，並在聚合時加入雜訊以符合差分隱私。完全避免 DP 訓練。
- **差分隱私合成資料生成（Google Research 2024）**：使用 LoRA + DP-SGD 進行 fine-tuning，取樣產生合成資料，再以合成資料訓練下游分類器。

兩種方案都以不同的威脅模型為代價，避開完整 DP 訓練的效用成本。

### 基於 LLM 反饋的差分隱私重新識別攻擊

2025 年新興攻擊：利用經 DP 訓練模型的信心分數作為神諭（Oracle），重新識別個人。即使模型輸出沒有洩漏資料，信心分布仍可能洩漏。

防護方式：不要暴露信心分數，或在暴露前將其截斷／量化。這是 (ε, δ)-DP 訓練之外的額外要求。

## Use It｜實際應用

`code/main.py` 在一個微型二元分類任務中完整模擬了 DP-SGD 的運作流程。你可以自由掃描雜訊乘數 σ 與梯度裁剪閾值 C，即時度量其累積消耗的 (ε, δ) 隱私預算以及對應的模型分類準確率折損。程式內嵌了一套微型金絲雀插入攻擊，直觀演示在實施差分隱私干預前後，基於 Log-loss 的統計檢驗能否成功偵測到金絲雀的存在。

## Ship It｜交付成果

本課交付標準實戰產物 `outputs/skill-dp-audit.md`。輸入一份語言模型部署的差分隱私主張，該 Skill 將檢查其 (ε, δ) 數值、使用的隱私會計器、MIA 評測流程，以及是否評估信心分數暴露向量。

## Exercises｜練習

1. 執行 `code/main.py`。掃描 σ in {0.5, 1.0, 2.0}，回報 (ε, δ) 與準確率的取捨，並找出效用開始崩潰的位置。
2. 在腳本中手動實作金絲雀插入邏輯與 Log-loss 偵測檢驗。精確測量在 σ = 1.0 的 DP-SGD 干預前後，金絲雀被成功檢出的機率變化。
3. 仔細研讀 Nasr 等人（2025）關於訓練資料提取攻擊的原著論文。為何在中等 ε 下，資料提取攻擊的成功率沒有大幅下降？這對以 MIA 作為評估手段有何含意？
4. 設計一套基於 PMixED（arXiv:2403.15638）架構、完全運作在推論時期的隱私服務方案。PMixED 所針對、而 DP-SGD 未處理的威脅模型為何？
5. 畫出基於 LLM 反饋的差分隱私重新識別攻擊示意圖。設計一項限制信心分數外洩的對策，並估算其部署成本。

## Key Terms｜關鍵術語

| 術語 | 常見說法 | 實際意義 |
|------|----------------|------------------------|
| DP | 「(ε, δ)-差分隱私」 | 形式化隱私保護：相鄰資料集變更時，輸出分布仍相近 |
| DP-SGD | 「注入雜訊的 SGD」 | 梯度裁剪並加入高斯雜訊；標準的差分隱私訓練方式 |
| LoRA + DP-SGD | 「高效率的私有 fine-tune」 | 在低秩 adapter 上執行 DP-SGD；2025 年常見的設定 |
| MIA | 「成員推論」 | 判定某個樣本是否出現在訓練資料中的攻擊 |
| Canary | 「插入的標記樣本」 | 用來衡量差分隱私洩漏的獨特訓練樣本 |
| PMixED | 「私有推論混合方法」 | 在推論時透過混合專家模型處理 next-token 分布的差分隱私方法 |
| DP Reversal | 「信心外洩攻擊」 | 利用模型信心作為神諭來重新識別個人的攻擊 |
