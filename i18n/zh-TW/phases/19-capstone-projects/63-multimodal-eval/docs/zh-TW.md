# 多模態綜合評估（Multimodal Evaluation）

> 訓練只是整個閉環的一半。另一半是客觀度量。本課將從最底層原語出發親手建構三大評估表面：圖文檢索評估（呈報為 R@1、R@5、R@10）、視覺問答評估（呈報為 Exact Match 精確匹配準確率），以及影像描述評估（呈報為 BLEU-4）。每個度量指標皆是作用於模型輸出之上的純函式，並可在數秒內執行合成評測套件。

**Type:** Build
**Languages:** Python
**Prerequisites:** Phase 19 lessons 58-62 (Track E foundations: encoder, transformer, projection, cross-attention fusion, pretraining)
**Time:** ~90 minutes

## Learning Objectives｜學習目標

- 在影像與圖說文字的 embedding 向量所構成的相似度矩陣上，精確計算雙向的 Recall@K（召回率@K）。
- 針對將「影像-提問」對映射至固定答案詞表的多模態模型，計算 Exact-Match VQA 準確率。
- 零依賴任何外部第三方套件，從零手寫實作包含簡短懲罰（Brevity Penalty）與平滑機制的 BLEU-4 指標。
- 在第六十二課訓練出的多模態模型之上，驅動這三大評估指標在合成測試套件上端到端運作。

## The Problem｜問題

當訓練損失函數曲線走平時，許多初學者會盲目慶祝模型訓練大功告成。然而訓練損失僅僅度量了模型對訓練資料分布的擬合程度；它無法告訴你該模型是否能在保留批次中檢索配對、回答視覺提問，或寫出人類認為流暢的圖說。常見的三大評估面向為：

- **圖文檢索（R@1, R@5, R@10）**：為一條查詢圖說計算 joint embedding 向量；依據餘弦相似度對評測池中的所有影像進行降序排序；呈報真實匹配的影像是否落入前 1 名、前 5 名或前 10 名。影像到文字的對稱檢索以完全相同的方式反向執行。
- **視覺問答（VQA 精確匹配）**：給定 (影像, 提問)，模型輸出單個答案 token。精確匹配在單樣本上是一項二值判定：預測答案 ID 是否等於標準答案 ID？在評測集上計算算術平均。
- **影像描述（BLEU-4）**：讓模型自回歸生成一段文字圖說。對照一組標準參考圖說，計算 1-gram 至 4-gram 的幾何平均精確率，並施加字串過短懲罰。多參考圖說（Multi-Reference，即一張影像對應多條人工撰寫的標準圖說）是常見形態。

每個指標皆被實作為精煉的純函式。本課在程式碼中完全自包含實作它們，使數學原理清晰透明且指標合約牢牢掌控在自己手中。真實世界的權威評測基準（MS-COCO、VQA v2、GQA、OK-VQA）在架構上皆完美對齊這套函式簽名。

## The Concept｜核心概念

```mermaid

  Model[已訓練的多模態模型] --> Embed[評測集上的聯合 embedding]
  Embed --> Sim[相似度矩陣]
  Sim --> R1[R@1]
  Sim --> R5[R@5]
  Sim --> R10[R@10]
  Model --> VQA[逐題預測答案 token]
  VQA --> EM[精確匹配率]
  Model --> Caps[生成的圖說]
  Caps --> BLEU[BLEU-4 與參考圖說比對]
```

### 相似度矩陣上的 Recall@K 計算

建立影像與圖說的 embedding 向量之間的 `(N, N)` 維餘弦相似度矩陣。針對每一行，將各列依照相似度得分進行降序排序。Recall@K 定義為：**主對角線上的目標列索引成功出現在前 K 個最高分位置中的樣本比例**。對稱的文字到影像召回率則在轉置矩陣上以完全相同的方式計算。兩項數值皆必須呈報。在包含 N=100 的評測集中，R@1 = 0.6 意味著 100 條圖說中有 60 條精準將其唯一的正確影像排在了第 1 名。

### VQA 精確匹配率（Exact match）

針對每個 (影像, 提問, 答案) 三元組，編碼器抽取影像特徵，並將提問文字轉換為 embedding，兩者在解碼器中透過交叉注意力融合，隨後讀取下一個位置的預測 token。比對預測 token ID 與標準答案 ID 是否相等。在評測集上求平均。真實的 VQA 資料集通常包含多名人類標註員給出的答案並採用軟精度公式（Soft-Accuracy，若 10 名標註員中至少有 3 人答案一致，得分為 1.0；少於 3 人一致時則按比例縮放）；本課採用單一標準答案的 Exact-Match 以求教學核心清晰。

### BLEU-4 核心公式與平滑

```text
BLEU-4 = BP * exp(mean(log p1, log p2, log p3, log p4))
```

其中 `p_n` 為修正後的 n-gram 精確率（生成文本中命中任意參考圖說的 n-gram 截斷計數，除以生成的 n-gram 總數）；`BP` 為簡短懲罰因子（Brevity Penalty）：

```text
BP = 1                if generated length > reference length
   = exp(1 - r/g)     otherwise, where r is reference length and g is generated
```

在極小樣本中，若某個高階 `p_n` 為零，就需要使用平滑處理。實作採用 Chen 與 Cherry 提出的「Method 1」平滑演算法（任一計數為零時，將分子與分母各加 1），作為處理短文字低計數情境的預設方法。

### 內建合成評測套件

在記憶體中基於第六十二課的模擬語料模式動態建構包含 50 個樣本的評測套件，並鎖定獨立的保留隨機種子。套件由三個專屬列表構成：

- `pairs`：50 組用於檢索評測的 (影像, 圖說 ID) 配對。
- `vqa`：50 組 (影像, 提問 ID, 答案 ID) 測試三元組。
- `caps`：50 組 (影像, [標準圖說清單...]) 多參考圖說項目（每張影像附帶最多 3 條參考答案）。

評測套件在隨機種子下具備嚴格的確定性，且在資料上與訓練集保持絕對隔離，確保所有指標皆計算在模型從未見過的全新樣本上。將評測套件儲存為 JSON 則留作練習（見下文）。

| 評測維度指標 | 數值範圍 | 純隨機猜測對照基準（N=50） |
|---|---|---|
| R@1 召回率 | 0 至 1 | 0.02（即 $1 / N$） |
| R@5 召回率 | 0 至 1 | 0.10 |
| R@10 召回率 | 0 至 1 | 0.20 |
| VQA 精確匹配率 | 0 至 1 | $1 / \text{vocab}$ |
| BLEU-4 圖說得分 | 0 至 1 | 極其微弱但非零 |

對於在合成資料上僅訓練 50 步的微型演示，我們並不指望指標絕對值有多麼驚人；核心在於確認**所有指標皆客觀高於純隨機對照基準**，這正是演示程式所嚴密檢驗的。

## Build It｜動手實作

`code/main.py` 實作了以下核心模組：

- `recall_at_k(sim_matrix, k)`：雙向計算並回傳落在 `[0, 1]` 區間內的浮點召回率。
- `vqa_exact_match(predictions, references)`：計算預測與標籤 `int` 值相等性的算術平均數。
- `bleu4(generated, references, smoothing=True)`：支援多參考圖說的 BLEU-4 計算器。
- `build_eval_suite(seed, n_samples, vocab_size, max_len)`：動態生成三大確定性評測清單。
- `evaluate(model, suite)`：統一驅動全套指標並回傳包含所有數值的 `dict`。
- 底部演示程式：載入第六十二課剛初始化的隨機模型執行首次評測；隨後驅動其微型訓練 50 步並再次評測；並列印出訓練前後的各項指標對比。

執行測試：

```bash
python3 code/main.py
```

輸出結果：前後指標表顯示，檢索表現從接近隨機的水準朝模型學得的訊號改善，VQA 表現高於隨機基準，BLEU-4 也有所改善（合成資料的結構足以帶來 4-gram 精確率提升）。

## Use It｜實際應用

本課所定義的每個指標函式，皆能 100% 直接對標真實正式環境中的權威學術榜單：

- **圖文檢索**：MS-COCO 5K 驗證集、Flickr30K 以及 ImageNet 零樣本分類，本質上皆是在相同的相似度矩陣上計算 R@K。只需將合成評測替換為真實檔案，函式簽名與計算邏輯完全原封不動。
- **視覺問答**：VQA v2、GQA 與 OK-VQA 皆採用完全同一的精確匹配骨架（VQA v2 採用軟精度變體）。
- **影像描述**：MS-COCO Captioning、NoCaps 與 Flickr30K 皆採用 BLEU-4、CIDEr 與 METEOR 作為核心指標。追加 CIDEr 僅僅是額外編寫一個輔助函式。

在真實工程中，只需將 `build_eval_suite` 替換為真實資料集的 DataLoader，而指標計算函式庫永遠保持穩固不變。

## 單元測試矩陣

`code/test_main.py` 覆蓋了以下核心測試項：

- 在完美的單位對角矩陣上，Recall@K 嚴格回傳 1.0；在完全反向的對角線上回傳 0.0。
- Recall@K 嚴格恪守 `k <= N` 的幾何邊界約束。
- 當生成文字與其中一條參考圖說完全一字不差時，bleu4 嚴格回傳 1.0。
- 當生成文字與所有參考圖說在詞表上完全正交無交集時，bleu4 嚴格回傳 0.0。
- VQA 精確匹配率精確等於完全匹配樣本的算術比例。
- build_eval_suite 產出的樣本數量、VQA 題目數與圖說條目數完全符合規格。

執行單元測試：

```bash
python3 -m unittest code/test_main.py
```

## Exercises｜練習

1. 為影像描述評估追加 CIDEr 指標實作。CIDEr 對 n-gram 實施 TF-IDF 權重調整，能更敏銳地獎勵那些攜帶高資訊量的生動詞彙。
2. 實作軟精度 VQA 評分規則：每道題目提供多個人類標註答案，當模型命中任意答案時，得分計算為 `min(human_count / 3, 1)`。完美復現 VQA v2 的官方評測標準。
3. 為 `bleu4` 實作防範 NaN 溢出的數值安全增強：確保模型吐出空序列時函式不會崩潰。
4. 在呈報 R@K 的同時，並列計算平均倒數排名（MRR，Mean Reciprocal Rank）。MRR 對正確答案在 Top-K 之外的具體排位更為敏感；而 R@K 則專注於是否命中門檻。
5. 在訓練中途的 5 個不同的 model checkpoint（第 0, 10, 20, 30, 40, 50 步）分別執行該評估套件，繪製學習曲線圖。觀察三大下游指標的變化是否跟隨底層訓練損失的變化趨勢。

## Key Terms｜關鍵術語

| 術語 | 核心定義 |
|---|---|
| R@K | 檢索查詢中，目標正例成功落入相似度排名前 K 位的查詢佔比 |
| Exact match（精確匹配） | 視覺問答中最簡潔剛性的評分標準：預測答案 ID 與標準答案 ID 二進位完全相等 |
| BLEU-4 | 1-gram 至 4-gram 修正精確率的幾何平均數，乘以字串過短懲罰因子 BP |
| Multi-reference（多參考圖說） | 一張影像可配有多條參考圖說 |
| Held-out（獨立保留） | 評測樣本所採用的隨機種子與訓練集完全正交獨立，確保模型從未在訓練中見過該資料 |
